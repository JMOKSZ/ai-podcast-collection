🔥 頭條 多模態 開源 機械人

主題：Black Forest Labs（Stability AI 前核心團隊）發布 FLUX 3 — 一個統一的多模態 Flow Model，涵蓋圖像、視頻、音頻和動作預測，並與機械人公司 mimic 合作推出 FLUX-mimic 視頻-動作模型。

技術詳情：

  • 統一架構：採用 Self-Flow 技術，單一模型處理文本→視頻、圖像→視頻、視頻→視頻、關鍵幀→視頻、多語言對話等，所有輸出包含原生音頻生成
  • SOTA 基準超越：在官方 benchmark 上擊敗 Seedance 2.0、Google Gemini Omni 和 Grok Imagine
  • 功能矩陣：風格多樣性極廣（從 camcorder 實拍到動畫/電影級）；強大字體生成和動畫設計能力
  • 開放權重：將發布 Dev 開發版（open weights）

FLUX-mimic 機械人模型：

  • 基於 FLUX 3 骨幹，加上 mimic 的機械人學習專業知識
  • 訓練數據：機械人操作 + 人類穿戴式數據
  • 單個 on-prem GPU 即可部署
  • 核心論點：更好的視頻世界模型直接轉化為機械人控制質量和樣本效率
  • 已在 Audi 工廠進行實際測試

同日重大AI新聞（同篇梳理）：

  • The Stack v3：迄今最大開源程式碼數據集 — 114TB raw、2.24億倉庫、44B文件、770種語言，過濾後約5T tokens。v2→v3: C++ x15、TypeScript x7.5、Rust x7、Python x4.8；包含 inline content（非 Software Heritage IDs），方便直接用於訓練
  • OpenAI ChatGPT Voice + Presence 上線：桌面應用程式語音控制，可操作 ChatGPT Work 和 Codex。同日 Claude Voice 也發布（「完全意外」撞期）
  • OpenAI Health in ChatGPT：美國用戶連接 Apple Health + 醫療記錄，額外加密不訓練模型不投放廣告
  • Andrew Ng OpenWorker：開源、模型無關的本地 agent，用於文件和辦公工具
  • Qwen-Audio-3.0-TTS：16種語言、inline 控制標籤（[whisper]/[angry]）、自然語言風格操控、3分鐘一次生成
  • Etched $300M C 輪 @ $10.3B：推理專用晶片，8萬sqft/10MW設施
