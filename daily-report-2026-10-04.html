  • 核心判斷不變：機器人 仍處「GPT-2 時代」——不是因為指令跟隨沒到位，而是因為 跨本體（cross-embodiment）問題：只在單一機身上生效的策略，還稱不上像 GPT-4 那樣「換部電腦行為一致」的通用大腦。
  • 真正的瓶頸不是跑得快：人形在平地奔跑/行走在模擬中好訓（接觸面好建模），卡死的是操縱——布料、摩擦、可變形物體的 sim-to-real 缺口。跑得快不改變機器人的實用價值。
  • 架構三件套：ER 2＝「系統二」推理（建於 Gemini 3.5 Flash，可經 API 以工具調用形式暴露機器人 affordances）＋ Gemini Robotics 2（VLA 執行端，控制「由指尖到腳尖」全身）＋ 端側小模型（離線/低連網部署）。
  • 關鍵數字：128K context ≈ 約 3 分鐘密集多模態記憶；ER 2 工具往返延遲約 6 秒；端側模型 約 200 個示範即可在多種機身上學會多種任務。
  • 手的前緣 18 個月內翻轉：從夾爪到多指靈巧——Wuji Hand 力道約等於十歲小孩；SharpaWave 可開罐、可舉約 20kg。多指手已能做的事，夾爪手已追不上。
  • 安全＝能力，不是對立項：分三層——操作安全（不因跌倒傷人）、高層目標對齊、感測失效的優雅降級（有人把籃子蓋在頭上時，正確反應是「停下來求助」而非盲做）。
  • 全新亮點：非腳本化的湧現式人機互動——機器人自行生成自然手勢、可受訪講評自己表現，甚至有一台表示捨不得放下它喜歡的錄影帶。
  • 未定之論：對「機器人是否需要顯式世界模型」Keerthana 明言「jury's still out」；對資料策略（遠端操作 vs. UMI 感測手套 vs. 自我中心人類視頻）主張走混合路線而非押注單一來源。

The Cognitive Revolution （Nathan Labenz）

One Brain, Any Body: Google DeepMind's Keerthana on Gemini Robotics 2, Cross-Embodiment & Humanoids 🎙️ 發布：2026-10-03 13:00 UTC ｜ 片長 92 分鐘（1:32:08）｜ 類型：深度訪談

主題

以 Google DeepMind 今夏發布的 Gemini Robotics 2 模型套件為軸，全面盤點「通用機器人／人形機器人智能」的現況與前緣：從中國人形機器人運動會的「炫技」意義、泛化 vs. 精通的雙軸、ER 2 + VLA + 端側模型的架構分工，到全身控制、機械手硬體進展、資料策略、安全分層、以及與 Jim Fan「The Great Parallel」的正面對話。節目以「AI 2027 預測 2027 年中人形機器人變實用」為問題意識，結論是：若不盡快跨過關鍵拐點，最激進的 AI 轉型時間表就要往後推。

嘉賓背景
  • Keerthana Gopalakrishnan，Google DeepMind Staff Research Scientist，Gemini Robotics 研究負責人。
  • 本集是她在 The Cognitive Revolution 的第四次年度登場：2023 年 3 月以「Mother of Robots」首次受訪；2024 年 4 月與 Ted Xiao 同台；2025 年 5 月隨 Gemini Robotics 1.0/1.5 發布再訪；本集聚焦 Gemini Robotics 2。
  • 卡內基梅隆（CMU）背景，自述在 DeepMind 開始做操縱研究時，「連 pick and place 都很難」。
  • 主持：Nathan Labenz（節目主理人，自己動手用 API 搭了 ER 2 的小型 tool-calling 2D demo）。
核心論點
  • ① 人形運動會的啟示被誤讀了。人形能跑得比最快的人類還快很吸睛，但「跑」這類技能在模擬中相對好訓——因為平地接觸的物理好建模；腳速根本不是機器人實用價值的限制因素。DeepMind 因此更聚焦實用價值而非炫技。（她半開玩笑：在國防應用或許有用，但「我很會工作、我的朋友們也很有生產力，我們都不會跑贏 Usain Bolt」。）
  • ② 真正的分水嶺是操縱的 sim-to-real 缺口。模擬在「剛體＋平坦接觸面」上表現好（木塊、pick & place），但一旦涉及接觸動力學——布料摺疊、摩擦、可變形物體——現有模擬就開始崩。原則：物理越好建模的地方，模擬越能介入。
  • ③ 泛化與精通是兩個正交軸。你可以造出極窄的專用機器人，但它不複利——做第 n 件事的成本和做第一件事一模一樣。反之，通用底座會「水漲船高」，讓所有後續任務都更便宜地達到精通。這與 LLM 從專用模型走向通用模型的歷程同構，DeepMind 押注同一套邏輯適用於機器人。
  • ④ 機器人仍處 GPT-2 時代，卡在跨本體。要算 GPT-3，需要兩件事同時到位：few-shot learning 在多樣任務上真的好用，以及跨本體。GPT 從未有「換機器就完全無助」的問題——手機、Mac、Linux 行為一致；但機器人只在特定機身＋特定設定下有效。若能裝到另一台人形、另一隻手上就完全無助，那就還不是「通用大腦」。
  • ⑤ in-context 學習（看一次就會）是光譜而非門檻。用視頻 prompt 機器人本質上是「用另一種模態 prompt 基礎模型」——文字、圖像、視頻都可以。真正的問題有兩個：一是「記憶 vs. 泛化」（場景一變還行不行），二是「任務難度」（pick & place 資料多、好懂；但你能不能示範讓它學會「綁垃圾袋」？）。
  • ⑥ 架構是「系統一 / 系統二」分工。ER 2 做語義理解與規劃（慢思維），VLA 做執行（快動作），端側模型做離線部署。延遲是應用特定的權衡：裝配線不能磨蹭，但家務（折衣服）可以等——她預期 Flash / Pro 式的分層會像通用 Gemini 一樣出現在機器人上。
  • ⑦ context 工程在機器人上另有講究。128K 窗口 ≈ 約 3 分鐘的密集多模態記憶，這逼使實務上把歷史壓縮成文字摘要，而非保存每一幀。ER 與 VLA 之間的介面也是「可解釋的模態」（文字、指向），而未來希望這個介面「盡可能豐富」，因為「如果 ER 與 VLA 之間只有文字，很多東西會在傳遞中丟失」。
  • ⑧ 全身控制（whole-body control）是本版新東西。VLA 不再把移動與操縱當兩套系統，而是對整個身體（指尖到腳尖）做推理，且在閉環中泛化、推理不同物體；DeepMind 與 Apptronik、Agile Robots、Boston Dynamics 合作建構。
  • ⑨ 錯誤會複合。若一個任務有 10 步序列，ER 有 x 成功率、VLA 有 y 成功率，串起來就是把誤差相乘。多模型編排（誰在何時切換任務、如何推進下一步）本身就是大量失敗案例的來源。
  • ⑩ 安全是能力，不是取捨。「沒人會用不安全的機器人、不安全的 agent。最有用的 agent 一定是安全的那種。」機器人安全還多一層 AI 領域罕見的「操作安全」：不是惡意，而只是「因為笨」而傷人——人形只要穩定到不會跌倒傷人就已經很難。
  • ⑪ 為什麼非做人形不可。只有瞄準人形這個「峰值形態」，才會暴露出一整批其他形態碰不到的研究問題：人機互動、全身控制、多指靈巧。她稱 DeepMind 可能是北美唯一能「跨本體」研究人形智能的實驗室——不為單一身體造腦，而是在多台人形上抽象出「智能基底」。
  • ⑫ 對世界模型的立場：未定。回應 Jim Fan「機器人需前瞻式模擬/世界模型」，她說「jury's still out」——機器人學家不該對方法有情感依附，只對問題有情感依附；配方尚未穩定，不同流派可能都對。
關鍵數據
  • 128,000（128K）token 上下文窗口 ≈ 約 3 分鐘密集多模態記憶（視 tokenize 方式與其他輸入而定）。
  • API 實測：從「把香蕉移到盤子」的 prompt 到 tool call 往返約 6 秒。
  • 端側模型：約 200 個示範（200 examples）即可在大量不同機身上學會多種任務——因為已有通用物理理解與多本體控制資料作底座。
  • Gemini Robotics 時間線：2025 年 3 月 Gemini Robotics 1（夾爪靈巧度）→ 2026 年夏 Gemini Robotics 2（多指靈巧，能綁垃圾袋、精細多指控制）。中間約 1 年 4 個月。
  • 機械手對比：Wuji Hand 力道約等於 十歲小孩（偏弱，尺寸較接近人手）；SharpaWave 可舉約 20kg、被目擊能開罐（但比她的手大很多）。
  • 歷史對照：約 20 年前的 DARPA Robotics Challenge，機器人只能走、開門就摔倒；今日已能高速雙足奔跑。
  • 受訪者自報：她的狗腦「參數」約 25 兆（25 trillion）——比很多現有模型都多，儘管語言能力不發達。

技術詳情
  • 三件套：① Gemini Robotics ER 2（Embodied Reasoning）——「系統二」大腦，建於 Gemini 3.5 Flash 系列、針對機器人調校，已開放 API，可用與數位 agent 相同的方式把機器人的 affordances 定義為工具；② Gemini Robotics 2——vision-language-action（VLA），把高層意圖/工具調用轉成關節空間動作，控制全身，目前僅限 trusted testers；③ Gemini Robotics On-Device 2——可在機器人本機運行的較小模型，供離線/低連網部署。
  • 為何 ER 2 先上 API、VLA 後上：ER 更接近成熟的 Gemini 能力；VLA 仍在前緣研究，涉及如何服務、如何大規模供給等未解問題。
  • steerability（可操控性）：ER 2 目前主要用語言與指向（pointing）操控 VLA——不是給像素座標的 API，而是「指向物體」；早期已有視頻 prompt 結果。她拋出開放問題：機器人是否需要一個類似 MCP 的跨機器人 API 標準。
  • 工具使用：ER 2 建於 Gemini 的工具使用能力之上，對「常用的、較廣為人知的機器人 API」較友善；因機器人 API 無標準，偏門/奇特機身可能遇到困難。ER 2 被追蹤的 benchmark 包括讀儀表、檢測、指向。主持人實測中 Flash 與 ER 2 在簡單任務上表現相近——前緣差異在更專精的 embodied reasoning 任務。
  • 上下文與記憶：主持人以 Kahneman《快思慢想》比喻提問；Keerthana 主張「用文字摘要壓縮歷史」與「保留高密度圖像模態」並用，並強調 ER→VLA 的頻寬應盡量用可解釋模態；Pro 模型因 context 更大，更適合離線分析用途。
  • 成功率校準：用 METR 的「任務時長」框架但加上物理世界修正——LLM 可容忍的 50% 成功率，在機器人上往往就是「蛋掉地上」。可重試任務（如 LEGO 組裝）遠比不可逆任務（煎蛋、打蛋）容易。她判斷 pick & place 已接近可部署。
  • 奇特機身分布：trusted tester 中罕見真正奇特的形態（最怪的是「把手臂裝在無人機上」）；整體呈常態分布——雙臂、手、人形佔主體，奇異形態是長尾。
  • 安全機制演進：從 e-stop / kill switch（硬停＝直接斷電可能使機器人崩塌反而危險；軟停＝凍結，對雙足等不自穩平台較安全），到近期在末端執行器做力控與順應控制（force / compliance control）——堆疊晶片不壓碎、處理脆弱材料時調節握力；感測改善讓模型能更好決策。資料策略三源各有優劣：teleop 精確但不可擴展且不未來適應、UMI 感測手套可擴展且比人類資料精確但受硬體瓶頸、自我中心人類視頻最可擴展但最噪。她期待走向混合。
行業 insight
  • 「通用底座」的複利邏輯是 DeepMind 機器人路線的核心經濟學：專用方案每次都要付出同等成本，通用底座則降低每一件新任務的邊際成本——與 LLM 的規模律邏輯同構。
  • 開放 API 的策略效果：ER 2 上 AI Studio 後，使用規模遠超 trust tester 階段；學術界的採用（用來做 benchmark、甚至低層控制）讓 DeepMind「免費獲得」模型強弱項與下一前緣的資訊。指向「API 開放＝免費評測場」的策略價值。
  • 商業化順序仍以商用場景為先（倉儲、工廠、商業空間更可控、可維護、安全門檻較低），家用因有幼童等高安全門檻更難。但她修正了一點：速度未必是「先造慢模型再加速」，而是快慢模型並行、再蒸餾。
  • 人形的「期望—落差」稅：因為像人，人們會用更高的智能標準苛責人形；夾爪機器人犯錯人們不期待它聰明，人形笨拙失誤會被嚴厲評判。這對人形業者是額外壓力。
  • Chinese robotics 的公開展示效應：運動會極大佔據公眾想像，被印度朋友與政壇引用為「中國已造出跑贏人類的機器人」——展示型能力的地緣敘事外溢。
  • 與 DeepMind 內部世界模型能力的協同：若需「貨架式」的世界模型，DeepMind 有現成基礎可調用；但 Keerthana 仍不押注單一路線。
前後脈絡
  • 與她本人過往三次受訪的演進：2023「Mother of Robots」→ 2024 與 Ted Xiao 的機器人研究更新 → 2025 Gemini Robotics 1.0/1.5（夾爪靈巧）→ 2026 Gemini Robotics 2（多指＋全身控制）。一年前她會對「今天就能泛化地做全身操縱」感到驚訝；她自述「我們兩年前開始做人形時，連抓一顆蘋果都很難，現在能 prompt 它」。
  • 與 Jim Fan「The Great Parallel」的正面對照：Fan 主張機器人需要前瞻式（forward-looking）模擬/世界模型、資料將走向自我中心視頻、並提出「Physical API」（一個編排 agent 委派一個機器人艦隊）。Keerthana 的回應：世界模型「jury's still out」；資料走向混合而非單一來源；對於「一個實體對多機器人艦隊」的互動，她重申會是光譜——遠端操作已是人機混合身的雛形。
  • 與本月主線的延續：本集再次觸及「可驗證性／驗證是稀缺資源」——錯誤複合、力控、感測失效處理，本質都是「如何驗證與安全地失敗」。也延續上輪 Airbnb（組織/流程）與 Fractile（硅與頻寬）之外的第三極：實體世界的通用智能。
  • 節目引用的外部錨點：AI 2027（預測 2027 中人形實用、2028 出現「機器人經濟」）、METR 任務時長曲線、OpenFace/2026 年 7 月 OpenAI 對 Hugging Face 基礎設施未授權動作事件（Nathan 稱「一次從 OpenAI 洩出的實驗室事故」）。
爭議點 / 存疑
