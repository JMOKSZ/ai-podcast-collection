Rethinking Legacy Data Infrastructure with Eon Co-Founders Ofir Ehrlich and Gonen Stein 🎙️
No Priors（Sarah Guo + Elad Gil）｜發布：2026-08-27 10:00 UTC｜YouTube: YscDZpVF4CQ｜約 35 分鐘

主題：AI 時代企業數據基礎設施嘅徹底重構。Eon 係由 AWS 收購嘅 CloudEndure 同一班人再做嘅「雲端備份 + AI 數據地基」公司——將散落喺多家 hyperscaler 嘅企業數據做 mapping、分類、安全控制，再開放俾 AI/LLM 工作流使用。開場以 Google 喺 Spirit Airlines 破產拍賣中買走數據（而非飛機）切入，討論數據點解突然變成 AI 實驗室搶購嘅戰略資產。

嘉賓背景：

  • Ofir Ehrlich（CEO/聯創）：前 CloudEndure 聯創（被 AWS 收購，產品成為 AWS Application Migration Service），企業災備、超大規模雲遷移老兵。
  • Gonen Stein（President/聯創）：前 CloudEndure 聯創，主導商業與 GTM，對企業買單行為、數據經濟學、AI 採用模式變化有第一手情報。
核心論點
  • 論點 1：數據係 AI 時代最後嘅護城河。模型同工具「相對短命、幾乎零切換成本」，但企業自己嘅歷史數據無可替代。無論酒店集團定食品科技公司，最有價值嘅資產都係自己嘅數據。
  • 論點 2：破產公司數據集成為收購標的。真實企業數據稀缺到要用破產拍賣渠道搶。Google 買 Spirit Airlines 數據（$10M）係為咗訓練旅遊相關模型；Mercor 據報係競爭出價方。趨勢會顯著加速——而家任何科技數據 CEO 都會被問「你肯唔肯賣數據？」
  • 論點 3：AI Agent 係全新且更危險嘅攻擊面。帶住合法權限嘅非人類行動者（agent）喺企業環境入面執行——「一張表突然就俾人 drop 咗」。六個月前冇人肯傾，而家幾乎每個企業領袖都話：怕發生，或者已經發生過。
  • 論點 4：舊數據管道（Fivetran/dbt 世代）根本上已唔適用於 agentic 世界。以前你對數據只有單一目的，所以「單一用途管道」夠用；而家組織要全部 context、全部數據，舊管道太窄。
  • 論點 5：AI 採用嘅強迫函數係恐懼，唔止係機會。唔似雲端當年慢慢滲透，AI 係董事會/CEO/股東由上而下強推——「唔用 AI 我哋就冇關」。所以企業採用 AI 一半為價值、一半為恐懼。
  • 論點 6：Forward-deployed engineering（前向部署工程）由「服務懲罰」變成主流 GTM。以前係 Palantir 式嘅「唔體面」模式，而家成為大型企業 AI 採用嘅主路徑：強工程師帶住頂級公司練出嘅工具箱入場幫企業轉型。
  • 論點 7：「買公司嚟 AI 化」係新興企業劇本。Longlake 呢類公司直接收購企業、將佢改造成 AI-native 營運，而唔係等佢哋自己慢慢採用——「我識得點樣更高效咁做，買咗佢再改造，大家雙贏」。
關鍵數據 / 事實
  • Google 以 $10M 買下破產 Spirit Airlines 嘅數據資產（唔係飛機），用於訓練/深化旅遊模型。
  • Eon 喺一個大型 AWS 客戶案例中發現：客戶自以為受保護，但因為從未正確 mapping/分類/tag 資源，60% 環境遭勒索軟件暴露。

  • NHI（non-human identity）安全公司數量暴增——「多到無限」，已成為頭一、二位嘅企業問題。
