主题

硅谷「Token Maxing」烧钱竞赛的转折点——从「用得越多越光荣」到「Token Minimizing」（ROI、预算、归因、节流）。嘉宾亲历半年内这场文化急转弯，并讲透本地开源模型底座 + 前沿模型的组合拳。

嘉宾背景
  • 张宏江：Llama Ventures 高级技术合伙人，美国国家工程院外籍院士，北京智源人工智能研究院（BAAI）理事长，源码资本合伙人；曾任微软亚洲工程院院长、微软亚太研发集团 CTO、金山软件 CEO。亲历互联网、移动互联网、AI 三波浪潮。

核心论点
  • Token Maxing 是泡沫吗？：去年底硅谷创始人/工程师争相晒 Token 账单、比谁烧得狠；到今年年中，成本失控和「虚假生产力」让竞赛触顶。Uber 四个月烧穿全年 AI 预算，Meta 被迫给员工设 Token 使用上限，公司开始提醒员工注意成本。
  • 黄东旭的转变：从「只选最强最贵、日烧四五百美元」，转向「本地开源模型底座 + 前沿模型」搭配——大量日常任务用本地模型「只烧电费、不烧 Token」，成本可控且更具性价比。本地开源模型经济账：每天电费约 1 美元（对比日烧四五百美元）。
  • 张宏江判断：Token Maxing 折射出所有人在 AI 浪潮面前的不知所措；AGI 奇点已经到来（IQ 测试已超人类，01:15:30），现在做 Agent 是好时机，但关键是「别做容易被大模型碾压的应用」；投资方向看好 toB 和 infra。
  • Agent 进化史：从 OpenClaw（研究到工程的转折点）→ Hermes（把成功经验沉淀成 Skill）→ Agent 蜂群的智能涌现潜力；Token 消耗不会停，未来会有更复杂的 A2A（Agent-to-Agent）网络。
  • 新问题：当新岗位也不再需要人，人类如何自处？（01:18:19）

中国一级半市场的水下江湖（5年-183期-5032条交易线索） 🎙️（2026-08-24 16:00 UTC）
发布于 2026-08-24 16:00 UTC · 时长 00:47:26 · 单口 + AI Agent 协作实验
主题

庄明浩把「不可能的任务」交给千问（Qwen）AI Agent 完成：抓取、整理、分析 36氪「资情留言板」栏目 5 年（183 期）共 5032 条一级半市场交易线索，最终产出一份数据看板 + PPT，并把整个过程做成一期播客。这是他自己 2-3 年前就想做、但「不会代码的人几乎不可能完成」的选题——AI Agent 让它成为可能。

核心内容：什么是一级半市场
  • 概念定义：一级半市场是介于一级（私募股权）与二级（公开交易）之间的老股转让/份额交易市场——公司还没上市，但股权已经私下流转。
  • 信息来源：36氪「资情留言板」——典型条目如「求购字节跳动公司老股份额（预期估值约 5300 亿美元，资产规模 3000-5000 万美元，希望是一层 LP 份额）」「求购乐聚机器人老股份额（资产规模约 3000 万人民币）」，留邮箱交易。
  • 为什么现在能做：AI Agent（千问的工作助理、思考研究功能）可以操作电脑本地文件、跑数据抓取-整理-分析，产出看板和 PPT——整集内容全部由千问一步步执行出来。
核心论点 / 观察
  • 一级半市场才有真正的 MAG7：SpaceX 一路走来是最大样本（19:04）——未上市公司估值变化在这里有最真实的价格信号；Forge 等平台指数（16:40）展示板块轮动：AI → 国防科技 → 半导体芯片。
  • 供需关系变化：从「转让」到「求购」的年度条目变动趋势（28:52-30:21），反映市场情绪由卖方向买方市场迁移；「布告栏」供需配比、行业热度迁移、热门公司 TOP5 与供需关系是「最有意思的一页统计」（38:09）。
  • 所谓「先行指标」：一级半市场交易热度可作为观察中国未上市 AI/科技公司估值水温的先行指标（42:49）。
重点引用
「此前这些零散的信息其实一直没有做成数据库；对我这种不会代码的而言，这么庞大的数据抓取-整理-分析工作几乎不可能完成。而在今天，因为 AI Agent 能力的爆发，此前不可能的任务成为了可能。」
行业 insight
  • AI Agent 正在把「数据分析型单口播客」变成一种可批量生产的形态——不会代码的人用 Agent 完成 5032 条数据的全流程分析，这是 Agent 落地 content 创作的真实样本。
  • 一级半市场是观察中国 AI 一级市场泡沫/估值的暗线：字节 5300 亿美元预期估值、乐聚机器人等具身标的的老股求购，提示产业资本对稀缺标的的追逐仍在。

Dwarkesh Podcast（Dwarkesh Patel）
Dylan Patel – Anthropic & OpenAI will have most of the world's compute by 2028 🎙️（2026-08-25 15:32 UTC）
发布于 2026-08-25 15:32 UTC · 全文转录已萃取 · 视频版 8/25 15:57 UTC（YouTube aV26V1UvkJw）
嘉宾背景

Dylan Patel：SemiAnalysis 创始人，全球最权威的 AI 算力/供应链分析师；与 Dwarkesh 是「双胞胎兄弟」的年度固定节目（实际上并无血缘，纯玩梗）。本期是系列第三期。

主题

未来几年实验室经济学：随 RSI 临近，算力从推理转向训练；Anthropic 与 OpenAI 将在 2028 年前控制全球大部分可用 FLOPs（因为它们能更好地把算力变现、从而出价最高）；以及 >$10T 总 AI Capex 是否会导致主权债务危机、压低非 AI 股票。一个未能解决的问题：有没有任何力量能对抗整个行业「向集中化狂奔」的趋势。

核心论点（逐段萃取）
  • 两个实验室将很快控制世界大部分算力：今年全球新增算力约 1/3 归 OpenAI + Anthropic；明年已签约项目将达 40-50%；到 2027 年底，全球增量算力的一半归这两家；2028 年底——如果趋势不变——它们将「独自控制全球大部分可用 FLOPs」。世界算力每年约翻倍，而前沿实验室算力每年翻三倍（2GW → 6GW → 18GW → 54GW 的推演路径）。
  • 实验室已从亏损转向盈利，利润再投入训练：Anthropic Q2 已转正，OpenAI 预计 Q3（靠 Codex、5.6）。一年半前还是纯 VC 亏损。核心机制：算力成本约 $10-15M/MW，而 Anthropic 推理收入已达 $50M/MW——「花 10 块买推理，产出 50 块收入，再把利润全砸进训练」。
  • $6B 晶圆厂 Capex 撬动 $1T+ 终端收入：1GW 算力 = 约 55K 片 N3 晶圆 + 6K N5 + 170K DRAM 晶圆；$6B fab Capex 每年产出 1GW，1GW 每年产生约 $100B 收入——5 年累计超 $1T 终端 AI 收入（扣除中间环节后仍有 ~100x 差距）。这就是「资本主义的镜子」：Carl Zeiss 需要为 2030 年造 100 台 EUV 光刻机的镜片，供应是鞭梢式的慢变量。
  • 算力价格将上涨：当前 $10-15M/MW 下「任何人都能赚钱」（拿 GB300 机架 + Kimi 权重 + vLLM/SGLang 就能上线开卖）；实验室要吞下 70-80% 增量算力，价格必须涨到 $25-50M/MW。Elon（SpaceX/xAI）已按 $40B/GW 级别（$25M+/MW）把算力租给 Anthropic/Google，一年回本。
  • 价值捕获的迁移：目前大部分价值被终端用户拿走（Jane Street 用 GPT-5.6 Ultrafast 独家合同赚得远超 Anthropic 的利润；Meta 一度占 Anthropic 业务 10%、靠广告优化赚更多）；应用层价值最少；模型层从负毛利走到巨额正毛利；2023 年时硬件/存储厂吃走全部毛利（TSMC 现在反而比存储厂捕获更少）。
  • 实验室正把算力从推理转向 R&D（非共识观点）：标准看法是「大部分算力将用于推理」，Dylan 认为恰恰相反——既然每 MW 收入在涨，把算力投入内部训练/研究（构建 AGI）的回报远超对外卖 token。过去三个月已可见：Anthropic 每月新增算力在涨、但 ARR 增速在平台期，边际 MW 越来越多流向 R&D。训练预算结构：60% 训练 / 40% 推理，其中训练内 50% 研究、10% 开发；Mythos 预训练峰值 <200MW，RL 更少。
  • 中国：新增算力 <10%，但其实验室需要更少：2022 年美国占全球新增 45-50%、中国 30-35%；今天美国 70%、中国 <10%。2028 年中国累计 AI 算力约 30GW 或更少（全球 200GW+），且国产芯片（SMIC/CXMT 2027-28 起量）每瓦性能远逊。但中国头部实验室只需 100-200MW（字节 Seed 例外），Kimi 连 1GW 都没有——算力差距短期不决定模型差距。中国 2029 年有能力年增 50GW，但质量折价后约等于美国 20GW。
  • 主权债务危机推演（与 Dwarkesh 连辩数日的核心）：2024-2029 累计约 $11T AI Capex，其中 $5T+ 需靠债务融资。实验室/云厂商发债推高利率（Meta 现发 5-6%，可能要到 8%，+250bps），挤出其他一切借贷方：非 AI 国家（巴基斯坦、尼日利亚等）违约、非 AI 股票因折现率上升而崩（J&J 这类 30 年稳定现金流股首当其冲）、银行利差错配受损。Dwarkesh 引 Basil Halperin：这是第二次 Volcker 冲击（80 年代 40 国违约重演）。美国自身：企业税只占联邦收入 <10%，80%+ 来自工资税/所得税——自动化会侵蚀税基；债务利息已占税收 20%，利率 +1% 五年后到 25%、+5% 则可能到 60%+。缓释：美国可对数据中心征税；但「全世界一起来减速 AI」也是真实约束。
  • 监管是最大变数：OpenAI 不发布 Astra、停训两周；Anthropic 不发布安全评估认定的「Model 2」（普遍认为是 Mythos 下一代）；Mythos 一度对内部也受限、不给外籍员工。Dylan：「世界上最好的模型是 2 月训练的」。监管对实验室的拖累大于对开源/中国模型的拖累——这是限制收入/MW 增长、从而限制集中化速度的关键力量。
  • 集中化无解？：训练规模经济 + 算力稀缺 + 持续学习/RSI 三重力量全部指向集中。「每一股力量都在尖叫着冲向集中化。」唯一对冲是监管减速、或慢速起飞（slow takeoff）。
关键数据 / 事实
  • 2026 年全球 AI Capex >$1T，2028 年 >$2T；2024-2029 累计约 $11T（$6T 现金流 + $5T 债务）。
  • OpenAI 年初 2GW → 年底 5GW+；Anthropic 年初 <2GW → 年底 5GW+（3-4x/年）。
  • Anthropic 推理收入 $50M/MW（最高），基础成本 $10-15M/MW；2027 年底可能 $70-80M/MW。
  • SpaceX 入场：向 Anthropic/OpenAI 出租大量算力；$40B/GW 级成交价（约 $25-40M/MW）。
  • GB300 / TPUv7 / Trainium3 每瓦性能是上一代 3-5x；新部署算力占全球存量大头。
  • Mythos 预训练单点峰值 <200MW、约两个月；RL 更少；多站点训练协调困难是利用率瓶颈。
  • 2028 全球算力约 200GW+；2029 年新增 90-100GW；中国 2028 约 30GW。
  • 中国头部实验室 100-200MW（字节 Seed 例外）；Kimi 无 1GW 级算力。
  • Meta 市值约 $1.5T（Dylan 认为按算力+现金流「被低估」）；存储股（Micron/Hynix/Kioxia）仅 2-3x PE。
  • AI 有效劳动力：前沿算力 FLOPs 年增 4-5x、能力所需算力年降 3x → 等效 AI 人口年增 ~10x；单实验室 AI 劳动力十年内超地球人口是「非常 plausible」的。

技术详情
  • 训练/推理预算拆解：60% 训练 / 40% 推理；训练中 50% 研究（架构、数据配比、超参、注意力机制试验）、10% 开发；推理部分用于产出收入并支撑训练扩张。
  • 推理成本结构：$10-15M/MW 是「base cost」，含电力与基础设施；新芯片每瓦性能 3-5x 提升使「新瓦特」远强于旧瓦特。
  • 供应链瓶颈：ASML EUV 光刻机（Carl Zeiss 镜片）为 2030 年目标 100 台/年；fab Capex $6B → 1GW/年 → $100B 收入/年，杠杆率 ~100x。
  • 持续学习 / RSI 将使训练占比进一步上升（continual learning、agentic RL、训练即部署）。
行业 insight
  • 算力市场的定价权正从「云厂商成本+」转向「实验室出价」：谁的单位 MW 收入最高，谁就定义算力价格上限（$25-50M/MW 是新的均衡区间）。
  • 集中化的本质：训练规模经济 + 稀缺算力溢价 + 部署数据飞轮三重正反馈——Dwarkesh 认为「未来劳动力集中到两家公司」比「国家化」更值得警惕，且与 Gavin Baker 此前「Dario 认为世界上只会剩一家公司」的争议呼应（Dylan：Dario/Sholto 否认过，但逻辑上 RSI 信仰必然导向集中）。
