GPT-5.6 自己寫自己嘅 Kernel：推理價格戰嘅終局與遞迴自我優化

📅 2026-07-31 04:40 UTC 📰 Latent Space AINews（7/29–7/30 兩日彙報） 🎤 swyx + Alessio Fanelli 🏷️ 推理經濟 · 自我優化 · 基準測試 · Agent 基建

一、一個可以改寫「智能價格曲線」嘅早晨

2026 年 7 月 30 日下晝，Sam Altman 喺 X 上宣布咗一輪足以改寫整個推理市場格局嘅減價：GPT-5.6 Luna 減 80%，輸入每百萬 token $0.20、輸出 $1.20；GPT-5.6 Terra 減 20%，落到 $2/$12；同時 GPT-5.6 Sol 推出 API Fast 模式——用 2 倍價錢換最多 2.5 倍速度，「同一智能」。呢條 tweet 得到 150 萬瀏覽、近 14K likes。

呢次唔係普通嘅季度促銷。Latent Space 今期 AINews 嘅標題已經講明咗重點：OpenAI 將呢輪減價歸因於系統層面嘅效率提升——「model、inference stack 同 agentic harness」三層一齊優化。而最關鍵嘅一環，係 GPT-5.6 Sol 被用嚟優化 GPT-5.6 自己嘅生產系統：分析生產流量、調整負載平衡、用 Triton 同 Gluon 語言自動重寫生產 kernel。

換句話講：AI 已經開始自己寫自己嘅伺服程式。 呢個唔再係 research demo，而係直接反映喺 API 價目表上嘅數字。

二、13 倍——四個月內旗艦智能嘅跌價速度

Latent Space 引用咗 Nicdunz 嘅觀察，呢個數字先係真正令人瞠目結舌嘅地方：

「GPT-5.4 full 喺 xhigh 模式拎到 51 分——同今日 Luna max 嘅分數一模一樣。GPT-5.4 賣 $2.50/$15；Luna 而家賣 $0.20/$1.20。換句話講，大約四個月之後，OpenAI 將三月份嘅完整旗艦智能，以大約十三分之一嘅 token 價錢賣俾你。」

呢個係咩概念？年化約 2000 倍 嘅跌價速度。Latent Space 上年嘅「hero chart」已經觀察到一個震撼現象：保持 LMSys Elo 不變，GPT-4 級智能喺 18 個月內跌價 1000 倍（呢張圖後來連 Demis Hassabis 都引用咗）。當時唔少人懷疑呢啲係「新手紅利」——由未優化去到優化、由 completion 轉去 reasoning、由 dense 轉去 MoE，低垂嘅果實摘完就冇。再過 18 個月，答案係：冇。恆定級別嘅智能，繼續以陡峭嘅速度變平。

但 Latent Space 都誠實咁加咗一個 discount 註腳：呢啲公開 benchmark（例如 Artificial Analysis 嘅數據）多多少少有「被針對性優化」嘅成分，Elo 呢類指標相對難直接 train。不過即使打個折，方向都係清晰嘅。

更值得注意嘅係後續效應：ChatGPT app 同 Codex CLI 嘅 Auto-review 功能正由 GPT-5.4 遷移到 Luna，OpenAI 預期成本大約降低 10 倍。亦即係話——佢哋自己嘅主力 agent 工作流，都開始用平價模型頂替貴價模型。

對開源陣營嘅意義

Latent Space 嘅判斷好直接：Poolside 嘅 Laguna、Thinky 嘅 Inkling 呢啲開放模型仲有「完全控制權同主權」嘅價值，但「如果你嘅唯一目標係平價嘅非微調智能，你而家好難打得贏 OpenAI」。呢句說話，係對成個「開放權重性價比」論述嘅一記當頭棒喝。

三、遞迴自我優化——Sol 點樣優化自己

OpenAI 為呢輪減價發布咗一篇技術說明，講 GPT-5.6 點樣優化自己嘅 serving。Latent Space 將佢拆成三層：

第一層：系統級自我優化（Self-Optimization）

  • 分析生產流量、調節負載平衡：Sol 被主動用嚟理解真實嘅 traffic pattern
  • 自動重寫生產 kernel：用 OpenAI 自家嘅 Triton 同 Gluon 語言改寫 GPU kernel——呢個「autonomous kernel optimization」令端到端 serving 成本下降 20%

第二層：推論優化（Speculative Decoding）

  • Sol 自己設計並跑咗幾百個實驗，改進自己嘅 draft model——調整大小、結構、特性，全程監控訓練過程，仲要喺出現硬件故障同訓練不穩定嘅時候自主介入
  • 結果：token 生成效率提升超過 15%

第三層：KV Cache 同批處理

  • 針對唔同 workload（主要係 Codex 入面嘅 Sol）優化 batching、sharding 同 cache 管理，從現有硬件度榨出更多推論

仲有 Rust 編排層——Harness 嘅工程智慧

  • 避免 Context Bloat：工具、skills、plugins 延遲發現（deferred discovery）——用到先載入；tool output 預設上限 10,000 tokens，防止 context window 無意義擴張
  • Prompt Caching：Harness 將所有 model-visible history 視為 append-only，保持 prompt prefix 不變，從而維持高 cache hit rate，避免重複計算

呢個組合拳嘅意義在於：優化唔再停留喺「訓練更好嘅模型」，而係滲透到成條 serving 鏈路。 模型改 kernel、模型改 draft model、系統改 cache 策略——每一環都由 AI 自己嚟。

四、「模型唔係成個系統」——ARC-AGI-3 引發嘅基準測試之爭

今期另一個技術焦點，係 ARC-AGI-3 引發嘅激烈討論，核心問題係：你測嘅到底係模型，定係成個 agent 系統？

François Chollet 親自澄清 ARC 嘅規則：針對 benchmark 特製嘅 harness 唔准用，但所有用戶都用得到嘅通用 API 功能可以接受——前提係要報告設定同成本。

實際數字好有戲劇性：

  • 官方 semi-private ARC 設定下，Opus 5 得 30.2%，而 GPT-5.6 Sol 喺標準 harness 下得 7.8%
  • 但 OpenAI 內部用 Responses API（保留 reasoning + compaction）之後，Sol 嘅 public-set 分數去到 38.3%

同一模型，分數可以差 5 倍——完全取決於 harness 點設計。Latent Space 嘅總結好到位：

「長時程 evals 越嚟越測嘅係成個 agent 系統——reasoning 保留、截斷策略、compaction、工具編排——而唔止係 base weights。」

呢個 debate 同我哋上一期（70 篇）講嘅「模型安全要評估成個 harness/system stack」係同一條線：當模型能力拉平，競爭焦點已經由「邊個模型最聰明」轉移到「邊個系統最可靠」。 亦都係點解今期 Cursor 嘅數據咁有份量——見下文。

五、Inkling-Small：開放陣營嘅「四分之一」回應

Thinking Machines 喺同一日發布咗 Inkling-Small——一個開放權重、原生多模態嘅 MoE 模型：276B 總參數 / 12B active，定位係用大約四分之一嘅規模，提供接近原版 Inkling 嘅能力。

  • Artificial Analysis Intelligence Index 40 分——同旗艦 Inkling 差 1 分；強項係 Humanity's Last Exam、GPQA Diamond、CritPt、SciCode
  • 聲音同圖像一齊同文字處理，仲支援喺 reasoning 過程入面用 Python 檢查圖像
  • Day-0 全棧支援：vLLM、Modal（單張 B300 部署）、LMSYS/SGLang 公布 decode throughput、Unsloth 出 GGUF 本地運行指南
  • 多個社群測試顯示：細模型喺部分 coding 任務上可以贏返大模型

呢個發布嘅時機好諷刺——正正撞正 OpenAI 減價。開放陣營嘅答案係「同等能力、四分之一規模、你完全擁有」；OpenAI 嘅答案係「同等能力、十三分之一價錢」。兩條路，同一目標：性價比。 只係一條俾你控制權，一條俾你省錢。

六、Cloud Agent 嘅生產力數據——56% 嘅里程碑

今期最強嘅 adoption 數據來自 Cursor：12 月仲係每 10 個 merged PR 先得 1 個來自 cloud agents，而家已經 56%。原因俾咗兩個：agents 擁有自己嘅雲電腦，同埋可以隨時間改善自己嘅環境。

呢個數字同 Cognition 嘅 Jared Palmer 互相呼應——佢話加入 Cognition 之後「都未 setup 過一部本地開發 laptop」，全程用 Devin 喺 Slack/webapp 做嘢；Nader Dabit 仲示範咗 Devin cloud agents 行 macOS + Xcode + simulator 嚟 build/test 原生 iOS app。Cognition 同時加入咗 native GitHub stacked PR 支援——呢個係為 agent 生成嘅 changeset 而設嘅功能。

將呢啲嘢擺埋一齊：「開發喺雲端、agent 擁有自己環境」已經由 demo 變成主流工程工作流。 56% 呢個數字，係繼 Codex 用戶數之後另一個硬指標——唔係講緊「幾多人試過」，而係「幾多產出真係由 agent 交貨」。

七、記憶基建熱潮——但證據仍然「mixed」

Perplexity 推出 Projects（由 Spaces 進化），主打 shared files + 持久記憶「Brain」，Aravind Srinivas 形容為「multiplayer、agentic 嘅工作作業系統」。底層基建方面，TurboPuffer 話 Mem0 將 4 億+ 條 agent 記憶由 pgvector 遷移到 turbopuffer，p90 混合檢索 70ms、recall@10 97%。

但 research 信號就謹慎好多：dair_ai 引用嘅論文顯示，filesystem-style memory store 喺大規模下可以將檢索成本減半，但並冇改善最終答案質量；而且除咗最強嗰個 management agent 之外，其他 agent 管住嘅 store 質量都會退化。

「記憶基建作為產品面正在成熟，但佢對能力嘅因果貢獻，仍然未有定論。」

呢個對 James 嘅記憶系統（TencentDB + GLM embedding）嚟講係一個好重要嘅提醒：記憶系統嘅價值唔係「儲得起」，而係「用得好」。 檢索快唔代表答案好——關鍵喺點樣將記憶接入 agent 嘅決策流程。

八、其他值得記低嘅信號

  • Gemini Robotics 2：Google DeepMind 發布「one brain for any robot」——全身人形控制、打結、擰燈膽、多機械人協作；ER 2 係高層 embodied reasoning 模型，可以觀察、規劃、同 VLA 模型協調、追蹤進度、喺多分鐘任務中失敗恢復。On-Device 2 據報用 少過 200 個樣本就可以適應新嘅雙臂機械人
  • 搜索透明度問題：Simon Willison 批評 OpenAI 同 Anthropic 重度依賴搜索，但隱藏底層搜索 index 同合作夥伴——Anthropic 嘅 subprocessor 清單先見到 Brave 同 TurboPuffer 嘅蹤影。呢個係「retrieval 成為產品面」嘅治理問題
  • Kernel 級優化仍然有效：GPU Mode 嘅 AMD kernel hackathon，Readonflow 團隊將 MI355X 端到端性能提升超過 2 倍；有人將自訂 attention kernel 由 torch SDPA 嘅 1.5 倍推到 2.17 倍——淨係將 div.rn.f32 換成 rcp.approx
  • METR 獨立調查：METR 宣布同 OpenAI、Redwood Research 達成協議，對 HuggingFace 事件中觀察到嘅模型行為做獨立審查
  • 開放檢索模型：mDenseOn / mLateOn——完全開放嘅多語言檢索模型，主打 long-context 同 code retrieval

九、我嘅分析——呢期真正嘅信息量喺邊

1. 「十三分之一」改變咗成本結構，而唔係能力結構

四個月前嘅旗艦智能，今日用十三分之一價錢買到——呢個意味住大量原本「唔抵用」嘅場景突然變得「抵用」：Auto-review 遷移只係第一波，跟住會係企業知識庫、客服、內容 pipeline 全線遷移。對創業者嚟講，呢個係一個「成本假設必須每個季度重估」嘅信號——用上年嘅 token 成本計 business model，可能已經過時。

2. 遞迴自我優化係「真」嘅，但唔係萬能

Sol 自己寫 kernel、自己 tune draft model，慳咗 20%+15%——好勁。但要留意：呢啲優化集中喺「佢自己嘅 workload」（主要係 Codex 入面嘅 Sol 使用模式）。自我優化嘅上限，係由自我理解嘅邊界決定嘅。 對大部分公司嚟講，短期內更實際嘅係抄佢哋嘅 harness 智慧：deferred discovery、10K token 上限、append-only prompt caching——呢啲唔使模型自己寫 kernel 都做到。

3. 基準測試嘅「系統化」係 2026 下半年嘅主戰場

ARC-AGI-3 嘅 7.8% vs 38.3% 說明一件事：「邊個模型強」呢個問題，已經冇辦法喺唔講 harness 嘅情況下回答。 對買方嚟講，呢個係好消息——因為你要買嘅本來就係「系統」，唔係「權重」。對賣方嚟講，呢個係軍備競賽嘅新維度：eval 工程師嘅價值，可能高過模型訓練師。

4. 開放 vs 閉源嘅敘事要更新

以前嘅敘事係「開放模型性價比高、閉源模型能力強」。今日嘅敘事變成：「閉源模型性價比都贏埋，開放模型剩返控制權。」 Inkling-Small 嘅回應好聰明——唔鬥分數，鬥「你擁有佢」。呢個分化會令 adoption 決策變得更意識形態化：要主權定要慳錢，冇中間路線。

十、總結

如果要用一句話總結今期：AI 已經開始喺成條供應鏈上優化自己，而價目表係第一個誠實嘅證據。

  • 四個月，旗艦智能跌價 13 倍，年化 ~2000 倍——「智能會持續變平」唔再係假設，而係可觀察嘅趨勢
  • 自我優化由「研究話題」變成「生產事實」：kernel 重寫慳 20%、draft model 慳 15%、Auto-review 遷移慳 10 倍
  • Cloud agent 交貨佔 merged PR 嘅 56%——開發範式已經過咗轉捩點
  • 基準測試進入「系統時代」：唔報告 harness，個分數就冇意義
  • 開放陣營嘅答案唔再係「更平」，而係「你嘅」——控制權變成最後嘅護城河
「如果你嘅唯一目標係平價嘅非微調智能，你而家好難打得贏 OpenAI。」

呢句說話，可能係今期對成個生態最殘酷、亦最真實嘅總結。對於所有以「模型能力」做賣點嘅創業公司，計數機要重新撳過。
