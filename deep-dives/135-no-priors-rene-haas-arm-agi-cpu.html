「CPU 仍然係現代運算嘅心臟」——Arm CEO Rene Haas：AI 唔係 GPU 獨腳戲，Agent 時代嘅樽頸係「邊個 orchestrate 成個 inference fleet」

📅 2026-09-03 10:00 UTC 發布·🎙️ No Priors（Sarah Guo + Elad Gil）·👤 Rene Haas（Arm CEO）·⏱️ 約 37 分鐘

2026 年 3 月 24 日，Arm 宣佈咗公司 35 年歷史上最 shocking 嘅一件事：由純 IP 授權商，變成親自出實體晶片——Arm AGI CPU，頭號客戶係 Meta。宣佈當日 Arm 股價單日 +17%。五個月後，CEO Rene Haas 上 No Priors，向矽谷 startup 圈完整解釋呢個轉身背後嘅邏輯：當 AI 由「訓練」走入「agent 時代」，樽頸唔再係 GPU 算力，而係「邊個負責 orchestration」——而 CPU，先係成個 AI 系統嘅心臟。

一、嘉賓：一個親歷 GPU 帝國崛起嘅人，而家企喺 CPU 嗰邊

Rene Haas 嘅背景令呢個訪問特別有戲劇性：佢 2022 年做 Arm CEO 之前，喺 NVIDIA 做咗 7 年——親眼見住 GPU 由遊戲卡變成 AI 時代嘅算力貨幣。而家佢反過嚟要講嘅係：「AI 唔係 GPU 嘅獨腳戲」。呢個「由 GPU 陣營跳去 CPU 陣營講大道理」嘅人設，本身就係成個訪問最有說服力嘅地方——佢唔係唔識 GPU 有幾勁，而係佢睇到 GPU 之外嗰層嘢。

Arm 嘅江湖地位不用多講：全球幾乎所有手機都用 Arm 架構，雲端嘅 AWS Graviton、NVIDIA Grace、Ampere Altra 都係 Arm-based——即係話「AI 伺服器入面嗰粒 CPU，好多已經係 Arm」。而家 Haas 要行嘅下一步，係由「授權 ISA/藍圖俾人哋造」變成「自己設計、自己出貨完整嘅數據中心 CPU」。

「From data center orchestrators to AGI and robotics, CPUs remain the heart of modern computing.」 ——節目官方簡介：由數據中心編排到 AGI 同機器人，CPU 仍然係現代運算嘅心臟
二、35 年商業模式嘅根本轉變：由賣藍圖到賣晶片

訪問最早嘅章節（01:14–04:23）講 Arm 喺芯片供應鏈嘅位置，同埋呢次轉型嘅性質。Arm 一直以嚟嘅商業模式係：設計 IP（指令集架構、核心設計、系統 IP），授權俾全世界嘅芯片公司，收 license fee + royalty——佢自己永遠唔會出貨一粒實體晶片。呢個「中立供應商」定位係 Arm 嘅金漆招牌：因為佢唔同客戶競爭，所以 Apple、Qualcomm、NVIDIA 先肯放心用佢。

今次出 Arm AGI CPU，係公司史上第一次賣實體 silicon——由「賣藍圖」變成「落場砌機」，直接殺入一個估計 $700 億嘅數據中心處理器市場。呢個唔係 product line extension，而係 35 年 business model 嘅根本轉變，風險在於會唔會得罪原本嘅 licensee（佢哋可能覺得「你而家同我搶生意」）。Haas 嘅解釋框架係：agentic AI cloud 時代需要嘅 CPU，同傳統伺服器 CPU 好唔同，Arm 要用自家設計去示範「呢個新 category 應該點造」。

Arm AGI CPU 規格（外圍核實） 最高 136 核 Neoverse V3、雙 die（每粒 CSS V3 chiplet 約 500 億電晶體）、TSMC 3nm｜全核 3.2GHz / boost 3.7GHz｜TDP 300W｜12 通道 DDR5 @ 8800 MT/s、>800 GB/s 頻寬、<100ns 延遲目標｜96 條 PCIe Gen6 + 原生 CXL 3.0｜宣稱 rack-level throughput >2× 同等 x86 平台｜2026/3/24 發佈當日即接受訂單、2026 年底量產出貨、2028 年起先有顯著收入貢獻｜宣佈後 Arm 股價單日 +17%

Arm EVP Mohamed Awad 稱之為「agentic AI 雲時代嘅 silicon 基礎」——呢粒 CPU 唔係用嚟訓練模型，而係負責 agent 世界嘅「大內總管」角色：管理 memory hierarchy、排程 storage、協調 data movement、確保 GPU/ASIC 永遠有嘢食（saturated）。Launch partners 包括 OpenAI、Cerebras、Cloudflare；Meta 係 lead customer + 共同開發夥伴——即係話呢粒晶片係同 Meta 一齊 design 出嚟，Meta 會大量採用。

三、點解 Agent 時代 CPU 反而更重要？——GPU 負責計數，CPU 負責「湊大個場」

呢個先係成個訪問嘅核心論點（33:31 CPU Opportunity + 04:23 CPU IP and Customers）。Haas 嘅邏輯係：GPU 嘅設計目標係「將最大量嘅矩陣運算塞入最細時間」——佢哋係超級計數機；但一個 AI 系統要真正運作，唔係淨係有計數機就得：

  • 邊個決定一行 prompt 要 routing 去邊個模型？——agent 世界會有成個 model zoo，要有人做 inference routing。
  • 邊個管理 memory hierarchy？——幾十 TB 嘅 KV cache、embedding store、context window 要分層放，唔可以全部塞 GPU HBM（貴到癲）。
  • 邊個排程 storage 同 data movement？——agent 要讀寫文件、查 database、fetch context，全部係 I/O 密集。
  • 邊個協調成個 inference fleet？——當你有幾萬粒 GPU 一齊行 agent 任務，總要有人派工、收數、處理 failure。

呢啲全部係 CPU 嘅本行——控制流、I/O、記憶體管理、排程。Haas 嘅講法係：agent 時代嘅 bottleneck 唔係「邊粒 chip 計得快」，而係「邊個 orchestrate 成個系統」；GPU 係 engine，CPU 係 cockpit。而 Arm 架構喺呢個角色特別有優勢，因為佢天生慳電（每 watt 性能），而數據中心而家最大的限制已經由「有冇 GPU」變成「有冇電、有冇散熱」。

「The bottleneck in the agent era is not which chip computes fastest — it's who orchestrates the whole system. GPUs handle the heavy compute, but someone has to keep the entire inference fleet fed.」 ——Haas 嘅核心論述（撮譯自 33:31 章節）：GPU 做 heavy compute，但總要有人餵飽成個 inference fleet
四、由 IP 授權到實體晶片：點解係而家？

訪問冇直接問「點解唔怕得罪 licensee」，但從脈絡可以睇到 Haas 嘅算盤：AI 客戶（Meta、OpenAI 呢類 hyperscaler）要嘅唔係「一粒標準 CPU」，而係「為 agentic workload 深度優化嘅系統」——呢種 co-design 需求，傳統 licensee 俾唔到，Arm 自己落場先可以同 Meta 呢種客戶由 instruction set 層面一齊 design。而且 Arm 揀嘅切入點好聰明：佢賣嘅係「CSS V3 chiplet」畀數據中心客戶，同手機嗰邊嘅授權業務（Apple 等）市場完全唔重疊——手機 licensee 唔會覺得受威脅。

另一條線索係供應鏈格局：而家成個 AI 供應鏈嘅 bottleneck 已經由 GPU 一粒擴散到成個系統——記憶體（HBM）、供電、散熱、網路（13:27 Data Center Buildout Bottleneck）。Haas 認為未來兩年最大嘅問題會係「數據中心起唔切」而唔係「芯片造唔切」：

  • 供電——一個大型 AI data center 嘅用電量堪比中型城市，電網升級慢過芯片迭代。
  • 散熱——由風冷轉液冷再轉浸沒，成個 facility 設計要重來。
  • 選址同社區 backlash（28:59）——能源、噪音、水資源，AI 基建嘅社會成本開始反噬，好多項目卡喺社區反對。
  • 記憶體——HBM 產能長期緊張，而 agent 工作load 嘅 KV cache 需求增長快過訓練。

呢個「系統級 bottleneck」論述，正正就係 Arm AGI CPU 嘅 market entry 藉口：當成個系統嘅樽頸係 memory bandwidth、orchestration 效率、每 watt 性能，CPU 嘅角色就由「配角」升做「主角之一」——尤其係喺 rack-level，一粒 orchestration CPU 慳到嘅電力同 latency，可能比換更勁嘅 GPU 更划算。

五、SoftBank 槓桿：用 Arm 撬動成個 AI 資本版圖

訪問中段（15:13 SoftBank Leverage and Capital Strategy + 17:43 Portfolio Overview）講 SoftBank 點樣用 Arm 做旗艦。呢 part 對睇資本結構嘅人好有信息量：SoftBank 揸住 Arm 90% 股權，而 Arm 而家市值係 SoftBank 成個投資組合嘅核心支柱——SoftBank 用 Arm 嘅估值做槓桿，去融資佢其他 AI 投資（包括傳聞中嘅巨型數據中心項目同 Stargate 類計劃）。Haas 冇直接評論 SoftBank 嘅財務操作，但佢提到 SoftBank 生態嘅協同：Arm 提供 chip 基礎，SoftBank 旗下嘅其他公司（包括佢投資嘅數據中心、機器人公司）提供需求——形成一個「chip → infra → application」嘅閉環。

呢個資本結構嘅啟示係：Arm 已經唔再係一間 pure-play IP 公司，而係 SoftBank 成個 AI 資本版圖嘅「晶片錨點」——佢嘅戰略價值超越本身收入，呢個都解釋到點解 Arm 肯冒險轉型做實體晶片：因為喺 SoftBank 嘅劇本入面，Arm 要由「收 royalty 嘅旁觀者」變成「AI 基建嘅關鍵供應商」，先撐得起成個故事。

六、AI 點樣改變芯片行業本身 + 機器人嘅下一個機會

訪問有兩段好「內行人」嘅內容。第一段係 AI Adoption at Arm + Changes in Chip Time to Market（06:55–13:27）：Haas 講 Arm 自己點用 AI 加速芯片設計——chip 嘅 time-to-market 被 AI 大幅壓縮（EDA 工具、驗證、RTL 生成、bug 查找全部有 AI 輔助）。呢個係「AI 自動化 AI 基建」嘅又一個例子：連芯片設計呢種最硬核嘅工程，都開始被模型加速。

第二段係 Robotics Opportunities（20:13）：Haas 認為機器人係 Arm 架構下一個大機會——因為 on-device inference 要慳電慳成本，而 arm 架構喺 embedded/實時系統有幾十年嘅積累（由手機到 MCU 到車）。佢嘅判斷係：具身智能嘅「大腦」可以行喺雲端 GPU，但「脊髓」級別嘅實時控制一定要行喺本地低功耗芯片——而嗰個市場，Arm 一早已經喺度。呢個論述同我哋之前覆蓋嘅 Pi（物理智能）、Hexiaopeng（Physical AI 鋼鐵豪賭）等觀點互相呼應：具身智能嘅 chip 格局唔會係 GPU 通吃，而係「雲端大模型 + 本地實時芯片」嘅分層架構。

七、美國製造獨立：供應鏈安全 vs 全球化效率

24:49 US Manufacturing Protectionism 一段，Haas 企喺業界立場好明確：美國半導體製造獨立係 critical——唔係因為經濟學上最優，而係供應鏈安全問題。呢個立場由 Arm 角度特別有意思：Arm 係英國公司（SoftBank 日本母公司），fab 全部靠台積電——佢嘅生意命脈本身就係全球化嘅產物，但 Haas 明確支持美國本土化生產（CHIPS Act 路線），因為「AI 已經變成國家安全基建，冇得再賭供應鏈唔會斷」。Elad Gil 喺呢度追問咗保護主義嘅代價（成本上升、效率下降），Haas 嘅回應係：安全溢價喺呢個時代係必須俾嘅——呢個立場同美國政策圈而家嘅主流一致。

點解咁重要：呢集係「AI 算力敘事由 GPU 獨大轉向全系統」嘅一個好清晰嘅風向標。三條線索夾埋睇：同一個星期 OpenAI 出 Astra（用嚟自動化自己嘅 AI Engineering infra）、Meta 出 Muse Spark 1.3（平到「almost too cheap to meter」）、Arm 出 AGI CPU 俾 Meta——模型、芯片、資本全部喺度為「agentic cloud」重新排陣。當模型能力開始商品化，真正嘅護城河會落喺 infra 層：邊個可以以最低成本餵飽最大量嘅 agent 任務。CPU 喺呢個敘事入面由「舊時代遺物」變成「agent 時代嘅大內總管」——呢個 re-rating 本身，就係未來兩年硬件投資最重要嘅主題之一。
八、行業 insight 同誠實嘅 caveat

對投資者同創業者嚟講，呢集最有用嘅框架係：「賣 inevitability，但 startup 要當佢係 direction 而唔係 roadmap」。Haas 拋出嘅係一個宏大願景——CPU 係 AGI/機器人嘅中心、agentic cloud 需要全新嘅 silicon 基礎——但節目冇交代幾樣嘢：

  • 實際節點性能數據——宣稱 rack-level >2× x86，但冇第三方 benchmark。
  • 授權定價細節——賣實體晶片嘅 margin 結構同 IP 授權好唔同，Arm 要重新學做 supply chain。
  • 同大 licensee 嘅競爭張力——NVIDIA（Grace）、Apple 都用 Arm 架構，Arm 自己出數據中心 CPU 會唔會令佢哋重新考慮長遠依賴？呢個問題 Haas 冇正面答。
  • 收入時間表好遠——2026 年底量產、2028 年先有顯著收入——即係話短期內 Arm 嘅故事仍然係 IP 授權嘅天下，AGI CPU 係「期權價值」多過「現金流」。

仲有一個值得留意嘅點：Haas 講嘅「CPU orchestration 樽頸」論述，某程度上係為自家產品講嘅故事——NVIDIA 嘅 CUDA 生態同 NVLink 已經做緊大量 orchestration，AMD 嘅 ROCm 都喺度追。CPU 唔會「重新統治」AI，更準確嘅講法係：AI 系統嘅分工會重新平衡——GPU 繼續做 heavy compute，但 CPU 嘅角色由「boot 機之後就唔關事」變成「成個 agent 系統嘅 traffic cop」。呢個 rebalancing 先係 Arm AGI CPU 真正嘅 bet。
