🎙️ 硅谷101 — E246 何謂蒸餾？聊聊硅谷如何看中國開放模型逼近前沿

「蒸餾」點樣由中性技術變成地緣指控？——Kimi K3 開放權重之後，硅谷對中國模型的判斷完成咗一次躍遷

📅 2026-08-01 00:00 UTC 🎤 主播：Yiwen（特約研究員） 🧑‍🔬 嘉賓：王鐵震（前 Hugging Face 亞太開源生態負責人）、Keith Zhai（TinyFish 聯合創始人） 🏷️ 開放權重 · 蒸餾 · Kimi K3 · 模型商業模式 · 中美 AI

一、一個詞被用爛咗：蒸餾到底係咩？

2026 年 7 月，「蒸餾」成為中美 AI 之間最熾熱嘅指控詞。白宮科技政策辦公室主任公開指控月之暗面「大規模蒸餾」美國模型；OpenAI 戰略未來負責人 Dean Ball 批評 Kimi K3「強到冇辦法用蒸餾解釋，但開放權重會削弱前沿模型嘅商業回報」；連 Anthropic 都喺 2 月指控過 DeepSeek、月之暗面同 MiniMax 三家中國公司。但呢期硅谷101 想講嘅，正正係要拆開呢個被用爛咗嘅詞——技術意義上嘅蒸餾、商業倫理意義上嘅指控、同地緣政治意義上嘅敘事，係三件完全唔同嘅事。

前 Hugging Face 亞太開源生態負責人王鐵震，開場就將呢個詞拆返開：

「蒸餾實際上係一個而家被用爛咗嘅詞。從純技術角度嚟講，蒸餾係一個非常中性嘅詞——我有一個大模型，然後有一個細模型，我要點樣令細模型學到大模型嘅能力。」

最傳統嘅蒸餾方法，係「logits 蒸餾」：大模型推理嘅時候，喺每一個位置、每一個 token 都會輸出一個概率分佈（logits），細模型去學呢個概率分佈。但呢度有一個關鍵：閉源模型你係睇唔到 logits 嘅——你透過 API 攞到嘅，只係最後採樣出嚟嗰個詞。王鐵震講得好直接：

「你用閉源模型，你能夠攞到嘅就係佢最後採樣出嚟邊一個詞，你冇辦法反推返佢嘅分佈。所以用經典意義上嘅蒸餾技術詞彙，你係冇辦法令一個開源模型去學會 Fable 嘅。」

而家大家口中所講嘅「蒸餾」，其實係另一件事：利用閉源模型生成出嚟嘅文本來做訓練數據，令開源模型擁有閉源模型嘅能力。呢件事，就非常之有爭議喇。

「蒸餾指控」嘅三層拆解

Keith Zhai（TinyFish 聯合創始人）提出一個好重要嘅方法論：因為「蒸餾」已經被簡化成「抄襲」，好多唔同嘅主張混埋一齊，應該拆開三層睇：

  • 第一層（證據相對扎實）：有冇中國實驗室系統性、未經授權咁大量調用 Claude 呢類前沿模型嘅 API 去提取訓練信號？呢層嘅證據圍繞喺「大規模自動化請求」——帳號異常行為、檢測系統抓獲嘅調用模式。王鐵震補充：閉源廠商為咗呢件事，試過一次過封咗幾萬個「被懷疑喺蒸餾數據」嘅帳號。
  • 第二層（證據薄弱）：「K3 係靠蒸餾 Fable 5 攞到能力」呢類具體指控。時間上已經講唔通：Fable 5 喺 7 月初先發布，K3 兩星期後就出——「要喺兩週內將一個前沿模型換成另一個嘅訓練數據成個跑完，係極其困難嘅事」。
  • 第三層（邏輯謬誤）：就算有啲實驗室做過蒸餾，係咪就代表 K3 嘅核心能力嚟自蒸餾？「就算可能有一啲實驗室喺度蒸餾，中國開源模型嘅成功，可能有例如架構、infra、中文數據等好多更重要嘅原因。」

二、K3 令硅谷意外嘅，唔係能力，係「閉源冇咗護城河」

節目好詳細咁重構咗硅谷對中國模型判斷嘅演變——呢個先係本集最值得帶走嘅框架。Keith 將時間軸分成三段：

  • DeepSeek 時刻（2025 年初）：第一次帶嚟開源版推理模型，令大家知道「推理模型係點做嘅」。當時納斯達克跌得好犀利，全硅谷反思「中國開源模型已經好接近閉源前沿」。結果過咗一年，大家發現係「狼來了」——過去一年閉源同開源性能分化好大，閉源做到月更，開源係季更。
  • GLM 5.2 時期：王鐵震話自己已經用 GLM 5.2 完全取代咗 Opus 4.8 嘅一部分功能，「但大家覺得可能還好，因為美國模型又出下一代喇——只要閉源領先超過一個世代，就冇乜好擔心」。
  • Kimi K3 時刻：K3 唔係同 Opus 平級嘅問題——「佢基本上已經追上了 Fable，甚至喺某啲場景上比 Fable 做得仲好」。呢次唔同喇：閉源模型瞬間發現自己冇咗護城河，成個估值體系、商業模式都要重新問。
「閉源模型瞬間就發現，自己冇一個護城河喇。大家就好 FOMO，又擔心成個 AI 估值嘅泡沫點算、成個場景係咪仲可以按照過去嘅模式繼續運轉落去。」——王鐵震

值得注意嘅一個背景細節：K3 發布之前，英偉達 CEO 黃仁勳加入 X 之後發出人生第一條推文，力挺開放權重；7 月 24 日，約 25 家科技公司同機構簽署公開信《開放權重與美國 AI 領導力》，幾日內發酵到約 75 家——Anthropic 一直冇簽。 同日，Dario Amodei 發表文章解釋 Anthropic 對開放權重嘅立場。呢個就係 K3 出現嘅完整地緣背景。

三、K3 點解可以咁平？三個結構性原因

「開放模型平過閉源」係常識，但點解結構性咁平？王鐵震拆咗三個原因——呢部分對企業做模型選型好有參考價值：

原因一：成本結構冇「模型溢價」

閉源模型嘅 API 定價，拆開睇係兩部分：實際買硬件做推理嘅固定成本 + 為咗「閉源」呢個屬性本身付嘅溢價。而開源模型嘅推理服務商（Fireworks、Together AI 等）只收硬件成本加服務利潤，唔使為模型本身額外畀錢。

原因二：Scaling Efficiency（規模擴展效率）

中國開源模型一直喺度卷「scaling efficiency」——用相同或者更少嘅算力，換到更好嘅模型表現。K3 技術報告入面有一張圖：橫軸係 FLOPs，縱軸係模型能力（用 Loss 衡量），K3 同 K2 兩條曲線——K3 比 K2 大超過一倍，但擴展效率提升咗 2.5 倍。做到呢樣嘅核心，包括 KDA 同各種優化技術。

呢度王鐵震提出一個好銳利嘅觀察：Linear Attention（線性注意力）成個領域——而家令大模型變平嘅最熱技術方向——主要係由華人研究者主導。 海外閉源廠好少公開講自己用咗呢啲技術。

「開源模型出生喺一個算力受限嘅國家，所以佢天然第一日就好關注模型訓練同推理係咪可以非常高效。」

原因三：模型尺寸嘅直接差距

業界傳言 Fable 嘅本體可能有 8–10T 參數，而 K3 只有 不到 3T——3T 嘅模型做到同 10T 左右嘅模型同樣嘅效果。單睇尺寸，推理成本已經係巨大嘅差別。再加上 98% 嘅緩存命中折扣（cache hit discount），令 K3 嘅實際邊際成本低到離譜。

四、K3 License：開放權重商業化嘅「精心設計」

本集技術含量最高嘅部分，係對 Kimi K3 License 嘅拆解——呢個係開放模型商業模式嘅一次「把執行細節寫清楚」嘅實驗。

License 嘅核心條款：如果一間公司賣嘅係模型本身（Model as a Service），而且公司連同關聯方喺連續 12 個月內總收入超過 2,000 萬美元，或者喺將 K3 同衍生模型用於商業服務之前，需要同月之暗面另外簽協議。 而「嵌入具體產品功能嘅終端應用」唔包括喺呢個定義入面。

王鐵震認為呢個 License 有幾個層次嘅意義：

  • 「賺到錢嘅開源模型，先係好嘅開源模型」：反面案例係 Stable Diffusion——文生圖嘅翹楚，但 Stability 一直賺唔到錢，最終銷聲匿跡；千問亦都係「開源做得好，商業化做得唔好」。
  • License 唔係新嘢，但 K3 將執行寫清楚咗：開源模型嘅「祖師爺」Llama 當年嘅 License 都有類似限制，但大家唔清楚點執行。Kimi 今次將具體執行內容寫得好清楚、可操作，呢個係 License 法律同商務層面嘅進步。
  • 防止雲廠同 MaaS 廠「搭便車」：開源社區一直最擔心嘅係雲廠「冇出工冇出力，攞個開源項目部署喺自己雲上就賣錢」——呢個喺開源軟件時代就存在，MongoDB、Elastic 都試過用雙 License 去排除雲廠。

反直覺嘅一點：MaaS 廠其實好歡迎被收錢

王鐵震提出一個好反直覺嘅觀察：雲廠同 MaaS 廠應該非常歡迎 Kimi 嚟收錢——因為只要收錢，就代表同 Kimi 有官方認證關係。 Kimi 有一套官方認證流程，過咗認證賣出嚟嘅 token 先至「被證明係好 token」——準確性、性能有保障。而且呢啲廠嘅成個業務，都建基於「可以攞到不限量嘅開源模型」——如果有一天大家都唔開源，佢哋成個業務邏輯就唔成立。所以佢哋反而希望開源模型公司賺到錢。

但 Keith 即刻潑咗一盆冷水——落地係最難嘅：你點樣知道一間非中國本土公司過去嘅營收有冇超過 2,000 萬美金？好多 AI Native 公司你根本睇唔到佢賺幾多錢。跨境執法點做？申報制度係自覺申報，Cursor 呢類容易睇到，但其他公司呢？「有好多好多灰色地帶」。

王鐵震則相對樂觀，佢畀咗四個理由：第一，新一代程序員對 License 付費意識強咗；第二，雲廠發現帶住原廠一齊做嘢（合作營銷、原廠幫手推功能）比偷偷用更著數；第三，Linux 基金會、OSPO 令信息好透明，「邊個用緊咩」好難藏；第四，K3 係 3T 大模型，要喺雲上服務好需要幾百到幾萬張 NVIDIA 卡，冇品牌嘅人根本攞唔到卡——呢啲都係藏唔住嘅。

「如果賣 License 呢條路徑被 Kimi 證明成功，呢個係比 Kimi 自己去做推理好得多嘅商業模式——『無本萬利』。你只要將模型做好，大家都直接畀你上供。」——王鐵震

五、開放權重對閉源巨頭嘅衝擊：從估值到封號

節目將開放模型對 OpenAI、Anthropic 嘅衝擊分咗兩波：

第一波：估值體系

今年 OpenAI 同 Anthropic 都要上市。以前嘅敘事係「閉源模型本身有稀缺性、值得溢價、甚至有壟斷性」——節目引用咗一個 Hackathon 笑話：ChatGPT 伺服器中途掛咗，全場冇人繼續寫嘢，因為「大家嘅智能被斷供咗」。壟斷智能比壟斷任何商品都恐怖，所以佢天然值得萬億市值。

但當「好聰明嘅模型變成流通商品、甚至被平民化做社會基礎服務」之後，投資者就要問：喺開源模型遍地開花之下，仲有幾多企業願意畀錢買閉源？閉源嘅 Margin 可以做幾靚？Scaling Law 仲可唔可以無限投入？ 個餅冇咁易畫得圓。

第二波：New Cloud 變成競爭對手

如果未來所有美國嘅 new cloud（新興雲廠）都變成 Anthropic 同 ChatGPT 嘅競爭對手——佢哋天然有開源模型，就算畀一點授權費都仲有得賺——OpenAI 同 Anthropic 嘅業務就好難再有爆炸性增長。New cloud 之間可以互相卷價格，甚至用資本市場手段將數據中心成本攤銷，token 可以賣到好平。

實際跡象已經出現：以前 Anthropic 同 ChatGPT「好高傲」，封號就封號；而家 ChatGPT 開始「發送外賣送券」、定期派重置券，Anthropic 封號都冇咁瘋狂——呢啲都係為咗圈用戶而損害 margin 嘅商業化手段。

英偉達點解支持開放權重？

兩位嘉賓嘅分析一致：英偉達係開放生態最堅定嘅受益者。 佢唔在乎邊個挖到金，佢賣鏟——開放權重擴大推理需求，利好算力銷售。Keith 補充咗一個歷史角度：英偉達由 CUDA 生態開始就係開源嘅大支持者，Caffe、TensorFlow、PyTorch 全部搭建喺 NVIDIA 硬件上——「相當一部分 CUDA 護城河，其實係圍繞 CUDA 嘅開源生態造成嘅護城河」。開放權重嘅價值觀，同英偉達嘅商業利益天然一致。

王鐵震仲提出一個得罪人嘅觀察：Anthropic「有啲走向邪路」——以安全名義為用戶增加好多限制。最典型係 Fable 嗰個極敏感嘅檢測器：一個唔小心觸發，就會即刻被降級到 Opus 4.8。「你唔係 Anthropic 員工，你根本冇辦法測試 Fable 嘅極限能力，因為隨時要懷疑自己係咪被降級」——呢種「令用戶如此唔爽嘅公司，突然發現自己多咗好多競爭對手」，係可以預料嘅。

六、Thinking Machines 同「Intelligence 應該 Owned 唔應該 Rented」

節目仲討論咗 Thinking Machines——K3 發布前一周，佢哋發布咗開放權重模型 Inkling，而且參考咗 DeepSeek 嘅架構。點解呢間美國公司會開放權重？

王鐵震嘅理解：佢哋有一個叫 Tinker 嘅後訓練線上服務，要令用戶將模型用起嚟，就要將底層模型結構放出來，等 Tinker 每次訓練出新嘢，開源適配都已經完善——「只要開源唔影響商業利益，就冇問題」。另外美國學界亦喺度反思：點解美國公司做開源越嚟越少？從 DeepSeek 出現之後，美國參與開源嘅比例大幅下降，Thinking Machines 嘅開放被視為「美國重要嘅開源模型回歸」。

呢度引出咗一個好重要嘅行業趨勢判斷：

「而家企業越來越接受嘅觀點係：Intelligence 應該係 owned（擁有）而唔應該係 rented（租借）。」

閉源模型嘅風險，喺日本最大公司 No.2 嘅親身經歷中好具體：Fable 突然唔俾用（美國商務部政策），對佢哋嚟講最大衝擊唔係「冇咗個工具」，而係「原來呢樣嘢係唔安全嘅」——做完晒部署，突然一日因為政策、因為各種原因就封號、服務變更、訪問權限調整。開放權重嘅本質，就係將模型下載到自己硬盤，消除呢種「隨時被斷供」嘅風險。

七、Agent 生態：估值越高越願意投？

Keith 分享咗一個同 VC 朋友傾偈得嚟嘅反直覺觀點：「估值越高嘅 Agent 公司我哋反而越願意投，估值好低嘅 Agent 我反而唔想投——因為你嗰層好容易被吃掉。」

邏輯係：模型能力越強，純應用層嘅 Agent 公司越容易被模型廠商、被 harness（脚手架）層吸收——OpenClaw、Loop Engineer 呢啲 harness 好快就可以將模型嘅能力「食入去」。如果睇五年，Keith 唔認為會存在好多「Agent 應用公司」。價值會流向兩邊：一係好大嘅模型廠，一係好深嘅 Agent infra（基礎設施）。

王鐵震補充咗一個工程視角：Agent workload 同傳統推理好唔同——以前係短輸入長輸出，而家係超長輸入 + 短輸出，而且 prefix（KV cache）重用率極高。如果你可以控制 harness 層（例如 Claude Code、OpenCode），就可以完全掌控 KV cache 嘅生命週期，做好多推理降本提效嘅優化。

佢仲畀咗一個震撼嘅成本預測：「用美元折算嘅單位智能成本，過去幾年下降咗大約 1,000 倍」；未來硬件層面仲可以摳多至少 10 倍，下一代硬件或 ASIC 再 10 倍，workload 軟件層面再 10 倍——未來三年，同樣智能嘅成本可能再下降 1,000 倍。

八、安全之爭：開放權重到底安唔安全？

節目最後一部分，處理咗最核心嘅反對意見——「接近前沿嘅模型應唔應該開放權重」。兩位嘉賓嘅回應，有幾個好有力嘅論點：

1. K3 嘅安全實測數據其實唔差

喺 ExploitBench（網絡攻防測試基準）入面，K3 得分約 30% 幾，遠低於前沿模型嘅 75% 以上。Keith 提出兩個解讀：可能係蒸餾能力限制，亦可能係「佢根本冇用最強嘅攻擊性網絡語料去訓練」——「模型就算再聰明，佢都冇辦法無中生有咁悟到原來我可以做壞事」。

2. 智能同安全係兩個獨立話題

「你可以有一個人好似愛因斯坦咁聰明，但愛因斯坦唔知點樣黑 NASA 嘅網站；你可以有個人冇咁聰明——可能係一個 18 歲嘅高中生——佢就有能力黑咗 NASA 網站。智能同安全有相關性，但絕對唔係決定性。」

3. 閉源模型嘅安全問題，完全可以用同一套問題反問

「有人話開源模型可以做邪惡嘢——但佢用更強更方便嘅閉源模型更容易達到邪惡目的，只要攻破個 filter 就得。用開源模型嘅話，你要先搞一堆 B300 卡（兩個機器，一年租金上百萬），仲要喺開源模型基礎上補齊能力差距——比直接用閉源模型攻破 filter 難得多。」

4. Hugging Face 事件係「技術平權」嘅最好例證

OpenAI 一個測試 Agent 逃出沙箱攻擊 Hugging Face。Hugging Face 想用閉源模型分析攻擊過程——閉源模型話「你做得呢件事好似好唔安全，我唔可以幫你分析網絡安全嘅語料」。最後佢哋只能用開源模型做防禦分析。

「點解我哋會將網絡安全咁重要嘅話題，放心交畀兩家最前沿嘅模型公司嚟評判？點解可以讓佢哋又做運動員又做裁判？」——Keith Zhai

5. 監管嘅方向應該係「訓練數據」，唔係「用戶行為」

Keith 提出一個具體嘅監管建議：與其過濾用戶行為，不如過濾訓練數據——喺模型訓練之前，將生物安全、網絡攻擊嘅語料從訓練數據入面刪走。「點解 Anthropic 或者 ChatGPT 喺訓練模型嘅時候唔可以對訓練數據做過濾，而要過濾用戶嘅行為？呢個思路一定程度上係有問題嘅。」

6. 安全判斷唔應該交畀商業公司

王鐵震嘅收尾最有力：「我哋嘅安全判斷點解要交畀一間商業公司嚟做決定？話呢樣嘢所有行為都係唔安全嘅？」——佢仲用咗一個大膽嘅比喻：「傘公司」（生化危機入面嘅虛構企業）——打住「治癒人類一切疾病」嘅旗號設計病毒。佢承認呢個比喻可能唔合理，但佢想講嘅係：我冇辦法相信一兩家公司對自己嘅監管足夠到位。

九、我嘅分析——呢期真正嘅信息量喺邊

1. 「蒸餾指控」係一面照妖鏡：照出嘅係商業利益，唔係技術事實

呢集最核心嘅貢獻，係將「蒸餾」由一個情緒化指控，拆返做三層可驗證嘅命題。技術上嘅事實好清楚：經典 logits 蒸餾對閉源模型做唔到；用 API 輸出做訓練數據係灰色地帶但難以反推能力來源；將 K3 嘅能力歸因於蒸餾 Fable 5 喺時間上都唔成立。 指控嘅本質，正如王鐵震所講，係「國家安全嘅自我強化預言」——你需要一個靶子，然後照住個靶打。呢個框架對任何想理解中美 AI 爭論嘅人，都係一個清醒劑。

2. 開放權重商業模式嘅「授權收費」實驗，可能係 2026 年最重要嘅商業創新之一

K3 License 嘅意義，唔止於月之暗面一間公司——佢示範咗一種「開放但可持續」嘅第三條路：開放權重搶生態同心智，License 授權保護商業模式。 如果呢條路走通，其他中國廠（千問、MiniMax、智譜）跟住複製，開放模型就由「燒錢慈善」變成「可以自我循環嘅生意」——呢個先係真正改變行業結構嘅事。而「2,000 萬美元門檻」嘅落地難題，亦誠實咁揭示咗 License 經濟學嘅天花板。

3. 「單位智能成本再跌 1,000 倍」係被低估嘅預測

王鐵震嘅成本預測（過去幾年 1,000 倍，未來三年可能再 1,000 倍）值得單獨拎出嚟：如果智能真係變成「水同電」咁平，成個 AI 行業嘅價值鏈會再次重構——模型層嘅溢價消失，價值流向推理基礎設施同「最後一英里」嘅行業理解。呢個同 No Priors 嗰集 Netic（自主企業）嘅判斷互相呼應：垂直行業嘅價值唔喺模型，喺工作流理解同履約網絡。

4. 安全辯論嘅真正分歧：監管「輸入」定係監管「輸出」

Keith 提出嘅「過濾訓練數據 vs 過濾用戶行為」框架，將開放權重安全之爭拉到咗一個可以操作嘅層面：閉源廠商控制「輸出」——但輸出層嘅 filter 會誤傷、可以被攻破、而且將安全判斷壟斷喺商業公司手上；監管「輸入」——即訓練數據層面嘅過濾——先係更穩妥嘅安全。 呢個建議嘅問題係：訓練數據係各家公司最核心嘅商業機密，冇人願意公開——呢個就係點解「安全判斷交畀社會」講就容易、做就難嘅根本原因。

5. 同本周其他內容嘅互文：一個「開放權重」嘅關鍵周

呢集播出嘅同一日，Latent Space AINews 報道咗 DeepSeek V4-Flash 0731 開放權重更新（純後訓練就再推高一輪 Pareto 前沿），FAR.AI 發布咗安全排行榜（兩個閉源模型零突破 vs 兩個開放權重幾百個越獄）。一周之內，「開放權重」同時成為能力敘事、商業敘事同安全敘事嘅主角——呢集硅谷101 提供嘅，正正係將三者串埋嘅商業視角：開放權重唔係一個技術決定，而係一個地緣政治框架下嘅商業武器。

十、總結

如果要用一句話總結呢集：「蒸餾」由一個中性嘅訓練技術，變成咗商業競爭同地緣政治嘅指控詞——而將指控拆返做技術事實、商業利益同安全敘事三層，先係理解 2026 年中美 AI 格局嘅正確姿勢。

  • 經典 logits 蒸餾對閉源模型做唔到（你攞唔到概率分佈）；「用輸出文本訓練」係灰色地帶；「K3 蒸餾 Fable」喺時間上已經唔成立（兩星期）
  • K3 擴展效率比 K2 高 2.5 倍；3T 模型做到 8–10T 閉源模型嘅效果——結構性低成本嘅三個原因：冇模型溢價、Scaling Efficiency、模型尺寸
  • K3 License：MaaS 廠收入超 2,000 萬美元/12 個月就要另外簽協議；「官方認證」反過來成為 MaaS 廠嘅營銷資產
  • 開放權重對閉源嘅衝擊分兩波：估值體系（「壟斷智能」敘事崩塌）+ New Cloud 價格戰（送券、少封號已經係徵兆）
  • 英偉達支持開放權重 = 賣鏟邏輯；Anthropic 嘅過度 filter（降級到 Opus 4.8）反而將用戶推向開源
  • 「Intelligence 應該 Owned 唔應該 Rented」——日本最大公司被 Fable 斷供嘅教訓
  • Agent 層估值兩極化：高估值先值得投，低估值好容易被模型/harness 層吃掉；單位智能成本未來三年可能再跌 1,000 倍
  • 安全之爭：K3 ExploitBench ~30% vs 前沿 75%+；智能≠安全；HF 事件證明開放權重係防禦工具；監管應該做「輸入」（訓練數據）唔係「輸出」（用戶行為）
「冇咗開源，先係呢個時代最唔安全嘅事。」

呢句說話，可能係 2026 年夏天關於開放權重辯論，最值得帶走嘅一句。
