「數據係 AI 時代最後嘅護城河」——Eon 兩位創辦人：Google 用 $10M 買破產航空公司嘅數據而唔係飛機，同埋「非人類身份」點樣成為企業頭號恐懼

📅 2026-08-27·🎙️ No Priors（Sarah Guo + Elad Gil）·⏱️ 約 35 分鐘·👤 嘉賓：Ofir Ehrlich（CEO/聯創）、Gonen Stein（President/聯創）——Eon，前 CloudEndure（被 AWS 收購）

「模型、算力，一切都係相對短命、幾乎零切換成本嘅嘢……但係如果你係一間公司，無論你係酒店集團定食品科技公司，都冇分別——你最值錢嘅嘢，其實係你自己嘅數據。」Eon 嘅 Gonen Stein 用一句話，將成個 AI 時代嘅價值錨點由模型層搬到數據層。兩日之前，Google 喺破產拍賣入面買走 Spirit Airlines 嘅資產——但唔係飛機，係數據，$10M。呢集 No Priors 表面係講一間「雲端備份公司」點樣轉型做「AI 數據地基」，實際上係一幅好完整嘅地圖：數據點解突然變成戰略資產、AI agent 點樣成為企業內部「有合法權限嘅破壞者」、舊一代數據管道（Fivetran/dbt 世代）點解注定唔夠用、以及「forward-deployed 工程師」點樣由唔體面變成主流 GTM。

一、呢集係咩：由「備份公司」講到「數據經濟學」

Eon 係咩公司？用佢哋自己嘅話講：一個「喺雲端運行嘅新數據地基（data foundation）」。佢哋做三層嘢：第一，幫客戶mapping + 分類佢哋跨多個 hyperscaler 嘅全部數據——搞清楚你有乜嘢、喺邊度、邊啲敏感邊啲唔敏感；第二，將結構化同非結構化數據統一 ingest 入呢個地基；第三，用極低成本維護（保護＋恢復）之餘，令數據可以俾人 query、搜尋、餵俾 AI 模型。起步點其實係 backup/disaster recovery——但佢哋好快發現：如果你喺備份層掌握咗客戶嘅全部歷史數據，你就企喺「數據資產化」嘅最佳位置。

呢個背景好重要：Ofir Ehrlich 同 Gonen Stein 之前創辦 CloudEndure，賣俾 AWS 之後成為 AWS Application Migration Service 嘅核心技術，親手做過成千上萬部伺服器嘅超大規模雲遷移。換句話講——佢哋係「企業基礎設施世代交替」嘅老兵：睇住 on-prem→cloud 嘅遷移，而家再睇住 cloud→agentic AI 嘅第二次遷移。佢哋對「企業買單行為」嘅判斷，係有第一手情報墊底嘅。

「Models, everything is relatively ephemeral, almost zero switching costs… But if you are a company, whether you are a hotel chain or a food chain technology company, it doesn't matter. The most valuable thing that you have is actually your data.」 ——Gonen Stein（00:03:02）：模型同工具都係短命、零切換成本；但企業自己嘅數據無可替代
二、破產拍賣變成數據拍賣：Google、Spirit Airlines 同 $10M

全場最「新聞性」嘅一段，係開場冇耐就拋出嚟嘅例子——Google 喺 Spirit Airlines 破產拍賣入面，買咗佢哋嘅數據資產，$10M，冇買飛機。Gonen 話：Google 認為呢啲數據好重要，用嚟訓練旅遊相關模型。而 Elad Gil 補咗一刀更癲嘅：據報呢單破產拍賣數據嘅另一個競投者，係 Mercor——即係話，兩間唔同類型嘅 AI 公司，喺度爭一間破產航空公司嘅企業數據集。

呢個例子嘅意義，唔係「Google 買咗間航空公司」咁簡單，而係：真實世界嘅企業數據，已經稀缺到要經破產拍賣渠道去搶。Gonen 話，如果你今日係一個科技公司 CEO，「你成日都會被問：你肯唔肯賣你嘅數據？」而且佢仲透露一個更被人忽略嘅信號——實驗室已經去華爾街，向對沖基金買數據，想「學習點樣 mapping 同分析公司」。以前企業啲數據係「放喺架上封塵嘅磁帶」，而家突然變成黃金。

「Just two days ago, you saw Google buy something from the bankrupt Spirit Airlines. They didn't buy airplanes. They bought the data. They bought the data for $10 million because they think it's very important… they're using it to train models.」 ——Gonen Stein（00:03:29）

點解一間航空公司嘅數據有價值？Gonen 嘅解釋好具體：如果你想訓練 agent，你唔可以淨係喺實驗室度砌——你需要真實世界嘅訓練數據。但「睇落似真實世界」嘅企業數據極難搵：Hugging Face 幾日前先啱發布咗一個法律數據集，但仍然稀缺到——啲人要用 Enron（二十年前破產公司）嘅公開電郵嚟當「企業運作數據」。Spirit Airlines 數據值錢，正正因為佢同時係「一間航空公司」同「一間大型企業」——有層級、有中層管理、有工人同管理層點樣協作嘅真實結構。呢個係合成數據畀唔到嘅。

Key Data Google 以 $10M 買下破產 Spirit Airlines 嘅數據資產（唔係飛機），用於訓練／深化旅遊模型；據報 Mercor 係破產競投過程嘅另一出價方。實驗室開始向 華爾街對沖基金 買數據，「學習點樣 mapping 同分析公司」。公開企業數據稀缺到要用 Enron 二十年前嘅電郵 當訓練材料。
三、核心論點 1：模型短命，數據長命——數據先係最後護城河

Gonen 嘅完整論證係咁：模型、算力、工具——呢啲全部係商品化最快嘅嘢，切換成本接近零。你今日用 GPT 聽日轉 Claude 後日轉 Gemini，冇任何代價。但企業自己積累嘅歷史數據，係唯一冇得喺市場買到、冇得靠切換供應商得到嘅資產。AI 會「將比賽場地剷平」——大公司小公司都可以用同一批最頂尖嘅工具，屆時企業之間嘅真正差異，剩返兩樣：人，同數據。

呢個論點仲有一個反直覺嘅延伸：數據資產化會反過來改變資本市場嘅行為。以前破產公司清算，資產清單係飛機、航線、品牌；而家出現咗「數據拍賣」呢個新品類。Gonen 判斷呢個趨勢會顯著加速——而佢嘅證據係實驗室嘅胃口：由網頁、書本等「公開訓練數據」，擴散到真實企業營運數據、金融數據。呢個同 No Priors 過去幾集嘅宏觀敘事（AI 基礎設施軍備競賽）完全對得上：軍備競賽嘅下半場，係數據軍備競賽。

四、核心論點 2：AI Agent 係「有合法權限」嘅新攻擊面

第二條主線係安全——但唔係你平時聽到嗰種。Ofir 講嘅威脅唔係「外部黑客攻入嚟」，而係帶住合法權限、喺企業環境入面執行嘅 AI agent。佢話：以前嘅威脅嚟自人類攻擊者；而家見到嘅係「on steroids」嘅版本——非人類行動者（non-human actors）有合法 access、合法 permissions，「然後，突然之間，一張表就俾人 drop 咗」。而且速度極快。

佢哋喺 AWS 時代親身經歷過人類版嘅呢個故事：一個超大客戶以為自己被完全保護（用緊佢哋嘅 disaster recovery 服務），但因為從來冇正確 mapping、分類、tag 自己嘅資源，結果 60% 嘅環境被勒索軟件暴露。呢個教訓直接催生咗 Eon——而家同樣嘅問題喺 agent 身上重演，但速度以倍計。

「What we're seeing now on steroids is that the same type of threat is coming from non-human actors, from AI agents that essentially have legitimate access to the environment with legitimate permissions… all of a sudden, a table is all of a sudden dropped.」 ——Ofir Ehrlich：帶合法權限嘅 agent，可以秒級 drop 一張表

最震撼嘅係市場反應嘅時間線：六個月前，冇人肯同佢傾呢個話題；幾個月前開始，幾乎每個佢見到嘅企業領袖都話——一係好驚呢件事發生喺自己公司，一係已經親身經歷過。Ofir 形容呢種由「唔想講」到「個個都中過招」嘅轉變係 crazy。背後係兩種恐懼疊加：外部——AI 令攻擊者更容易打你；內部——你自己批準運行嘅 agent 喺你嘅環境入面搞嘢。

Key Data Eon 喺 AWS 客戶案例中發現：客戶以為受保護，但因為從未正確 mapping／分類／tag 資源，60% 環境遭勒索軟件暴露。NHI（non-human identity）安全公司數量「多到無限」，已成為企業第一、二位嘅問題。威脅討論時間線：6 個月前無人肯講 → 而家每個領袖都話怕過或中過招。
五、核心論點 3：舊數據管道（Fivetran/dbt 世代）根本上唔適用於 agentic 世界

Sarah Guo 問咗一個好尖銳嘅問題：而家成個 ETL／data engineering 基礎設施，會唔會 survive？Ofir 嘅答案係「有強烈理由去改晒佢」——因為舊管道係「單一目的」設計：為咗你本來就諗好要做嘅嘢而建。以前你對數據只有一個用途，所以「攞出嚟、放喺度、處理完」就完事，每一段管道之間冇 context 相連。但而家組織想要嘅係全部 context、全部數據——因為你唔知 AI 會用呢啲數據問出乜嘢問題。

佢用一個好生活化嘅例子：Gonen 落樓買咖啡，信用卡過數，交易寫入某個 database——舊世界嘅做法係「有人將數據抽出去放喺某度，完」。另一個人喺另一時間用另一種方式處理同一批數據，「佢哋冇 context」。但今日，如果你識得聰明咁收集、清洗、高效儲存、激活全部數據，你就可以「畀一個團隊放縱咁用佢哋有嘅所有數據」——紐約鍾意漢堡嘅人清單 + 鍾意薄餅嘅人清單，以前永遠唔會有人將兩者 join 埋；而家你得。

對舊工具嘅評價，佢哋好公道但好狠：Fivetran 係「incredible company」、dbt 都係，但「好 specific 嘅工具，為咗嗰個 purpose 而設」——喺 agentic 世界，管道要為「未知用途」而建，而唔係為「已知用途」而建。佢仲點名 Databricks——「地球上最勁嘅公司之一」——話佢哋不停 reinvent 自己，因為佢哋明白「更多同更多嘅數據係由 agent 生成嘅」，如果打唔贏就加入：自己起 agent、自己起 database，將「數據點樣被使用同被創造」嘅主導權攞返嚟。

「Today it's very different. Today you understand that you can collect — if you're able to smartly collect and clean all your data and make sure you store it in an efficient manner, and if you can activate that efficiently — you can let a team go wild with all the data that they have… And think of things which were unimaginable.」 ——Ofir Ehrlich：舊管道為「單一用途」而建；而家要為「未知用途」而建
六、核心論點 4：AI 採用嘅強迫函數係恐懼，唔止係機會

點解企業 AI 採用同雲端當年咁唔同？Ofir 嘅觀察：雲端係抽象嘅——「雲端就係人哋嘅電腦」，好難同祖母解釋；但 AI 唔使解釋——由 ChatGPT 嗰刻開始，人人都親眼見過 AI 做嘢。所以 AI 採用係由 CEO、董事會、股東由上而下咁推：「用 AI 做嘢，否則我哋就冇關。」佢形容：企業採用 AI，一半為價值，一半為恐懼。

呢個「恐懼驅動」嘅採用模式，直接解釋咗今集下半場講嘅兩個新商業現象：forward-deployed engineering 由「服務懲罰」變成主流 GTM——以前係 Palantir 式嘅「唔體面」模式，而家大企業「好想採用 AI 但唔識點做」，唯一快速路徑就係放一班勁工程師入嚟，帶住喺矽谷頂級 startup 練出嚟嘅工具箱，幫你轉型；以及「買公司嚟 AI 化」呢個新劇本——好似 Longlake 呢啲公司直接講：「你哋慢慢採用太慢喇，我識得更高效咁做——我買咗你間公司，將佢改造成 AI 公司，大家雙贏。」

七、反直覺觀點：Agent 時代儀表板唔會消失，反而會更多

Sarah 問：agentic 世界入面，dashboards 會唔會消失？主流想像係「agent 取代人類分析，儀表板冇人睇」。Gonen 嘅答案完全相反：「我諗我哋會見到更多儀表板」——因為呢個會係人類搞清楚世界發生緊乜事嘅唯一方法。當 coding agent 寫住世界上大部分 code、agent 啟動 agent、agent 再啟動 agent，要追蹤「責任鏈」（chain of responsibility）幾乎係不可能任務——人類要保持任何 situational awareness，剩返儀表板呢個出口。可審計性越低，人類越需要視覺化。

呢個觀點同佢哋對「數據越多越好」嘅立場係一體兩面：越多 agent 生成嘅數據，人類就越需要工具去理解、去分類、去睇住。所以數據地基唔單止係「俾 AI 食」，亦係「俾人睇住 AI」——兩個需求疊埋一齊。

八、被忽略嘅信號同戰略啟示
被忽略嘅信號 1：實驗室向對沖基金買金融數據。一句帶過但意義重大——前沿實驗室對「高質量、結構化、真實世界」數據嘅渴求，已由公開網頁延伸到華爾街。對沖基金可能成為意外嘅數據變現生意；而呢啲數據會直接塑造下一代模型嘅推理能力。
被忽略嘅信號 2：端點安全被本地 agent 徹底顛覆。員工喺筆記本電腦上跑 agent，agent 同時連 WhatsApp、內部網絡、OpenAI API——傳統網絡邊界塌晒。呢個係全新安全品類（「多網絡 agent 嘅端點安全」），而家冇公司明確喺做——產品空白。
戰略啟示：先分類、後建管道。AWS 案例嘅教訓係「以為受保護但其實冇」——60% 環境暴露。AI 數據項目必須先 mapping／分類／tag，再起 pipeline。唔好俾 CEO／董事會嘅急迫感壓縮呢個順序——呢個係 Eon 成間公司存在嘅理由。

仲有一個好 personal 嘅坦白：Gonen 承認自己過去一直主張「PLG（product-led growth）對 dev tools 唔 work」——而家證明佢錯咗。Cognition（Devin）示範咗「PLG 入門 → forward-deployed 攻銀行」嘅混合打法，Eon 自己都行呢條路。呢個係企業基礎設施領域一個真正嘅世代轉變：由「銷售驅動」到「產品驅動入門＋服務驅動落地」。

九、同大盤嘅互文：由「邊個模型最勁」到「模型之下嘅底座」

今集嘅位置好特別：No Priors 一貫係「基礎設施＋宏觀格局」路線，但今次由模型層落到數據層。配合過去幾日嘅其他節目，行業焦點好清楚咁由「邊個模型最勁」轉向「模型之下嘅數據、身份、執行底座」：Latent Space 8/18 講 model routing、8/22 講 agent harness 演化；Cognitive Revolution 8/26 講 CoT monitoring 唔夠（Apollo 嘅 Bronson Schoen）；而「Google 買 Spirit Airlines 數據」同時印證咗 AINews 一直報道嘅實驗室數據軍備競賽——由訓練數據擴散到真實企業營運數據。

對 James 嘅語境，呢集仲有一個直接 hook：「酒店集團」被 Gonen 指名做例子——「無論你係酒店連鎖定食品科技公司，你最值錢嘅都係自己嘅數據」。酒店行業嘅數據資產（會員、住客歷史、營運數據）正正係錦鯤呢類平台嘅核心資產——呢集提供咗一個現成嘅敘事框架：點樣將「數據地基」講成「AI 時代最後護城河」。

「Six months ago, no one would even discuss with me. But a few months ago, pretty much every person I meet, every leader in a company tells me either they are afraid of that happening to them, or it personally happened to that person who was speaking with me.」 ——Ofir Ehrlich（00:17:01）：NHI 威脅由「冇人肯講」變成「個個都怕過或中過招」
十、爭議點
  • 「合成數據解決唔到真實世界數據稀缺」——直接挑戰業界主流假設。論據：合成數據捕捉唔到真實組織行為（層級、協作、中層管理嘅決策方式）。但呢個立場同時係 Eon 嘅商業利益所在，要打折聽。
  • 「收購企業嚟 AI 化」（Longlake 模式）——將 AI 轉型外包俾資本收購者，喺員工、文化、數據控制權層面有明顯爭議；Gonen 用「大家雙贏」嚟 framing，但冇回應「被收購公司嘅人點算」。
  • Agent 安全歸因——Ofir 強調問題根源喺執行底座（有合法權限嘅 agent 可秒級 drop table），暗示模型／harness 層嘅安全措施唔足以防禦。呢個同 Apollo 嘅結論互相呼應，但亦係 Eon 嘅「賣藥」立場。
  • 「實驗室買對沖基金數據」嘅倫理問題——節目一句帶過，但金融數據買賣涉及客戶私隱、監管、同「數據資產化」嘅界線，係未來一定會爆嘅爭議。
