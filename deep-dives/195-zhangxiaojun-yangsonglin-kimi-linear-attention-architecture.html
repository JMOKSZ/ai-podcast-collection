「雕完 FFN 出咗 MoE，而家輪到雕 Attention」——張小珺 × 楊松琳：Kimi Linear 嘅 KDA、三比一混合注意力共識，同中國算法創新點樣跑贏「冇卡」

📅 2025-11-03·🎙️ 張小珺商業訪談錄·👤 張小珺 × 楊松琳（MIT 博士生，flash-linear-attention 作者，Kimi Linear 論文作者之一）·⏱️ 1h43m25s·📝 小宇宙 / 語言即世界工作室

呢集係一個好好嘅「反潮流」樣本：當全世界嘅注意力都喺 scaling law、數據、算力嘅時候，呢集講嘅係一條被忽略嘅第三駕馬車——算法同架構。嘉賓楊松琳係 MIT 在讀博士，研究方向就係線性注意力，佢做過一個好硬核嘅開源庫 flash-linear-attention（FLA），亦是 Kimi Linear 論文嘅作者之一、Qwen3-Next 嘅參與者。節目以 2025 年秋幾篇架構論文（Kimi Linear、MiniMax M2、Qwen3-Next）做切入點，帶大家「考古」由 Transformer 到 MoE、再到線性/稀疏注意力嘅變種史。一句話總結呢集嘅世界觀：Transformer 得兩個模塊，FFN 已經雕成咗 MoE，下一個被雕嘅就係 Attention；而因為中國冇咁多卡，中國公司反而被迫喺「雕架構」呢條路上行得更前。

一、點解「雕架構」喺 2025 年突然變得重要

主持人開場就畀出一個清晰嘅因果鏈：數據、算力、算法係驅動人工智能嘅三駕馬車；喺「數據撞牆」呢個無奈前提下，各家模型公司不得不重新返去「雕模型架構」，期望 scaling law 嘅魔法可以繼續。而更微妙嘅一層係：

「由於中國的算力相對美國有限，這反而讓中國的 AI 算法創新走在了世界前沿。」 ——節目背景設定（中段亦有嘉賓親口認同：「中國 AI 的算法創新相比海外肯定是更強的——因為沒有那麼多卡」）

呢個命題係成集嘅底色，亦係一個好好嘅經濟學觀察：約束反而塑造優勢。當你冇本錢用「加卡」去買性能，你唯一可以做嘅嘢就係令每一張卡跑得更有效率——於是架構、kernel、硬件親和度呢啲「辛苦工」，反而變咗中國團隊嘅核心競爭力。

二、主持人同嘉賓：由一個開源庫講起

楊松琳嘅背景有幾個關鍵坐標：

  • MIT 在讀博士，研究方向係線性注意力機制（linear attention）。
  • flash-linear-attention（FLA）開源庫作者——呢個庫係線性注意力相關 kernel 實現嘅重要基礎設施，後來亦成為 Kimi Linear 開源 kernel 生態嘅一部分。
  • Kimi Linear 論文作者之一（論文標題《Kimi Linear: An Expressive, Efficient Attention Architecture》），同時參與咗 Qwen3-Next 嘅部分工作。

呢個身份組合好重要：佢唔係隔籬講架構嘅評論者，而係親手寫 kernel、親手參與論文嘅人。所以佢講「3:1 混合比例」、「DPLR 分塊算法」呢啲細節，係有一手經驗嘅（詳見第五、七節）。

三、點通俗理解 Linear Attention 嘅「Linear」

節目有一節專門「用最通俗嘅方式理解 Linear Attention 嘅 Linear」（chapter 07:04）。要點係：

  • Full Attention 嘅代價隨上下文線性增長（二次方）：傳統全局注意力要對每個 token 同所有歷史 token 做相似度計算，長文本解碼（decoding）時 KV cache 會爆炸式膨脹。
  • Linear Attention 把注意力嘅計算壓縮成一個固定大小嘅狀態：本質上係將 attention 重新表述成一個 RNN-like 嘅遞歸——「每個 token 更新一個狀態」，所以推理階段嘅計算同顯存成本大幅降低。
  • 代價係表達能力：把無限長嘅歷史壓入固定大小嘅有限狀態（finite-state），必然會丟失信息——呢個就係成集反覆圍繞嘅「表達能力 vs 效率」權衡（expressivity vs efficiency）。

節目中有一句總結得極好嘅話，直接點出大家點解每隔幾年就會重新關心線性注意力：

「每一次大家關心 Linear Attention 都是因為大家撞到了 Context Wall（上下文之牆）。」 ——楊松琳（節目 28:05 章節）

換句講法：linear attention 唔係新技術（2020 年就有），佢係一個「周期性復活」嘅選項——每當長上下文解碼嘅成本變成痛點，佢就會被重新翻出嚟審視一次。2025 年之所以係佢嘅「復活之年」，正正因為「最近長文本的 decoding 卷土重來」。

四、Kimi Linear 論文：KDA、Scaling Ladder，同「三比一」

呢集嘅技術核心，係楊松琳親手參與嘅 Kimi Linear。論文（arXiv 2510.26692，2025-10-30 首發）嘅核心貢獻係一個叫 KDA（Kimi Delta Attention）嘅模塊：

  • KDA 擴展自 Gated DeltaNet，加入更細緻嘅門控（finer-grained gating），令有限狀態 RNN 嘅記憶用得更有效率。
  • 配合一套特製嘅分塊（chunkwise）算法，透過 Diagonal-Plus-Low-Rank（DPLR）轉移矩陣嘅特殊變體，大幅降低計算量，同時更貼近經典嘅 delta rule。
  • 模型係 KDA 同 MLA（Multi-Head Latent Attention）嘅逐層混合，規模為 3B 激活參數 / 48B 總參數。

節目提到，Kimi 內部有一個 「Scaling Ladder（規模階梯）」嘅工作方式——「在一個規模下面表現好，就在下一個規模下面去 scale，就像通關」。呢個係一個好務實嘅研發紀律：唔係一次過掟去最大規模，而係逐級驗證架構嘅可擴展性。

而論文最硬嘅結果，係「公平比較下，混合線性注意力首次超越全注意力」：

Kimi Linear 官方數據 ①3B 激活 / 48B 總參數，KDA + MLA 逐層混合；②在 short-context、long-context、RL scaling 三種場景嘅公平比較下，首次超越 full attention（full MLA）；③KV cache 使用量降低最多 75%；④1M 上下文下解碼吞吐提升最多 6 倍；⑤可作為 full attention 架構嘅drop-in replacement（即插即用替換）；⑥開源 KDA kernel、vLLM 實現，同預訓練／指令微調 checkpoint。
五、兩條路線：Kimi 線性 vs DeepSeek 稀疏

節目將中國公司應對「長上下文解碼效率」嘅策略，清晰咁分成兩條路線：

「Kimi 走線性注意力路線，DeepSeek 走稀疏注意力路線，都想解決長文本 decoding（長上下文生成）的效率問題。」
  • DeepSeek → Sparse Attention（稀疏注意力）：唔改變「全局」嘅目標，但只揀一部分 token 去計算，靠「揀得準」嚟慳成本。
  • Kimi → Linear Attention（線性注意力）：改變狀態嘅表示方式，用固定大小狀態去遞歸，靠「壓縮」嚟慳成本。
  • MiniMax：年初 M1 版本試 Linear Attention，但到剛發布嘅 M2 又退回 Full Attention——呢個「退回」係整集最值得思考嘅信號之一（見下節）。

楊松琳亦提到矽谷嘅方案「不方便說」，但可以淺聊 OpenAI 有 paper 嘅方案——暗示呢條戰線唔止中國公司在打，只係公開程度唔同。

六、MiniMax 由 M1 到 M2 點解「退返」Full Attention

呢個係成集最有信息量嘅「反高潮」。當大家都以為線性注意力係大勢嘅時候，MiniMax 由 M1 嘅線性方案回退到 M2 嘅全注意力。楊松琳嘅解釋指向一個具體嘅能力缺陷：

「MiniMax 曾經也提到，混合線性注意力 / 混合滑窗注意力在『多跳推理』上會有缺陷。」

換句話講：線性/滑窗注意力喺「要串連多個分散信息點」嘅推理任務上會漏水。呢個係「有限狀態」嘅宿命——當你需要記住嘅係一堆相隔好遠、又互相依賴嘅線索時，固定大小嘅狀態會唔夠用。MiniMax 寧願食返全注意力嘅成本，都要保住呢個能力。

但楊松琳亦畀咗一條出路：

「對於『多跳推理』，如果我們開發一些硬件高效但表達能力更好的 RNN（循環神經網絡），這個 GAP 有可能縮小。」

——即係唔係放棄壓縮，而係要設計表達力更強嘅遞歸單元。KDA 對 Gated DeltaNet 嘅改良，本身就係呢個方向嘅一步。

七、混合注意力：三比一成為「不共識中的共識」

既然純線性唔夠力，現實嘅做法就係「混合」——而節目畀出咗一個極清楚嘅業界收斂信號：

「純 Linear Attention 是無效的，混合注意力機制還是有很多全局注意力層，這樣下限有保證。Kimi Linear 每 3 層 KDA 插入 1 層全注意力層，三比一的比例快變成共識了。Minimax 之前用的是七比一，但現在大家逐漸回到三比一——這成為不共識的混合注意力機制中的共識了。」 ——楊松琳（節目 38:16–40:30 章節）

呢段要用經濟學嘅角度去讀：

  • 純線性「無效」——因為冇全局層兜底，表達能力下限太低，任務一難就穿底。
  • 全局層係「保險」——保留少量 full attention 層，保證模型唔會喺關鍵推理上徹底失手。
  • 比例由 7:1 收斂到 3:1——反映業界喺實測之後發現，全局層唔可以太少；3:1 係「效率」同「安全下限」之間嘅經驗平衡點。

而呢個平衡點之所以叫「不共識中的共識」，係因為大家對「點解係 3:1」其實冇統一理論——更多係不同團隊獨立試出嚟嘅經驗值碰巧一致。呢種「實證先於理論」嘅狀態，好典型咁反映咗當前架構研究嘅階段。

八、Linear 嘅真正對手：唔係 Sparse，係 Sliding-Window

呢集一個好反直覺、但對理解競爭格局極有用嘅判斷，係澄清咗「邊個打邊個」：

「Linear Attention 和 Sparse Attention 沒什麼競爭關係，Linear Attention 的競爭對手可能是 Sliding-Window Attention（滑窗注意力）。」 ——楊松琳（節目 49:36、55:36 章節）

點解呢？因為 Linear 同 Sparse 解決嘅係唔同層面嘅問題——Linear 係「點樣表示狀態」，Sparse 係「點樣揀邊啲 token 去算」。反而 Sliding-Window（只睇最近一段固定窗口）同 Linear 係直接競爭：兩者都係「用有限範圍去近似全局」，只係一個用窗口、一個用狀態。

而佢想像中嘅未來理想方案，係一個好具體嘅組合：

「我想像中的理想方案是：把混合注意力的全局注意力（Full Attention）換成稀疏注意力（Sparse Attention）。只要 Sparse Attention 選得準，完全可以取代 Full Attention，但現在的問題是它選不準。」 ——楊松琳（節目 49:36 章節）

呢個設想嘅關鍵詞係「選得準」。稀疏注意力嘅天花板，唔係算法複雜度，而係「邊啲 token 重要」呢個判斷本身嘅準確率——呢個本質上係一個學習問題，亦係佢口中「工業界 Linear + Sparse 結合嘅探索似乎還未開始」嘅原因。

九、算法變種史：Transformer → MoE → Attention，動因係「同一 FLOPs 更低 loss」

節目中段有一段「考古」（chapter 57:05、01:23:12），將近年架構演變整理成一條主線：

「近幾年架構方面突破最大的是 MoE，下一個突破可能是 Attention；Transformer 就兩個模塊，一個是 FFN，一個是 Attention；現在 FFN 已經雕成 MoE，現在 Attention 大家也可以雕一下。」 ——楊松琳（節目 58:26 章節）

呢個「兩個模塊」嘅框架好清爽：

  • FFN 模塊：已經被雕成 MoE（混合專家）——「MoE 是更高效的 FFN 嘅替代品」，用稀疏激活換取更大參數量下嘅效率。
  • Attention 模塊：正被雕成 Linear / Sparse / Sliding-Window 等變種。

而所有變種背後嘅統一目標函數，楊松琳講得好樸素：「給定你相同的 FLOPs，利用這些 FLOPs，取得更低的損失函數」。呢句係成集最重要嘅一把尺——任何架構創新，最後都要用呢條尺去量：同樣算力下，loss 有冇更低？冇嘅，就係花巧。

十、架構嘅未來：干掉全局注意力 + Continual Learning

被問到架構嘅未來，楊松琳畀出兩條具體嘅問題清單：

「架構的未來：1、能不能干掉全局注意力？它是阻止 context window 繼續 scale up 的主要瓶頸；2、Continual Learning，讓 AI 自己學習。」 ——楊松琳（節目 01:02:48 章節）

第一條，正正回應咗成集嘅主線：只要 context window 想繼續 scale up，全局注意力就會係最大嘅成本瓶頸，所以「干掉全局注意力」係一個有明確經濟動機嘅研究方向（而 Sparse「選得準」就係通往呢個目標嘅一條路）。

第二條則跳出「推論效率」，指向「持續學習」——一個同 continual learning 直接相關、亦係好多前沿討論嘅核心議題。

十一、其他訓練細節同「中國算法創新」

節目尾段有幾個值得記低嘅細節：

  • 優化器投入差異：楊松琳觀察到「美國公司更多投入優化器一點，國內在逐步重視」——即係話，架構之外，訓練優化器係另一條被低估嘅戰線。
  • NoPE vs RoPE：位置編碼嘅取捨亦係架構討論嘅一部分。
  • DeepSeek-OCR：被提及為硬件親和探索嘅例子；而 DeepSeek「非常追求硬件和算法的匹配」。
  • Delta Rule + 硬件親和：主線指向「算法要配硬件」呢個實務約束。

關於心態，楊松琳有一句好值得記低嘅話（chapter 01:15:16）：

「當你很清楚地要做什麼的時候，你是不會遇到什麼挫折的。」 ——楊松琳（節目 01:15:16 章節）

佢補充話自己 PhD「還挺順利」，得益於「入學之前嘅半年考古」——即係話，佢喺正式開始研究之前，先用半年時間系統咁讀通咗成條算法變種史。呢個「先考古、後研究」嘅方法論，本身就係呢集最有價值嘅 meta-lesson：喺一個變化極快嘅領域，最穩嘅護城河唔係追最新論文，而係先掌握整條歷史脈絡，先知道「下一個突破點大概率喺邊」。

十二、Vee 嘅萃取：呢集點樣重塑「架構之爭」嘅理解

呢集播出喺 2025 年 11 月，距 Kimi Linear 論文首發（10 月 30 日）只有幾日，所以佢係一個近乎實時嘅技術拆解。讀完之後，我覺得有四點值得長期記住：

  • 「三比一」係一個可驗證嘅行業共識信號：由 MiniMax 嘅 7:1 回落到 3:1，係一個具體、可追蹤嘅工程收斂。日後再見到任何新架構宣稱「純線性可行」，最直接嘅反問就係——「你嘅全局層放喺邊？」
  • 「泛化瓶頸」嘅精確定位係 multi-hop reasoning：線性注意力嘅弱點唔係「唔識長文本」，而係「唔識串連分散線索」。呢個區分對評估任何「壓縮式」方案都好關鍵——你要問：佢丟失嘅係邊類信息？
  • 競爭關係比表面更複雜：Linear 嘅對手係 Sliding-Window，唔係 Sparse；而理想方案係將混合架構嘅全局層換成「選得準」嘅稀疏層。呢個「問題分層」嘅能力，係楊松琳呢集最硬嘅貢獻——佢幫你避開「所有效率技術都係同一條線」嘅粗暴歸類。
  • 「同一 FLOPs 下更低 loss」係唯一嘅尺：呢句話可以過濾掉市場上絕大部分「架構創新」嘅噪音。
行業 insight：呢集真正講嘅唔止係「邊個架構贏」，而係一個更深層嘅判斷——當 scaling 嘅兩條傳統槓桿（數據、算力）都受限時，「算法」就由配角變成主角；而算法創新嘅分布，係跟住「約束」走嘅。中國因為冇咁多卡，被迫將工程師嘅創造力集中喺「點樣用同樣算力榨出更多性能」；於是出現咗 Kimi Linear、DeepSeek Sparse、Qwen3-Next 呢批「雕架構」成果。呢個唔係民族主義敘事，而係一個好標準嘅資源經濟學結論：約束塑造比較優勢。而對於任何一個開發者嚟講，最務實嘅 takeaway 係楊松琳嘅方法論——先花時間「考古」整條變種史，因為下一個突破點，通常藏喺歷史規律嘅延長線上。
一句話記低 FFN 雕成 MoE → Attention 雕成 Linear / Sparse / Sliding-Window；純線性無效，3 層線性 + 1 層全局係當下共識；Linear 嘅真對手係 Sliding-Window，終局想像係用「選得準」嘅 Sparse 取代全局層。衡量任何架構創新嘅唯一尺：同一 FLOPs 下，loss 有冇更低。
