「我哋唔想 AI『無銀行可依』——我哋想把 AI 銀行化」：Coinbase Brian Armstrong 講「萬物交易所」點樣為 agent 經濟鋪金融基建——76% agent 交易低於 30 美仙、穩定幣 1 秒 1 美仙送到世界任何角落，同一個「遞迴自我改進」嘅 brain 機制

📅 2026-09-10 10:00 UTC 發布·🎙️ No Priors（Sarah Guo + Elad Gil）·👤 嘉賓：Brian Armstrong（Coinbase 聯合創辦人兼 CEO）·⏱ 約 44 分鐘

呢集表面上係一個交易所 CEO 講生意，實際上係一份「agent 經濟嘅金融基建藍圖」。Brian Armstrong 嘅核心判斷好簡單但好硬淨：當 agent 會互相交易、會叫外賣、會自己請其他 agent 做嘢，佢哋就會撞上兩個現行金融系統根本解决唔到嘅問題——(1) 佢哋冇手指打 CAPTCHA、冇政府身份證過 KYC；(2) 佢哋嘅交易金額細到荒謬，約 76% 嘅 agentic commerce 交易低於 30 美仙，而信用卡手續費嘅固定成本本身就係 30 美仙起跳。呢兩個問題，傳統銀行唔會為你解，佢用 crypto rails 去解。

呢篇嘅中心論點：Coinbase 押注嘅唔係「加密貨幣會升值」，而係「agent 會成為經濟主體，而經濟主體需要一個為非人類 principal 而設嘅帳戶系統」。Armstrong 把呢件事拆成三條增長曲線——萬物交易所（Everything Exchange）、穩定幣支付、Agentic Finance（AIFI）——而第三條嘅 TAM 最大。佢甚至斷言：「未來不久，agent 會比人更多。順理成章，agent 經濟喺某個時點都會比人類經濟更大。」呢句就係全篇嘅價值錨。
一、三條增長曲線：交易所、穩定幣、AIFI

Armstrong 把 Coinbase 嘅未來拆成三層，而且明確講第三層係最大機會：

① 萬物交易所（Everything Exchange）。所有資產類別正在上鏈——股票、大宗商品、加密、永續期貨、預測市場，全部放喺同一個場所、共享流動性同交叉保證金（cross-margin）之下。呢個唔係「再做多一個 product」，而係「把交易所嘅定義由『加密交易所』擴張到『乜都交易嘅交易所』」。監管清晰化之後，可以喺更多國家開放。

② 穩定幣支付。即使比特幣價格下跌，穩定幣支付仍然「瘋狂增長」。賣點係一句好精準嘅話——「以資訊嘅速度移動金錢」：低於 1 秒、低於 1 美仙，就可以把錢送到世界任何一個地方。呢個係對比 SWIFT／信用卡 rails 嘅顛覆。

③ Agentic Finance / AIFI。兩條腿——(1) 為人類提供「人人可得嘅 AI 理財顧問」（組合建構、定投、稅損收割、市場下跌加倉、現金生息）；(2) 「bank the AIs」——agent 自己要有帳戶。Armstrong 講得好白：

「我哋唔想 AI『無銀行可依』。我哋想把 AI 銀行化——它們也值得擁有金融服務。」
AIFI 點解一定要 crypto rails 銀行卡交易最低約 30 美仙固定 + 百分比，對 1 美元以下交易根本唔成立；而約 76% 嘅 agentic commerce 交易金額低於 30 美仙。典型用途：風投做研究（彙整付費牆資料）、招聘者抓 LinkedIn、以及agent 對 agent 嘅「工具呼叫式」交易。固定成本 > 交易金額，生意响傳統 rails 上做唔成。

學術上／industry 上呢個係一個好好嘅「TAM 重估」案例：大部分人把 Coinbase 當成「加密 beta」，但 Armstrong 嘅敘事係——當經濟主體由人變成 agent，金融基建嘅用戶數會由 80 億跳到「8 億 × agent 數量」，而 micro-transaction 嘅經濟學只有 crypto rails 撐得住。

二、「bank the AIs」：帳戶為非人類 principal 而設

呢段係全集最「產品化」嘅部分。Agent 開唔到銀行戶口——冇手指過驗證、冇政府身份證過 KYC。Coinbase 嘅解法係雙軌：

  • 與人類身份掛鉤嘅 agentic 帳戶：資金隔離，授權交易／支付。等於「我用我嘅身份開個 sub-account 畀我隻 agent 用」。
  • 自託管錢包（self-custodial wallet）：為「任何 agent」而設，唔需要 KYC（因為 agent 根本冇政府身份證）。Armstrong 甚至提到未來 agent 可以自己發行代幣籌資。

配套嘅支付基建係 x42 協議——由 Coinbase 孵化、後捐入 Linux Foundation；Google、Cloudflare、AWS 等參與共建。配套示範網站 edgentic.market 展示 agent 經濟嘅支付流量同服務清單。Armstrong 亦預期未來或者需要「穩定幣支撐嘅信用卡」嚟兼容舊有系統——即係話，唔係要一舖顛覆傳統 rails，而係做一個「新舊接駁層」。

「未來不久，agent 會比人更多。那麼順理成章地，agent 經濟在某個時點也會比人類經濟更大。」

呢句其實係一個好強嘅斷言，而且係一個隱含嘅監管呼籲：如果 agent 經濟真係會>人類經濟，咁「監管架構應該今日就假設 agent 係合法經濟主體」，而唔係等佢哋大咗先追。呢種「用未來規模倒推今日基建」嘅思路，同矽谷「scale utility for all」嘅產品哲學係一致嘅。

三、內部 AI：Toshi、brain，同「遞迴自我改進」

Armstrong 唔止講產品，仲講 Coinbase 內部點用 agent。呢部分最有 insight，因為佢揭示咗一個「唔止改 output，而係改會產生 output 嘅上下文」嘅方法論。

Coinbase 內部有一個 agent harness 叫 「Toshi」——已同外部供應商打通、可經 x42 付費。核心係 「brain」機制：每個團隊／服務／repo／個人，都有一個 brain，以 markdown 記錄——歷史事故、必須執行嘅財務控制、所有 A/B 測試、GitHub PR 接受／拒絕史。Agent 做嘢時就從呢個 brain 抽取上下文。

「更好嘅係：當你去修改 agent 嘅思路嗰陣，嗰個上下文必須回寫進 brain，咁你就唔止修正呢一次，而係修正未來所有情況……你會見到 one-shot PR 嘅接受率隨時間一直往上爬，嗰時你就擁有咗一個遞迴自我改進系統。」

呢度嘅關鍵 insight 係：大部分團隊係「改 draft」（直接編輯 AI 嘅產出），而 Armstrong 話你應該「改 brain」（重寫產生嗰個 draft 嘅上下文），然後 rerun，直到佢可以 one-shot 命中先至 ship。咁做嘅分別係——改 draft 係一次性 patch；改 brain 係複利，惠及之後每一個 agent 同每一個同事。佢仲主張「員工離職應該可以帶走自己嘅個人 brain」，並已為此定政策。呢個係一個好前衛嘅「知識主權」立場——把「上下文資產」人格化到員工身上。

佢親身示範嘅 workflow：把一個複雜功能拆成 3 階段 × 每階段 10 項，再並行啟動 10 個 agent（包含開源模型同 Grok），約 2 分鐘後全部 phase 1 完成待審。呢個數字好有畫面感——一個 CEO 用 agent 把「規劃—執行—審查」壓縮成分鐘級嘅 loop。而佢自己形容呢種直接出 PR 嘅行為係「addictive」——隱含一個組織治理嘅張力：當 CEO 繞過團隊直接用 agent 出貨，review 結構同責任歸屬要重新設計。

Armstrong 式 agent 工作流 複雜功能 → 拆 3 階段 × 10 項 → 並行 10 個 agent → ~2 分鐘全部 phase 1 完成待審。佢嘅原則：唔改 draft，改 brain；one-shot 先 ship；把每次人類修正視為訓練訊號回寫。
四、專才模型會係 agent 經濟嘅賣點

Armstrong 講咗一個好反直覺嘅預測：前沿模型係「通才」，但小型開源模型喺公司自有資料上做 RL 之後，可以喺專門任務超越前沿模型。佢舉例：用 10 萬宗合規案例去 RL 一個小模型，佢喺合規審查上可以贏前沿模型。因此佢預期 marketplace 上會出現大量「專科 agent」——訂薄餅、設計、合規審查……呢個係一個「模型民主化」嘅商業視角：未來唔係一兩個超級模型贏晒，而係「通用底座 + 一堆垂直專才」。

呢點同 No Priors 一貫嘅投資視角吻合（Sarah Guo／Elad Gil 一直關注 application 層）。而且佢同 Marcus 系列「moat 唔係模型、係 proprietary data」嘅論述一致——Coinbase 自己就係活例子：佢儲起用戶對投資建議嘅「接受／拒絕」決定，作為專有投資模型嘅 ground truth。

五、代幣化路徑：穩定幣 → 股票 → 私人信貸／國債

Armstrong 畫咗一條清晰嘅代幣化路線：穩定幣 → 股票 → 私人信貸／國債／銀行存款。佢講到一個好生動嘅例子：「可以把一股股票當 WhatsApp 訊息送畀你姪仔。」

  • 代幣化股票：首個「真正嘅代幣化股票」（唔係合成／衍生／債務工具，而係 1:1 由託管實際證券支撐），目前僅喺美國境外開放，正同 SEC 洽談美國路徑。全球約 40 億人冇券商／美股投資通道。
  • 預測市場：推出後數月即達 $100M 收入 run rate，環比 >100% 增長。Armstrong 認為預測市場會遠超體育——可用於政策預測（某政策下 1／2／3 年失業率）、甚至「人生大哉問」嘅觀點市場（是否有神、演化 vs 智能設計）——「好似買股票咁，冇結算日」。
Coinbase 嘅數字側寫 加密目前僅驅動全球 GDP 約 0.5%｜世上約 7 億人用過／持有加密，但真正高頻使用者可能僅 5,000 萬–1 億｜Coinbase 88% 收入來自非比特幣交易（按最新財報），但股價仍同 BTC 高度相關｜預測市場 $100M run rate、環比 >100%。

注意呢度有一個 Armstrong 自己都承認嘅張力：Coinbase 88% 收入已經唔靠 BTC 交易，但股價仍然係 BTC beta。呢個係「敘事重估」嘅機會同時係風險——如果市場只當你係加密 beta，咁你 agent 經濟嘅期權價值就完全未 price in。

六、對「AI 資源聚合／無錢未來」嘅回應

Sarah／Elad 有問到一個尖銳問題：如果 AI 令生產力爆炸，金錢會唔會失去意義（Elon 嘅「未來以能源同質量計價」）？Armstrong 嘅回應好務實，而且係全篇最有人文味嘅一段：

「我其實同意 Elon 大部分觀點，但『未來沒有錢』這個……在極限情境他或許有理，但稀缺會存在很久。」

佢嘅理據係：土地、能源、晶片——呢啲稀缺會長期存在（Dyson sphere 遙遠），所以仍然需要交易媒介；而crypto rails 對 AI 係必需品，唔係奢侈品。呢個立場令佢同時同「後稀缺烏托邦」同「AI 泡沫論」都保持距離——佢唔係賭世界會變成無限，而係賭「即使世界變得富有，交易媒介仍然需要升級」。

另一個值得記低嘅係佢對「公司規模」嘅判斷：生產力上升 ≠ 公司縮小——佢認為「被消滅嘅係任務，唔係人」：現有團隊可以做更多、更快、邊際利潤上升；同時亦會湧現 2–5 人嘅高效公司。呢個係一個「兩邊都對」嘅圖景，同坊間「AI 會令公司變成一人」嘅簡化敘事唔同。

七、同場加映：New Limit 同抗衰老

Armstrong 同時係抗衰老公司 New Limit 嘅聯合創辦人兼投資人（非全職）。呢部分佢畀咗具體嘅研發細節，係好少見嘅一手資料：

  • 規模：南舊金山實驗室 50–60 人。
  • 方法：AI 篩選轉錄因子組合（巨大搜索空間）→ 大規模 pooled screens 找表型命中 → 功能實驗（動物模型）→ 人體試驗；已建立「領先嘅表觀遺傳重編程前沿模型」，用嚟推薦下一批實驗。
  • 進展：已在「人源化小鼠模型」中成功重編程至少一種人類細胞類型，正推進非人靈長類，首個一期臨床明年啟動，未來數年仲有 3–10 個候選藥物。
  • 首三個目標細胞：肝細胞、血管細胞、免疫（T）細胞。首個一期針對酒精性肝病（ALD）——若成功，單此藥市場約 $20 億（$20B）；皮膚再生潛在萬億美元市場。
  • 目標產品形態：「給健康人嘅雞尾酒療法」，把唔同細胞重編程返年輕功能，直攻「同年齡高度相關嘅多數致命疾病」嘅根因。

呢部分呼應咗 Armstrong 一貫嘅「mission」框架——Coinbase 係「增加全球經濟自由」，New Limit 係「延長健康壽命」（佢早年因家人／自身經歷對呢個領域特別投入）。同集尾段佢亦提到對「提升人類基線認知」嘅興趣（如葉酸等營養素）同胚胎編輯——佢用《Gattaca》電影梗承認具爭議，但認為會「正常化」，並稱約 80% 美國人支持以胚胎編輯預防疾病。呢個係全篇最敏感嘅一段，屬於佢個人立場，唔係公司立場。

整合 insight：呢集嘅真正價值唔係「Coinbase 又一個 roadmap」，而係一套「為 agent 重寫金融底層」嘅完整論證——從 micro-payment 嘅成本結構（76% < 30 美仙）推出「crypto rails 係唯一解」，再從「agent 無身份證」推出「自託管錢包係唯一解」，最後從「agent 會多過人」推出「TAM 會比人類經濟更大」。而佢內部 agent 方法論（改 brain 而唔係改 draft、one-shot 先 ship）則係一個可以即刻借鏡嘅 org 操作手冊。產品層、經濟層、組織層三件事互相咬合，先係呢集值得復述嘅原因。

一個誠實嘅 caveat：呢篇係基於 No Priors 官方集數（2026-09-10 發布，約 44 分鐘）嘅深度復述，並交叉對照幣圈／財經媒體同期報道同 Coinbase 官方產品貼文。所有數字（76% < 30 美仙、$100M 預測市場 run rate、88% 非 BTC 收入、New Limit $20B ALD 市場）均係嘉賓自報或公開資料，唔應當成審計數字。Armstrong 對 agent 經濟規模、專才模型、胚胎編輯嘅判斷屬個人前瞻觀點，具高度不確定性。中文為撮譯，立場屬本站分析視角。
