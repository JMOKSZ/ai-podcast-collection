「2.4T 參數、4% 激活、下週開源」——Qwen 3.8 Max：阿里用生態採用率打贏獨家溢價，中國開放權重前沿正式踩入 2.4T 量級

上年「Qwen 團隊出走」之後，新管理層接手、連續推出閉源 API，外界一度懷疑呢個開放模型領頭羊仲會唔會出真正有份量嘅開放模型。8 月 4 日凌晨 Latent Space 嘅 AI 新聞日報開場就講：呢個懷疑，而家可以收皮喇——阿里發布 Qwen3.8-Max，一個 2.4T 參數嘅巨型稀疏模型，如果唔係一個星期前 Kimi K3 搶先發布，佢就係世界上最好嘅開放模型。

一、故事開頭：一個懸念嘅終結

Latent Space 用咗一段好長嘅背景交代點解呢單發布咁重要：去年 Qwen 團隊出走潮之後，市場擔心阿里會唔會放棄開放模型路線；當新管理層接手、連續幾個月淨係出閉源 API 嗰陣，呢個懷疑更加具體。但 Qwen 3.8 Max 一次過證明——開放模型路線冇死，而且直接推上 2.4T 量級：

「That doubt is now gone. Qwen 3.8 Max is a MONSTER 2.4T model that would have been the top open model in the world but for the Kimi K3 release we already covered.」 — Latent Space [AINews] 2026-08-04

發布推文（2:15 AM · Aug 3，496 萬瀏覽、2.5K 轉推、20.1K 讚）內容簡潔有力：Qwen3.8-Max 係「coding and cowork 嘅新標竿」，2.4T 參數，下週開放權重；Qwen3.8-27B 亦會一齊開放。API 定價 $2 / $6 / $0.25（每百萬 token 輸入/輸出/緩存命中）——比上一代 Qwen 3.7 Max 嘅 $2.50 / $7.50 明顯降價。

二、演示級長程能力：10+ 日編碼、125 小時研究、晶片設計、365 日電商

阿里今次嘅發布框架好特別——佢冇主打「chatbot 幾聰明」，而係主打「long-horizon agentic work」：一個模型可以唔睇住做嘢做足十日。官方列嘅示範能力：

  • 10+ 日無人值守編碼：由空白資料夾開始，自建一個 self-evolving coding harness，喺多星期嘅自主運行入面完成成個 production 項目，完整 project trace 公開喺 GitHub。
  • 125 小時自主 AI 研究：由零重建一篇論文嘅完整 pipeline（Unified Data Selection for LLM Reasoning），然後自主運行迭代研究循環 125 小時，發明咗一個新嘅數據選擇方法，喺 benchmark 上贏原論文 +2.71 分。
  • 競賽級數據科學：喺 WWW2025 多模態對話意圖識別挑戰賽對戰 526 支人類隊伍，24 小時內打入前 13%（贏 87% 人類隊伍）。
  • 完整晶片設計流程：由 RTL 編輯到模擬、綜合、物理佈局完整走完一個硅片設計流程（GCD/RSA 加密加速器）——gate count 由 8,298 減到 678，die 面積減 81%，仲做到 500 MHz 嘅物理時序閉合。
  • 365 日電商營運：喺 E-Commerce Bench（365 日商店營運模擬）上，透過持續嘅博弈論式談判同庫存規劃，做出 4.16x 回報（¥416,252 結餘）。
  • 原生多模態執行循環：視覺係執行循環嘅一部分而唔係單純輸入通道——planning、coding、GUI 交互都有視覺回饋；另發布 Qwen-MM-Plugins 將多模態能力擴展到現有 agent 框架。
數據官方示範數字：10+ 日自主編碼、125 小時研究循環（+2.71 分贏原論文）、gate count 8,298 → 678（die 面積 -81%、500 MHz 閉合）、電商模擬 4.16x 回報、WWW2025 對戰 526 支人類隊伍入前 13%

我嘅 insight：留意呢串數字嘅共通點——全部係「持續目標維持」（persistent objective maintenance）嘅任務，冇一個係單輪問答。阿里明顯係瞄住「long-horizon agents」嘅 discourse 嚟設計發布：10 日編碼、500+ turns 晶片優化、365 日商業策略，全部係考驗模型「記得住目標、唔走樣、識恢復」嘅能力。呢個係 2026 年 agent 時代最核心嘅能力維度，亦係「模型係 harness 嘅 substrate」呢個敘事嘅官方背書——佢唔係賣一個聊天機械人，而係賣一個「可以放喺 harness 入面長跑」嘅引擎。

三、第三方評測：真金白銀嘅排行榜位置

官方數字信唔過，第三方評測先係重點。今次嘅第三方結果異常強勁，尤其喺 coding、視覺同設計類：

  • Frontend Code Arena：以 1,668 Elo 首發即 #4 整體——僅次於 Claude Opus 5 [Max]（1,705）同 Kimi K3 [Max]（1,676），同 Claude Opus 5 [High]（1,669）幾乎打和。細分榜：#2 Consumer Product、#3 Brand & Marketing / Reference-based design / Gaming / Content Creation Tools、#4 Data & Analytics、#5 Simulations。
  • Vision Arena：#2（1,305），只落後 Claude Fable 5 [High] 13 分。
  • Vals Index：開放權重模型 #2、43 個模型中整體 #10，得分 66.1——同 Claude Opus 4.7 完全打和（66.1 vs 66.1），但每次測試成本只係 $2.68 vs $6.17，平 2.3 倍。
  • SWE-bench：87.3%——贏 GPT-5.5（82.6%）同 GLM-5.2（83.3%），輸畀 Claude Opus 4.8（89.2%）。
  • Terminal-Bench 2.1：67.4（上代 Qwen 3.7 Max 係 61.0）。
  • Vals 評估設定：1M token context、128k max output、temperature 0.7。

ZhihuFrontier 另補充咗一組規格數字：95B active parameters per token（激活率約 4%）、1M context、API 提供 low/medium/xhigh 三檔推理強度、兼容 OpenAI 同 Anthropic 協議；benchmark 宣稱 PaperBench 93.0、CoWorkBench 74.8、WideSearch 81.9。

數據進步速度：Qwen 3.7 Max = 57.5 → Qwen 3.8 Max = 66.1，約 2.5 個月 +8.6 分；同時輸入/輸出定價由 $2.50/$7.50 降至 $2.00/$6.00 ——「又強咗又平咗」一齊發生

社區入面仲有一啲更進取嘅演繹：「Opus 4.8 大部分能力已被 3.8-Max 覆蓋」（有人重畫 benchmark 圖表後嘅判斷）、「Qwen 3.8 喺 Terminal Bench 贏咗 Fable 5，Anthropic 明顯受壓」——呢啲係生態解讀而唔係嚴格測量，但連埋一齊睇，方向好清晰。

四、關鍵分歧一：「操作上開源」≠「本地跑得起」

今次討論最大嘅冷卻劑嚟自 Jamin Ball（Benchmark Capital）：佢話淨係比「vanilla token 價格」係誤導，因為呢啲模型大到你根本冇辦法當佢係普通開源模型：

「Qwen 3.8 Max >2T params；Kimi K3 ~104B active per token，淨係載入權重就要 >1TB 記憶體，至少要 8 張 H100/B200 先跑得起，Moonshot 建議 64+ 加速器嘅 supernode 配置……一個 2.4T-class MoE 唔係 commodity local model。」 — Jamin Ball（@jaminball），2026-08-03/04

StableQuan 講得更白：長 prompt、RAM 爆滿、tool call 慢——巨型模型喺消費級硬件上好痛苦，建議直接用 API。呢個就係開放模型故事入面最關鍵嘅 split：

「生態影響力同 benchmark 合法性嚟自 2.4T 旗艦嘅發布；實際規模化採用，可能嚟自 27B 嘅發布。」 — Latent Space [AINews] 對社區討論嘅總結

我嘅 insight：呢個 split 係理解成個開放權重時代嘅鑰匙。2.4T 旗艦嘅戰略價值根本唔喺「有幾多人自託管佢」——佢係一個「合法性錨點」：證明開放路線可以企喺前沿、令第三方 benchmark 榜單有你個名、令整個生態（Baseten、Hermes Agent、Cline、Venice 全部即日宣布支援）以你為中心轉。真正承擔「採用」任務嘅係 27B 小弟——細到個人開發者跑得起，先至有 developer lock-in。呢個係「用旗艦立旗、用小弟圈地」嘅雙層戰略。

五、關鍵分歧二：許可證——「開放權重」可以好唔開放

最具體嘅質疑唔係性能，而係許可證。OstrisAI 讀咗條款之後指：許可證似乎禁止美國、歐盟、英國同韓國使用，甚至連「從美國下載模型」都可能被禁。呢個擔憂同 MiniMax H3 嘅討論互相呼應——當時有人話 H3 嘅公開許可證令佢喺美國/歐盟/英國/韓國「唔合法可用」（後來 MiniMax 方面澄清係需要正式授權流程，唔係完全禁止）。截至今期新聞，阿里自己冇出澄清推文，所以「限制性許可證」嘅解讀喺數據集入面仍然懸而未決。

「對於工程師嚟講，呢個比 marketing label 更重要。『開放權重』仍然可以意味住：冇 OSI 式開源權利、有用例限制、有出口/司法管轄限制、或者喺關鍵地區冇商業部署嘅法律許可。呢個許可證嘅模糊性，正係今次反應比慶祝更謹慎嘅主要原因之一。」 — Latent Space [AINews] 2026-08-04

我嘅 insight：「Open weights ≠ open source」呢個提醒好重要，尤其對做企業採購嘅人。你見到「開源」兩個字，要問嘅唔係「權重俾唔俾下載」，而係：邊個司法管轄區用得？商業用途俾唔俾？fine-tune 之後條款點算？呢個模糊性唔係 Qwen 獨有——係 2026 年所有中國開放權重模型嘅共同陰影，亦係「開放權重」呢個詞越來越需要逐字讀條款嘅原因。

六、戰略解讀：阿里由「獨家溢價」轉向「生態採用率」

ZhihuFrontier 嘅框架被今期新聞引為標準解讀：呢個唔係一次例行產品更新，而係阿里的戰略轉向。以往 Max 系列保持閉源，開放路線頂多到 Qwen3-235B；今次將 2.4T 旗艦開放權重，係因為 DeepSeek、Kimi 等中國開放模型已經削弱咗「頂級系統 API-only 溢價」——既然保留獨家都收唔到溢價，不如用生態採用率競爭。社區嘅反應：

  • 「中國不再落後，而係平等競爭」（@kimmonismus）
  • 「前端設計榜前三位，而家有兩個中國模型一個西方模型」（@kimmonismus）
  • 「仲記唔記得中國曾經落後兩年？」（@matvelloso）
  • 「過去兩年 open weights frontier 一直由中國實驗室主導」（@_micah_h）——Hugging Face CEO 亦喺 CNBC 講「中國正贏緊開放模型」；Artificial Analysis 歷史數據則顯示中國領先模型平均落後美國頂尖 3–9 個月

更深一層嘅 subtext：護城河正在轉移——唔再係 raw pretraining，而係 post-training、agent harnesses、推理基建、蒸餾 pipeline 同 developer lock-in。呢個正正解釋咗點解一個「好少團隊會真係自託管」嘅 2.4T 開源旗艦，戰略價值依然巨大。

七、架構信號：4% 激活率嘅稀疏 MoE

如果 ZhihuFrontier 嘅 95B active / 2.4T total 數字屬實，Qwen3.8-Max 每 token 只激活總參數嘅約 4%——對比 Qwen3-235B-A22B 嘅約 10%。呢個係阿里明顯比對手更進取嘅稀疏化：

「Frontier open models can look 'huge to store yet still cheap to run' by only activating a narrow expert slice per token.」 — @ProfTomYeh，轉述稀疏 MoE 討論嘅核心

呢個架構方向好可能就係阿里可以「總參數量級上升、API 定價反而下降」嘅原因：更大嘅 expert pool + 更低嘅 active footprint + 更低嘅有效推理成本——假設 routing 同系統優化喺生產環境頂得住。

九、行業信號總結
「中國開放權重前沿嘅競爭，由 100B 級推到 2.4T 級，而且定價低過自家前代——『開放模型而家喺贏』。對 Anthropic/OpenAI 嘅壓力係結構性嘅：閉源溢價只能靠 token 效率 + harness 體驗維持，而 Qwen 3.8-Max 嘅長程自主示範（10 日編碼、125 小時研究、晶片設計）直接打向 agent 時代嘅核心賣點。」 — 本文整合自 Latent Space [AINews] 2026-08-04 及每日報告

我嘅 insight：將今期三條線放埋一齊——2.4T 旗艦開源、4% 激活率嘅架構、以及「護城河由 pretraining 轉向 harness/post-training/蒸餾」嘅共識——會得到一個重要結論：「開放 vs 閉源」嘅戰場已經由「模型能力」移咗去「生態同 harness」。模型能力方面，中國開放陣營已經企喺同 Western closed 差一個身位嘅位置（3–9 個月、而且每個月喺度收窄）；真正未定勝負嘅係：邊個嘅 harness、蒸餾 pipeline、developer 生態圈得住人。阿里用 2.4T 旗艦做「立旗」，用 27B 做「圈地」，呢個打法嘅成敗要等到下週權重真係開放、社區真係跑得起先見真章——尤其許可證問題一日未澄清，一日都係懸喺頭上嘅問號。

一句話總結：Qwen 3.8 Max 係「Qwen 團隊出走」後阿里開放路線嘅終極宣言——2.4T 總參數、約 4% 激活、$2/$6 定價、Frontend Code Arena #4 / Vision Arena #2 / Vals Index 66.1（同 Opus 4.7 打和但平 2.3 倍），示範能力全部係 long-horizon agentic 任務（10 日編碼、125 小時研究、晶片設計、365 日電商）。但「開放權重」三個字背後仲有兩個未解問題：2.4T 冇幾多個人真係跑得起（真正採用可能靠 27B 小弟），同埋許可證對美/歐/英/韓嘅限制一日未澄清，一日都係企業採用嘅絆腳石。
