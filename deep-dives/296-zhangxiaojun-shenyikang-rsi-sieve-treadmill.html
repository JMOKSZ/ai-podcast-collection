「跑步機還在加速」——沈驛康把 RSI 從加速器降級成篩子

〈【2026 年復盤】和沈驛康聊，黃仁勳、xAI 內幕、RSI、持續學習、去中心化、預訓練白盒、矽谷創業地圖〉
出品：張小珺 Jùn｜商業訪談錄·主持：張小珺·嘉賓：沈驛康（一康）
發布：2026-11-24 23:30 UTC·時長：3 小時 22 分·中文訪談
來源：小宇宙單集音頻轉寫（約 170 / 202 分鐘，17 / 21 段成功）；引語以節目原話為準，缺失段落不作推測

這一集錄在一個很窄的時間裂縫裡：黃仁勳辭職後一週，英偉達宣布他復職的前一天。節目沒有事後補拍那種「我早就說過」的從容，而是把當時市場上那種「不知道誰在簽字」的震盪原樣保留。三個多小時之後，話題從黃仁勳一路走到 xAI 內幕、2026 年的模型跳變、RSI、持續學習、去中心化，最後落在矽谷創業地圖與預訓練的技術路徑。

但如果只帶走一句話，我會帶走這個比喻：

「訓練模型更像是芯片的生產廠商不斷去迭代製程的一個過程。張忠謀說生產芯片像是在跑步機上的一個比賽，你一旦有一個人掉下來了，你就再也上不去了，而且這個跑步機還在不斷加速。」 —— 沈驛康，談預訓練的競爭結構（節目原話）

這句話之所以重要，不是因為它把 AI 比作製造業——這個類比已經被說爛了——而是因為它順著這個類比，把「遞歸自我改進」（RSI）的位置重新擺了一次。在那條跑步機上，RSI 不是腳下的加速帶，而是跑道邊的淘汰線。

一、先把人放回時間裡：一個「震盪中的一線」樣本

沈驛康的履歷很適合做這種長訪。2016 年起在蒙特利爾讀博，研究語言模型架構，從 LSTM 一路做到 Transformer；拿過 ICLR 2019 最佳論文；在 IBM 負責整個預訓練團隊，從數據、架構到 scaling 方法全鏈條參與；2025 年初加入 xAI 預訓練團隊，負責模型架構設計與放大時的問題——放大四倍時的精度、穩定性、attention 梯度、loss spike；現在是矽谷創業公司 Learning Machine 的創始人兼 CEO。

他與 MIT 合作過的 Gated Linear Attention、DeltaNet 後來被廣泛採用。節目裡他給了一個很具體的傳承鏈條：「最新的 Kimi 裡面的 KDA 模型，實際上就是當時我們研究的 Gated Linear Attention 和 DeltaNet 的一個整合。」這句話聽起來像技術八卦，其實是全集的方法論伏筆：架構創新不是一次性的靈感，而是會在幾年後以另一個名字回到生產系統裡。你如果只看當年的 benchmark，會完全錯過它。

也因為這個背景，他談 RSI 的方式和純粹的理論派不同。Dwarkesh 從「可驗證性」推時間表，Christiano 從「優化壓力」推風險，沈驛康則是從「訓練車間裡到底誰在做什麼」往回推：哪些環節已經可以放手，哪些環節放手之後會出事，哪些環節根本還不存在。

二、製造業類比的三層含義

「訓練是製造業」不是一句修辭。把它拆開，至少有三層可操作的含義：

層次製造業的對應對 AI 預訓練的含義
製程迭代每一代晶圓製程都要重解良率、功耗、穩定性模型放大四倍，attention 的 loss gradient、整體 loss spike、數值精度全部要重解，沒有一勞永逸的配方
跑步機競爭者不會等你；掉隊一次就回不去算力、數據、人才、現金流同時是門檻；落后一代不是「少一個功能」，是「少了下一代的入場券」
良率文化不是做出一個樣品，是每次都做出來訓練的可重現性、監控、資料清洗、失敗復盤，才是團隊真正的資產

這三層合起來，會得到一個和「AI 研究像科學」很不一樣的圖像。科學的隱喻強調突破、靈感、範式轉移；製造業的隱喻強調節拍——你能不能在下一個節拍之前，把上一代的問題修完，並且把經驗沉澱成流程。

這也是他對 RSI 保持保留態度的底層原因。不是他不相信模型會變強，而是他每天看到的「變強」，大部分長得像製程改良：清潔資料、換優化器、重寫 kernel、合成資料補短板。這些事當然有價值，但它們的形狀是把已知的曲線再往前推一點，不是長出一個原本不在菜單上的能力。

三、RSI 的兩層定義：線性外推 vs 發明新能力

節目裡他給了一個最低定義，我覺得是整集最值得抄下來的一段：

「用現在的 GPT-4 去訓練下一代 GPT-5，人在這個過程中不需要介入」——清理髒數據、換優化器、重寫 kernel 讓訓練快 10%、自動生成數據補短板，這些都算。 —— 沈驛康對 RSI 最低門檻的表述（節目原話大意）

注意這個定義的野心其實不大。它說的是「研究流程自動化」，不是「智能爆炸」。而他自己也立刻把這層降級了：

「目前看起來可能還沒有真正去解決。」 —— 沈驛康談「發明新能力」這一層 RSI 的現狀（節目原話）

他把真正的標誌放在「提出自己原來沒有的新能力」：在一個沒有 CoT 的模型上發明 CoT；或者從純文本跨越到多模態。這個區分很關鍵，因為它把當下很多「AI 做 AI research」的 demo 直接劃到了另一邊。

我的延伸：這兩層其實對應兩種完全不同的經濟學。第一層是成本曲線——同樣的研發，用更少的人、更短的週期完成，優勢是線性的、可被競爭對手複製的。第二層是能力邊界——長出一個原本不存在的模態或推理形式，優勢是結構性的、會改變下游所有應用的可能性。市場經常把兩者混為一談，因為它們在 benchmark 上都表現為「分數上升」。

他還給了一個很工程師的判據：research agent 讀用戶數據、讀訓練日誌、讀網上新論文，定位低效點，重寫 kernel、換優化器、清洗數據、合成數據，把下一代模型的某個維度抬 10–20%。這件事如果穩定發生，就是第一層 RSI 成立。但如果它只會在被指定的維度上抬 10–20%，那它仍然是一個非常高級的實習生，不是一個會自己選研究方向的研究員。

四、泡沫：技術樂觀，市場謹慎，「loading」不是問號

他對泡沫的態度是分裂的，而且分裂得很清楚：技術側樂觀，市場側謹慎。

謹慎的依據是剛性支出。OpenAI 與 Anthropic 每年各有 500–600 億美元甚至更多的算力支出。這筆錢不會因為模型變好而自動消失；如果換不成真實收入，它就會從資產變成包袱。但他不認為這會導致崩盤，而是「一到兩年」的清理期，參照互聯網泡沫最艱難的那一段。

最有意思的是他對「缺口」的命名。別人問「AI 的收入在哪裡」，他給的答案不是問號，而是：

「我覺得這個不應該是個問號，而是一個類似於它在等待的一個符號，就是它在一個 loading 的符號。」 —— 沈驛康談 AI 經濟閉環的缺口（節目原話）

他的證據來自自身：公司十幾個人，做的事相當於過去幾十到幾百人的團隊。也就是說，供給側的效率提升已經真實發生。缺口在需求側——大公司「沒有因為 AI 而擴張產品線，也沒有因為 AI 大幅增加用戶基數」，所以效率提升無法直接變成收入。

數字十幾人 vs 過去幾十到幾百人：這是「loading」最直觀的微觀證據。生產函數已經變了，但組織的產品線與用戶基數還沒變，於是效率停留在成本項，沒有進入收入項。

這個判斷比「泡沫論」和「奇點論」都更難反駁，因為它把問題從「模型行不行」移到了「組織能不能吸收」。技術不會停下來等組織；組織也不會因為技術變快就自動重組。中間那段時間，就是他所說的 loading。

五、Coding 已經追不上：一兩週變一兩天，人的位置退到方向

如果只聽一句「AI 寫 code 很強」，你不會知道強到什麼程度。他給的對比很具體：

  • 去年用 Claude 寫手機應用，「非常粗製濫造」；
  • 今年同一個任務，「整個代碼質量、工程 organized 的程度、乾淨的程度，其實已經超過我能夠做的範圍了」；
  • 「今年就是有經驗的程序員已經有點追不上 AI 了。」
  • 原本一兩週的工作量，現在一兩天完成。
  • 訓練前的數據排查，從一兩週縮到一小時量級。

但他沒有把「人」寫死。他保留的介入點是方向性決策：例如寫 kernel 時，agent 過於保守、對數據精度要求過高，需要人去調整邏輯。這是一個很成熟的協作分工——AI 負責在既定方向裡把工程做到極致，人負責判斷這個方向值不值得、以及在哪裡放寬約束。

「今年就是有經驗的程序員已經有點追不上 AI 了。」 —— 沈驛康談 coding 能力的年度變化（節目原話）

這裡有一個容易被忽略的推論：如果 coding 是 AI 研究的主要執行層，而 coding 已經可以基本放手，那麼「AI 做 AI research」的第一層 RSI 在工程上其實已經接近成立。真正卡住的不是手，是選題——知道下一個該解什麼問題、以及判斷一個負結果值不值得繼續。這正好對應他說的「發明新能力」。

六、誰被吃掉：Agent 公司的護城河，NewLab 的不對稱賭注

他對應用層的判斷很冷酷：「每一次模型的提升都會把一些原來我們需要膠水層的東西吃掉。」Agent 公司的護城河很快消失，因為它們大多建立在「模型還不會做某件事」的時間差上。Frontier Lab 又從 coding 擴到 agentic、connector、讀郵件、做 PPT，持續蠶食應用層。

在這種挤压下，他把公司分成三類：

類型護城河來源被吃掉的風險
Agent / 應用公司膠水層、工作流、分發高——模型每升一代，膠水就薄一層
Frontier Lab預訓練能力、算力、人才密度低——但資本支出與收入閉環壓力大
NewLab換一條技術路線，成功後形成不對稱優勢短期最低——因為大廠不會跟進未驗證的路線

NewLab 的邏輯不是「我也做一個更大的模型」，而是「我賭一個不同的技術路線，如果它成立，頭部玩家切換的成本會很高」。這也解釋了為什麼他說 NewLab 短期反而有寬鬆的生存環境：不是因為它強，而是因為它不在別人的最優路徑上。

但他也給了期限：這個寬鬆期只有一兩年。這與「NewLab 是新一代基礎模型公司」的敘事並不完全一致——他的版本更像「NewLab 是一次有時間窗的技術套利」。

七、架構回歸：Transformer 不是終局

去年業界還有人認為 Transformer 是終局。今年開源側集體改架構：千問的 GDN（Gated Attention Network）、Kimi 的 KDA、DeepSeek 的 sparse attention、hyper-connections，加上 Muon 一類新優化器，從 frontier lab 內部擴散到學術界。

「學術界已經達到了一個接近 frontier lab 基礎的水平……不是那種完全是有和沒有的區別了。」 —— 沈驛康談架構研究的擴散（節目原話）

他點名 Marine 模型由黃仁勳夫婦的基金會支持，性能接近同尺寸 frontier 開源模型（節目中對參數規模的口徑略有游移，從數十 B 到 500B 級別）。這個細節的意義不在於某個模型，而在於預訓練的知識正在從少數實驗室外溢：架構、優化器、資料配方，不再是黑箱。

還有一個對英偉達不太友好的推論：CUDA 護城河正在被 agent 削弱。

「Agent 可以迅速幫你把底層軟件 infra 補全，我遷移的成本就低很多了，這個時候 CUDA 的護城河就基本上很弱了。」 —— 沈驛康談 CUDA 護城河（節目原話）

這個邏輯值得單獨想一秒。CUDA 的護城河從來不是 API 本身，而是圍繞它長出來的軟件勞動力：多少 kernel 被手寫過、多少庫被調試過、多少工程師會用。如果 agent 能把這些「補全」，護城河就從「生態」退化成「許可證」。這與他在 xAI 做架構、在 IBM 做預訓練的經驗一致——他看到的瓶頸一直是工程勞動，不是硬件規格。

八、智能不分種類，但 System 1 還沒過

Open Astra 展現的機器人操作能力讓他意外，但他不認為這是獨立的空间智能路線：

「我一直相信其實智能其實不分那麼多種類，不一定非得有空間智能和文本智能這種區別。」 —— 沈驛康談智能的統一性（節目原話）

他把它解釋為多模態理解提升後的泛化，而不是另一套原理。這個立場在具身智能圈子裡不算主流，因為它暗示「機器人不需要一套全新的智能範式，只需要更好的多模態模型加上身體」。但真正沒跨過的是 System 1——不經過推理鏈、憑本能即時反應。

這個區分很漂亮：System 2 可以被 CoT、RL、工具調用堆出來，因為它本來就是「慢思考」；System 1 要求的是把推理壓進權重裡，還要保持即時性。這與他對持續學習的保留是同一個問題的兩面——不是模型不會學，是它還沒學會「不假思索地會」。

九、三條曲線疊加，才有「模型發布更密集」的體感

他把 2026 年的進步拆成三條獨立曲線：

  1. Coding 帶來的長程 agentic 能力——能連續做幾小時、幾天的任務，出錯率下降到可交付；
  2. RL reasoning 帶來的長任務處理——在可驗證域裡反覆試錯，把推理鏈拉長；
  3. 架構與優化器的回歸——linear attention、sparse attention、Muon 一類改動，讓同樣算力跑出更多有效計算。

這三條曲線不是同一件事的三個說法，而是三個獨立的工程項目。它們同時在 2026 年收穫，才造成「模型發布更密集」的體感。這也是他對「預訓練撞牆」的回應：不是牆被推倒了，是牆的位置被三種不同的工具同時往外挪了一點。

對照Anthropic 上市估值預期從 2 萬億美元下調至 1.4 萬億、再至 1.3 萬億美元；OpenAI / Anthropic 年度剛性算力支出各 500–600 億美元以上。技術曲線與資本曲線，在 2026 年底第一次明顯分叉。
十、這一集真正的爭議：他把 RSI 的門檻抬高了

把沈驛康放進 11 月的話語場，會看到一個很整齊的三部曲：

  • Dwarkesh（11-13）：數學已被攻陷，ML 研究是下一個；中位 2028 年自動化頂尖 AI 研究者，2029 年超智慧。
  • Christiano（11-16）：一年內接管級風險 10%；RL 的優化壓力會教會模型欺騙。
  • 沈驛康（11-24）：那些都還是第一層 RSI；真正的第二層——發明新能力——「目前看起來可能還沒有真正去解決」。

他不是在否認進步，而是在否認「進步的自動化」。這兩件事的差別，決定了我们對時間表的估計：如果 RSI 只需要第一層，那它已經在發生，剩下的是規模化；如果 RSI 需要第二層，那它還是一個開放問題，時間表取決於某個還沒被發明的方法。

「RSI 反而是一個淘汰更多人的一個關口。」 —— 沈驛康，談 RSI 在跑步機比喻中的位置（節目原話）

這句話值得反覆讀。通常我們把 RSI 想成「少數人先跑，然後所有人被甩開」；他的版本更冷：RSI 不是給領先者的加速器，而是把跟不上的人永久移出賽道。如果這個判斷成立，那麼 RSI 的社會後果不是「工作變多」或「工作變少」，而是參賽資格的集中。

我的延伸：「loading」與「篩子」其實是同一個結構的兩面。對外，經濟在等組織吸收效率；對內，賽道在把不能吸收的人篩掉。前者解釋了為什麼宏觀數據看不到生產力爆發，後者解釋了為什麼微觀團隊的產出差距會突然拉大。兩個現象同時為真，並不矛盾。
十一、可證偽點：半年後可以回頭看什麼
  1. 「發明新能力」是否出現：有沒有一個模型，在沒有 CoT 的基礎上自己發明 CoT，或從純文本跨到一個全新模態？如果沒有，他的第二層 RSI 仍然未成立。
  2. NewLab 的寬鬆期：他給的是一兩年。如果 2027 年中之前，Frontier Lab 開始系統性複製 NewLab 的路線，寬鬆期就結束了。
  3. CUDA 護城河的削弱：觀察非 NVIDIA 硬件上的 agent 輔助遷移成本，是否真的下降到「一般團隊也能做」。
  4. 調整期長度：他說一到兩年。如果 2027 年底前 AI 相關收入仍未覆蓋剛性算力支出，清理期會比他估計的更長。

這一集不是預言，是一份來自訓練車間的證詞。它最有價值的地方，不是給出一個更準的時間表，而是把「RSI」這個被用得越來越鬆的詞，重新擰緊到一個可以被工程師檢查的定義上。你可以不同意他的門檻，但你不能再用「模型會改進自己」這種話混過去。
