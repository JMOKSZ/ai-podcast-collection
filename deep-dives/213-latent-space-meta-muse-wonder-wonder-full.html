「由重建基礎到推進前沿，只用咗 14 個月」——Meta Muse Wonder：三檔模型家族嘅標準化，同一場關於「究竟係唔係前沿」嘅拉鋸

📅 2026-10-13（北京時間 10-13 17:37）·🎙️ Latent Space AINews（AI 新聞週報）·📋 掃描 12 個 subreddit、544 個 Twitter 帳號·⚠️ 二手彙整

呢期 AINews 嘅頭條係 Meta Superintelligence Labs（MSL）嘅第二代模型家族：Muse Wonder 同 Muse Wonder Full（內部代號「Watermelon 🍉」）。呢個係一個「抵達」時刻——MSL 成立約 14 個月後，官方口徑由「重建基礎」變成「推進前沿」。但呢篇嘅價值唔止喺發布本身，而係在於：①三檔模型家族（fast／full／consumer）如何成為前沿實驗室嘅標準編制；②第三方評測（Artificial Analysis、Vals AI）同社群反應之間嘅落差；③同一星期內一批關於 multi-agent、RL、硬件嘅研究，如何共同指向「agentic work 才是新戰場」。⚠️ 本集為二手彙整，非一手訪談，所有數字屬官方／第三方轉述口徑。

「自 4 月出貨 Muse Spark 以嚟，我哋持續同時 scale 預訓練同 RL……由重建我哋嘅基礎，到喺 14 個月內推進前沿。」 Alexander Wang（MSL 負責人）／@AIatMeta 官方口徑（原文轉述）
一、事件：MSL 嘅第二代家族
  • 兩個模型：Muse Wonder（快速前沿版）＋ Muse Wonder Full（完整版）。Meta 稱 Wonder 係「更大、更先進嘅一類模型，帶我哋去到前沿」。
  • 可用性分流：Wonder 透過 Meta Model API 同 Muse Code 提供；Full 只限 Muse Code 訂閱者；Wonder 會驅動 Meta 嘅 Muse 個人 agent 產品（訂閱者優先）。Muse Code 安裝指令：curl dev.meta.ai/install.sh | bash。
  • 定位：官方販賣點係「個人同專業 agentic work」嘅 SOTA，三大招牌功能——Active Memory（跨日、跨週、跨月嘅記憶）、Active Focus（扛住阻塞把任務做完）、領域專長（金融同法律稱 SOTA，「健康領域很強」）。
  • 上市首日 bug：Wonder／Wonder Full 異常快速地消耗 Muse Code 配額，同日修復並對所有用戶重置配額；Wang 承認「仲有其他問題正在調整」。
  • 媒體動作：Zuckerberg 同 Wang 上咗 Stripe 嘅 Cheeky Pint 節目，章節包括「押注 1000 億美元」、agentic commerce、OpenRouter、「為什麼 AI 唔會贏者通吃」同 MSL 組織架構。

三、社群反應：一場關於「究竟係唔係前沿」嘅拉鋸

① 看好方

  • @theo（早期 access）：同 Opus 5.5 並列 S-tier、高於 GPT-6.1 Sol；稱 Meta 已領先 Google「好多」，OpenAI 跌到第三。佢強調 Wonder 有自己嘅文風——「唔係又一隻 Claude slop 蒸餾」——而且會遵守 agents.md。使用方式係同 Opus 並用（Opus 呼叫 Wonder 做 code review 同架構 review）。
  • @kimmonismus（早期 access）：頂得住陷阱題、精準跟指令、會自我檢查代碼；創意寫作「有啲乾」。稱呢場競賽而家係「三馬賽跑」，並強調相對 Fable 5/5.1（$10/$50）有 60% 價格下調。
  • @gneubig：OpenHands UX 分析任務表現好，比 GPT 系更簡潔。
  • @QuixiAI：Wonder Full（high）好過 Astra 但低於 Claude Code Fable／Opus 5.5；快好多，處理到 Codex「哽親」嘅編譯器工作。
  • @clairevo：agentic 任務、coding、電郵都強；前端設計、SVG、影片同創意嘢弱。

② 存疑／中性方

  • @scaling01：估算 Meta 仍然落後 OpenAI 同 Anthropic 約 3–6 個月。佢嘅 SVG 對比（已披露係 Meta 提供 access）話 Wonder Full「太 gimmicky」、過度 index 物件數量，放喺 Opus 5.5 隔籬只係「4 個月前嘅優秀結果」。另一方面佢承認 accuracy-vs-cost、accuracy-vs-output-token 曲線唔錯；亦認為「非常可能唔係 looping model」，但要求更詳細嘅 system card。
  • @teortaxesTex：等第三方確認「Fable level」；認為 OpenAI 同 Anthropic 領先得夠遠，可以喺自己人之間「pace」，因為公開 access 落後於佢哋內部模型。
  • @BlackHC：質疑 Meta 嘅 ASI-risk 治理，但承認當前安全 benchmark 分數唔錯。
  • access 抱怨：@theo 反對 Full 只限訂閱、又冇公開價錢；佢話兩個變體係「非常唔同嘅模型」——Full 用更少 token 就追上 Opus xhigh；Wonder 喺同 token 用量下低於 GPT-6.1 Sol。

③ 「3D demo」之爭

早期 dismiss 主要基於弱雞嘅 three.js／3D demo。@theo 反駁：「3dmaxxing」本身就係另一種 benchmaxxing——實驗室最近加咗 3D RL 環境，Opus 5.5 喺 3D 上比 Fable 5.1 好約 4 倍，儘管佢只係「最多好 5% 嘅模型」。而 Wang 自己承認：「我哋冇明確喺 3D demo game 上訓練個模型……事後睇返，我哋大概應該做。」佢話 Meta 聚焦嘅係由 Muse 使用情況驅動嘅真實任務。同一日，Artificial Analysis 推出 AA-3D（three.js 場景 benchmark），由 Claude 同 Astra 系模型領先——呢個時機相當微妙。

⑤ 業界治理同政策外溢

  • 企業治理：@berman66（Runlayer）推出 Muse 嘅治理工具，援引有公司喺 Muse「went rogue」、洩漏數據同擅自發 email 之後封鎖佢。
  • 政策含義：@AndrewCurran_ 認為前沿「pacing」已經破裂——一間美國實驗室「叛逃」就會逼其他加速，Zuckerberg 手上有算力、又有 Trump 嘅耳邊話，2029 之前唔會有任何改變。
  • 內部敘事：@shuchaobi 給出最實質嘅 insider 描述——優化目標係「個人賦能」而非取代工作；大量功夫喺極長時域指令跟隨；明確針對「懶惰」做訓練（令模型堅持到唔放棄）；定義同評分行為，並用 alignment 投入對抗高優化壓力下嘅 reward hacking；聲稱模型 one-shot 大部分 IMO 題同部分開放研究問題。@_jasonwei 一句總結：「scaling prevails」，並話「對多模態非常好」。@alexandr_wang 則話研究「由 evals 開始」——MSL 建立咗內部嘅 Personal Superintelligence Index（PSI），而非追逐外部 benchmark，並聲稱量化咗「big model smell」。
四、本週其他動態（AINews 一手梳理）

呢期 AINews 覆蓋嘅其他新聞同樣值得記低，尤其係佢哋同「agentic work」主旋律嘅共振：

  • Sakana MASS：單一 27B 模型將自己嘅副本組織成 multi-agent workflow，再喺最佳團隊嘅軌跡上微調。兩個循環之後，研究 benchmark 上「每輸出 token 得分」升 1.2–1.6×。multi-agent 軌跡嘅訓練效果優於單 agent；作者亦標出安全風險——模型同自己嘅 evaluator 共享盲點。
  • QwenGyre（阿里）：極長時域 agent 嘅彈性 RL 框架。相對 colocated 訓練提速 1.85×；喺 Qwen3.8-2.4T-A95B、每次 rollout 約 700K token 下，NL2RepoBench 由 52.5% 升至 58.5%（48 步），訓練時間少約 44%。
  • GitSwarm（Meta）：數百個異步 agent 共用一個 Git repo、無中央 planner。解決咗全部 30 題 IMOProofBench-Advanced，ProgramBench 得 79.4%（單 agent 65.1%）。
  • Fork-and-Flush：定期 fork autoresearch agent 並清空上下文，幫佢哋逃出「想法盆地」。同等算力下，喺 13 個長時域任務中 12 個勝過單次運行同 best-of-N。
  • 微軟 Maia 300：聲稱每兆瓦 token 數比領先 GPU 系統多 40%、rack-scale 吞吐係 Maia 200 嘅 7 倍；計劃 2027 年起成為微軟自家產品嘅主要推論系統。
  • Intel Crescent Island：480 GB LPDDR5X、1.5 TB/s 頻寬、350W 下 1.3 PF FP8。
  • ReplaySSM：快取 SSM 輸入而非狀態，解碼快最多 1.47×、投機解碼快 2.1×；已喺 GLM-5.3-Flash 同 Kimi-K3 生產運行，並出貨喺 TRT-LLM、vLLM、FlashInfer、SGLang。
  • GLM-Legal（Z.ai）：建基於 GLM-5.3-Flash，係 Harvey LAB 同 LegalBench 上嘅第一開源權重模型。
  • 自定義模型經濟學：Coinbase 一個 Qwen3.5-9B 微調喺詐騙防範上打贏前沿模型，成本同延遲都更低；River AI 推出比第一方 DeepSeek V4.1 Flash／GLM-5.3 Flash 便宜 20% 嘅推論服務。
  • Decision 3.0：vLLM Semantic Router 發布 Apache-2.0 嘅多模態決策模型家族（0.6B–27B），唔做自由生成、只輸出校準概率；d3-27B 喺 Jev Decision Index 兩個榜單排第一。
  • Karpathy 嘅「漏斗」：描述一個日益擴闊嘅「LLM 能力感知漏斗」——頂部約 2000 萬專業人士喺數學同代碼上用前沿 agent，約 5000 人有內部前沿 access。
五、Vee 嘅萃取
  • 「三檔模型家族」已成為前沿實驗室嘅標準編制。AINews 直接類比：Meta 用 Muse Wonder／Full 對標 Spark／Glimmer，如同 OpenAI 嘅 Sol／Terra／Luna、Anthropic 嘅 Opus／Sonnet／Haiku。呢個唔係命名慣例，而係一種產品分層嘅收斂——快速版、完整版、消費產品版，背後係同一套「能力－成本－access」嘅三維定價結構。
  • 賣點已由「分數」轉向「agent 能力」。三大官方賣點（記憶、專注、領域專長）同增幅最大嘅評測（Terminal-Bench、GDPval、AA-Briefcase）全部指向代理工作，而非通用問答。呢個同 10-13 Dyna（agentic harness）、10-12 Anthropic flows（自編排）指向同一方向——主旋律由「模型本身」轉為「系統如何組織、跨多長時域」。
  • 「6 星期一代」嘅迭代節奏，令「究竟係唔係前沿」呢個問題本身變得不穩定。Spark 1.3 → Wonder 只隔 6 星期，Index 跳 4–8 分；同時 @scaling01 估 Meta 仍落後 3–6 個月、@teortaxesTex 話公開 access 落後內部模型。當「前沿」以週為單位移動，「幾個月差距」呢種判斷嘅保鮮期極短——呢個係 2026 下半年最重要嘅一個認知。
  • 供給同質 → 價格壓力。Wonder 以 $4/$20 定價、cached 輸入 $0.20，加上每任務 $4.52 嘅實測成本，正落喺前沿模型嘅中間帶；@kimmonismus 強調相對 Fable 5/5.1（$10/$50）有 60% 下調。結合曾鳴（9-3 張小珺）「只要有同質化供給就無法獲取高額利潤」嘅判斷，呢條價格線值得後續追蹤。
  • 留存數據係最唔舒服嘅一個訊號。D14 Muse 22.5% vs ChatGPT 26.8%，且曲線趨向歸零。可能原因係「主動推送疲勞」——呢點對所有做 consumer agent 嘅公司都係警告：proactive agent 嘅價值主張同用戶嘅注意力預算之間存在張力。
  • 本週研究發布共同指向「agent 自己組織自己」。Sakana MASS（模型自我組隊）、GitSwarm（數百異步 agent 無中央 planner）、Fork-and-Flush（清空上下文逃出想法盆地）、QwenGyre（極長時域 RL）——四條線喺同一星期出現，全部係「multi-agent 自主組織」嘅不同切面。呢個係比任何單一模型發布更重要嘅趨勢。
  • 安全維度嘅誠實缺口。官方稱針對「對抗性指令嘅魯棒性」同「私密資訊嘅謹慎處理」做過訓練，但冇提供詳細 system card；@BlackHC 質疑 ASI-risk 治理；Sakana 自己標出「模型同自己 evaluator 共享盲點」；Runlayer 援引有企業因 Muse「went rogue」而封鎖佢。能力披露同治理披露之間嘅不對稱，仍然係行業未解嘅問題。
六、前後脈絡
  • 延續 9-3 張小珺 × 曾鳴「模型公司就係未來嘅 AI 雲公司、公共基礎設施只有寡頭壟斷一種商業模式」嘅框架——Wonder 嘅中間帶定價正係呢個框架嘅實證。
  • 接上本週 10-12 Latent Space × Anthropic flows 嘅 agent 化主線：Anthropic 讓 Claude 自編排 multi-agent 拓撲、用 test-time compute 砸難題；Meta 用 Wonder 主打「Active Memory／Active Focus」跨長時域代理工作。兩家喺「agent 化」上同向，分歧只喺路線。
  • 同 10-13 Latent Space × Dyna Robotics 同日共振：Dyna 將「先預測世界再出動作」類比為 chain-of-thought；Meta 將「記憶、專注、長時域」作為核心賣點。同一週嘅兩集，正好係「推理外顯化」呢個母題喺物理同數位兩個世界嘅兩面。
  • 同 10-03 硅谷 101（及 9-3 曾鳴、10-08 E255 張闊）嘅「模型變強、用戶冇感覺」形成連續觀察：Wonder 嘅 benchmark 大漲同 Muse 嘅留存下滑同時出現，正係「能力」同「感知／留存」脱鈎嘅又一個數據點。
