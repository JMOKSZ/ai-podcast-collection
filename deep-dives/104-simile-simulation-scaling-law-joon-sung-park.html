  • 起點：2020 年入讀史丹福博士，正值 GPT-3 誕生前夕。佢哋一齊寫咗《Opportunities and Risks of Foundation Models》——「foundation model」呢個term就係由佢 co-founder Percy Liang 命名嘅。

  • 今日：Simile 為 Fortune 100 客戶（如 CVS）跑數千萬次模擬，聲稱對真人焦點小組有 85–99% 準確率；每周收集數萬人數據，全球面板夥伴覆蓋數千萬人。

第二選擇係乜？係個人化 agent 自動化工具——「但係好接近第二」。而呢個「第二選擇」正正帶出 Joon 最重要嘅一個論點：要做好個人 agent，你首先要有人類用戶嘅深度模型。

「我叫個模型幫我買宵夜，佢幫我嗌咗夏威夷薄餅——但我唔鍾意菠蘿。咁就完全失敗咗。要唔犯呢個錯，唯一方法就係對『我係邊個』有深度理解。」

呢個論點對 James 嘅四艦隊架構（尤其 Hermes 嘅 memory / 用戶畫像設計）係直接嘅價值論證——模擬（理解人）要行先於自動化（為人做事）。Joon 嘅 bet 係：模擬技術、創造準確嘅人類表徵，應該 precede 更加複雜嘅自動化世界嘅 agents。

仲有段好有意思嘅對話：swyx 直接問 Joon 對 OpenClaw 呢類個人 agent 有咩期望。Joon 話 OpenClaw 用 Markdown 檔案做記憶「好聰明」——

「OpenClaw 用緊嘅係 Markdown 檔案，我覺得好聰明。呢個同我哋 Generative Agents 論文嘅直覺同源——2022 年嗰陣我哋諗：要唔要整 knowledge graph？要唔要 train 個 bespoke model？最後決定：唔好，語言模型好擅長處理文字，直接將所有嘢放喺 Markdown / text file，搞掂。……但係有局限：要喺極大量數據入面檢索同理解，係好多功夫。」 —— Joon Sung Park 對 OpenClaw Markdown 記憶架構嘅點評

佢仲補充一個關鍵立場：有啲嘢淨靠 prompting 係塑造唔到嘅，要掂 model 嘅參數本身。幾時要 train？Joon 畀咗一條好清晰嘅分界線——

「如果模型要學習佢所處世界嘅新社會物理（new social physics），就要 train / post-train；如果基礎統計已經有、只係對環境做反應，咁 prompting 就夠。我認為公開模型仲未學識人類社會嘅完整社會物理映射——呢個係 Simile 嘅核心論點之一。」
三、行為基礎模型：「模型要同我一樣蠢」

Simile 想做嘅嘢叫 行為基礎模型（Behavioral Foundation Model）——同 ChatGPT / Claude 呢啲「超理性客觀機器」完全相反。Joon 講得直接到肉：

「前沿模型嘅數據來自 Mercor、Scale，佢哋搵專業程式員、科學家做標注，整出嚟嘅模型擅長推理——呢啲就係佢哋做嘅嘢。Simile 完全唔 care 呢啲。我哋想創造嘅係『同我一樣蠢』嘅模型——如果我會犯某啲錯，個模型就要犯同樣嘅錯。」 —— Joon Sung Park 對「模型應該幾理性」嘅反主流立場

swyx 即刻接：「你喺解決 Murphy's paradox。」（要準確模擬人類嘅非理性，比模擬理性更難。）呢個立場同 AI 行業追求「更理性」嘅主流方向直接對立，亦係 Simile 最易被誤解、又最核心嘅差異點。

點解網絡數據唔夠？Joon 嘅講法係——

「模型訓練自 web 數據：社交媒體、Wikipedia。呢啲本質上係『自我曝露嘅態度數據』，加埋零星嘅行為數據。佢仲未學到人類嘅深層行為本質——唔係人哋喺網上話自己會做啲乜，而係現實生活中佢哋真正做啲乜。呢個係我稱之為『人類嘅 dark knowledge』嘅嘢。」
四、數據三桶理論：訪問、行為、因果

要補返呢個 dark knowledge，Simile 將數據分三桶：

  • ① 訪談數據（Interview）：長尾定性信息。「講吓你嘅人生故事」——童年記憶、創傷、初戀。呢啲嘢好難預測但提供大量「texture」。
  • ② 行為數據（Observational / Transaction）：交易記錄、可以 scrape 到嘅網絡數據——提供人嘅 base statistics。
  • ③ 因果數據（Causal / RCT）：Joon 認為最重要嘅一桶——隨機對照試驗（RCT）。「飲咖啡嗰日 vs 唔飲咖啡嗰日，行為有冇變化？」呢啲先係人點解做決定嘅 whys。

後訓練（post-training）嘅思路就係用 RCT 數據去教模型「人點解做決定」嘅因果機制，而唔係只學 base statistics。呢度有個好靚嘅數據來源：Open Science Framework——社會科學複現危機之下，科學家開始註冊研究（先寫低假設、唔准事後改），平台累積咗數以萬計高品質嘅真人行為實驗同 RCT。Simile 用呢批數據 post-train 模型，實驗證明可以顯著提升模型預測人類行為嘅能力。

五、1,000 人數字孿生：85% 準確率點樣驗證

「LLM 會幻覺，你咪淨係一層層疊幻覺？」——Vibhu 問出所有人嘅疑慮。Joon 用佢哋嘅奠基論文《Generative Agent Simulations of 1000 People》回應，呢個亦係模擬/合成面板領域嘅地基：

  • 將 1,000 名代表美國人口樣本嘅受試者請入虛擬實驗室；
  • 用 2 小時收集廣泛數據——訪談（劇本源自 American Voices Project）+ 行為數據；
  • 受試者離開後，用數據建立佢哋嘅數字孿生；
  • 兩星期後請真人返嚟做一籃子測試：行為經濟學博弈、Big Five 人格、General Social Survey、甚至 PNAS 上發表過嘅隨機對照試驗；
  • 數字孿生預測原人會點做——準確率 85%，等於人自己重複自己答案嘅準確率。
關鍵數據 85% = 數字孿生復現原人行為/態度嘅準確率，與真人自己復現自己嘅準確率持平；測試包括行為經濟學博弈、Big Five、GSS、PNAS 已發表 RCT。

而對比之下，前沿模型喺呢類任務嘅表現：一般人群大概 50–60%，落入特定小眾人群（客戶真正 care 嘅群體）可以跌到 20–30%——「你唔會想用呢啲結果去做商業決定」。將準確率由 50% 拉到 85%，就係客戶興奮嘅原因。

點解前沿模型咁差？因為佢哋被訓練成「理性機器」，而模擬需要嘅係「同你一樣蠢」——複製人嘅偏見同錯誤。呢個係完全唔同嘅數據同訓練目標。

六、模擬 ≠ 預測：你唔係想知結果，係想改變結果

Joon 反覆強調一個概念區分：模擬（simulation）同預測（prediction）係兩回事。預測係「個 survey 會得到咩答案」，模擬係「畀個 goal 你，行返條 path 出嚟」：

「模擬嘅最高形態係：你唔係問『人哋會點答條 survey』，你係話『呢度有個目標——喺《基地》入面，我哋想將混亂維持喺 1,000 年以內，而家要行邊條路先到嗰個未來？』」 —— Joon Sung Park 引用阿西莫夫《基地》嘅心理史學（psychohistory）

《基地》第一幕就係心理史學模擬器計出嚟嘅第一步係「將預言帝國崩潰嘅科學家流放去銀河邊陲」——反直覺到極，但喺模擬入面就係正確嘅第一步。現實版本：車廠想谷 EV 銷量，但模擬可能話你知「咁樣會改變公眾對非 EV 車款嘅觀感，搞到整體銷售跌」——你淨係 track EV 銷量嘅話，永遠睇唔到呢個 counterintuitive 嘅路徑。

呢個亦係 Simile 同 Shopify SimGym（Mikhail Parakhin）嘅共通點：唔係問態度，係影響多輪行為互動。

七、由 Schelling 到 80 億人：社會級模擬嘅野心

Joon 嘅精神祖師係 Thomas Schelling——1970-80 年代 agent-based modeling 嘅開創者，佢嘅種族隔離網格模型（紅點藍點）證明咗一個震撼結論：即使人對同色鄰居嘅偏好極之輕微，社會最終都會完全隔離——呢個發現啟發咗混合收入住房政策，Schelling 亦因此拎咗諾貝爾經濟學獎。Joon 話：紅點藍點唔係對人嘅豐富描述，所以 agent-based modeling 之後被遺忘；但 generative AI 提供咗高保真度嘅機會——「如果真係work，呢個就係會攞諾貝爾獎嘅工作」。

由 Schelling 嘅網格世界到「模擬 80 億人」，Joon 描繪嘅終極願景係：

  • 「呢度有一座諾貝爾經濟學獎等緊人攞」；
