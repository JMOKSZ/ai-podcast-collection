你真的信 WorkBuddy 有 2000 萬月活？——莊明浩嘅「數據打假」與真 Agent 時代嘅度量衡之爭

📅 2026-08-01·⏱️ ~28 分鐘·🎙️ 莊明浩（單口）·🏷️ 數據打假 真 Agent 時代 ARR
📌 為乜要睇呢篇

2026 年 8 月，中國 AI 圈最荒謬嘅一幕：一個第三方統計機構嘅「PC 端月訪問量」，經過媒體、研報、自媒體嘅三手加工，變成咗「WorkBuddy 有 2000 萬月活」嘅行業「事實」，再被反覆引用去證明「中國 Agent 時代已到」。莊明浩——中文 AI 圈最出名嘅「數據控」——忍咗成個月，最後用一期 28 分鐘嘅單口 + PPT 把件事拆到見骨。

但呢期嘢嘅價值遠超「打假」本身。佢借 WorkBuddy 一個數字，問咗一個更難答嘅問題：當 Chat 時代嘅 MAU/DAU 已經失效、Token 量又被營銷污染，2026 年衡量 AI 公司嘅錨點究竟係乜？ 佢自己嘅答案係「只能回到 ARR」——但佢同時坦白：自己過去用「新指標」衡量行業嘅嘗試「都不太成功」。呢種自我懷疑，正正係佢同一般吹水主播嘅分別。

🎙️ 播客背景

屠龍之術係莊明浩嘅個人播客：前大廠、前美元 VC，而家以「游走在互聯網與風險投資行業邊緣嘅人士」自居。佢嘅節目特色係單口 + 70–130 頁 PPT，一期等於一份行業研究報告，中文 AI 播客圈資訊密度最高嘅一檔。今期主題出自一個活動邀請——佢話「趁著一個活動邀請，我做了這期的 PPT」，而 PPT 嘅內容，其實遠大過 WorkBuddy 一個數字：「從 Chat 進入真 Agent 時代，且國內 work agent 似乎成為了所有人的共識」。

節目開頭引用咗王慧文喺即刻嘅一句感慨——「時光，時光，慢些吧……」（01:13）——為全期定調：行業變化快到連資深玩家都覺得暈。

一、數據打假：2000 萬月活係點樣「煉成」嘅

莊明浩開場就講明：呢期係「吐槽節目」。佢喺即刻已經吐槽咗成個月，忍唔住先錄成節目。佢拆出嚟嘅數據鏈係噉嘅：

  • 第一手（第三方統計）：易觀（Analysys）統計 WorkBuddy PC 端月訪問量突破 2000 萬，超過第二名同第三名之和——注意，呢度講嘅係「月訪問量」，一個流量口徑。
  • 第二手（券商研報）：花旗研報寫「月活 2000 萬、日活 1300 萬」——把「訪問量」偷換成「月活」，仲自行加咗個「日活 1300 萬」。
  • 第三手（媒體/自媒體）：直接寫成「WorkBuddy 有 2000 萬月活」，再二次演繹，DAU/MAU 被引為 65%–75%，「對標 Slack」；再疊加「平台人均 Token 消耗增長超十倍」呢類產品側營銷口徑。
「我最受不了的就是這種不知道數字概念，逮著一個數據源就瘋狂『演繹』的狀況……」
— 莊明浩，節目開場白（即節目標題註腳）

佢嘅不滿唔係針對 WorkBuddy 產品本身，而係針對一種行業病：媒體唔做交叉驗證，逮住一個數據源就全盤照抄，仲要逐級加碼。 佢做嘅「打假」方法好樸素——搵多個獨立口徑對比，包括易觀、花旗、產品側、以及作為參照系嘅飛書日活（約 1000 萬量級）。當一個新產品嘅「月活」數字企到飛書日活兩倍，而呢個產品上線先得三個月，理性嘅人第一反應就應該係「睇清楚口徑」，而唔係興奮轉發。

二、CodeX 已經係「新嘅 ChatGPT」——度量單位換咗

打假只係引子。PPT 嘅正題由 02:44 開始：CodeX 已經成為「新的 ChatGPT」（03:28 提到 CodeX 活躍用戶達千萬級）。莊明浩嘅判斷係：由 2026 上半年開始，行業競爭嘅主軸已經由純 Chat 對話，轉向 Coding Agent 與通用 Agent 嘅大眾化爆發，「Claude Code 時刻」被反覆提及。

呢個判斷嘅含義係：Chat 時代嘅用戶數、對話量，已經唔再係衡量 AI 價值嘅合適標尺。 如果 CodeX 係新嘅 ChatGPT，咁「千萬活躍用戶」先係新時代嘅「億級用戶」——量級嘅語義徹底唔同。你唔可以再用舊尺去量新物體。

三、行業重心轉移：Harness 崛起、Agent Infra 繁榮、評估空前重要

由 06:03 開始，莊明浩講咗 2026 年真正嘅行業重心——模型本身唔再係全部故事：

  • Harness 崛起（06:03）：圍繞 Agent 嘅工程外殼——工具、記憶、權限、沙箱、觀測——成為新戰場。模型係引擎，Harness 先係部車。
  • 異常繁榮嘅開源 Agent Infra 生態（06:35）：開源嘅 Agent 基礎設施（框架、協議、運行時）多到「異常繁榮」，呢個係中國特別強嘅一段。
  • 評估空前重要（07:11）：Evals 從「模型評測」擴展到「Agent 任務評估」，因為冇評估就冇法迭代、冇法對客戶交代。

呢三段直接呼應佢 7 月中《重估一切，文藝復興——2026H1 AI 行業觀察》嘅判斷（該集本系列已有深度復述 #49）。今期係將宏觀判斷落到一個具體案例。

四、「workagent 共識」形成得極快——大戰已開

08:03 嘅小標題係「workagent 的共識形成很快」，11:57 就係「workagent 大戰開啟」。莊明浩指出一個唔尋常嘅現象：國內大廠同創業公司幾乎喺同一時間認定「讓 AI 幹活」係下一步——共識形成速度遠超以往任何技術周期。由共識到達成競爭格局，中間只隔咗幾個月。

呢個「共識速度」本身係雙刃劍：一方面證明需求真實、時機成熟；另一方面意味住窗口期極短——所有人都睇到嘅機會，通常唔係機會。大廠（騰訊 CodeBuddy、字節、阿里）同創業公司同時開火，work agent 戰場瞬間變成紅海。

五、中國究竟有幾多人用緊 Agent？——事實與估算

13:16 開始係全期最「數據控」嘅一段：「中國現在有多少人用上了各種 Agent？」 莊明浩畀咗自己嘅估算框架（13:49），再用第三方數據佐證（17:45）。佢嘅意圖好明顯：行業熱度（媒體頭條）與真實滲透率之間，存在巨大落差。

佢冇畀一個「正確答案」——而係示範一個負責任嘅分析師應該點樣答呢條問題：先定義「Agent 用戶」嘅口徑，再分層估算（深度用戶 / 嚐鮮用戶 / 被動接觸），最後用多個獨立數據源交叉驗證。呢種方法論，同佢鬧媒體「逮著一個數據源就演繹」嘅行為，形成直接對照。

六、用戶量唔重要、Token 量都唔重要——只能回到 ARR

24:17 開始係全期最誠實嘅部分。莊明浩逐個拆：

  • 用戶量仲重要嗎？（24:17）——唔重要。因為用戶數已經被營銷污染，仲因為 Chat 時代嘅「用戶」同 Agent 時代嘅「用戶」根本唔係同一種嘢。
  • Token 量似乎都唔重要喇（24:57）——Token 可以灌水（長任務、循環重試、惡意刷量），人均 Token 消耗增長十倍呢類口徑，營銷意義大過業務意義。
  • 所以只能回到 ARR（25:15）——收入係最難造假、最反營銷嘅指標。客戶肯畀錢，先係真實需求嘅終極證明。
  • 但係……（25:57）——佢回顧自己過去幾次用「新指標」衡量行業嘅嘗試，結論係「似乎都不太成功」。最後佢反問：「這次會不一樣嗎？」（27:04）——開放收尾，冇畀答案。

呢段自我懷疑好珍貴。一個行業觀察者嘅價值，唔在於佢次次啱，而在於佢知道自己邊度可能錯。莊明浩承認：由流量指標過渡到收入指標，佢自己都未搵到一個穩定好用嘅框架——呢個唔係佢嘅失敗，而係成個行業嘅未解難題。

💡 我的洞察
1. 呢期係 2026 年「中國 Agent 元年」共識嘅可檢驗化。 莊明浩冇否定「真 Agent 時代」——佢自己都信。佢做嘅係把一個模糊嘅行業共識，拆成可以驗證嘅命題：CodeX 係咪新 ChatGPT？Agent Infra 係咪真繁榮？「多少人在用」有冇可靠答案？當一個行業連「幾多人用緊」都講唔清嘅時候，恰恰說明佢處於由技術 Demo 走向真實商業化嘅混亂過渡期。
2. 數字打假嘅本質，係喺「敘事市場」做套利。 媒體賣嘅係故事，唔係事實。當一個數字可以支持「中國 Agent 起飛」嘅敘事，就會有無限多嘅人想信。莊明浩嘅價值在於：佢係少數願意花成個月、錄一期節目去拆穿敘事嘅人。對投資人嚟講，呢種「反敘事」嘅人先係最貴嘅資訊源。
3. ARR 唔係終點，係退無可退嘅落點。 佢話「只能回到 ARR」，語氣係無奈而唔係篤定。原因好簡單：ARR 亦會被污染（收入確認方式、關聯交易、補貼單）。但喺用戶數同 Token 都已經徹底淪陷嘅前提下，ARR 至少係「最唔爛嘅蘋果」。呢個選擇本身，就係行業現狀嘅縮影。
4. 今期同 42章經「AI 發展了 4 年，把應用發展沒了」係同一焦慮嘅兩面。 曲凱嗰邊問「應用嘅錢喺邊」，莊明浩呢邊問「應用嘅人喺邊、數字真唔真」。兩個問題其實係一個：Agent 時代嘅真實商業化，仲未搵到可靠嘅度量衡。呢個問題未解決之前，所有「爆發」敘事都要打折扣。
🔮 延伸思考
  • WorkBuddy 真正嘅月活係幾多？如果企喺飛書日活（~1000 萬）量級，作為上線三個月嘅桌面 Agent 已經係現象級；如果企喺 2000 萬，就係中國軟件史嘅奇蹟。兩個都值得研究——但係你必須知道你自己睇緊邊個口徑。
  • 「共識形成太快」對創業者意味住乜？窗口期縮短 → 執行速度取代判斷力成為第一競爭要素；同時，紅海化會令「細分場景 + 深度交付」反而成為新藍海。
  • 如果 ARR 成為行業唯一錨點，會唔會催生下一輪「收入造假」？歷史話畀我哋知：任何被全行業盯上嘅單一指標，最終都會被博弈污染。下一個「反 ARR」嘅指標會係乜？
