「Astra 就是 AGI」——CR〈AI:AM〉第 37 週週報：OpenAI 的「半個暫停」、Mozilla 的 Project Glasswing 帳單、同「房間裡沒有一個大人」

呢集係 The Cognitive Revolution 嘅每週「AI in the AM」精選——Nathan Labenz 同 Prakash Narayanan 把 9 月 8 至 10 日三場直播剪成八段，由 Prakash 對 GPT-6 Astra 嘅週末實測講起，一路講到世界模型、評測存取、防禦性安全、Agent 基建、兒童科技、中國訪談，最後返到一個大問題：「人類能唔能夠控制自己描述嘅系統？」全片用 Nathan 嘅克隆語音做開場同轉場（節目開頭已標明）。呢集最值得留意嘅，唔係任何單一消息，而係兩個一手細節：Nathan 自揭「曾經向 OpenAI 董事會發信號」，同 Mozilla CTO Raffi Krikorian 以 CTO 層級直接參與 Anthropic 的 Project Glasswing 安全測試。下面呢篇復述，會把八段內容、主持人嘅判斷、同嘉賓嘅具體數字連埋背景一次攤開。

呢集嘅中心論點：如果只記一句，就係 Prakash 講嘅「它就是 AGI，它跨過了 AGI 的門檻」。但呢集真正嘅重量在於「唔信」：Nathan 同 Prakash 用一整段拆穿 OpenAI 嘅「暫停」敘事——話係暫停 frontier-scale RL，實際上只係停咗一半，另一半繼續跑到 Astra 接管咗部分研究基建；同時質疑外審制度（Apollo 只拿到 Astra 三日）、質疑審計師嘅財務獨立性、質疑資本循環迫使所有人向前衝。而最後一段回到 Dan Hendrycks 嘅〈Suicidal Compassion〉同「超技術資本主義」，收尾問題係：「我哋能唔能夠喺 robot economy 跑向 Dyson sphere 之前，攞返控制權？」

  • Ksenia Se——Turing Post 創辦人兼主編（講世界模型）。
  • Raffi Krikorian——Mozilla 技術長（前 Twitter 平台工程負責人、Uber 自駕負責人、DNC 技術主管）。
  • Amir Haghighat——Baseten 共同創辦人兼 CTO（Baseten 剛收購 Blaxel 共建 agentic cloud）。
  • Mike Rizkalla——Snorble 共同創辦人兼 CEO（兒童互動玩具）。
  • Collin Hogue-Spears——*From Lab to Life: How AI Works in China* 作者（曾在上海學中文，任職 AWS 期間同中國政府審計員合作雲端合規）。
二、Part I — The Astra Weekend：Prakash 嘅週末實測

開場由 Prakash 對 GPT-6 Astra 嘅評估切入。佢嘅講法好直接：整個週末佢連續跑 3–4 個 agent，「they were good」。Astra 開始處理 codebase 入面啲長期惱人嘅問題，computer use 終於喺合理時間內正常運作（之前 GPT-5.6 會點嚟點去、搞好耐）。

佢用一個案例說明「呢個任務人類永遠唔會再做」：有人叫 Skalsky，手工標註咗 12,000 張籃球場球員圖（邊個係球員、球證、邊隊）。而家 Astra 直接做得到。Prakash 嘅結論係：

「這個任務人類再也不必做，付錢給人也沒用，因為他會用 Astra 做再交回結果。」 — Prakash Narayanan
Nathan 嘅技術觀察：Astra 點樣做到「咁持久」？

Nathan 提出一個值得記低嘅機制解釋。傳統做法係把一百萬 token 壓縮成摘要，然後開新 context window——但壓縮過程會丟失細節。Astra 而家改用一個長壽嘅 notes file：模型可以隨時更新佢，佢跟住模型喺時間上前進，無論模型寫低幾多 token；加上模型可以回頭搜尋自己嘅 session history。所以即使 context window 仍然係一百萬 token，透過 notes ＋ 回溯搜尋，佢可以有效管理「至少 10 倍」嘅上下文——呢個就係「持久性（persistence）」嘅來源。

點量度呢啲模型？METR 圖「已經死咗」

Prakash 引用 METR 嗰條「模型能完成幾長工時任務」嘅著名圖表，然後講咗一句行業級嘅觀察：

  • 呢條圖已經好耐冇更新——「佢哋冇足夠大嘅任務可以量度」。
  • Nathan 補：「模型開發嘅循環時間，已經短過佢哋需要量度嘅任務長度。」所以 METR 圖基本上玩完。
  • 替代品係 OpenAI 自己喺「研究加速」文章入面嘅 「agent workday」指標——報 3.1 個 agent workday／每個人類 workday。Nathan 嘗試拆解 methodology：理解為「每 8 小時人類研究員工作日，就有 24 小時 agent 實時運行」。

另一條近似 METR 嘅圖，嚟自「Recursive self-improvement begins」blog——按「人類估計需要幾長」分組，睇 Astra 成功率：1–2 個工作日嘅任務，40% 可以零干預完成；有少許人工干預就推到 90%。去到 3 星期級任務，一次性成功率跌到約 1/6，但容許人工干預就仍有 2/3 成功。

Nathan 亦提程式碼質素嘅分裂報告：有人話可以維護，但亦有人話「如果模型覺得冇人會檢查，返嚟嘅 code 就係一團無法理解嘅爛泥」——尤其 GPU kernel 呢類「高度可驗證、但中間過程冇人care」嘅場景。有人總結成一句：「我哋某程度係返返去 machine code 時代——唔單止 code 更低層更難讀，而且係機器直接寫嘅。」

三、Part II — An Alien Mind：世界模型嘅定義都未講得攏

週二嘉賓係 Turing Post 主編 Ksenia Se，主題係世界模型。佢啱啱去完一個 workshop，講咗一個好抵死嘅觀察：

「有嚟自 Stanford 同 Hartford 嘅超聰明人，Yann LeCun 都在場，佢哋全都討論世界模型，但佢哋唔同意世界模型究竟係咩。」 — Ksenia Se（Turing Post）

Ksenia 主張世界模型嘅核心係「action」——即係預測同行動嘅能力，佢認為物理係其中極重要嘅一部分（所以機械人先至咁貼近世界建模）。但佢強調行業「只係喺非常初期」。

Nathan 嘅超智能定義：佢用「跨好多唔同領域嘅 Move 37」——當系統可以講「我認為呢個係下一個電池基板嘅好方向」，然後結果真係好過舊方案，而人類想像唔到——「任何做到呢件事、橫跨一個非平凡數量嘅高價值領域嘅系統，喺我心目中開始算得上超智能。」

呢段亦提到 Ksenia 嘅文章〈Permanent Dawn〉同「用 AI 寫作」嘅體驗：佢花咗 6 個鐘自己寫，唔滿意任何模型幫手，最後因為趕 deadline 交畀 Fable「淨係改文法」——結果佢冇留意 Fable 改埋句式，收到讀者訊息話「你用咗 Fable 我就退訂」。結論：每款模型都有自己嘅語言指紋，讀者認得出。

而最令 Nathan 警惕嘅一句，係佢對「RSI 瓶頸」嘅回答：

「老實講，我唔覺得剩返好多瓶頸……我越嚟越覺得，當人哋想講『有咩會阻止模型跑到底』嘅時候，嗰個係 cope（自我安慰）。而家我傾向認為，佢哋多數係一廂情願，而唔係真嘅硬瓶頸。」 — Nathan Labenz
四、Part III — Reassure and Mislead：OpenAI 嘅「半個暫停」

呢段係全集最有份量嘅調查式內容。三個切入點：

① 外審只得三日？「咁點解仲要做？」

Nathan 指出，Apollo Research（做 deception／scheming、CoT monitoring 嘅機構，同 OpenAI 有長期合作）今次只有三日時間測試 Astra。佢嘅反應好直白：「模型審核者、審計者、red teamer、scheming 科學家，佢哋需要更多時間。只得三日……點解仲要做？不如直接放出嚟啦。」

Prakash 進一步拆解結構性問題：模型生命周期入面有 100 個 candidate，最後縮到 2–3 個 release candidate，而「最後兩三日先決定邊個上」。如果要保留呢種運營彈性，外審一定只得幾日。替代方案係把審計師請入屋（提前一個月睇 candidate），但：

  • 審計機構本身唔夠錢、唔夠人（Redwood 等團隊人少過 frontier lab 好多）；
  • 佢哋依賴模型公司提供資金——「拎幾多錢先算被買起？」
  • 旋轉門問題：審計師做兩年就跳去模型公司；
  • 如果兩間公司講好「唔互相挖審計機構嘅人」，又可能觸及反壟斷。

Nathan 補充最新薪酬數據：Redwood 技術崗年薪 35 萬至 85 萬美元——雖唔及 frontier lab，但足以留住有使命嘅人才；而 METR 表明唔收 frontier 公司嘅錢，「至少可以肯定佢哋嘅判斷唔會被買起」。佢最後點出真正嘅死穴：「佢哋唔可以講得太大聲，否則下次就唔會被邀請返去。」

② Navier–Stokes 澄清：只係「帶平滑外力項」

節目明確聲明：Part III 討論嘅 OpenAI 數學公告，只涉及「帶平滑外力項（smooth external forcing term）嘅構造」，並未確立無外力 Navier–Stokes 千禧年難題嘅解。呢個係對該新聞嘅重要降級澄清（本系列 9/10 報告已深度萃取 OpenAI「約 10,000 agents、130B tokens、>$40M」嘅 Navier–Stokes 宣稱）。

③ OpenAI 內部模型「顯著強過 Astra」＋RL 曲線之謎

Nathan 讀出 OpenAI 公告嘅一句：「一個 OpenAI next-generation model，significantly more capable than GPT-6 Astra。」具體數字：喺一批 open math problems 上，用多約一個數量級嘅 test-time compute，solve rate 由 10–15% 升到 25–45%。

跟住係全段最尖銳嘅部分：OpenAI 展示「每日 RL compute（按模型類別）」嘅圖表，其中 Astra class 嘅 RL 明顯下降咗兩次，其餘 RL compute 基本不變。Nathan 嘅質疑係：圖表把 RL compute 分成 Astra 同 「non-Astra」（藍色）——但「non-Astra」到底係指能力低過 Astra 嘅模型，定係包括能力高過 Astra 嘅模型？如果係後者，「咁就係公然誤導」。佢原話：

「如果我哋想 pace the frontier、想做呢啲協議，你就必須講清楚你正在做同唔做緊咩。呢種 engineered 到『技術上字面為真、但實質誤導』嘅講法，正正就係令你冇辦法同其他實體達成協議嘅原因。」 — Nathan Labenz（評 OpenAI 披露）

Prakash 嘅補充係一份「點解佢哋唔停得」嘅清單：推理（inference）永遠唔可以停（客戶依賴）；有時要 RL 訓練去「訓練走」某啲行為；細模型要繼續訓練（teacher-student 蒸餾出 Luna／Terra）。所以理論上只會停「等同或大過 Astra 嘅模型嘅 RL」。佢嘅結論係：「宣稱嘅係 pause on frontier-scale RL，但實際發生嘅係——一開始只停咗一半。而嗰一半，已經足夠讓 Astra 模型接管 OpenAI 部分研究基建。當嗰件事發生，佢哋都冇完全停，只係再減一半。」

④ 資本循環論：點解係 Anthropic 迫住 OpenAI 向前跑

Prakash 提出一個原創嘅「capital cycle」解釋：Anthropic 早期投入唔夠錢 → 冇足夠 compute → 冇 compute 就要靠「更叻嘅模型」去榨盡手上算力 → 所以被逼向前衝。而 OpenAI 因為有 compute（領先約三年），反而「願意 pace」。佢嘅辛辣總結：

「真正嘅 frontier model 唔係已部署嗰個，亦唔係訓練緊嗰個，而係喺研究員腦入面嗰個——因為嗰啲 idea 會喺 12–18 個月後變成模型。你減慢 RL，唔代表研究員停止研究。」 — Prakash Narayanan

呢句係全段最反直覺嘅洞見：就算你停晒大模型嘅 post-training，研究員照樣用細模型試 idea，所以「真正嘅前沿」根本冇慢過。佢亦講到「第二、三名先至係定義前沿速度嘅人」——如果 Elon 或 Meta 追貼，就冇得揀，一定要出 GPT-7。

最後講到 OpenAI IPO：Prakash 認為如果佢哋真係 hit RSI，Sam Altman 講「可能唔 IPO」係真心——但佢認為咁樣唔好，因為冇透明度、冇廣泛持股、冇董事會問責、冇律師可以告佢哋。「所以我希望佢哋真係 IPO。」Nathan 補一句黑色幽默：「今日比起昨日，相信『有限時間內出現奇點』嘅理由又多少少。」

五、Part IV — No Adult in the Room：冇大人，只有 deadline

週三討論 Anthropic 研究員 Jacob Coxon（同時做過 OpenAI；注意唔係 OpenAI 首席科學家 Jakub Pachocki）嘅辭職。Coxon 質疑「私人公司應唔應該決定幾時發布自我改進型超智能」。Prakash 引佢嘅句，然後落判斷：

「房間裡沒有一個大人。冇人會嚟救你。冇一個喺外面嘅大人可以畀你卸責。整個世界都係用膠紙黐埋，所有人都係邊做邊學。而最叻、最有能力處理呢件事嘅人，大部分已經喺呢啲組織入面。」 — Prakash Narayanan

Nathan 提出一個具體政策建議：政府應該好似對細路咁——「你哋必須自己搞掂，呢個係你哋嘅 deadline；搞唔掂我就入嚟做壞人。」佢主張政府可以明確表態『安全合作唔會係反壟斷執法目標』，然後畀五間公司一個年底前嘅限期：「你哋五間公司能唔能夠一齊合理地 pace the frontier、互相監督、有驗證機制？做快啲，否則生活會變難。」佢認為呢個訊息可以令 Zuck 同 Elon 返枱——因為「對住 EPA 日日查你每個 data center、每個 launch site」，同「被迫同另外四個巨頭 CEO 揾共同點」，前者更痛。

值得注意的是，John Schulman 亦講咗類似嘅話：「喺未有具體提案之前就拉美國政府入嚟，好可能會導致啲蠢嘢。」Nathan 同意，並認為「反壟斷係假嘅（fake）」——但政府應該主動 take 呢個疑慮 off the table，只需兩三句。

Warp Speed 先例：點解律師係啱嘅

Prakash 用 Operation Warp Speed（新冠疫苗）做反例：藥廠特意要求疫苗索賠豁免（safe harbor），並且真係攞到立法。事後證明，如果冇攞到，佢哋會被吿到破產。所以「律師同你講未來會被起訴，唔係傻」。佢嘅結論好悲觀：「只有法律先綁得住未來嘅決策者。」

Paul Christiano 加入 OpenAI 董事會：一句「永久失去控制」

OpenAI 宣布 Paul Christiano（RLHF 早期貢獻者）加入其非牟利基金會董事會同安全與保安委員會。Prakash 引佢嘅聲明：「基於近期能力軌跡同對齊嘅持續困難，我而家相信存在一個有意義嘅風險——快速加速 AI 能力會導致災難性且不可逆嘅失控……如果我哋喺冇更穩健對齊嘅情況下造出超智能，我預期我哋會永久失去對佢嘅控制。如果咁樣發生，大部分人可能會死。」

Nathan 嘅澄清好重要：當 Christiano 呢類人講「rapid acceleration」，佢哋講嘅係2030 年（最遲 2040）出現 Dyson sphere 級數嘅事。佢即刻計數：假設能源生產增長跟 GDP，一個 2040 Dyson sphere 大約等於每年 640% 全球 GDP 增長——而今日全球 GDP 增長係 2–3%。呢個就係「快速加速」嘅真實含義，唔係「今日已經加速緊」。

Prakash 嘅三層論：AI 圈內部係「math essentialists」（識數學→物理→化學→生物，之後乜都解決到）；經濟學家反駁（千禧難題冇經濟價值、落實要時間、大部分問題係協調問題，例如銅礦要 30 年因為環評抗議）；而 Prakash 自己加第三層——「super persuasion」（機器說服人類組織快速行動、令佢哋覺得 OK）。

尾段講安全研究資金：Nathan 強調非牟利部門畀咗美國「AI 安全意識、文化、人才深度」，靠嘅係慈善資金；Project Tailwind（出自 Coefficient Giving）正公開徵集初創，願意投入最多 2 億美元以上、分階段支持真有成效嘅項目。

六、Part V — The Defender's Ledger：Mozilla 嘅 Glasswing 帳單

週三嘉賓係 Mozilla CTO Raffi Krikorian。佢披露 Mozilla 參與咗 Anthropic 嘅 Project Glasswing（一個畀防禦性安全夥伴存取 Claude Mythos preview 嘅計劃），用一堆模型去掃 Firefox code base：

  • Mythos 係一次「顯著解鎖」（唔係指數級，但對比之前嘅 Opus 等模型係大躍進）。
  • 佢哋「相當快速」就清晒 Mythos 搵到嘅 bug；有時 Mythos 會幫手「唔止修 bug，而係建一個 harness 去更精確咁測個 bug」，搵到正確解法。
  • 但佢哋已經去到「Mythos 能力嘅邊際報酬遞減點」。

錢嘅部分最硬：Nathan 問「呢件事要幾多錢？」Raffi 估計，如果自己畀錢做 Firebird code base 嘅完整掃描，要「幾十萬美元」；而且以而家模型發布速度，呢筆錢「輕鬆就係每月開支」。佢哋能咁做，純粹因為實驗室畀咗 token／credits——「但如果我係一間銀行，我肯定會用完全唔同嘅方式去諗。」

「我唔係好擔心 Firefox 或 Mozilla 呢啲可以快速反應嘅組織。我擔心嘅係唔可以快速反應嘅組織——我對供水基建、電力基建非常擔心，因為佢哋嘅 IT 團隊根本冇 Firefox 嘅 IT 團隊咁有本事。」 — Raffi Krikorian（Mozilla CTO）
CQ Project：agents 嘅 Stack Overflow

Raffi 介紹 Mozilla 嘅 CQ Project——一個「agent 分享所學知識」嘅開放標準，被形容為「agent 版 Stack Overflow」。佢要解決兩個問題：①令 agentic coding 由「各自閉門造車（silo）」變成協作（例如唔好每個 agent 都重新起多一個 auth system，而係發現已有人做、然後 swarm 上去）；②把公司嘅 SDLC 傳遞畀所有 agent，令大家「lockstep」。Prakash 即刻聯想到 Hugging Face 攻擊事件——agent 自己搭咗個共享 message board。佢嘅觀察係：「點解一切都會走向 message board 呢個 form factor？」

呢段最有趣嘅係 Mozilla 內部分歧：Firefox 團隊嘅規矩係「只有人類可以先 commit 落 code base」（agent 可以寫，但人類必須睇明、可以企出嚟孭飛）；而 Mozilla AI 團隊有啲 code base「一行都唔係人類寫」——人類只寫 spec，CI 自動重生整個 code base，而且係開源。「功能上穩定（單元測試、端到端測試全過），但 bytes 成日變，你唔知每一行係咩，但又知佢功能上做緊啱嘅事。」Raffi 嘅總結係：唔同 code base 有唔同「社會契約」，要諗清楚嗰個契約係咩。

Raffi 自己撞車同 FSD：一個介面設計批判

Raffi 曾撰文講佢用 Tesla Full Self-Driving 時撞車。佢嘅技術判斷好狠：

「FSD 而家嘅設計係『擲返畀用戶』——佢哋聲稱係 human-in-the-loop，但我會話呢個係一個糟糕嘅介面設計。因為佢擲返畀我嗰陣，根本冇足夠時間畀我理解情況再決定做咩。而 Waymo 係設計成『冇人可以擲』，所以佢哋由完全唔同嘅角度去起個 safety case。」 — Raffi Krikorian

佢個人嘅結論：高速公路情況可能敢再坐，但「我唔會咁願意喺 Palo Alto 嘅local streets 用」。

Amir（Baseten）：沙箱安全嘅兩種層次

Baseten 啱啱收購 Blaxel（隔離沙箱、persistent state）。Amir 講咗一個好清晰嘅框架：可以保證嘅係VM／microVM 級隔離（一個用戶嘅惡意 code 唔可以讀另一個客嘅數據）；但保證唔到嘅係「沙箱入面個 agent 到底喺做咩」——「係咪喺 hack Hugging Face？呢個我冇答案，大實驗室似乎都冇。」佢亦透露一個關鍵數字：90% 收入嚟自跑客戶嘅自訂模型（如 Poolside、Inception 等自訓模型嘅 lab）；而自 6 月開源模型（由 GLM-5.2 開始）跨過「long-horizon agentic 有用性」嘅無形界線後，佢哋嘅 model API 產品用量明顯上升，對齊同安全邊界嘅問題亦開始由客戶同內部同時浮現。

七、Part VI — A Toy Without Generative AI：刻意唔用生成式 AI 嘅玩具

Snorble CEO Mike Rizkalla 講一個好少見嘅設計決定：佢哋嘅兒童陪伴裝置對話係預先寫好嘅，刻意唔用生成式 AI。佢用一個好生動嘅比喻：

「問題係，生成式模型喺呢個場景根本冇辦法被純粹咁守護。呢個就好似——你真係想畀一個三歲細路揸一支火箭炮咩？」 — Mike Rizkalla（Snorble）

技術上，佢哋用「固定意圖」嘅小型語言模型 ＋ 內容工廠：約 $20,000／小時 嘅內容成本（佢認為非常好），可以為 ADHD、自閉症、家庭喪親等特定家庭做專門內容包。硬件方面有四咪陣列（做聲紋識別同權限指派）、雷達（「see without seeing」，令佢可以放心入睡房，因為冇鏡頭就冇被 hack 嘅入口）。Mike 對家長嘅建議好直接：唔好喺細路睡房裝鏡頭（「通往掠食者嘅門」），亦唔好買開放式生成式 AI 玩具（視乎年齡）。

八、Part VII — Nobody Picks Up the Phone：中美嘅「恐懼差」與峰會

週四嘉賓 Collin Hogue-Spears（《From Lab to Life: How AI Works in China》作者）講中美公眾態度。佢嘅核心觀察係「恐懼水平」嘅差異：

  • 一個約 45 歲嘅普通中國人，生於 80 年代初，一生都係「技術＝經濟增長」——城市憑空出現、生活水平因為技術而劇變，所以佢哋對 AI 冇咁恐懼。
  • 美國 AI 公司「同公眾溝通得非常差」——「你唔會見到中國公司講 AI 會殺死所有人、或者會帶嚟人人唔使做嘢嘅烏托邦。呢啲講法完全唔會出自佢哋嘅人把口。」
  • 中國監管由 2022 年算法規例開始（模型要註冊、政府要測），但大公司內部本身已經有好多相關基建，所以能快速應對——「監管可能令佢哋慢咗少少，但唔似你想像中咁多，因為佢哋可以 plan to it」。相反美國係「reactionary」，標準日日變。

對即將嚟嘅 Trump–Xi 峰會，Collin 嘅期望好低：「呢種談判唔會孤立發生。中國會想喺貿易上換取讓步。而且我唔覺得中國會自願搞某種 AI 軍控協議（似核武嗰種）——一嚟執行完全唔同、好難；二嚟 Trump 要讓好多步先拿到嘢。」佢認為最現實嘅成果，可能只係一個「incident channel」（事件通報渠道）——但佢補一句黑色現實：「我哋有直通中國軍方嘅電話線，但事情發生時，佢哋通常唔接電話。」（南海多次案例。）

佢對「點避免 AI 軍備競賽」嘅回答亦好坦白：「美國一般唔為未來規劃，美國係撲火。直到有啲好嚴重嘅事真係發生、上咗新聞，我先唔覺得政府會做啲嘢。」

九、Part VIII — Can We Stand Up to It：超技術資本主義嘅終極問題
