「瓶頸已經唔喺模型 IQ」——同一日被 Navier–Stokes 搶晒風頭嘅四件事：Meta Muse 個人 agent 嘅「權限作業系統」、Harvey RLM 令 M&A 盡調 23%→62%、vLLM／Cohere／Baseten 三條 infra 信號、同 Jacob Hilton 嘅辭職警號

📅 2026-09-09 05:04 UTC 發布·🎙️ Latent Space AINews（swyx + Alessio）·👤 非訪談——獨立成篇：同日其餘重磅新聞拆解·📝 latent.space/p/ainews-openai-reports-navier-stokes

上一篇（#144）拆咗今日唯一頭條：OpenAI 嘅 Navier–Stokes 10,000-agent claim。但同一日嘅 AINews 其實疊咗一堆一樣重磅嘅嘢——Cognition 以 $48B 估值融 $2B+、Mistral 融 $24B、OpenAI 出 GPT Image 2.5、Meta 出常駐 personal agent Muse、Harvey 用 RLM harness 將 M&A 盡調通過率由 23% 升到 62%、vLLM／Cohere／Baseten 齊齊出 infra 突破、Anthropic 安全人事震動。AINews 自己嘅開場白好坦白：「Today was a tough news cycle to launch anything… but the bar is higher these days.」呢篇就係嗰啲「原本可以自己做頭條」嘅新聞。

呢篇嘅中心論點：如果 #144 講嘅係「AI 攻入前沿數學」，咁呢篇講嘅係相反方向嘅同一件事——agent 系統嘅價值，越嚟越唔在於底層模型 IQ，而在於三層工程：產品化（權限同安全架構）、harness（orchestration + post-training）、infra（serving + rollout）。有從業者睇完 Meta Muse 之後嘅評價最到位：佢可能係首批「瓶頸唔在模型 IQ、而在 context 與 access」嘅 personal-agent 產品。
一、Meta Muse：個人 agent 賣嘅唔係智能，係「權限作業系統」

Meta 由「Dreamer joins Meta Superintelligence」重新包裝成面向消費者嘅 Muse——定位係 always-on、連接 app、可用瀏覽器、目標導向嘅 personal agent，靠 Meta 自家分發（Instagram／Messenger／Facebook／WhatsApp）同 integrations 打市場。產品細節反覆出現：每個 Muse 跑喺一部獨立隔離嘅 Linux VM、有瀏覽器操作能力、WhatsApp／app 入口，connectors 覆蓋 Gmail、Calendar、Outlook、Plaid、OpenTable、Docs、Spotify、Peloton，再加 Meta 原生嘅 Instagram、Messenger、Facebook、Marketplace。

但 Meta 推得最用力嘅差異化，唔係能力，而係安全架構。官方團隊講得好清楚：每部 Muse 跑喺自己嘅 secure VM；動作由一個獨立嘅 Sentinel 中介（mediator）；密鑰唔會直接暴露畀 agent；敏感操作需要批准；加上公開 bug bounty，最高 $300k。商務基建同樣齊全：Stripe Link 支付 + 一套「agentic payment protection／退款保證」，並將接入 Shop Pay。

Meta Muse 一覽 架構：每 agent 一部隔離 Linux VM｜中介：獨立 Sentinel 做 action mediation｜安全：secrets 唔落 agent 手、敏感操作需批准、bug bounty 最高 $300k｜連接：Gmail／Calendar／Outlook／Plaid／OpenTable／Docs／Spotify／Peloton + Meta 原生四 app｜支付：Stripe Link + agentic payment protection／退款保證 + Shop Pay｜首日用量：超內部預期 10×

從業者反應意外地正面，尤其喺 permissioning、secrets management 同 consumer utility 三點。@matthuang、@signulll、@lilyjclifford 等嘅評論都指向同一個結論：Muse 可能係首批「瓶頸唔在模型 IQ，而在 context 同 access」嘅 personal agent 產品——即係話，用戶要嘅唔係再叻嘅模型，而係一個「接得入我啲 app、又唔會亂用我啲嘢」嘅系統。呢個 framing 同本站較早覆蓋嘅 Grok Bot vs OpenClaw（#136）、Frontier AEO Tracker（#140）係同一條線：2026 personal-agent 平台戰嘅核心坐標，係「managed agent computer vs user-owned agent platform」，而權限同入口先係 moat，唔係模型。

模型／生態位置：Meta 嘅 Muse Spark 1.3 好快就被第三方工具（例如 Cursor）整合；arena 式 benchmark 亦將 Muse Spark 1.3 Max 定位為 web-dev coding workload 上 price/perf 有競爭力。要注意：呢度嘅 Muse（consumer agent 產品）同 Muse Spark（模型）係同一牌頭嘅兩層，Meta 一路用自家分發硬推。

二、Harvey RLM：harness 同 post-training 一樣關鍵——23% → 62%

如果話 Meta Muse 講「產品層」，咁 Harvey + Baseten 嘅 M&A 盡調案例就係「harness 層」最清晰嘅 case study。佢哋嘅 RLM（recursive language model）harness：用一個 root agent 去搜 data room、委派 sub-agents 審文件、再跨語料聚合發現——語料規模可以去到 80M tokens。喺合成嘅 LAB Diligence benchmark 上，單單係將「標準 tool loop」換成 RLM harness，平均 rubric pass rate 就由 23% 升到 62%（跨唔同 model 都成立）。

更關鍵嘅係第二層：harness 內部嘅 post-training，重要性唔低於 harness 本身。Harvey 報數：self-distilled SFT（用 GLM-5.2）令 pass rate 46% → 60%；GRPO（用 Qwen3.5-122B-A10B）令 held-out rooms 嘅 pass rate 30% → 63%，document coverage 更由 62% → 96%。呢組數字嘅含義係：agent benchmark 以後唔可以再將 orchestration 同 post-training 當成「模型以外嘅 glue」——佢哋係 model system 嘅一部分。

Harvey M&A 盡調：四條數 標準 tool loop → RLM harness：23% → 62% rubric pass rate｜self-distilled SFT（GLM-5.2）：46% → 60%｜GRPO（Qwen3.5-122B-A10B）：held-out rooms 30% → 63%｜document coverage：62% → 96%｜語料規模：~80M tokens

同一時間，LangChain／deepagents 出咗一批「harness 設計」嘅 QoL primitives：subagent forking（將 supervisor context 傳落 subagent，唔使重新砌）同 managed connections（抽象 OAuth／token／consent flow，支援 agent-owned 或 user-owned 身份）。呢啲係 stack 開始成熟、開始圍繞「long-horizon agent workload」收口嘅信號——唔再係 demo 級嘅 glue code。

三、推理同系統：vLLM／Cohere／Baseten 三條 infra 信號

第三層係 infra，今日一次過出咗三條清晰信號：

① vLLM Hybrid HiSparse（針對 sparse-MLA）。做法係：KV 盡量留喺 GPU，cold KV pages 先 offload 去 host memory，另外用一個 hot buffer 服務 indexer。實測喺 GLM 5.3、1M context、8×H200、configured concurrency 32 之下，純 offloading 只撐到 5–6 條 request，Hybrid HiSparse 去到 19–25 條。呢個數字對 RL rollout 同長 context 併發直接有利——以前 VRAM-bound 嘅 decode 會殺死 throughput。

② vLLM 嘅 agent 流量全棧優化（AgentX benchmark）。三個發現好反直覺：pipeline parallelism 對 cold long prompt 有用，但喺 warm short turn 反而蝕；decode context parallelism 高度取決於模型嘅 attention stack；session-sticky routing（黏 session 的路由）勝過 naive load balancing——因為喺快 turn agent 場景，warm KV cache 比「平均排隊」更重要。即係話，agent serving 嘅優化目標，同傳統「平均分攤請求」係兩回事。

③ Cohere decode megakernel + Baseten live rollout。Cohere 開源咗一套以「decode megakernel」為核心嘅 serving stack，聲稱喺 North Mini Code 上比 vLLM 快 1.58×，高 batch size 下 end-to-end 增益 1.25×–1.41×。Baseten 就報：frontier RL rollout 而家可以喺全球唔夠 40 秒內上到新 policy 權重，只需要 6 秒暫停。

趨勢很清楚：infra 正由「靜態模型 serving」轉向「為持續 post-training 同 rollout refresh 而設」。 ——AINews 對今日 infra 三條新聞嘅總結

呢三條拼埋睇，係同一個故事：當模型每幾個月換一次 pre-train、RL checkpoints 每月迭代、harness 每週更新，serving infra 就必須支援「權重快速換、長 context 高併發、session 黏住 cache」。呢個係 #144 嗰種「用海量 inference compute 攻一個問題」嘅底層前提——冇呢層 infra，10,000 agent 並行 88 小時根本唔可行。

四、同日嘅錢：Cognition $48B、Mistral $24B、GPT Image 2.5

今日「被搶風頭」嘅商業新聞其實件件都係大新聞：

  • Cognition 宣佈融資 $2B+，估值 $48B；run-rate revenue 由 5 月嘅 $492M 升到接近 $900M。AINews 註：如果唔係撞正 Navier–Stokes，佢會係當日頭條。（Cognition 係 Devin 母公司，同 agentic coding 直接相關。）
  • Mistral 完成 $24B Series D（由 Anjney Midha 公佈）。歐洲 frontier lab 嘅估值亦追上嚟。
  • OpenAI GPT Image 2.5 / ChatGPT Images 2.5：對比 2.0 延遲最多降 50%；更真實；重複編輯一致性更強；支援「comment-based 局部修改」；透明背景；新增 Sketch 引導生成工具。兩個 API 變體：Flare（速度／質素平衡）同 Sunburst（高精度細節）。Arena 聲稱喺 text-to-image、image-edit、multi-image-edit 三個榜拎到 #1 同 #2，多圖編輯增益尤其大。整合迅速落地 fal、Higgsfield、Manus、Hermes Agent。

仲有 GPT-6 Astra 嘅全面鋪開：OpenAI 話 Astra 已完整 rollout 到 Plus、Pro、Business、Enterprise（涵蓋 Codex 同 ChatGPT Work）。社群實測亦幾誇張——@theo 報 Astra 喺 macOS 上編譯並以 120 FPS 運行《任天堂明星大亂鬥 Melee》（約 6 小時 loop）；Vals 報 Astra 喺無專用 harness 下、3 小時內建出 Minecraft 地獄門，幾乎打爆一個未公佈嘅 computer-use eval。

將呢條同 #144 疊埋睇，對照非常尖銳：同一日，一邊係「10,000 個比 Astra 更強嘅 agent、自主組織、連跑 88 小時解前沿數學」；另一邊係一位前安全研究員話「兩大 lab 都喺不負責任地衝自我改進型超智能」。呢個就係 2026 下半年的核心張力——能力曲線同治理曲線唔同步。值得一提，Hilton 用嘅係「self-improving superintelligence」（自我改進型超智能），而 #144 嘅 Navier–Stokes agent swarm，技術上正就係「用 agent 自動化做研究」嘅雛形——兩者係同一件事嘅兩面。

六、一個 meta-frame：四層能力疊加，同時加速

Towards AI #221 提供咗一個好有用嘅框：而家嘅 AI 能力進步，其實係四層同時疊加——

  • 更大嘅 foundation model：約每三個月一次（據報 GPT-5.5-Sol、GPT-6 Astra、同未公開嘅新模型係三個唔同 pre-train）；
  • RL 迭代／checkpoints：約每月一次；
  • Codex／Claude harness 改進：約每週一次；
  • memory、compaction、skills：日復日改善個人重複 workflow。

呢個框解釋咗點解今日會「四件事同時重磅」：呢四層嘅節奏唔同、但同時向前，所以任何一日都會有好多唔同維度嘅新聞一齊爆。Towards AI 作者更報咗一個訊號：OpenAI 內部 chart 顯示，median researcher 嘅每日 agent spend（按 API 價計）由 7 月初到 8 月中上升約四倍，去到每日超過 $600，而公司報 3.1 agent-workdays per human workday——即係話，AI 正在加速「生產下一代模型」嘅研究本身，形成一條回饋迴路。

整合 insight：今日呢批新聞合埋睇，會見到一條清晰嘅分層——產品層（Meta Muse：賣權限同 access，唔係 IQ）、harness 層（Harvey RLM：orchestration + post-training 決定 23% 定 62%）、infra 層（vLLM／Cohere／Baseten：為持續 rollout 而設）、資本層（Cognition $48B、Mistral $24B：錢繼續湧入 agentic coding 同 frontier）。而最值得記住嘅一句，係從業者對 Muse 嘅判斷——當 agent 能力去到某個水位，樽頸就由「模型夠唔夠叻」轉移到「context 同 access 有冇打通、權限有冇設計好」。呢個轉移，正正就係 infra、harness、產品三層要一齊答嘅問題。

一個誠實嘅 caveat：呢篇係 AINews 當日輿論聚合 + 官方貼文嘅整合分析，唔係一手測試。所有數字（Muse 首日 10×、Harvey 23%→62%、vLLM 19–25 併發、Cohere 1.58×、Baseten 40 秒／6 秒）都係各方自報或 benchmark 特定設定下嘅結果，唔應當成常態成績表。Jacob Hilton 嘅表態屬個人公開陳述，同 lab 官方立場未必一致。引用一律以來源帖文為準。
