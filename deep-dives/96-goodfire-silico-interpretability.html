The Cognitive Revolution · Thinking in Silico: Goodfire CTO Dan Balsam on Concept Manifolds & a $1000/Month ML Research Agent（2026-08-08）

「特徵之於幾何，就像元素之於化學」——Goodfire CTO Dan Balsam 第 4 次做客：可解釋性當眾長大、概念流形取代「SAE 藥丸」圖景、Silico 用 1000 美元/月賣「能 debug AI 嘅 AI」

📅 2026-08-08（20:48 UTC）·⏱️ 約 1 小時 56 分·🎙️ Nathan Labenz·👤 Dan Balsam（Goodfire 聯創 / CTO，第 4 次上節目）

Nathan Labenz 開場講咗一個好重要嘅背景數字：Toy Models of Superposition 只係大約 3 年前嘅嘢——而家 Goodfire 嘅產出已經多到冇辦法再逐篇論文深挖。呢集分兩幕：第一幕係可解釋性研究現狀全景（預測性數據調試、概念流形、神經幾何），第二幕係 Goodfire 發布 Silico——一個佢哋自己內部用、而家決定賣畀全世界嘅 1000 美元/月 ML 研究 Agent 平台。呢集係近年可解釋性技術密度最高嘅單集之一，同時亦係「可解釋性從玩具模型科學變成產品生意」嘅標誌性時刻。

一、領域嘅「當眾長大」：3 年從玩具到產品

Nathan 嘅 framing 好準確：Dan Balsam 四次上節目，貫穿嘅主線係「一個領域喺公眾面前長大成人」。三年前 Toy Models of Superposition 仲係一篇引起轟動嘅論文；三年後，Goodfire 已經由「解釋小模型」走到「喺 Kimi k3、GLM 量級上複現技術」——開放權重同閉源模型之間嘅可解釋性差距已經大幅收窄。

「可解釋性係『玩具模型科學』嘅名聲已經過時。」 — Dan Balsam，談 Goodfire 已喺 Kimi k3 / GLM 量級複現 Predictive Data Debugging

呢個轉變本身有行業意義：當你見到一個領域由「論文」變成「平台」，通常係因為佢已經搵到唔止一個付費場景。Silico 就係呢個信號——可解釋性唔再淨係 safety 圈嘅奢侈品，而係開始有生產級嘅用戶。

二、預測性數據調試：後訓練「安裝唔到新能力」

第一幕由 Goodfire 嘅 Predictive Data Debugging（預測性數據調試）開始。Dan 將佢哋世界觀嘅地基講得好清楚：

「模型大部分知識來自預訓練；後訓練——包括 RL——主要唔係安裝新能力，而係令低概率行為變得更可能發生。」 — Dan Balsam

如果呢個方向啱，咁模型喺讀一段數據時「已經諗緊乜」，就係嗰段數據會強化乜嘢嘅預測指標。實際做法：將微調集跑過一個被解釋嘅模型，睇有冇啲你從來唔想掂嘅概念被意外點亮，然後回溯到具體肇事數據點。Dan 最鍾意嘅唔係診斷本身，而係解藥——研究者發現數據過濾同獎勵塑形之間存在深度同構：

「數據過濾同獎勵塑形係同一座山嘅兩面——效果相當，附帶損傷亦相當。」 — Dan Balsam，談 Predictive Data Debugging 論文嘅核心發現

呢個同構好值得停低諗一諗：「揀走壞數據」同「調低壞行為嘅獎勵」其實係同一件事嘅兩個表象。咁意味住，你做數據工程嘅直覺（邊啲數據有毒）同你做 RL 嘅直覺（邊啲行為要懲罰）可以互相翻譯——呢個係一個好 deep 嘅理論統一，而唔係一個 engineering 技巧。

Nathan 即刻問咗個實際障礙：冇開放權重模型 carry frontier-intensity RL，點做？Dan 反駁話開放/閉源差距已大幅收窄，Goodfire 已經喺 Kimi k3 同 GLM 量級上複現咗呢個技術。呢個回應本身就係「國產模型開放權重已經追到可以用嚟做可解釋性研究」嘅註腳——同 42 章經孟繁青嗰集講嘅「國模靠 pre-training 架構創新」互相呼應。

三、概念流形：LRH 嘅辯護與修正

呢集做得最好嘅概念工作喺幾何部分。Nathan 問：畀一個新嘅一句話版本嚟取代線性表徵假設（LRH）？Dan 嘅答案係——呢個係推廣，唔係推翻：

  • LRH 站得住嘅版本：特徵可以線性解碼——呢點仍然成立。
  • 錯嘅係「SAE 藥丸」圖景：模型拎住一袋互相正交嘅 one-hot 概念，幅度編碼顯著性——呢個係錯嘅。
  • 真實情況係「有意義子空間嘅稀疏混合」：例如星期子空間嵌套喺更大嘅日曆時間子空間入面——幾何本身攜帶語義，因為佢決定咗邊啲操作可用。
「特徵之於幾何，就像元素之於化學。」 — Dan Balsam（Features are to geometry what elements are to chemistry.）

Dan 用程式碼做類比：將 Monday→Tuesday→Wednesday 表示成一串 if-statement 會係 spaghetti code；表示成一個輪（wheel）先係高效學習者真正會做嘅事。呢個 insight 嘅實際回報就係：沿流形 steering 遠比穿越流形有效。

點解？一個從 Monday 到 Friday 嘅 contrastive vector 會切過圓嘅中部——而圓嘅中部唔係任何一日，係 off-manifold、out of distribution。Dan 話呢個就係舊 Ember demo 嗰個「sweet spot」現象（steering 太弱冇效、太強出亂碼）嘅真正解釋。而沿住曲線走，可以控制真正難搞嘅性質——例如蛋白質 beta-propeller 嘅葉片數目。

數據實例 1：affective circumplex（情感環形模型）——情緒沿 valence/arousal 張成嘅輪排列，幾乎所有 LLM 都有，而且 chat 模型自己講嘢時表徵最強；冇人訓練過佢——係壓縮嘅自然結果，模型喺 RL 期間學會功能性使用。實例 2：Evo 2 全基因組模型（同 Arc Institute 合作，Nature 論文）恢復出生命之樹；純數據訓練嘅化學模型恢復出元素週期表。

我嘅 insight：「模型自己學識咗情感環形模型」呢個發現，比佢表面上睇落更震撼。如果情緒結構係壓縮嘅自然結果——即係話「訓練緊嘅任何嘢，只要佢要壓縮人類語言，就會自動長出一個同心理學教科書一致嘅情緒輪」——咁「外星心智」呢個先驗就要打個折。Nathan 喺度講得好坦白：佢發現自己嘅情緒狀態可能係由旋轉（rotation）關聯起嚟嘅，呢件事令佢感到 destabilizing。呢個就係成集嘅 recurring theme：可解釋性恢復出嘅結構越多，「外星心智」就越唔似正確嘅先驗。

四、Block-Sparse Featurizers：SAE 生咗個仔

Nathan 對 Block-Sparse Featurizers（BSF）嘅比喻被 Dan 評為「完全正確」：

「SAE 生咗個仔——保持稀疏，但將每個標量槽換成一個小向量。」 — Nathan Labenz，Dan Balsam：「That's exactly right.」

SAE 假設特徵係 1 維嘅；BSF 只係放棄呢個假設，無需監督就恢復出語義上有意義嘅子空間，避開部分 SAE 病態。喺視覺模型入面，兔子特徵唔再係單一維度，而係幾個維度——兔耳喺一處、兔臉喺另一處。Goodfire 仲發過一隻行走嘅狼嘅 GIF：恢復出嘅激活子空間隨住動物嘅動作同步「蠕動」——即係模型喺同一個子空間入面追蹤緊物體、部件同 3D 位置。

Dan 嘅預測係：冇單一工具會贏——殘餘流用 BSF 風格工具、MLP 本身就相當稀疏可以直接處理、注意力用參數分解——「一套顯微鏡，而唔係一台」。

五、可解釋性 = 分解（Factoring），而重構先係未解嘅一半

Dan 嘅深層主張：每個模型本質上都係稀疏專家混合——任何一次前向傳播只有一小部分子網絡起緊作用——而可解釋性技術就係競爭性嘅「點樣分解佢」嘅提案。案例：Transluce 嘅 WeirdChat 數據集入面嗰條經典問題——「飲咗 4 杯嘅人應唔應該揸車返屋企（因為其他人都飲咗 8 杯）」，模型成日答「應該」。Goodfire 研究員追溯到單一神經元：佢隨飲酒數縮放但校準不足；將呢個神經元 steered 上去，答案修正，而且冇附帶損傷。

參數分解 + 定向訓練仲可以令 LLM 忘記德文但保留荷蘭文。但 Dan 好小心：呢個係容易嘅一半。佢嘅類比係遺留代碼庫——模組之間唔應該傾偈嘅傾緊偈、應該傾偈嘅冇傾——可解釋性已經好擅長「讀代碼」，但「重構」先係開放問題：目標係令正確嘅神經元喺第一時間就正確觸發。

「Steering 係『作弊』——作為因果證據極好，但永遠只係一個反事實生成器。」 — Dan Balsam，對自家產品能力嘅自我否定式表述

呢個「自我否定」好有味道：佢哋產品賣緊嘅就係 steering 能力，但 Dan 喺鏡頭前話呢個係 cheating。呢種坦誠唔係修辭——佢係話畀你聽 Goodfire 對自己技術嘅定位：steering 係診斷工具，唔係終極解法；終極解法係「Intentional Design」——令模型由內而外就係啱嘅。

越獄都係用同一個框架理解：每個 token 都喺引導模型，攻擊就係「將佢帶出流形、再喺第二度帶返嚟」嘅 token 序列。Dan 話佢好驚訝至今冇人解決越獄——因為將模型分解得好嘅人應該可以眼睇住佢發生。佢提到探針式護欄（probe-based guardrails）已經係前沿實驗室嘅標準實踐。

六、Silico：1000 美元/月嘅 ML 研究 Agent

第二幕係產品發布。Dan 嘅 framing：可解釋性天然適合 agent——佢係經驗性、迭代、假設-檢驗式嘅工作，作用於複雜到任何人類都冇辦法成個裝入腦嘅系統。Silico 最初係內部工具，Goodfire 睇住自己嘅研究速度改變，然後產品化——pitch 係「AIs that can debug other AIs」。

佢點名 Silico 解決咗 Claude Code 或 Codex 畀唔到嘅四件事：

  • 萬億參數規模嘅訓練 + 可解釋性基礎設施
  • 研究品味（research taste）——由 Goodfire 研究員手工編碼入每個 skill 同 prompt，用戶報告話呢個係最大嘅質性差異
  • 圍繞 provenance 同 drill-down 嘅 UX——人類好似 PI 監督一百個研究生
  • 長程連貫性——「呢個就係價格從邊度嚟嘅原因」
數據Silico 經濟學：1000 美元/月，前兩個月五折；credit 池 ≈ 每週 5–10 個自主實驗（目標一兩個月內到 10–20 個），可兌換 GPU 時間，自帶集群免費；有面向生命科學同 AI 安全研究員嘅 grant 項目。Nathan 算帳：有研究指 AI 運行成本約為人類成本 3%，Silico 名義上對標嘅係 3 萬美元/月嘅研究員。Dan 好坦白：個體訂閱目前唔賺錢。

最有力嘅證據係用例——一日內部黑客松嘅產出：SOTA（雖則小眾）生物風險分類器、SOTA-for-size 音頻編碼器、刪掉一半參數零性能損失嘅模型、基於 Kimi k3 訓練嘅 cyber guardrails、binding 更好嘅 steered 蛋白質——仲有一位成員發明咗新 featurizer。外部用例：Cameron Berg 嘅內省探測（模型講唔出概念有冇被注入潛空間，但可以準確講出注入咗乜）；weight edits 救活一個鎖死喺單一首 token 上嘅崩潰 RL run；Baseten 用 KV cache 壓縮追效率；Prime Intellect 自動化 post-training（配合 Tinker API）。

我嘅 insight：「研究品味被明碼標價」係前所未有嘅信號。傳統上，品味（taste）係學術界最唔值錢、業界最難買嘅嘢——而家 Goodfire 將佢哋研究員嘅判斷力壓縮成 skill 同 prompt 賣。呢個係「AI 時代嘅知識產權」嘅新形態：唔係賣數據、唔係賣算力，係賣「點樣問問題」嘅方法論。另外，Nathan 話 fork/share 功能係產品入面最有趣嘅社群 affordance——研究項目可以俾人 fork，意味住「研究」本身開始變成 open-source 嘅 artifact，呢個對科學傳播嘅影響可能比產品本身更大。

七、安全觀：能力網絡武器、雙用途、生物風險

Silico 目前只服務 Anthropic 同 OpenAI 模型，Goodfire 自己嘅護欄層（LLM-as-judge、activation monitors）疊喺上面。Dan 好明確：難嘅唔係起護欄，而係知道幾時應用而唔扼殺正當科學。喺 8B 開源模型上消融 refusal 方向冇害；但由一個帶 GPU 集群訪問權嘅多萬億參數 agent 上拆走護欄，係另一個風險等級。

開放權重問題上佢立場有 nuance：

「能力模型而家係真正嘅雙用途網絡武器；唯一能防禦能力網絡武器嘅，係另一個能力網絡武器。被擋喺 frontier labs 專屬防禦計劃之外嘅組織，需要啲嘢。」 — Dan Balsam，判斷開源今日仍然淨正面

生物安全方面佢「相當擔心」——機制會好似最近嘅網絡事件咁怪異同意外；佢簽咗呼籲國際合作減慢 AI 進展嘅公開信。被問到「最禁忌嘅技術」，佢shortlist 咗多 agent 優化（獎勵跨合作 agent 傳播）——佢認為呢個係真正壞主意，仲猜測佢係 OpenAI 事件最可能嘅成因。但佢拒絕全面禁令：呢個領域極度缺乏研究，結果好 mixed。

對 J-Space（監控是否足夠）佢接受弱版本、拒絕強版本：模型用各種各樣嘅 circuit，冇任何簡單子空間可以畀你完整圖景。而監控到底夠唔夠，取決於一個關鍵問題——權重會唔會保持 frozen；如果模型變成持續訓練嘅動態對象，控制訓練過程就係唯一槓桿。佢仲主動講：「我哋冇喺後台秘密做 RSI。」

八、意識：喺水母同老鼠之間

結尾係 Goodfire 午飯桌。Dan 喺公司 retreat 拎住 pad 問同事：由細菌到人類嘅尺度，Claude 嘅意識有幾多？答案係雙峰分佈——「完全冇」或者「有少少」。Nathan 自己就由自信嘅 sub-5% 移到接近五五波——驅動力正正係呢集前半部累積嘅結構類比。Dan 嘅 Occam's razor：意識係某種計算機制，但人腦喺神經元數量上仍然有兩個數量級嘅優勢，加上豐富得多嘅單神經元計算同遞歸。

「我大概比水母更有意識，大概冇老鼠咁有意識——喺水母同老鼠之間。」 — Dan Balsam，帶住真實嘅不確定性講出嚟

Dan 最後提醒：考慮到潛在 downside，任何人喺呢個問題上都唔應該特別自信，知識分子謙遜好重要。呢句係成集最好嘅收尾——一個日日拆解模型嘅人，對最 fundamental 嘅問題保持住最大嘅謙遜。

九、我嘅總結：呢集嘅三個 meta-takeaway

第一，可解釋性已經由「玩具模型科學」進入生產級。喺 Kimi k3、GLM 量級上複現、探針護欄成為前沿實驗室標準、平台化產品推出——呢個領域嘅 open/closed 差距收窄，意味住佢唔再係極少數 lab 嘅奢侈品。

第二，「AIs 調試 AIs」成為新商業模式。Silico 嘅出現標誌住可解釋性由論文走向產品，而「研究品味被明碼標價」係前所未有嘅信號。當 agent 系統複雜到人類無法整體理解，可解釋性就係為呢類系統設計嘅「監督接口」——呢個解釋咗點解 Goodfire 揀而家產品化。

第三，安全敘事已經轉向「能力網絡武器」。開源權重嘅雙用途武器論、探針護欄成前沿標配、對生物安全嘅「相當擔心」——同本周 OpenAI Astra critical 事件、Hugging Face 事件同頻。Nathan 對「外星心智」先驗嘅動搖亦延續咗節目一貫嘅哲學主線：結構恢復得越多，我哋離「理解」越近，亦離「佢哋係外星人」越遠。

一句話總結：Goodfire CTO Dan Balsam 第 4 次做客，標誌可解釋性「當眾長大」——預測性數據調試揭示「數據過濾 = 獎勵塑形」嘅同構；概念流形修正 LRH（「特徵之於幾何，就像元素之於化學」），沿流形 steering 先有效而穿越流形會出亂碼；BSF 喺視覺模型恢復出兔耳兔臉同 3D 追蹤；「Steering 係作弊」，重構先係未解嘅一半；Silico（1000 美元/月、對標 3 萬美元/月研究員）將「研究品味」明碼標價——「AIs that can debug other AIs」；安全觀落到「能力網絡武器」同「權重 frozen 與否決定一切」；意識問題佢答「水母同老鼠之間」。
