呢集嘅中心論點：2026 嘅 AI 圈唔係一條直線，而係四張平行嘅飯桌——模型主桌、Coding 桌、多模態桌、Agent 桌——每兩個月一次洗牌。最值得記低嘅唔係邊個賽道熱，而係三條反直覺但可操作嘅判斷：① 單 token 定價已經失效，要改用「有效成本 = token 成本 + 試錯成本 + 人工糾正」；② 「AI 沒有網絡效應」，所以護城河唔會自動複利；③ 下桌嘅玩家——「服務型應用一半可能消失」。投資判斷則收斂成最赤裸嘅一句：一級押具身，二級買算力。

OUTLINE：03:29 主桌之争｜07:40 SOTA 模型快速折舊與智譜的萬億市值｜13:06 2026 敘事日曆

「主桌之争」仍然係模型本身嘅問題——但呢張主桌唔再穩定。講者指出 SOTA 模型正快速折舊：今日嘅前沿，可能兩三個月後就被追平甚至反超；佢哋用「智譜嘅萬億市值」做敘事錨點，說明市場點樣為「國產模型頭部」定價，同時亦暗示呢種定價帶有情緒成分。

2026 嘅敘事日曆被切成兩段：春節嘅視頻模型爆發 → 暑期嘅 Agent 混戰。呢個「兩段式」嘅觀察好有用——佢解釋咗點解上半年嘅注意力喺視頻／多模態，而年中開始急速轉向 Agent。而貫穿全年嘅底色，係「每兩個月一輪洗牌」：座次未定，敘事先行。

三、第一張被掀嘅桌：Coding——國內外路線已分叉

OUTLINE：20:25 美國頭部 ARR 已破 10 億美金｜23:02 中國 Coding 的「彎路」：從寫代碼變成辦公助手｜27:49 Coding 桌誰會留下：中國要看 To B 生態

四張桌入面，最先被掀翻嘅係「Coding 桌」——但唔係因為佢冇價值，而係因為佢嘅贏家已經明顯分化。

美國側嘅事實好硬：頭部 Coding 應用嘅 ARR 已經突破 10 億美金。呢個數字嘅份量在於，佢證明咗「寫代碼」呢件事本身係一個可以養出巨型公司嘅市場，唔係一個功能。

中國側嘅診斷就辛辣啲：中國 Coding 走咗一條「彎路」——由「寫代碼」漂移成「辦公助手」。呢個觀察直指一個產品定位嘅偏離：當國產 Coding 產品為咗迎合更廣嘅用戶而弱化咗「工程師工具」嘅定位，佢就同時失去咗兩邊——既唔夠硬核畀專業開發者長期付費，又唔夠輕巧去贏辦公場景嘅通用助手之爭。

所以「Coding 桌邊個最後留得低」嘅答案係：中國要看 To B 生態，而唔係單純睇模型 benchmark。呢句同 Latent Space 側嘅 FDE 熱潮（Vinoo Ganesh 講「護城河係被修正過嘅行業營運真相」）形成跨語言嘅共鳴：Coding 嘅終局唔喺模型，喺企業落地同生態。

Coding 桌 美國頭部 Coding 應用 ARR 已破 10 億美金｜中國路線漂移：由「寫代碼」→「辦公助手」（講者稱之為「彎路」）｜下一階段勝負手：To B 生態，唔係 benchmark 排名。
四、第二張多模態桌：中國領跑係唔係成立？

OUTLINE：30:36 美國多模態邊緣化、中國百花齊放？｜31:35 Seedance 2.0 之後，情緒面大翻轉｜33:24 中國短視頻基建如何反哺視頻模型？

呢一節嘅論述係「美國多模態邊緣化、中國百花齊放」。呢個講法本身帶有情緒成分，但講者畀出咗一個相對結構性嘅解釋。

轉折點係 Seedance 2.0——佢之後，情緒面出現大翻轉。所謂「情緒面」，即係市場同從業者對「中國視頻模型能唔能夠追上／反超」嘅集體判斷。呢類情緒轉折通常先於硬指標，但佢會直接影響資本同人才嘅流向。

而更值得記低嘅係佢哋提出嘅結構性原因：中國短視頻基建反哺視頻模型——包括數據、分發同工程基建嘅複用。呢個係一個「中國特有嘅供給側優勢」論證：短視頻平台累積嘅海量視頻數據同高效分發／工程能力，令中國做視頻模型嘅邊際成本更低、迭代更快。呢個唔係單純嘅「模型做得好」，而係生態位嘅差異。

五、第三張桌 Agent：由「能聊天」到「可托付」

OUTLINE：35:41 Agent：從「能聊天」到「能幹活」｜38:23 Agent 破圈：真實下沉場景已經開始｜41:33 從 OpenClaw 到「可托付」：Agent 基礎設施才剛起步

Agent 桌嘅核心命題係「由能聊天到可托付」。呢個講法比「Agent 好唔好用」精準得多——「能聊天」係 demo 階段，「能幹活」係能力階段，而「可托付」係信任階段：你敢唔敢真係把一件有後果嘅事交畀佢，唔使肉眼覆核每步。

講者指出，Agent 嘅真實下沉場景已經開始——即係唔再局限喺技術圈嘅玩具 demo，而係開始滲入具體行業同真實工作流。但佢同時畀咗一盆冷水：由 OpenClaw 到「可托付」，Agent 基礎設施才剛剛起步。呢句關鍵在於把問題由「模型夠唔夠聰明」搬去「infra 夠唔夠穩」：權限、隔離、審計、可靠性、失敗恢復——呢啲先係「可托付」嘅真正門檻。呢個判斷同近期 Latent Space 講 Meta Muse 個人 agent 嘅「權限作業系統」、以及 OpenAI Agents API／沙盒嘅方向完全一致。

六、第四張桌 價格：斬殺線橫亙，單 token 定價正在失效

OUTLINE：43:30 價格戰：從中國燒到矽谷的「斬殺線」｜46:31 有效成本 = token 成本 + 試錯成本 + 人工糾正｜48:52 Token 補貼與無效消耗：AI 沒有網絡效應

呢一節係全期最可操作嘅部分。價格戰由中國燒到矽谷，「斬殺線」橫亙——即係某個價位以下，玩家基本上冇得玩。但講者真正想講嘅係：單 token 定價正在失效，因為佢反映唔到真實成本結構。

有效成本 = token 成本 + 試錯成本 + 人工糾正 — OUTLINE 04-48 段「價格桌」論點

呢條公式嘅價值在於佢把「AI 平唔平」呢個問題拆成三截。當 token 單價因為補貼而趨近於零時，用戶體驗到嘅總成本其實由另外兩截主宰：試錯成本（問錯、猜錯、重跑嘅消耗）同人工糾正（agent 做錯之後，人要花幾多時間去執手尾）。呢個正好解釋咗一個反直覺現象：token 越來越平，但企業嘅 AI 總支出反而上升——因為佢哋買嘅唔係 token，係「可交付嘅結果」。

講者仲點名 token 補貼同「無效消耗」 嘅問題，並拋出一個全場最反直覺嘅判斷：

「AI 沒有網絡效應。」 —《有點Yi思》第 14 期「價格桌」

呢句值得停一停。傳統互聯網嘅護城河公式係「用戶越多 → 數據越多 → 產品越好 → 用戶更多」，但 AI 應用嘅呢條迴路明顯更弱：模型能力係租返嚟嘅（會折舊）、數據嘅邊際增益唔一定複利、用戶轉換成本亦未必隨規模上升。如果「AI 沒有網絡效應」成立，咁多數 AI 應用嘅估值邏輯就要由「平台」改回「生意」——呢個係一個偏空、但極具體嘅判斷。

七、2026 年 AI 嘅錢流向邊？

  • 投資人視角：「掀桌子太快，但人在江湖身不由己」——呢句道盡一級市場嘅兩難：明知賽道輪換太快、估值有泡沫，但唔落注又怕錯過，落咗注又怕接火棒。
  • 一級押具身，二級買算力：呢個係全期最赤裸嘅資金流向判斷。一級市場押注具身智能（希望押中下一波硬件浪潮嘅頭部），二級市場則買確定性最高嘅算力（賣鏟人邏輯）。呢個「一級風險、二級確定」嘅分野，係 2026 資本市場最清楚嘅一條線。
  • 大廠身位：大廠嘅策略係「邊打邊看」，而講者點名「組織是核心變量」——即係話大廠勝負唔喺模型本身，喺能唔能夠快速重組團隊、迭代打法。
  • 下桌嘅玩家：最扎心嘅一句——服務型應用一半可能消失。呢個判斷同「AI 沒有網絡效應」+「單 token 定價失效」構成一套邏輯：當模型能力被平台化、而應用層冇網絡效應護城河，中間好多「套殼服務」會被上下夾擊而消失。
2026 錢流向一圖睇 一級：押具身（風險注）｜二級：買算力（確定性）｜大廠：邊打邊看、組織為核心變量｜下桌：服務型應用一半可能消失｜定價邏輯：單 token 失效 → 改用有效成本。

OUTLINE：01:29:56 克服恐懼，AI 比以往所有新事物都更容易接受
