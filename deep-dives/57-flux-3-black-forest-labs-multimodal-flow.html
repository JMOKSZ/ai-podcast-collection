FLUX 3：統一多模態流模型——從圖像到機械人動作嘅世界模擬器

📅 2026-07-23 · 🎙 swyx, Alessio Fanelli（主持） · 👤 Black Forest Labs（Stability AI 前核心團隊）
FLUX 3 Self-Flow 多模態 開源權重 機械人 The Stack v3 世界模型

一、FLUX 3：唔係一個模型，係一個世界模擬器

2026 年 7 月 23 日，Black Forest Labs（Stability AI 前核心團隊出走創立）發布咗 FLUX 3——一個統一嘅多模態 Flow Model。但呢句描述太抽象。具體啲講：FLUX 3 係一個用同一套權重同時做圖像生成、影片生成（包原生音頻）、字體渲染、動畫設計、同機械人動作預測嘅模型。唔係三個模型共用一個品牌名，係一個模型嘅三個能力。

呢個區別好重要。現有嘅「多模態」模型大部分係：一個語言模型 + 一個視覺編碼器 + 一個音頻解碼器——三件嘢用 glue code 痴埋一齊。FLUX 3 嘅做法截然不同：圖像、影片、音頻三種模態喺同一個 flow matching 訓練過程中同時學習，互相約束、互相教學。

「Each is a projection of the same underlying reality, captured by different sensors, each of which loses some information in the process. Images capture spatial structures… Video restores time… Audio reveals causal relationships… Learn from all of them at once and their mutual constraints tell you more: the sound has to match the impact, the motion has to obey the mass, the future has to follow from the past.」

— Black Forest Labs，FLUX 3 官方博客

呢個表述唔係營銷語言，係架構層面嘅設計哲學。每一種模態都係同一個物理世界嘅投影——圖像睇到空間結構，影片睇到時間動態，音頻揭示因果關係。單獨學任何一種，你只係學到投影本身。一齊學，佢哋嘅相互制約會教會模型世界係點運作嘅：一個杯跌落地應該有碰撞聲，而唔係隨便一個撞擊 noise。呢種「因果一致性」係 FLUX 3 最核心嘅競爭力。

技術基礎係 Black Forest Labs 之前發表嘅 Self-Flow 方法——一種高效對齊多模態生成同理解嘅統一架構。FLUX 3 將 Self-Flow 大幅擴展算力同數據規模，做到同時訓練影片、圖像同音頻。

「A model that generates video, images, audio, and robot actions from the same weights is not a media model. It is a world simulator.」

— 獨立分析，Wan 2.7 FLUX 3 評測

二、影片生成：原生音頻係殺手功能

FLUX 3 Video 係首個上線嘅模塊，已經開放 Early Access。佢嘅核心能力係：單次生成最長 20 秒含原生音頻嘅影片，支援 text-to-video、image-to-video、video-to-video、keyframe-to-video 四種模式，以及多語言對話同 agentic chaining（智能串聯多個片段形成長序列）。

原生音頻——市場上獨一無二嘅能力

呢個係 FLUX 3 同所有競爭對手最明顯嘅分別。Kling v3 Pro、Seedance 2.0、Runway Gen-4.5、Luma Ray 3.2——冇一個喺生成過程中同時產生音頻。全部需要後期用獨立音頻模型對齊。Sora 2 後來加了音頻，但都唔係同一個 inference pass 生成。

FLUX 3 嘅做法：你 prompt「一個爵士鼓手喺昏暗俱樂部打鈸，鼓棍擊中嘅瞬間同步有 crash 聲」——生成嘅影片入面，鼓棍打到鈸嘅同一個 frame，crash 聲同時產生。唔使對音軌。唔使 lip-sync 後期。一次 inference 完成。

人類偏好基準：初步勝出，但不等於統治

Black Forest Labs 發布咗初步嘅人類偏好評價（10 秒 720p text-to-video clips）：

  • Luma Ray 3.2：93% 偏好 FLUX 3
  • Runway Gen-4.5：77%
  • Grok Imagine Video：69%
  • Kling v3 Pro：60%
  • Seedance 2.0：52%
  • Gemini Omni Flash：52%

⚠️ 重要免責：呢啲係 vendor-published 初步數據。52% 對 Seedance 2.0 同 Gemini Omni Flash 基本上係統計噪聲範圍內（2-3% 差異可歸因於單次 100-200 評估批次）。真正嘅指標係第三方獨立測試。另外 Seedance 2.5 已經發布，支援 30 秒 4K 同 50 個多模態 reference——FLUX 3 嘅窗口唔係永久的。

字體生成——被低估嘅突破

AI 影片嘅字體渲染向來係一個頑疾。字母扭曲、跨幀 morphing、可讀嘅畫面文字需要後期手動合成。FLUX 3 因為從圖像訓練中學到字體渲染（圖像對 spatial structure 嘅理解直接遷移到影片），呢個痛點有望第一次被解決。如果 community testing 證實呢個 claim 成立，咁單係呢個能力已經可以節省大量後期製作工時。

三、從數碼內容到物理世界：FLUX-mimic 與機械人動作預測

呢個係 FLUX 3 發佈中最令人意外、可能亦係最長遠影響嘅部分。Black Forest Labs 同機械人公司 mimic robotics 合作推出咗 FLUX-mimic——一個將 FLUX 3 嘅影片世界模型直接用於機械人控制嘅視頻-動作模型。

邏輯係咁嘅：FLUX 3 從大量影片訓練中已經學識咗物理動態——物體點樣移動、碰撞、變形、互相作用。將呢種理解應用於機械人控制——預測機械臂下一步應該點做——係同一套能力嘅自然延伸。模型唔需要為影片同機械人分別學物理；從影片中學到嘅物理直接遷移。

「Better video world models directly translate to better robot control quality and sample efficiency.」

— Black Forest Labs，FLUX 3 技術博客

呢個論點挑戰咗機械人學界一個主流假設：即係認為「數碼內容模型」同「物理世界模型」係兩個唔同嘅問題。FLUX 團隊認為佢哋係同一個問題嘅兩種 manifestation——都係預測「下一幀」同「下一動作」。呢個觀點同近年興起嘅「世界模型就是機械人大腦」運動（如 Physical Intelligence、Covariant）完全一致。

FLUX-mimic 已經喺 Audi 工廠進行實際測試。訓練數據包含機械人操作數據同人類穿戴式數據。單個 on-prem GPU 即可部署——呢個對工業場景嚟講係關鍵優勢。

🔬 關鍵洞察

FLUX 3 嘅動作預測能力，某程度上驗證咗一個更廣泛嘅假設：scaling 影片數據可以學到通用嘅物理直覺。如果呢條路行得通，機械人學習嘅數據瓶頸可能被繞過——唔需要每個任務都採集大量真實機械人數據，因為世界模型已經從互聯網影片中掌握咗基本物理。

當然，呢個仲係早期。從「識睇物理」到「識控制機械臂」之間嘅 gap，仲需要大量 RL 同 fine-tuning 嚟填。但 FLUX-mimic 嘅 Audi 測試至少證明咗條路係可行嘅。

四、The Stack v3：開源碼庫嘅「大爆炸」

同日，另一件同 FLUX 3 無直接關係但同等重要嘅事：The Stack v3 發布——迄今最大嘅開源程式碼數據集。

  • 114TB raw 數據
  • 2.24 億倉庫
  • 44B 文件
  • 770 種程式語言
  • 過濾後約 5T tokens
  • 包含 inline content（非 Software Heritage IDs）——可以直接用於訓練

v2 到 v3 嘅增長驚人：C++ 15x、TypeScript 7.5x、Rust 7x、Python 4.8x。呢啲增長幅度反映出開源社群嘅爆炸性擴張——特別係 Rust 同 TypeScript 呢啲較新嘅語言。

「The meta-point: companies that can encode their value into evals and environments may gain a more durable edge than those relying on capital or raw scale alone.」

— Latent Space AINews，對 The Stack v3 + Codex 現象嘅總結

The Stack v3 嘅影響唔只係「又多一個數據集」。佢解決咗開源 code 數據嘅最大痛點——version 2 用 Software Heritage IDs 做 pointer，意味住你要自己去拉數據；v3 直接包含內容，大幅降低咗使用門檻。對於預算有限嘅學術團隊同中小型 AI 公司嚟講，呢個 dataset 可能係訓練自家 code model 嘅關鍵。

六、蒸餾政策爭議：開源權重嘅地緣政治

FLUX 3 嘅發布同時引發咗一場更大嘅辯論：蒸餾（distillation）政策。

白宮暗示可能制裁開源模型以防「工業化蒸餾」——即係中國團隊用美國模型蒸餾出自己嘅開源版本。但社區反駁稱 The Stack v3 同開源模型對國防同競爭力至關重要。Garry Tan（Y Combinator）公開表示：open weights are strategically important。

「Garry Tan：open weights are strategically important.」

— 引述自 Latent Space AINews 7/24

呢場辯論嘅核心係：開源比封閉更安全定係更危險？兩邊都有合理論點。開放派指出 HuggingFace 黑客事件中，開源模型 GLM-5.2 喺防禦中起到關鍵作用，而封閉模型嘅安全防護反而阻礙咗調查。封閉派則指出蒸餾可能導致知識產權流失同國家安全風險。

呢個矛盾冇簡單答案。但可以肯定嘅係：隨着 FLUX 3 Dev（open-weight 版本）喺今年稍後發布，呢場辯論只會越演越烈。

七、深度萃取：FLUX 3 意味住乜嘢？

🧠 我嘅睇法

  1. 「多模態統一架構」唔只係效率問題，係能力天花板嘅問題。分開訓練嘅模型永遠無法達到 joint training 嘅因果一致性。FLUX 3 嘅原生音頻、跨模態編輯、同機械人動作預測，全部係 unified architecture 嘅副產品。呢個趨勢會加速：未來的基礎模型將唔會係「語言模型加視覺」，而係從一開始就 multi-modal 嘅模型。
  2. 影片模型嘅商業價值正在從「媒體製作」擴展到「物理世界理解」。FLUX-mimic 嘅 Audi 測試係呢個趨勢嘅早期信號。如果世界模型可以從 YouTube 影片中學到物理直覺，機械人公司嘅數據成本將大幅下降。
  3. FLUX 3 Dev（open weights）係今年稍後值得關注嘅事件。Black Forest Labs 一直係開源嘅堅定支持者（FLUX.2 Dev 同 Schnell 版本廣泛使用）。FLUX 3 Dev 可能成為開源多模態領域嘅新標杆。
  4. Seadance 2.5 同 Runway Gen-4.5 嘅反應將決定 FLUX 3 嘅窗口長度。目前 FLUX 3 喺「原生音頻 + 字體 + chaining」嘅組合上有獨特優勢，但競爭對手嘅更新週期以週計。六個月後呢個差距可能消失。
  5. The Stack v3 + FLUX 3 Dev = 開源 AI 嘅夏天。數據同模型嘅開放權重版本同步爆發，對於預算有限嘅開發者同研究者嚟講，呢個係最好嘅時期。

最後，一個值得留意嘅信號：FLUX 3 嘅發布方式——先 video、再 image、再 action——反映咗 Black Forest Labs 嘅市場策略：用影片（最高調嘅媒體形式）吸引注意力，用機械人（啱啱崛起嘅垂直領域）建立長期護城河。呢個 triple play 比單純發布一個 benchmark 榜首模型更加深思熟慮。
