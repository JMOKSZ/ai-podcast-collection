硅谷101 · E248｜一个「催发货」AI 要跑通 260 步，和阿里瓴羊朋新宇聊聊中国式 FDE（2026-08-10）

「老闆唔會在乎背後用咩 token」——阿里瓴羊 CEO 朋新宇：唔接定制大單、唔做 1000 人天駐場，中國式 FDE 同 Palantir 反著走

📅 2026-08-10（發布 08-11 01:45 UTC）·⏱️ 1 小時 03 分·🎙️ 泓君 Jane（硅谷101 創辦人）·👤 朋新宇（花名小芃），阿里巴巴集團副總裁、瓴羊 CEO

硅谷最火新職位 FDE（前線部署工程師）喺中國係咪同一個劇本？瓴羊做咗 5 年「FDE」工作——比呢個詞流行仲要早。佢哋嘅答案係：唔係。硅谷派最聰明嘅人、開最高嘅薪、駐場深度定制；瓴羊揀咗完全相反嘅路——做標準化 agent + 接入企業私有數據，搵企業最痛嘅環節，一個催發貨 agent 要跑通 260 步流程。呢集係 E240（OpenAI 聯手 PE 砸 40 億美元押注硅谷 FDE）嘅中國篇，亦係「AI 商業化主戰場返返 B 端」嘅一個清晰信號。

一、硅谷風向變咗：AI 戰場由 C 端回到 B 端

泓君開場就點題：2026 年 AI 商業化嘅主戰場返咗去企業服務。硅谷最熱嘅新職位 FDE——前沿部署工程師（Field Deployment Engineer）——代表嘅邏輯係：AI 要入企業，就要開行業最高嘅薪、派一批最聰明嘅人駐扎入去。OpenAI 甚至聯手 PE 砸 40 億美元落注呢個模式（E240 報道過）。

但朋新宇嘅答案係「同一份工，中國行咗另一條路」。瓴羊脫胎於阿里數據中台體系，做企業數據同 AI 落地已經 5 年——比「FDE」呢個詞流行早好多。佢哋發布嘅企業級 Agent 平台 AgentOne，路線同硅谷完全相反：

「不接定制化的大單，不做 1000 人天的駐場開發。我們找的是企業裡最耗人、最耗錢、最耗時的環節，把預設好的 agent 接入企業私有數據，去解決真實的業務難題。」 — 朋新宇，瓴羊 AgentOne 嘅路線選擇
二、一個「催發貨」背後藏住 260 步流程

成集最 concrete 嘅例子係催發貨客服 agent。外人睇「催發貨」好似好簡單——但落場先知道，一個完整嘅催發貨流程要跑通 260 步：由訂單狀態查詢、物流節點判斷、異常識別、供應商溝通、承諾時間更新，到升級路徑、話術選擇、客戶安撫……每一步都係真實業務規則。

關鍵數字 一個催發貨流程，客服 agent 需要跑通 260 步流程——呢個先係「企業 Agent」同「Chatbot」嘅真正分別。

朋新宇嘅意思係：企業場景冇「一步到位」嘅魔法，每一個 agent 都係由一格格業務規則砌出嚟。而呢啲規則唔係 AI 自己諗出嚟——係由企業入面最熟悉崗位嘅人，一格一格教俾 agent。呢個亦解釋咗瓴羊點解揀「最痛嘅環節」而唔係「最大嘅單」：因為只有最痛嘅環節，先值得企業付出咁大心力去調教。

三、90 天調價一萬次：AI 向最優秀嘅投手偷師

第二個例子更精彩——頂級人類投手（應該係電商營運入面負責定價/促銷策略嘅人）。一個頂級投手，90 日內要調價 10000 次。呢 10000 次調價嘅表面動作好容易複製，但 AI 要學嘅係呢 10000 次調價背後嘅決策邏輯——點解嗰日加價、點解嗰個 SKU 唔跟、點解呢個渠道要優先。

「一個頂級人類投手，90 天內調價 10000 次，AI 要學會的是這 10000 次調價背後的決策邏輯。」 — 朋新宇：AI 偷師嘅唔係動作，係決策模型

呢度有個好重要嘅 insight：企業 AI 落地嘅本質係「把老師傅嘅決策邏輯變成可運行嘅系統」。調價 10000 次入面，邊啲係規則、邊啲係判斷、邊啲係直覺——呢個萃取過程本身，就係 FDE 最核心嘅工作。而呢啲嘢靠嘅唔係模型 SOTA，係「團隊配合同工程化嘅推進」。

四、點解順利嘅部署都係「自上而下」

朋新宇講咗一個反直覺嘅觀察：順利嘅 AI 部署都係「自上而下」嘅。佢用銷售 Agent 做例子——由最落後嘅區域做起，做到銷冠。點解係自上而下？因為 AI 落地首先係組織同流程問題，唔係技術問題：

  • 老闆落 order，先有資源同權限打通數據；
  • 流程唔改，agent 只能喺舊流程入面打轉；
  • 考核機制唔變，銷售團隊冇動力用 agent。

呢個觀察同好多 AI 落地案例吻合：失敗嘅 pilot 通常係「下而上」——一線團隊自發試用，但冇組織授權，最後淹沒喺流程同 KPI 入面。朋新宇嘅結論好實際：AI 落地嘅第一道坎唔係模型，係老闆。

五、做標準化增長 agent，同 Palantir 反著走

講到路線之爭，朋新宇好坦白：瓴羊做嘅係「標準化 + 可複製」嘅產品路線，同 Palantir 反著走。Palantir 係深度定制化、諮詢式交付——派精英團隊入客戶現場，一年做幾個大單；瓴羊揀嘅係「預設 agent + 私有數據接入」嘅規模化交付，唔接 1000 人天嘅駐場開發。

「做標準化增長 agent，跟 Palantir 反著走。」 — 朋新宇：可複製、可規模化，先係中國市場嘅答案

呢個選擇背後係三樣嘢嘅差異（節目尾段詳細講）：

  1. 信息化地基：中國企業嘅數字化底子同美國唔同，冇咁多「乾淨數據」可以畀精英團隊做定制；
  2. 付費習慣：中國企業唔慣為「駐場人天」畀錢，但願意為「算得過賬」嘅產品畀錢；
  3. 工作方向：美國 FDE 係「人海戰術 + 深度定制」，中國 FDE 係「工程化 + 標準化」。

呢個係成集最值得同 E240 對照睇嘅位：同一份工，兩個市場行咗兩條完全唔同嘅路。

六、部署周期：三份一、三份一、三份一

朋新宇仲畀咗一個好具體嘅部署配方——一個 agent 落地嘅周期點樣分：

部署配方 1/3 熟悉崗位（理解業務流程同痛點）｜ 1/3 做建模（萃取決策邏輯、做規則）｜ 1/3 調教 AI（讓 agent 喺真實場景跑順、打磨邊角位）。

呢個三份一結構透露咗佢嘅人才觀：FDE 團隊唔係「AI 專家團」，而係一個三角組合——

  • BA（業務分析師）定方向：搞清楚邊個環節最痛、agent 要解決咩問題；
  • AI 架構師選模型：揀啱模型、搭好工程框架；
  • 業務首席當教練：由最熟悉崗位嘅人，負責將老師傅嘅決策邏輯教俾 AI。

留意：呢個組合入面冇「算法科學家」嘅位置。朋新宇嘅意思好清楚——中國式 FDE 嘅核心能力係懂 AI、懂業務、懂數據三樣嘢湊埋，而唔係模型 research。

七、「老闆唔會在乎背後用咩 token」

講到模型策略，朋新宇拋出咗成集最金句嘅一句：

「企業算得過來賬，背後用什麼 token，老闆不會在乎。」 — 朋新宇：模型選擇係算賬問題，唔係信仰問題

呢句同硅谷嘅 token-maxxing/minimizing 討論形成好靚嘅對照（CR 嘅 Flo Crivello 同集就喺度計 DeepSeek 平 100 倍）。硅谷仲喺度辯論「邊個模型最強」，中國企業直接問「邊個 model 最抵」。冇對 SOTA 模型嘅迷信，亦冇全能型嘅個人英雄——「務實，算賬，打地基，這就是 FDE 在中國的故事。」

呢個立場亦解釋咗瓴羊點解可以做「標準化」：因為模型層已經商品化，價值唔再喺模型，而喺數據接入、流程嵌入同調教方法論。同樣嘅 agent 模板，換個模型、接入唔同客戶嘅私有數據，就可以複製去下一個客戶。

八、中美 FDE 對比：地基、付費、方向

節目尾段泓君將話題拉返去中美對比，朋新宇畀咗一個好完整嘅框架：

「沒有全能型的個人英雄，也沒有對 SOTA 模型的迷信。務實，算賬，打地基，這就是 FDE 在中國的故事。」 — 朋新宇，成集嘅核心總結
  • 硅谷 FDE = 高薪精英駐場、人海戰術、深度定制——適合信息化地基好、願意為人天付費、客戶單價高嘅市場；
  • 中國 FDE = 標準化 agent + 數據接入、工程化、規模化——適合地基參差、付費謹慎、要求「算得過賬」嘅市場。

差異嘅根源，朋新宇歸納做三點：信息化地基、付費習慣、工作方向。呢個框架其實可以推廣去任何新興市場——中國式 FDE 可能先係大多數市場嘅答案，而唔係硅谷式。

九、我嘅總結：呢集嘅三個 meta-takeaway

第一，「中國式 FDE」可能先係 AI 落地嘅主流劇本。硅谷式 FDE 好性感——最聰明嘅人、最高嘅薪、40 億美元 PE 落注——但佢假設客戶有錢、有數據、有耐心。中國式 FDE 嘅假設係「算得過賬就得」：標準化、可複製、嵌入流程。如果 AI 商業化要 scale 出利潤，後者嘅可複製性先似係大數法則入面贏嗰個。呢個同 42章經/屠龍之術近期講嘅「AI 商業化睇毛利同規模」係同一條線。

第二，企業 Agent 嘅護城河唔喺模型，喺流程萃取。260 步催發貨、10000 次調價嘅決策邏輯——呢啲先係客戶唔會走嘅原因。模型商品化令「用咩 token」變成無所謂，但「識唔識將你嘅業務變成 agent」係另一回事。呢個亦係瓴羊可以「同 Palantir 反著走」嘅底氣：定制化護城河喺人，標準化護城河喺方法論沉澱。

第三，「自上而下」先係企業 AI 落地嘅常態。呢個觀察好平實，但好少人講得咁直接：AI 落地首先係組織同流程問題。由最落後區域做到銷冠嘅銷售 Agent、1/3 熟悉崗位、業務首席當教練——呢啲細節拼埋，係一幅「AI 落地嘅中國現實圖」：冇英雄、冇魔法、冇 SOTA 迷信，只有算賬、打地基同慢慢調教。對照同日 CR 嗰集嘅「Iron Man suit」願景，兩者正好係光譜嘅兩端。

一句話總結：硅谷101 嘅「FDE 中國篇」——阿里瓴羊 CEO 朋新宇用 5 年實戰回應 E240 嘅 40 億美元硅谷 FDE 熱潮：中國唔玩「高薪精英駐場 + 深度定制」，玩「標準化 agent + 私有數據接入」；一個催發貨 agent 要跑通 260 步、AI 要學頂級投手 90 天 10000 次調價背後嘅決策邏輯；部署周期三份一熟悉崗位、三份一建模、三份一調教 AI；FDE 團隊 = BA 定方向 + AI 架構師選模型 + 業務首席當教練；「企業算得過賬，背後用咩 token，老闆唔會在乎」；路線之爭暗含對 Palantir 模式嘅批評——「務實、算賬、打地基，就係 FDE 喺中國嘅故事」。
