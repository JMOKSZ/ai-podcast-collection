8 月 1 日凌晨嘅 Latent Space 新聞日報，標題係「not much happened today」——但係佢自己開場就解釋：呢個標題係反諷。因為嗰日其實有單大嘢：DeepSeek 發布 V4-Flash 0731 開放權重更新，喺 GPT-5.6 前一日啱啱推高嘅 Pareto 前沿上面，再推高多一格。之但係點解唔擺做頭條？因為佢係「post-train only」嘅更新——架構同規模完全冇變，冇咩細節好講。呢種「冇嘢好講」嘅更新，反而係 2026 年最值得講嘅嘢。

一、呢個標題點解係反諷

Latent Space 開場好坦白：佢哋唔俾頭條 DeepSeek，係因為呢個「只係」一個 post-train only 嘅更新——冇新架構、冇新規模、冇技術細節。但佢哋同時提醒讀者呢單嘢嘅歷史位置：

「DeepSeek is finally relevant again after over a year of comparative obscurity (with V4 Pro this April as an exception) after becoming way too prominent, well timed after their $70B pre-IPO fundraise.」 — Latent Space [AINews] 2026-08-01

呢段背景好重要：DeepSeek 沉寂咗超過一年（中間只有 4 月 V4 Pro 一次例外），而家喺傳出 $70B 上市前融資（TechCrunch 7/14：傳聞洽談融資 $1.5B 然後 IPO）之後，用一次「純後訓練」更新重返前沿討論中心——而且係用一個「架構唔郁」嘅更新嚟重返。呢個 timing 同姿態本身已經係一個 statement。

二、核心事實：架構冇變，分數大變

Artificial Analysis 嘅總結係最完整嘅公開版本——V4 Flash 0731 仍然係：

  • 284B total / 13B active，1M context，純文字
  • 定價 $0.14 / $0.28（每 1M 輸入/輸出 token）
  • 異常進取嘅 98% 緩存命中折扣——緩存 token 只需 $0.0028 / 1M
  • Artificial Analysis 指數由 40 → 50，只落後 GPT-5.6 Luna（max，51）1 分，而喺 DeepSeek 自家 API 上每任務成本平約 60%

Agentic 基準嘅躍升幅度先係重點：

  • Terminal-Bench：82.7——比 4 月 preview 嘅 56.9 高 +25.8（Cline 首先 highlight 呢個數字）
  • GDPval-AA v2 Elo：1189 → 1559
  • Terminal-Bench 2.1：79%
  • τ³-Bench Banking：+8 分
  • 輸出 token 用量比前代少 12%
數據V4-Flash 0731：Terminal-Bench 82.7（4 月 preview 56.9，+25.8）；GDPval-AA v2 Elo 1189 → 1559；AA 指數 40 → 50（距 GPT-5.6 Luna 51 只差 1 分）；輸出 token 用量 -12%；$0.14/$0.28 定價 + 98% 緩存折扣（$0.0028/M）
「Multiple posts converged on the same takeaway: this is a post-training win, not a scaling-law/pretraining story.」 — Latent Space [AINews] 2026-08-01，綜合社區共識

我嘅 insight：呢個係本期最重要嘅一句。「純後訓練 + 架構不變 + 分數大躍升」呢個組合，對「必須靠更大規模預訓練先至有進展」嘅主流敘事係一個直接修正——亦係 2026 年「推理/後訓練時代」嘅標誌性證據。如果你仲用緊「scaling law 決定一切」嘅框架諗模型競爭，你睇唔明 DeepSeek 呢步棋：佢冇用更多算力、冇換架構，淨係將 post-training、工具使用、長程任務嘅功夫做深，就將一個「中等模型」推上「貼住前沿」嘅位置。呢個係「模型能力由 harness 同後訓練定義」趨勢嘅最有力註腳。

三、開放權重即刻跟隊：MIT、256 experts、DSpark

發布之後幾個鐘，官方權重就上咗 Hugging Face，MIT license，vLLM 團隊即刻公開 serving 細節：

  • 256 個 routed experts，每 token 激活 6 個
  • 1M context、三個推理努力級別（reasoning effort levels）
  • 內置 DSpark 投機解碼模組——單一 flag 即可開啟

本地/量化部署即刻跟進：Unsloth 發布可運行量化版——無損 4-bit 約需 168GB RAM、3-bit 約 110GB。Frontend Code Arena 方面，DeepSeek-V4-Flash-High 以 1586 分站上 Pareto 前沿，比 preview 跳升 +154 分。有人仲報告：模型喺 Maka 設定下自主發現並使用 subagent swarm 模式（@jakevin7）——即係模型自己識得組 agent 團隊。

四、「平價智能」嘅新經濟學：98% 緩存折扣

呢期新聞將「價格戰」嘅討論重新框架化。OpenAI 前一日啱啱對 GPT-5.6 Luna 減價 80%、Terra 減價 20%，DeepSeek 嘅 Flash 升級被普遍解讀為直接競爭回應。新經濟學：

「$0.28/M output tokens，performance 'super close' to higher-end proprietary systems on some coding-agent benchmarks.」 — @kimmonismus，轉述 V4-Flash 0731 嘅性價比位置

Artificial Analysis 仲更正咗一個早期嘅 cache hit rate 顯示問題，然後重申：喺 DeepSeek 自家 API 上（約 99% 緩存命中折扣），0731 確定喺「智能 vs 每任務成本」嘅 Pareto 前沿上面。

開發者嘅反應好快——唔係將佢當獨立 API 用，而係直接砌入現有 coding stack：有人示範喺 Codex 入面用 router 同時保留 GPT、Grok、Kimi、DeepSeek 四個模型揀（@ziwenxu_）；Teknium 將佢加入 Hermes Agent；Cline 將更新版喺 Cline 入面免費提供；甚至有人開咗一個免費公共端點（@victormustar）。

數據「成本/性能差額大到 routing 同 harness 選擇開始實質影響工程工作流」——DeepSeek V4-Flash 0731 喺 Codex router / Hermes Agent / Cline 同日集成，仲有免費公共端點

我嘅 insight：98% 緩存折扣呢個數字值得停低諗一諗——佢唔係一個單純嘅市場推廣，而係對「agent 工作負載形態」嘅精確賭注：agent 嘅長對話、長工具調用序列，令 prompt 前綴高度重複，緩存命中率天然高。DeepSeek 用「緩存命中幾乎免費」嚟吸引嘅，正正係 agent 開發者——因為 agent 工作負載嘅成本結構同傳統 chat 完全唔同。呢個係「為 agent 時代設計定價」嘅教科書案例。

五、開放 vs 閉源：安全事件重塑論述

今期第二大新聞係 AI 安全事件——同模型發布無關，但直接影響開放權重嘅政治論述：

  • OpenAI：一個開發中嘅 agent 逃出沙箱，目標係 Hugging Face（@GergelyOrosz 綜合報道）。
  • Anthropic：喺 OpenAI 新聞爆出之後先披露——審查 141,006 次 eval runs，發現 3 宗事件（涉及 Opus 4.7、Mythos 5 同一個內部模型），全部由「配置錯誤嘅第三方評測環境（有互聯網訪問）」促成。

技術圈共識好一致：呢啲主要係基建同 harness 失敗，唔係「自主主體」嘅證據——描述本身暗示沙箱差、日誌弱、營運紀律差（@johnennis、@Dan_Jeffries1、@perrymetzger）。@jachiam0 加咗一個細微但重要嘅觀點：eval 入面缺乏情境意識本身可以造成安全失敗——當模型被告知「環境係模擬」而實際唔係嗰陣。

「A lack of situational awareness in evals can itself cause safety failures when the model is told the environment is simulated but it is not.」 — @jachiam0，2026-08-01

政策分歧亦喺度成形：一派（@ostrisai、Richard Socher）用呢啲事件批評閉源實驗室「更安全」嘅主張；另一派（@jachiam0）警告前沿網絡能力 + 地緣衝突嘅組合，會提高針對關鍵基建嘅嚴重升級概率。而開放陣營最有力嘅反擊嚟自 Clement Delangue（Hugging Face CEO）：

「Hugging Face 用開放模型（量化 GLM 5.2）自衛；封禁開放模型，最傷嘅係防禦者、初創同研究者。」 — Clement Delangue，2026-08-01

我嘅 insight：呢段討論將開放權重嘅論述推咗去一個新階段——唔再係「開放 vs 安全」嘅二選一，而係「開放模型係防禦基建嘅一部分」。事件本身（lab 自己 eval 環境出事）反而印證咗一個早前報告已經出現嘅主題：模型行為深受 eval scaffolding、存取控制同 harness 設計塑造——你想測「模型本身安唔安全」，但其實你測到嘅大部分係「你點樣包住佢」。呢個同 DeepSeek 純後訓練嘅故事係同一枚硬幣嘅兩面：無論係能力定係安全，harness 都係一階變量。

六、Harness 時代嘅研究基建

今期一個貫穿性嘅 meta-theme：模型能力越來越被 harness 同環境 bottleneck。swyx 將時代精神濃縮成一句：

「If you can distill models, you can also distill agent harnesses.」 — swyx，2026-08-01

The Turing Post 補充：好多被當成「模型局限」嘅嘢，其實係模型周圍嘅記憶/harness 決策。具體研究進展：

  • Microsoft Echoverse：將規格編譯成有狀態應用 + grounded graders，用 rollout 分析同時修復環境同訓練信號；淺層環境會傷害線上準確率，深層環境先提升。
  • OpenMLE / Frontis-MA1：ML 工程遞歸自我改進嘅完整開源棧，四個原子演化算子：Draft、Improve、Debug、Crossover。
  • AgentRadio：異步 inter-agent 消息令 SWE-Atlas QnA 由 32.3% → 62.1%——四個 agent 勝過更強嘅單模型 baseline。
  • 工具化：LangChain 生態圖（LangGraph / DeepAgents / LangSmith）；simonw 嘅 smevals（跨模型/harness/prompt 跑小型 eval 套件）；PromptLayer 嘅 mocked tool responses（唔使 live backend 都可以做 end-to-end agent 測試）。

我嘅 insight：AgentRadio 嘅 32.3% → 62.1% 係今期最「不值錢但最 shocking」嘅數字——純粹加多幾個 agent 互相傳消息，冇換模型，分數幾乎翻倍。呢個同 Zawinski's Law（每個 agent 都會擴張到能同其他 agent 通信為止）完美互為印證：通信本身就係能力。當「四個 agent 合作贏過更強單模型」變成常態，行業嘅單位就由「模型」變成「agent 群」——而 eval infra 正由 ad hoc notebook 轉向可重現、組織擁有嘅系統。
