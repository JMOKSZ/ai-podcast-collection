「於是轉身向具身走去」——24 歲首席科學家王家偉：基模唔會「降維打擊」具身，因為「杯滑落」嗰一刻需要動作模型

📅 2026-09-16 18:00 UTC（北京 09-17 02:00）發布·🎙 十字路口 Crossing（Koji 楊遠騁）·👤 嘉賓 王家偉（深朴智能 Simple AI 首席科學家）·🏷 具身智能 / VLA / 世界模型

呢集由一個好具體嘅畫面切入：GPT-6 Astra 操控機械臂。然後主持人 Koji 拋出一個行業級問題——OpenAI 呢類基礎模型公司，會唔會「降維打擊」具身智能模型？ 嘉賓王家偉（深朴智能首席科學家，24 歲）畀出嘅答案係「唔會完全食晒」：通用大模型會承擔越來越多「理解同規劃」，但當隻杯開始滑落，機械人仍然需要一個能夠即時反應嘅動作模型。節目上半場係人物路徑同選擇，下半場係對具身智能技術範式同前沿工作嘅逐家點評——而當中有一條相當反直覺嘅方法論警告：「觀察到 Scaling 趨勢」唔等於「存在 Scaling Law」。

呢集嘅中心論點：如果只用一句話記住呢集，就係——「基模負責慢思考，具身模型負責快反射；兩者係分層協同，唔係互相取代。」王家偉用「杯滑落」呢個瞬間嚟界定呢條唔可以讓渡嘅邊界：通用大模型嘅推理延遲以秒計，但物理世界嘅失敗以毫秒計。由此推出三個連鎖判斷——① 具身嘅路線、評估、產品都未有共識，所以風險更高，但正因為未定型，先畀到年輕研究者「定義問題」嘅空間（「風浪越大，魚越貴」）；② 因此深朴必須做全棧（數據 → 基模 → Agentic OS → 本體），因為上層意圖同底層動作之間嘅橋接買唔到；③ 亦因此，具身領域嘅最大瓶頸唔係算力，而係缺乏公認 Benchmark——冇共識性評價體系，就冇可信嘅模型證明。
一、呢集嘅切口：由「Astra 操控機械臂」到行業級追問

節目開頭嘅時間軸由 04:02「GPT-6 Astra 操控機械臂」開始，緊接 06:27「OpenAI 等基模公司會擊穿具身模型嗎」。呢個編排本身就係一個隱喻：當通用智能開始「外溢到物理世界」，具身智能嘅護城河到底喺邊？

王家偉嘅回應係「唔會完全食晒」，而且佢唔係靠立場，係靠時間尺度嚟論證。呢個係成集最核心嘅技術切口：把「邊個做咩」嘅爭論，翻譯成「邊個喺咩時間尺度上負責反應」嘅工程問題。

二、嘉賓路徑：一條「直通大模型最前沿」嘅線

王家偉嘅履歷係近期中文播客嘉賓裡少見嘅「一條線拉到底」：

  • 中科大少年班 → 中科大與微軟亞洲研究院（MSRA）聯合培養博士；
  • 博士期間喺微軟亞洲研究院、DeepSeek、字節跳動 Seed 團隊都做過核心研究員，親歷國內頂尖大模型從 0 到 1；
  • 谷歌學術引用超過一萬次；
  • 畢業之後，佢卻由大模型轉向具身智能，出任深朴智能首席科學家。24 歲。

佢自陳想離開嘅唔係大模型，而係「只能跟隨既定計劃嘅狀態」。呢句係理解佢整集立場嘅鑰匙——一位做大模型出身嘅人，反而唔認為大模型係具身嘅終點。呢種「由最前沿轉身」嘅路徑，令佢嘅判斷唔係外行式嘅樂觀或悲觀，而係帶住對模型能力邊界嘅第一手手感。

節目仲談到佢對「聰明」嘅定義（13:14「聰明係會提好問題」）同 DeepSeek 嘅工作方式（19:44「DeepSeek：唔靠工作強度換成果」，21:32「由 DeepSeek 多模態到 Seed Agent」）——呢兩段係人物側寫，價值在於揭示一種「唔靠內卷、靠問對問題」嘅研究文化。

三、核心論點：六條可操作嘅判斷
  • 基模唔會擊穿具身，但分工在變。通用大模型會持續吞掉「理解同規劃」層；但物理世界需要低延遲嘅反射式動作模型。佢用「杯開始滑落」呢個瞬間界定呢條不可讓渡嘅邊界。
  • 「風浪越大，魚越貴」。具身嘅路線、評估同產品都未有共識，風險更高——但恰恰因為未定型，先畀到年輕研究者「定義問題」嘅空間。呢個係佢由大模型舒適區轉身嘅核心動機。
  • 深朴必須做全棧。由 HiFi-UMI 數據 → 具身基礎模型 → Agentic OS → 本體，四層都要碰。理由係上層意圖同底層動作之間嘅橋接（Agentic OS）無法外購。
  • 唔追逐「世界模型」概念。佢認為具身嘅關鍵係 Context——由「一秒因果」到「長期記憶」嘅連續譜，而唔係貼一個流行標籤。
  • 「Scaling 趨勢 ≠ Scaling Law」。呢條係佢最反直覺、亦最有方法論價值嘅一條：觀察到規模效應在漲，唔等於存在可外推嘅定律。若把觀察當定律，路線判斷會出錯。
  • 冇公認 Benchmark，就冇可信嘅模型證明。具身領域缺乏共識性評價體系，呢個既係機會（可以定義標準），亦係最大不確定性來源。
四、點解基模食唔晒具身？——「杯滑落」嘅時間尺度

呢個係全集最值得反覆咀嚼嘅一段。業界常見嘅「降維打擊」敘事係：既然大模型能力咁強、Scale 得咁快，咁具身智能只係「加個身體」嘅問題，早晚被通用模型吸收。王家偉嘅反駁係一條物理約束：

「當隻杯開始滑落，你冇時間去問一個大模型。」 — 概括王家偉對「反射層不可讓渡」嘅論證（節目 06:27 段落）

拆開嚟講，佢嘅邏輯鏈係：通用大模型嘅價值在於「諗得深」，但代價係「諗得慢」——一次完整推理要行成個 Transformer 棧，延遲以百毫秒到秒計。而物理世界嘅失敗係毫秒級嘅：杯滑落、物件傾倒、人手突然介入，全部要求即時閉環。呢個唔係「模型夠唔夠聰明」嘅問題，而係控制迴路頻寬嘅問題。因此合理嘅架構唔係「大模型單體包辦一切」，而係分層協同：大模型做慢速嘅語義理解同長程規劃，專用嘅動作模型 / VLA 做快速嘅反應閉環。

呢個判斷同稍早（9/13）十字路口外灘大會圓桌嘅四條路線互相呼應又各有側重：嗰場爭論嘅共識之一是「通用大模型唔會消滅具身，而係分層協同、甚至反哺大模型」。王家偉呢集把「分層」嘅切線畫得最清楚——切喺「毫秒級反射 vs 秒級推理」呢條線上。

時間尺度 通用大模型推理延遲：百毫秒～秒級（適合規劃、理解）；物理失敗反應窗口：毫秒級（杯滑落、傾倒、人機碰撞）。→ 推論：反射層必須由專用動作模型承擔，唔可以由通用推理兼職。
五、深朴點解「必須做全棧」——四層都要碰

節目提到深朴嘅四層架構（25:24「深朴為什麼必須做全棧」、26:40「HiFi-UMI 開源 2,000 小時」、44:34「Agentic OS」）：

  1. 數據層（HiFi-UMI）：自研低成本、高精度嘅純視覺 UMI + Ego 數據採集系統，並圍繞佢建「冷啟動」同「熱循環」兩條數據管路。
  2. 模型層：具身基礎模型——分層記憶增強嘅智能體架構，結合自研世界動作模型 + 端到端 VLA，提升長程任務規劃、跨本體零樣本適配、非標場景操作泛化同指令遵循。
  3. Agentic OS：上層意圖同底層動作之間嘅橋接層。王家偉嘅講法係：呢一層買唔到，所以必須自研。
  4. 本體：硬件，因為要同模型共同設計、共同迭代。

值得注意嘅係「全棧」呢個選擇本身係一個反共識嘅賭注。多數具身公司會揀一個切口（做本體、做模型、或者做數據），但深朴判斷「單點領先三個月就會被拉齊」，真正難複製嘅係「模型—數據—本體—場景」嘅閉環，同埋真實作業數據嘅持續回流能力。呢個判斷同公司創辦人李曉飛（清華汽車系博士、自動駕駛公司智行者聯創）嘅視角一致——佢經歷過自動駕駛由 L2 量產到 L4 嘅完整週期，因此更加看重「把難而正確嘅事做到」嘅長期生態位價值。

「冷啟動」同「熱循環」：兩條數據管路
  • 冷啟動：機械人入場之前，透過大規模真實操作採集訓練數據，為模型打底。公司口徑係預計呢條管路今年內累積幾十萬小時訓練數據。
  • 熱循環：機械人入場作業之後，持續採集自主運行過程嘅真機數據——尤其係邊緣案例同失敗案例——高效回傳，驅動持續微調同強化學習。

呢個設計針對嘅係傳統數據採集嘅先天局限：一旦採集條件同輸入方式固定，餵畀模型嘅數據就會被鎖死喺有限分佈內。而真正驅動進化嘅，恰恰係真實物理世界入面「分佈外」嘅邊緣同失敗場景。

數據規模 節目提到：對外開源 2,000 小時具身數據（HiFi-UMI），內部累積數萬小時；公司口徑嘅「冷啟動」管路目標係幾十萬小時。已觀察到一定嘅 Zero-shot 泛化——唔靠後訓練即可處理新任務。佢亦提到一個有趣嘅細節：GPT-6 比人更會標數據。
六、兩個反直覺洞見：呢集真正嘅方法論乾貨

如果要揀兩段最值得帶走嘅，會係以下兩條。佢哋唔係關於「做咩產品」，而係關於如何思考一個未定型領域。

洞見一：「Scaling 趨勢 ≠ Scaling Law」
「觀察到 Scaling 趨勢，唔等於存在 Scaling Law。」 — 王家偉（節目 41:52 段落）

呢句聽落似學術咬文嚼字，但殺傷力極大。語言模型之所以能 Scale，係因為背後有一條可外推、可預測嘅定律（loss 隨參數／數據／算力冪律下降），所以「加資源＝加能力」係可靠嘅工程指引。但喺具身領域，你可能只係觀察到某啲任務隨數據量增加而變好——呢個係「趨勢」，唔係「定律」。把趨勢當定律嘅代價係：你會用一條唔存在嘅外推線去規劃路線、估值同資源投放，然後喺某個拐點撞牆。 呢個係一個典型嘅「認識論紀律」提醒：分清「我睇到嘅」同「我推得嘅」。

洞見二：唔追逐「世界模型」概念，關鍵係 Context

王家偉話具身嘅關鍵係 Context——一條由「一秒因果」到「長期記憶」嘅連續譜，而唔係一個可以貼上去嘅流行標籤（36:10「唔追逐世界模型概念」）。呢個觀察同另一條行業線暗合：近年「世界模型」被過度使用，以至於失去鑑別力。王家偉嘅做法係還原到需求——你到底需要模型記得幾長、反應幾快？答案唔係一個名詞，而係一條時間尺度上嘅譜。

配套洞見：冇公認 Benchmark，就冇可信嘅模型證明

節目 48:09 一段直指具身領域嘅結構性短板：缺乏共識性評價體系。呢個既係機會（邊個定義標準，邊個就掌握話語權），亦係最大嘅不確定性來源——因為冇公認 Benchmark，任何「我哋嘅模型更好」嘅宣稱都無從第三方驗證。呢一點同另一條線（AIUC 講嘅「信任／第三方差異化」）異曲同工：能力可以被宣稱，但只能被「可檢驗嘅標準」證明。

七、前沿逐家點評：節目下半場嘅「減法」

節目後半（54:14 起）王家偉對行業前沿工作逐一表態，係近期中文播客少見嘅「一線技術人做減法」：

  • Astra（GPT-6）：通用智能開始「外溢到物理世界」，擅長規劃同理解，但反射層仍然留畀具身模型。
  • GEN-1.5：驗證咗「預訓練 + 自然湧現」嘅路線——能力可以由規模自然長出嚟。（公司新聞稿口徑為 Generalist 嘅 Gen-1：基於 50 萬小時數據預訓練，喺手機入殼、摺疊紙箱等精細任務上把成功率由 64% 提到 99%。）
  • π0.7：強化咗 steerability（可操控性），即係可被指令／人在環引導嘅程度。
  • Skild AI 嘅 In-Context Learning：佢明確質疑其被高估——認為嗰個更似係為 Demo 專門訓練嘅產物，泛化被誇大。
  • 行業冷水：「具身領域，噱頭可能大於真實。」（01:00:04）

而節目收尾嘅一問（01:09:57）相當有畫面感：「三年後，機械人可唔可以幫人洗碗？」 呢條問題嘅價值唔在答案，而係把宏大敘事拉返到一個可證偽嘅日常任務——呢種「落地嘅事，唔係藍圖」嘅取向，正好同創辦人李曉飛嗰句「demo 變產品、產品變商品」互相照應。
