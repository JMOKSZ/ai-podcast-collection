「最好的模型」與「最便宜的最好模型」——GPT-6.2 把前沿競爭的計分板換成智能每美元

OpenAI 在 Anthropic 預期的首個交易日之前兩天，同時發布了 GPT-6.2 Astra 與 GPT-6.2 Sol。這個時間點的選擇本身，就是這場發布最值得讀的部分：它不是一次「我們更強了」的宣告，而是一次在對手上市前重新定價的動作。

Latent Space 的定性只有一句，但這一句把整場競爭的計分板換掉了：

「Anthropic still owns the world's best model, but OpenAI owns the world's most efficient models in terms of intelligence per $.」 — Latent Space，2026-11-18（原文英文）

翻譯成中文：Anthropic 仍然擁有世界上最好的模型，但 OpenAI 擁有世界上智能／美元效率最高的模型。「最好的模型」與「最便宜的最好模型」是兩個不同的王座，而這一週，OpenAI 選擇了後者。

62 vs 65 Astra 的 Artificial Analysis Intelligence Index 為 62，Fable 5.2 為 65。三分之差。
≈15% Sol 以約 15% 的每任務成本，追平 9 月版 Astra 的分數。
2 天 發布時間距離 Anthropic 預期首個交易日。
High OpenAI 首次把對外發布模型的「AI 自我改進」風險評為 High。

一、兩個 SKU：旗艦模型分裂成兩種產品

這次發布最清晰的商業信號，不是任何一個 benchmark，而是同一家族拆成兩個定價帶：

Sol 的定價「沿用上一代」——這句話看似平淡，其實是全篇最狠的一筆：上一代旗艦的價格，這一代變成入門款。在摩爾定律失效的 AI 硬體語境裡，這種「同價位、換世代」的節奏，等於每年把單位智能的價格砍半再砍半。

對企業客戶而言，這是一個決策架構的改變：以前是「選最強的模型」，現在是「選任務與模型的配對」。長時程工程任務用 Astra，日常高頻調用走 Sol——模型選型從「技術決策」變成「採購決策」。

把原文的數字攤開，會看到一個非常不對稱的圖景：Astra 在可驗證、長時程、工程類任務上大幅領先，在視覺、開放式、主觀品味類任務上則明顯吃虧。

這張表最值得學的不是任何單一數字，而是它的內部矛盾：OpenWorldEngineer 領先 12.6 點，WANDR 的單位成本卻高出 Sol 4.7 倍。同一個模型家族，在不同任務分佈下的「性價比」可以完全反轉。

採購推論：「每任務成本」是一個平均值，而平均值會說謊。真正的決策規則應該是按任務類型分別測——工程類看 Astra，研究代理類看 Sol，法律類看有檢索索引的企業配置。單一百分比（15%、5%、1/3）只適合做公關標題。

三、負評：為什麼同一模型會有兩個世界

這次發布最不尋常的地方，是 influencer 的負評強度。Latent Space 的原文用了「STRONGLY negative influencer feedback」，並提到 OpenAI 為此做出了防禦性回應。

「We think that some of this is overreacting and normal influencer tendency to either have everything be 🤯🤯🤯 or the literal WORST.MODEL.EVER, BUT also that some of the criticisms are valid, and the RL artefacts are noticeable and downright bizarre (don't even get us started about the terrible launch video).」 — Latent Space，2026-11-18（原文英文）

這段話的結構值得拆開看。它同時做了三件事：貶低反應強度（一部分是網紅的兩極化傾向）、承認批評有效（部分批評是對的）、指出可觀察的技術成因（RL 痕跡明顯且怪異）。

最刺眼的一句來自 Matt Shumer：他在測試數週後稱這批模型「essentially unusable」，並說他的 Opus 與 Fable agent 會拒絕 Astra 交出的子任務成果。

「被另一個 agent 拒絕」是一個非常新的失敗模式。它意味著：模型的可靠性已經開始被同儕模型評判。在 multi-agent 工作流裡，一個 agent 的輸出要經過另一個 agent 的驗收；當驗收方判定不合格，這個模型在實際生產鏈裡就等於不存在——不管它的 benchmark 多高。

Pietro Schirano 則把早期問題大部分歸因於 harness；Arena 的 Peter Gostev 在視覺 coding 上做對比，特別點名 Astra 畫的 SVG 孔雀。這些都是「體感」層面的證據，與 benchmark 的「分數」層面構成兩個世界。

四、Harness 才是隱藏變量：4.4 倍的成本差

如果只讀 benchmark，會以為模型是唯一變量。同一天的情報給出了反證：

  • Baseten 測了 22 個 harness × 5 個開源模型，每通過任務的成本最高差 4.4 倍。這意味著 harness 選型對帳單的影響，可能大於模型選型。
  • Hugging Face 的 Pi adapter：一個在 pi 內部訓練的小適配器，把 Qwen3.8-27B 在最難的 51 道 SWE-bench Pro 上從 15 題提升到 32 題，同時工具調用減少 55%。模型沒換，成績翻倍。
  • Google SIM：保留過往 harness 修改的理由與結果；但一個在 Opus 上演化出的 harness 在 Gemini 上只得 68.41，低於起始 harness 的 73.89——harness 會過擬合到模型。

第三條是對 agent 產品護城河敘事最壞的消息。如果「為某個模型進化出的腳手架，換個模型就貶值」，那麼 agent 公司的核心資產（累積的 harness 與工作流）就無法跨模型遷移。每一次模型世代更替，都可能要重做一次工程。

「一個在 Opus 上演化出的 harness 在 Gemini 上只得 68.41，低於起始 harness 的 73.89。」 — Google SIM 研究摘要，經 Latent Space 轉述

把這條與 Astra 的負評放在一起，會得到一個更合理的解釋：很多「模型不行」的判斷，其實是「模型 × harness」這個組合不行。而組合的數量是乘法，不是加法。

五、RL 痕跡與「自我改進 High」：風險評級進入產品頁

OpenAI 首次把一個對外發布的模型在 AI Self-Improvement 項評為 High。同時，Vals 的 RSI-Index 從 27.07% 升到 29.01%（人類參照為 50%）。

這兩件事放在一起看，意義超過任何 benchmark：

  • 風險評級開始出現在發布材料裡，不再是論文附錄。使用者買模型時，會同時看到能力分數與風險等級。
  • RSI 被壓縮成一個可比較的數字。一旦有了單一數字，它就會被寫進採購合約、監管表格與新聞標題。
  • 「High」的含義仍然模糊：它是指模型真的能改進自身，還是指它能顯著加速 AI 研究？在政策上，這是兩個完全不同的問題——前者是自主性，後者是生產力。

Latent Space 提到 Astra 的行為帶有「明顯且怪異」的 RL artefact。這一點與「自我改進 High」放在一起，指向同一個技術現實：後訓練的強度已經大到改變模型的默認行為風格。模型不只是在能力上變強，它在「怎麼做事」上也留下了訓練的指紋——而有時候，那些指紋看起來就是怪。

六、真正的頭條：Anthropic 的 IPO

Latent Space 對這場發布的最終裁決，並不關於模型：

「Great ship, but Anthropic's IPO is unaffected and that will be probably the headline of the week/year/decade (until OpenAI IPO's….)」 — Latent Space，2026-11-18（原文英文）

這句話值得慢慢讀。它說的是：船很好，但 Anthropic 的 IPO 不受影響，而那大概會是本週／本年／本十年的頭條（直到 OpenAI 也 IPO）。

這裡有兩層判斷。第一層是敘事權的轉移：模型發布曾經是整個行業的頭條，現在它只是資本市場事件的背景音。第二層是競爭維度的轉移：當兩家前沿實驗室都進入公開市場，競爭的計分板會從 benchmark 變成營收、毛利與算力成本。

把這一點與同日 NVIDIA 的財報放在一起，圖景更完整：過渡 CEO Colette Kress 交出 $115.8B 季度營收、同比 +103%，Vera Rubin NVL72 已出貨，董事會表示不打算恢復黃仁勳。硬體需求曲線與個人無關，模型價格曲線則在快速下壓——上游收租，下游降價，中間層被兩邊擠壓。

七、同日其餘情報：五條值得記住的線索

Microsoft 有了自己的 coding 模型

MAI Code 2（多步 coding）與 Code 2 Flash（快速編輯）進入 GitHub Copilot 模型選擇器、Copilot Fusion 與 Foundry；Decision 模型獲得多模態升級。Copilot Fusion 以多模型編排在同口徑下報 Terminal-Bench 4.1 71.2%，成本比 Claude Fable 5.2 低 88%。MAI Image 2.7 在 AA 圖像編輯榜排第一，$34.82／千張。

Gemini Tasks 開始打電話

由 Hydrogen 驅動，在六國免費開放，包含需要打電話或發短信的任務；同時展示 Antigravity 機器人插件與 MuJoCo 仿真。這是「agent 代替你完成線下動作」的早期量產版本。

多智能體的收益遞減

Cognition 推出常駐 Devin Bots；Perplexity 稱混合模型團隊在 Terminal-Bench 與 WANDR 上勝過四個同款主模型；但 Replit 報告 16→32 個 agent 在 NumPy 任務上收益遞減。Hugging Face 的 1,000-agent 實測更直接：任一時刻只有 40–60 個 agent 在調用模型，每寫 1 個 token 要讀約 130 個 token，合併與測試是瓶頸。

緩存的經濟學

SemiAnalysis 樣本中，1.8% 的未緩存請求貢獻了約 15% 的支出。這解釋了為什麼所有模型都把 cached input 定價壓到接近零（Astra $0.40、Sol $0.10）——緩存命中率是新一代的成本護城河。

開放訓練與長上下文

Marin 釋出 535B-A23B 訓練的 57 個中間 checkpoint；K2 報告用同一批 22T token 訓四個尺寸，並稱解碼適配器帶來 2.2× 加速。Zyphra 稱把多個模型改為次二次注意力後，10M token 下加速 9–60×，Qwen 在 1M RULER 上掉不到 2 分。vLLM 為 Kimi K3.1 Pro 用滑動窗口 draft，接受長度最高 +30%。

八、三個不能忽略的爭議

Astra 到底「能不能用」

一邊是 Mercor／Vals／AA 的全面領先，一邊是 Matt Shumer 的「essentially unusable」。Latent Space 的裁決是「批評部分有效」，但沒有給出可復現的判別標準。沒有判別標準，就意味著這場爭論無法被解決，只能被下一次發布覆蓋。

15% 成本的可比性

「每任務成本」高度依賴任務分佈與重試次數。在 Agents' Last Exam 上是 1/3 成本，在 WANDR 上是 $12.54 對 $2.65（Sol 反而便宜 4.7 倍）。單一百分比容易誤導，尤其容易被放進標題。

「自我改進 High」的政策含義

評級上調是否意味著模型真能改進自身，還是只代表「能顯著加速 AI 研究」？前者關乎控制，後者關乎經濟。把兩者混為一談，會讓監管討論失焦。

九、這一集真正在說什麼

把全部情報收攏，這次發布的核心不是「OpenAI 追上了」，而是競爭的計分板被換掉了：

  • 從峰值智能到智能每美元。三分的差距，十五分之一的價格——當差距小到這個程度，買方會用價格投票。
  • 從單一模型到 SKU 組合。Astra 賣峰值，Sol 賣成本，企業按任務配對。模型選型變成採購決策。
  • 從模型能力到 harness 能力。4.4 倍的成本差、15→32 的 Pi adapter、68.41 vs 73.89 的過擬合——工程層的槓桿大於模型層。
  • 從產品發布到資本事件。真正的頭條是 Anthropic 的 IPO，模型只是背景音。

而對使用者的實際建議，其實藏在 Latent Space 那句自嘲裡：「However, we still use it to automate our work and that's all that matters in the end.」——不管爭議如何，他們仍然用它來自動化工作。這句話比任何 benchmark 都誠實：模型的價值，最終由「能不能替你把事辦完」定義，而不是由「能不能在榜上贏三分」定義。

給 James 的一句話：這一集最值得抄走的不是任何一個分數，而是那個順序——先看「智能每美元」，再看「harness 乘數」，最後才看「峰值分數」。因為峰值分數決定你能不能做某件事，而前兩者決定你能不能一直做下去。Astra 的 62 分不是重點，重點是它在 15% 的成本上做到了 62 分——這才是把前沿能力變成日常工具的條件。
