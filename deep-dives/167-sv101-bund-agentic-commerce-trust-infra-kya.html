「你敢把錢包交給 AI 嗎？」——硅谷 101 外灘大會圓桌：Agent 交易爆發前夜，KYA 成為新身份基建

📅 2026-09-18 00:00 UTC 發布（原錄於 2026-09-10 外灘大會主論壇）·🎙 硅谷 101（泓君 Jane）·👤 韓歆毅（螞蟻集團 CEO）· Jorn Lambert（萬事達卡首席產品官）· 劉作虎（OPPO 高級副總裁兼首席產品官）· 周靖人（阿里巴巴集團首席科學家）·🏷 Agentic Commerce / 支付基建 / 信任

呢集係一段線下圓桌錄音，但佢嘅價值唔在「四位高管同台」，而在一句幾乎冇人願意公開講嘅話——螞蟻 CEO 韓歆毅坦言：今年 Agentic Commerce 實際落地嘅速度，「比大家預想的要慢很多」。呢句係成集嘅定調。當 AI 由「會答問題」走到「會辦事」，再走到「會交易」，真正卡住嘅唔再係模型能力，而係一整套信任基建：授權、身份、權限、責任。四位嘉賓分別代表支付網絡、超級 App、手機終端、雲與模型四種位置，講嘅其實係同一件事嘅四個切面。

呢集嘅中心論點：如果只記一句，就記——「互聯網交易靠 KYC / KYB，Agent 交易要多一層 KYA（Know Your Agent）。」呢句出自韓歆毅，係成集最有結構性嘅概念。佢嘅意思係：當交易主體由「人」變成「人 + 人的 Agent + 商家的 Agent」，你唔單止要確認對面係邊個，仲要確認呢個 Agent 係唔係真嘅、佢嘅權限有幾大、佢做嘅嘢係唔係你真係授權咗、出事之後追得到邊個。萬事達卡 CPO Jorn Lambert 用電子商務 25 年前嘅歷史做類比——當年消費者喺陌生網站輸入銀行卡號都係一件令人不安嘅事，最後令電商普及嘅唔係支付技術本身，而係身份認證、交易規則、爭議處理、消費者保護呢四樣嘢慢慢建立起來。
一、四位嘉賓，四個位置，一個共同瓶頸
  • 韓歆毅（螞蟻集團 CEO）——代表「超級 App + 支付」嘅供給側。佢嘅核心詞係「催化劑」同「雞同蛋」。
  • Jorn Lambert（萬事達卡首席產品官）——代表支付網絡。佢嘅核心詞係 superbloom（超級綻放）、A2A Commerce、新憑證、支付軌道。（節目說明：Jorn 先生嘅發言為後期中文配音呈現。）
  • 劉作虎（OPPO 高級副總裁兼首席產品官）——代表終端/OS。佢嘅核心詞係「意圖入口」、「主動智能」、「能力信任 vs 風險信任」。
  • 周靖人（阿里巴巴集團首席科學家）——代表雲同模型。佢嘅核心詞係「意圖理解係 Agent System 嘅工作」、沙箱、強約束 vs 數據。
二、核心論點：八條可帶走嘅判斷

① 「雞同蛋」：Agentic Commerce 卡喺供需兩端嘅冷啟動

韓歆毅嘅診斷好具體：「用戶想用，但商家沒有很好的 Agent 服務；商家看到沒有用戶在用，就不太敢投入去開發 Agent。」呢個係典型嘅雙邊市場冷啟動問題——唔係技術唔得，而係兩邊都喺等對方先郁。螞蟻嘅定位就係做「智能體時代嘅催化劑」：幫更多商家開發更多 Agent，令佢哋被用戶搵到、用得起、用得好，個循環先轉得動。

「今年 Agentic Commerce 实际落地的速度，比大家预想的要慢很多。……用户想用，但商家没有很好的 Agent 服务；商家看到没有用户在用，就不太敢投入去开发 Agent。」 —— 韓歆毅，蚂蚁集团 CEO（2026 Inclusion·外滩大会主论坛）

呢句嘅分量在於發言人身份：講「慢」嘅唔係旁觀者，而係擁有全球最大支付生態之一嘅公司 CEO。行業普遍嘅敘事係「Agent 交易即將爆發」，而供給側嘅一號位親自降預期。

② 「先有雞還是先有蛋」——節目自己用咗呢個做第一段標題

官方章節時間軸嘅第一段就係 04:25「先有雞還是先有蛋」：智能體商業為什麼卡住了。呢個編排說明主持人泓君都認為呢個係全場最實嘅一段：唔係暢想，而係卡點診斷。

③ 意圖理解唔係模型嘅工作，係 Agent System 嘅工作

周靖人嘅判斷係全場技術含量最高嘅一句：「意圖的理解不單單是模型的工作，是 Agent System（智能體系統）的工作。」佢嘅解釋係：模型需要歷史記錄等嚟建立對上下文嘅理解，從而更好地理解人，而呢啲資訊要由 Agent System 有效組織起來。佢嘅結論分兩半——技術層面已經達到一定程度，但系統、產品維度上仍然需要一系列創新。

「意图的理解不单单是模型的工作，是 Agent System（智能体系统）的工作。……从技术方面，我认为已经达到了一定的程度。但今天在系统、产品的维度上，还需要一系列的创新。」 —— 周靖人，阿里巴巴集团首席科学家

呢句同 agent 圈近半年嘅主線高度一致（可對照本集 #163 講嘅「Agent 運行時升為一等公民」）：瓶頸由模型移到 harness / runtime / context 管理。

④ 終端由「連接人和 App」走向「連接意圖同結果」

劉作虎嘅表述好清楚：「以前我們做得更多的是連接人和 App。接下來在 Agent 時代，人只需要有一個意圖，你想做什麼，這個手機就可以幫你去完成。」手機未來嘅價值有兩半：一半係做用戶表達意圖嘅入口，另一半係結合長期記憶、實時上下文同更多設備服務，更好地理解用戶。

佢仲推咗一步：Agent 會由「響應式服務」走向「主動智能」——例如個人 Agent 結合用戶日程、興趣同習慣，主動建議某個時間去睇一場演唱會，並進一步幫用戶完成安排。呢個係由「工具」到「代理」嘅質變，亦係信任問題變得尖銳嘅原因。

⑤ 信任要拆成兩層：能力信任 vs 風險信任

劉作虎嘅拆解值得單獨抄低：

  • 能力信任——Agent 到底能唔能夠把任務做好；
  • 風險信任——Agent 未來越來越自主，用戶會覺得越來越不可控。

佢指出呢度有一個矛盾，而解決方法唔係叫用戶相信 Agent 永遠唔會犯錯，而係建立一套約束，令佢喺可控嘅基礎上完成任務——呢個需要精確嘅授權邊界、可追溯機制等基礎能力。作為提供操作系統能力嘅手機廠商，佢主張聯合行業生態夥伴，一齊建立一套針對 A2A（Agent-to-Agent）嘅行為規範。

「要解决的问题不是让用户相信 Agent 永远不会犯错，而是能否建立一套约束，使其在可控的基础上完成任务，这需要精确的授权边界、可追溯机制等基础能力。」 —— 劉作虎，OPPO 高级副总裁兼首席产品官

呢個係成集最「落地」嘅一句：把信任問題由「模型可靠性」翻譯成「權限工程」。亦呼應章節 19:59「手機廠商視角：能力信任、風險信任與 A2A 行為規範」。

⑥ KYA：身份基建嘅第三層

韓歆毅將信任體系概括為幾個方面：授權、身份、Agent 能力評估、資金安全，以及可追溯、可審計機制。喺身份層面，佢指出過去互聯網交易主要強調 KYC（Know Your Customer）同 KYB（Know Your Business）；Agent 開始進入交易之後，仲要進一步建立 KYA——Know Your Agent。

佢認為未來仲要解決Agent 之間嘅能力信任問題：「一個用戶個人的 Agent，憑什麼相信商家的 Agent 能夠很好地滿足我的需求？」而佢坦白目前行業喺呢方面做得仍然比較少，最終需要時間，讓大家建立起「唔係對於技術本身，而係對於 Agent 幫你執行任務同支付嘅信任感同安全感」。

金句 周靖人嘅簡化法：「今天對 Agent 信任，最後來講沒有那麼複雜，今天我們就把 Agent 想成一個人就好了。」——人們畀同事或助理派任務時，都會同時畀出權限、約束同執行空間，Agent 都係類似邏輯。關鍵三件事：① 把約束條件講清楚；② 建立安全嘅沙箱執行環境；③ 讓模型能夠區分邊啲係必須遵守嘅強約束、邊啲只係任務過程中需要處理嘅數據。佢仲補一句：安全執行唔止係模型自身嘅問題，Agent Harness 同 Agent Framework 層仲需要承擔權限管控、授權、追溯、審計等能力。

⑦ 支付網絡要為「機器高速交易」重寫

Jorn Lambert 表示萬事達卡而家非常關注 Agent-to-Agent Commerce。佢嘅判斷係：今日嘅支付體系仍然係按照「人參與交易」設計嘅，但未來 Agent 可能需要同銀行卡、傳統支付賬戶不同嘅新型憑證，同時仲需要新嘅權限機制，以及能夠適應機器高速交易嘅基礎設施。

「未来究竟会变成什么样，其实非常难预测。与其试图预测未来，不如先把基础设施铺好，让其他人能够在它之上创新。」 —— Jorn Lambert，万事达卡首席产品官

呢個係一個典型嘅「賣鏟人」姿態，亦係章節 31:15「A2A 商業，海量微交易所需的支付軌道」嘅由來。值得留意嘅係「海量微交易」呢個詞：當 Agent 對 Agent 傾偈，交易頻率會由「人嘅操作頻率」變成「機器嘅調用頻率」，而每次交易嘅金額可以細到接近零——傳統卡組織嘅固定費率模型根本跑唔通。呢個正係 Lambert 講「支付網絡一切都要徹底重寫」（章節 06:26）嘅意思。

⑧ 流量嘅邏輯由「時長」變成「意圖」

韓歆毅畀出一個頗有洞察嘅商業判斷：流量嘅邏輯正在從時長變成意圖。以商戶端嘅營銷轉化為例——商家嘅營銷由原來嘅「投流、提高轉化率」，變成「如何能夠按照用戶嘅個人意圖去解決問題」，從而更精準咁提供服務。供給側亦有新變化，例如為智力付費——讓人的經驗可以被泛化同複製，透過 AI 大模型把供給擴大化，帶來許多新機會。

三、行業 insight：呢集同其他幾集拼埋一齊讀
  • 同 9/11 No Priors × Brian Armstrong（#146）對照：Armstrong 講嘅係「everything exchange」——所有資產、所有交易最終會上鏈、由 agent 代理。外灘圓桌講嘅係同一件事嘅另一面：當 agent 真係可以動錢，法律同信任層需要咩。一個講願景，一個講基建，缺一不可。
  • 同「硅谷 101」自己嘅路線對照：9/16 嘅 E251（#157）講推理芯片——「訓練看算力，推理看帶寬」；本期講 Agent 交易——「交易看信任」。兩集合埋係一條完整嘅 agent 經濟基建鏈：算力 → 推理成本 → 應用 → 交易軌道 → 信任。
  • 同 AIUC × Rune Kvist（#159）嘅結構性對應：Rune 嘅一句話係「the binding constraint on adoption is risk」——採用嘅綁定約束由「能力」轉為「信任」。外灘圓桌四位嘉賓用四種語言講咗同一句：韓歆毅講 KYA、劉作虎講風險信任、周靖人講沙箱、Lambert 講重寫支付軌道。東西方兩邊、保險同支付兩個行業，收斂到同一個瓶頸。
  • 可操作檢查項（投資/產品視角）：當你評估一個「Agent 交易」項目，唔好只問「佢個模型幾強」，要問四條——① 授權邊界點表達？② Agent 身份點認證（KYA 有冇方案）？③ 出事之後邊個埋單、點追溯？④ 沙箱同 harness 層邊個做審計？呢四條答唔到，商業化就仲喺 demo 階段。
  • 「800 億 Agent 的商業想像」（章節 26:03）：節目把未來 5 年新商業機會嘅量級擺喺呢個章節標題度——值得留意嘅係呢個數字係一個想像框架而唔係預測。真正可以量度嘅信號反而係韓歆毅嗰句「落地比預想慢很多」。
四、爭議點與未被回答嘅問題
  • 「把 Agent 想成一個人」係唔係足夠嘅工程類比？周靖人嘅簡化極之好用，但佢有一個盲點：人類助理犯錯可以被理解、被原諒、被追責；Agent 犯錯嘅頻率係機器級嘅——一日一千次調用，即使 99.9% 正確，都係一日一次事故。呢個正係劉作虎講「能力信任 vs 風險信任」嘅深層原因：類比解決咗理解問題，但解決唔到規模問題。
  • 邊個應該定 A2A 標準？劉作虎主張手機廠商聯合生態夥伴建立 A2A 行為規範；Lambert 主張「先鋪好基建，畀其他人喺上面創新」；韓歆毅則以螞蟻做「催化劑」。三方都想做規則制定者，但節目冇觸及一個尖銳問題：跨國、跨平台嘅 A2A 身份體系，最終由邊個簽發憑證？
  • 「慢」係週期性定係結構性？韓歆毅講嘅「雞同蛋」係一個典型嘅可解嘅協調問題（一邊先補貼就轉得動）。但如果真正嘅卡點係 KYA 標準、責任歸屬、監管定性，呢個就唔係補貼可以解決嘅——而節目冇明確區分呢兩者。
  • 模型仲缺咩？章節 12:34 標題列出「長期上下文、提問能力與可靠執行」——呢三樣係全場最接近「技術短板清單」嘅一段，但節目中四位嘉賓對此嘅展開相對簡略，說明行業對「可靠執行」嘅具體標準仍然未有共識。
