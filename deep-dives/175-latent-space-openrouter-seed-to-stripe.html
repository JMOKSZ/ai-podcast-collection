「一間被叫做 wrapper 嘅公司」——Latent Space × OpenRouter：被 Stripe 以約 $7B 買下，同「agentic fraud 將會像海嘯一樣打過嚟」

📅 2026-09-25 23:14 UTC（可對應 09-26 07:14 CST）·🎙 Latent Space·👤 Alex Atallah（OpenRouter 聯合創始人 & CEO）、Anjney Midha（AMP）·🏷 分發層 / 中立路由 / 收購 / agentic fraud

呢集表面上係一單收購新聞嘅訪談，實際上係一條產業史：由 2023 年「得 OpenAI 一間」講到今日「幾十間前沿實驗室」，由 Llama 講到 Mistral 嘅磁力鏈 checkpoint，由 Discord 嘅內容審核拒答講到 Stripe 嘅反欺詐基建。而貫穿全場嘅只有一個判斷：模型層會分化，所以中間要有中立嘅路由／發現／計費／版本管理層；而當 agent 開始搬動價值，呢層就會變成攻擊目標。

一句話抓住本集：OpenRouter 由「開源權重第一波」長成 AI 生態嘅中立路由層——>1,000 萬開發者、每日 >10 兆 tokens；佢被貼過「只係 wrapper／marketplace」嘅標籤，結果一個月後 Menlo 就把估值 mark up 約 10×。收購方 Stripe 嘅戰略理由，被嘉賓講成一句好重嘅話：「token 經濟」會成為下一個系統性風險面，而下一代欺詐唔止嚟自人，係嚟自自主 agent 攻擊日益值錢嘅 token 流。
一、起點：一個 $600 嘅 Alpaca 時刻

Anjney Midha 從頭講佢嘅「頓悟時刻」。2022 年底，OpenAI 幾乎係唯一選擇，加一堆早期開源權重嘅嘗試。2023 年 1 月 Llama 出嚟，「令人興奮，但沒辦法同它聊天」——它的 benchmark 贏 3，但唔係一個 engaging 嘅模型。似乎只差幾步 RLHF。

然後 Alpaca 出現：一支史丹福團隊用合成數據微調 Llama，只花 $600。Midha 嘅形容好具體——他當時在飛機上用它，「好多情況下根本分唔清 ChatGPT 同 Alpaca 嘅輸出」。

「如果做一個模型係咁容易，咁第一，我們有一種全新嘅『把數據變現』嘅方式——你可以拿好有價值嘅數據，用 $600 變成一個服務，而呢個成本大概會隨時間下降。」 —— Anjney Midha。佢嘅延伸推論係：只要有「爆款應用 ＋ 一套可以用自己 flavor 複製它嘅框架」，一個即時生態就會冒起——因為單一公司嘅決策同更廣生態可以做出嘅變化之間，有巨大落差。

Midha 講得好清楚，當時最接近嘅係 Hugging Face——但 HF 冇閉源模型、當時亦唔可以真正用那些模型，仲冇「邊個在用、用嚟做乜」嘅數據。而單一開發者想要嘅，係一個可以睇到「LLM 被用幾多、邊個用、點解用」嘅 home base。呢個缺口，就係 OpenRouter 嘅位置。

二、Discord 嘅遺產：為何「拒答」催生了硬需求

Alex Atallah 嘅背景被一筆帶過但好關鍵：他創辦過 OpenSea，之後做過 Discord 平台負責人（管 crypto/NFT 安全、250M MAU 嘅部署同內容審核）。而導入 OpenRouter 嘅手shake，係 13 年前在史丹福《Stanford Review》——Peter Thiel 創辦嗰份自由派報紙——嘅一次編輯會上，兩個二年級生第一次見面。

真正嘅技術動機則好實際：Discord 用當時嘅模型做內容審核時發現模型會拒答。每個伺服器有自己嘅社群規範（好多其實違反 OpenAI 嘅規則），但模型用「哈利波特／商標內容一律拒答」呢種粗糙規則去擋，結果就係硬需求——可切換嘅模型、開放權重嘅選項。另一個被點名嘅能力遷移係：Discord 上曾跑過「數十億美元 GMV 嘅 NFT 交易」，團隊因此學會在規模化社群裡面防釣魚、防社交工程、防 DDoS，呢批經驗直接變成後來 OpenRouter 嘅計費同反欺詐能力。

而 Midjourney 提供咗另一個模板：由發布到 $100M 收入 run rate，唔夠八個月，而它係寄生在 Discord 上嘅應用體驗。之後 Stable Diffusion 出現，事情就變質：「一個開發者可以整自己嘅 Midjourney」——但前提係要有一個唔使自己搞 hosting 嘅 API。呢個就係「模型 API 層」嘅誕生條件。

三、核心判斷：前沿實驗室「識訓練，唔識分發」

呢段係整集最有商業洞察嘅部分。Midha 講當年 VC 反對投資 OpenRouter 嘅最大理由，係「會有一個 Google 式壟斷贏晒」。他反過來認為，scaling law 恰恰係 OpenRouter 嘅順風——因為 scaling law 意味住至少會有多個團隊做出前沿模型，所以需要一層中立嘅路由／發現／計費／版本管理基建。

「你會震驚——早期 OpenAI… 唔好意思，Anthropic、BFL、Mistral 嘅訓練團隊，在『把研究拿出實驗室、放大影響』嘅默認做法上，係幾咁相似：checkpoint 做完，丟個 API，搞定，然後——一片死寂（there'd be crickets）。」 —— Anjney Midha。具體到咁樣：Anthropic 嘅第一個 Claude checkpoint，做完之後在內部放咗成年先對外發布；發布時得三個開發者示例，其中一個係 Discord bot、一個係 Midha 妻子 Vivian 嘅創業公司、另一個係 Notion——「因為朋友就係咁樣湊出嚟嘅」。
「得一個 checkpoint 係做唔到任何嘢嘅。你需要一大堆 plumbing 圍住它，先可以令一個開發者用得着。」 —— Alex Atallah。呢句係對「just a wrapper」嘅正面反駁。

對照數字好有說服力：Atallah 提到，一家前沿實驗室花了超過 12 個月才做到首個 1,000 萬美元收入；而 Black Forest Labs 選喺 OpenRouter 上線時，OpenRouter 可以「你發布嗰日，我們可以送你 100 萬個開發者」——Midha 形容呢個係「一個鐘之內嘅 step function change」。Atallah 補一句好誠實嘅校正：「我覺得今日大約係 400 萬。」（指當時平台規模；全站開發者後來超過 1,000 萬）

而 Mistral 係「競爭性推理市場」嘅第一次真正證明：他們發布嘅第一個 checkpoint 係 torrent 磁力鏈，完全冇 API。大約 2023 年 12 月嘅 Mistral 8x7B「價格戰」，令價格跌咗約 80%——呢個在嘉賓眼中係正面訊號：第一次有真正嘅競爭出現。

四、為何「just a wrapper」係最蠢嘅還原論（兼一次 10× mark up）

Midha 直接開火，明確點名好多 VC「在呢個領域冇任何運營經驗」：

「當時對幾個投資者嚟講，OpenRouter 唔止係一個圍住 API 嘅 wrapper 呢件事，並唔明顯。而呢點令我好嬲。我當時想：『乜嘢？我冇時間同你辯論。我們要投。』然後我記得，大約一個月之後，Matt Murphy 就把估值 mark up 咗 10 倍。」 —— Anjney Midha。OpenRouter 官方訪談摘要亦保留咗一句：「如果一個 app 只係模型嘅 wrapper，咁 OpenRouter 就係 API 嘅 wrapper——投資人不也是 LP 嘅 wrapper 嗎？」

佢嘅正面論證係：API 編排 ＋ 按金鑰／Provisioning／版本控制 ＋ 社群 flywheel，本身就係護城河。而呢個護城河嘅本質，係一個「資訊不對稱」問題——見下面呢段本集最好嘅比喻：

「我們係一個中立層，望住呢個市場，好似望住一間巨大嘅黑房——所有角落對用戶嚟講完全模糊，用戶行入去、四圍摸，試圖搞清楚枱上有乜嘢物件可以拿走、砌入自己嘅公司。而呢種做法係瘋狂嘅。模型唔係那種可以將所有功能列在網站上嘅產品。」 —— Anjney Midha（00:21:57 前後）。佢嘅補充係：「打燈嘅必須係中立第三方」——因為模型實驗室自己做嘅 marketing 同中立層對同一個模型嘅呈現係兩回事。
五、OpenRouter vs LM Arena：為何係兩間公司

swyx 問得好直接：你又係 LM Arena 嘅投資人，你又識個 flywheel，為何你唔做 Arena？為何 Arena 唔做 OpenRouter？

Midha 嘅答案好清楚，而且係一個結構性理由，唔係策略性理由：

「一間公司同時做兩件事係好難嘅，因為一間係拿數據去賣，而另一間按默認係唔可以嘅。所以我覺得呢度有個 branding 上嘅理由，令呢度會係兩間公司。」 —— Anjney Midha。LM Arena 係偏好評測（拿數據賣）；OpenRouter 係路由層——「在 OpenRouter，冇訓練、冇 property」。兩者使命根本唔同。

呢個分別對理解「排行榜」有直接含義：Arena 嘅 leaderboard 係偏好信號；OpenRouter 嘅 leaderboard 係即時產業地圖——它反映真實嘅使用結構，而唔係抽樣評分。

六、Focus 作為戰略：刪咗嘅嘢同返嚟咗嘅嘢

OpenRouter 做過幾個「原型但從來冇發布」嘅產品。最重要嘅係 MOM（Mixture of Models）：讓你揀幾個模型（或平台幫你揀），最後用另一個模型（集合中最聰明嗰個）把結果融合，中間過程用一個 Kanban 式界面展示晒出嚟。

他們後來把成個代碼庫刪咗——因為「2024 年初嗰時技術仲係太原始、形態亦唔啱，要再迭代幾次」。但幾年之後，fusión 又返嚟，而且「好得多」。Midha 給出嘅技術理由值得記：

「RL 擴展咗每個實驗室內部 ML 研究者嘅創造力面積，所以佢哋可以更有效地令唔同模型嘅推理能力分化。」——他稱之為佢對「fusión 為何今日 better」嘅理論。

而復活嘅觸發點係一個好樸素嘅實驗：「問所有模型，融合結果係否比各自嘅結果更好。佢哋全部話係。呢個發生咗幾次，我就想——好，抽查唔錯，我哋應該 benchmark 佢。fusión 就係咁樣 build 出嚟。」Focus 嘅價值在於：當你唔做 fine-tuning、唔做 memory、唔做一堆相鄰產品，你就可以等到一個技術真正成熟嘅時刻，再一次做對。

七、增長拐點：Sonnet、OpenClaw 同每日 10 兆 tokens

swyx 用「state of AI」嘅方式數里程碑：由 Mistral 價格戰，到 leaderboard，到「一百兆 tokens—啊唔係，你而家一星期十兆」。Midha 校正：「我們而家係一日十兆。」再由 Sonnet、OpenClaw、auto-routing 帶來嘅使用結構變化，一路推到收購。

規模 >1,000 萬開發者（訪談中一度講「發布日可送 100 萬開發者」，Atallah 事後校正「今日大約 400 萬」——即係全站規模與單次活動口徑唔同）·每日 >10 兆 tokens · 收購方為 Stripe，訪談摘要與節目描述提到交易規模約 $7B。全部數字來自公司自報或節目描述，無第三方核實。

唔應該忽略嘅係 leaderboard 嘅角色。當你係「中立路由層」，你就會有全網最完整嘅「邊個模型被邊種任務用幾多」嘅即時資料。呢個係一個資訊資產，而且係 Arena 式偏好評測拿唔到嗰種——因為它係真實付費流量，而唔係抽樣投票。

八、最重要嘅前瞻判斷：agentic fraud 會像海嘯

最後一段係整集最有前瞻價值嘅部分，亦係 Stripe 收購嘅戰略理由。swyx 提到「十萬億美元 GMV 同全球 GDP 增長」嘅框架，Midha 接落去：

「我覺得其中有好大一部分會係欺詐、濫用。而如果人們唔信任 token，我們可能永遠到唔到嗰個規模。呢種基建並唔存在……我覺得人們未意識到，由 AI agent 造成嘅惡意行為（agentic fraud）將會像海嘯一樣打過嚟。」 —— Anjney Midha（約 01:17–01:18）。呢個就係 Stripe 收購 OpenRouter 嘅戰略邏輯：Stripe 嘅反欺詐基建 ＋ OpenRouter 嘅 token 流，組成「token 經濟」嘅信任層。

要明白呢句嘅重量：OpenRouter 係每日 10 兆 tokens 流經嘅閘門。如果 agent 開始自主搬動價值（買嘢、開帳戶、跑自動化），咁「token 流」就會由一種運算資源，變成一種可以直接被套現、被攻擊、被洗錢嘅高價值資產。而攻擊者亦會由人類升級成 agent——呢個係「推理閘道正在變成欺詐目標」嘅具體含義。

收購後嘅預期（Midha 訪談最後一句）：「我覺得呢個係一個好方法，令我們可以加速市場、更快走上 upmarket。」即係由「開發者自助市場」推向「企業級／支付級基建」。

九、我嘅萃取（Insight）
  1. 價值正由「模型層」遷移到「harness／路由／評測／後訓練」。OpenRouter 係呢條線最成熟嘅商業化證明：底層模型唔係它嘅，但它掌握分發、發現、計費、版本控制同 anti-fraud。同週 AINews 亦反覆講「同模型同 prompt，harness 唔同就能顯著改變 benchmark 結果」——兩條線講嘅係同一件事。
  2. 「Google 式壟斷」在 LLM 時代更難成立。理由唔止係技術樂觀——而係「造好競爭者嘅經濟性被大幅去中心化」，加上 LLM 唔止係一個介面，而係「起新公司嘅原料」。呢個係 OpenRouter 嘅存續前提，亦係它願意押注多模型未來嘅理由。
  3. 「識訓練，唔識分發」係前沿實驗室嘅系統性缺口。「checkpoint 做完 → 丟個 API → 一片死寂」呢個畫面，配上「內部擱置成年」同「三個示例靠朋友湊」嘅細節，說明分發唔止係 marketing 問題，係工程同產品嘅一個獨立學科。呢個缺口撐起咗一整層基建公司。
  4. 社群運營 ＋ 系統思維係被 ML 圈長期低估嘅能力。由《Stanford Review》→ Discord/OpenSea 嘅反欺詐 → OpenRouter，呢條人脈線同能力線，同「純 ML 研究」係兩種完全唔同嘅訓練。而喺基建層，後者往往更決定成敗。
  5. 「agentic fraud」係目前最被低估嘅 AI 經濟風險。呢個唔係一個模型安全問題，而係一個金融基建問題。把 token 流當成高價值資產、把 agent 當成潛在攻擊者——呢個框架值得任何做 agent 支付／自動化嘅團隊直接抄。
十、前後脈絡
  • 同本週 Latent Space 嘅 Runway／WorldPrompt、Bio-security 兩集連成一個「基建／能力／安全」三角。Runway 講生成能力、生物安全講防守落後、OpenRouter 講分發同信任——三集合起來，正好係「2026 下半年嘅 AI 產業地理」。
  • 同 #168〈Diogo Almeida：Jev / System One〉、#165〈六個 Jev 克隆〉相接。如果決策／路由係新原語，OpenRouter 就係「路由」在商業層嘅對應物。Jev 在 OpenRouter 上係 1K–10K context 嘅第一名模型——兩條線本來就交叉。
  • 同 9/25 AINews 提到嘅 TypeSafe（Jev）$10B+ 估值一併睇。「決策／路由／系統一模型」呢一層正在被資本重估，而 OpenRouter 被 Stripe 買下係同一趨勢嘅另一個數據點。
  • 同 #167〈Bund：agentic commerce 信任基建〉、#146〈Brian Armstrong：agentic finance〉同一條線。「agent 開始搬錢」之後，信任層（KYC、承保、反欺詐）就係下一個必爭之地。
爭議點 / 需留意之處
  • 嘉賓有明確立場。Midha 係 OpenRouter 嘅投資人，他對「wrapper 論」嘅攻擊帶有明顯的利益相關；「Menlo mark up 10×」係佢嘅敘事，細節（金額、時間）他自己都講得唔精確。
  • 「1,000 萬開發者」口徑唔嚴。Atallah 在訪談中先講「發布日送 100 萬開發者」，被追問後更正「我覺得今日大約 400 萬」，而官方描述係「>1,000 萬開發者」。要留意「註冊帳號」同「活躍開發者」之間通常有大量重複註冊（account duping），需要去重。
  • 每日 10 兆 tokens 係公司自報。無第三方核實；亦要留意「tokens」嘅統計口徑（是否含快取讀取、是否含內部測試流量）。
  • Stripe 收購價約 $7B 來自節目描述。唔係官方財報數字，唔應當成已核實嘅事實。
  • 「agentic fraud 海嘯」目前係預言，唔係數據。Midha 冇給出任何量化證據（例如現時 fraud rate、增長曲線）。佢嘅框架合理，但作為預測，讀者應保持「方向可能對、量級未知」嘅態度。
  • LM Arena vs OpenRouter 嘅「兩間公司」講法，係事後合理化嘅一種。它也確實對應一個真實嘅結構差異（一間賣數據、一間按默認唔可以），但唔排除同時係一個 positioning 選擇。
如果只記一句：呢集真正嘅主題唔係「OpenRouter 賣咗幾錢」，而係「當模型變成一種可以互換嘅原料，價值就會沉澱在嗰層負責發現、路由、計費、同信任嘅中立基建上」。而 Midha 最後嘅警告提醒我哋：呢層基建越值錢，就越會成為攻擊目標——因為下一個要防守嘅邊界，唔係模型嘅拒答，而係 agent 手上嗰條 token 流。
