Claude Opus 5：Fable 級效能、Opus 價格——同埋一場 Benchmark 信任危機

Claude Opus 5 Anthropic Benchmark 危機 FrontierCode ECI Agentic AI

一、週五突襲：一個反常嘅發布時間

2026 年 7 月 24 日星期五，Anthropic 做咗一件好反常嘅事——喺週五發布 Claude Opus 5。

喺 AI 業界，週五發布通常意味住兩樣嘢：要麼你覺得呢個產品唔夠震撼想低調推出，要麼你根本唔在乎傳統 PR 節奏。Anthropic 明顯係後者——Opus 5 帶住接近 Fable 5 嘅能力、Opus 4.8 嘅價格，同埋一大堆 benchmark 爭議，炸翻咗整個週末。

「Opus 5 comes close to the capabilities of Claude Fable 5 in many domains at half the price.」

— Anthropic 官方發布稿

但真正有趣嘅唔係 Opus 5 有幾勁——而係佢引發嘅一場關於 AI benchmark 信任危機 嘅大辯論。官方數字話 Opus 5 「接近」Fable 5，但社區實測話「贏咗」。呢個 gap 本身，就係 2026 年 AI 產業最值得關注嘅信號。

二、數字之戰：四個 Benchmark，四種敘事

Opus 5 嘅 benchmark 數據，取決於你信邊個。

📊 Opus 5 vs Fable 5 —— 四大測試框架

  • Epoch ECI（整體）：Opus 5 = 159 vs Fable 5 = 161（-2 分，官方口徑係「接近」）
  • SWE-ECI（軟件工程）：Opus 5 = 161，與 Fable 5 完全持平
  • AA-Briefcase（Artificial Analysis 代理知識工作）：Opus 5 超越 Fable 近 150 Elo，每任務成本降低 20%
  • EEG 對比 Opus 4.8：僅 +1 ECI 分——但社區認為實際體驗遠超呢個數字

呢四個數字講緊四個唔同嘅故事：

  • Epoch ECI 話你知：Opus 5 整體上係「接近但未超越」Fable 5
  • SWE-ECI 話你知：喺編碼呢個關鍵領域，Opus 5 同 Fable 5 已經平起平坐
  • AA-Briefcase 話你知：喺 agentic knowledge work（代理式知識工作）——即係最實際嘅企業使用場景——Opus 5 明顯勝出
  • EEG 話你知：官方 aggregate benchmark 可能嚴重低估咗 Opus 5 嘅真實進步

Epoch AI Research 嘅推文好謹慎：「Claude Opus 5 achieves an ECI of 159, slightly below Fable 5's value of 161, while matching Fable 5 on SWE-ECI at 161」。但社區反應幾乎立即反彈——@scaling01 話：「ECI is incredibly underrated. It's only +1 vs Opus 4.8 but seems much better at everything. We need harder public benchmarks.」

「ECI is incredibly underrated. It's only +1 vs Opus 4.8 but seems much better at everything. We need harder public benchmarks.」

— @scaling01

三、FrontierCode 異常：當更多計算 = 更差結果

呢次發布中最技術性嘅爭議，來自 @jerhadf 發現嘅 FrontierCode 異常：Opus 5 喺 medium effort 嘅得分竟然高過 high effort。

呢個發現違反咗直覺——正常情況下，比更多 test-time compute（推理時計算）應該得到更好結果。但 FrontierCode 上嘅 anomaly 顯示，對於 Opus 5 嚟講，effort scaling 並非單調遞增。

「Opus 5 scored better on FrontierCode at medium effort than at higher effort, even though more effort improved performance on other evals.」

— @jerhadf

呢個現象嘅含義遠遠超出一個 benchmark 嘅 bug：

  • 部署策略（deployment policy）可能比模型質量更重要——點樣分配 inference-time compute，可能同模型本身一樣決定最終表現
  • Frontier Labs 日益依賴 test-time compute——但如果呢種 compute 嘅回報唔係線性嘅，咁舖 compute 嘅競爭就唔係「越多越好」嘅簡單遊戲
  • Effort scaling 本身需要成為 eval 嘅一部分——而唔係被當作一個 hyperparameter

呢個發現對 OpenAI 嘅 o-series 同 Anthropic 嘅 thinking mode 都有直接含義：如果 medium effort 喺某啲任務上比 high effort 好，咁我哋可能需要重新思考 test-time compute 嘅分配策略——唔係畀愈多愈好，而係要揾個 optimal point。

四、真實世界嘅 Agent 表現

Benchmark 嘅爭議之外，Opus 5 喺真實世界嘅表現獲得咗一致好評——特別係 agentic tool use 方面。

最令人印象深刻嘅 demo 嚟自 @abacaj：Opus 5 「opened the browser and canceled a ChatGPT Pro subscription」，跟住佢補多句：「This thing can really drive a browser wow.」呢個看似簡單嘅操作背後，係 browser automation + decision making + security credential handling 嘅完整 agentic loop。

Mikhail Parakhin（@MParakhin）——一個被廣泛引用嘅工程師——話 Opus 5 喺佢嘅測試中「clear head-to-head win against Fable for math and everything, really」，特別係用 best-of-n sampling 嘅時候。

「Best-of-n rules — clear head-to-head win against Fable for math and everything, really.」

— Mikhail Parakhin (@MParakhin)

Stripe 工程師 Cristian Rivera 嘅描述更具體：「Over one weekend, I gave it a chief-of-staff role over my dev environments: it built its own monitor, drove each box, and pulled me in only for the judgment calls.」呢個正正係「AI 同事」嘅感覺——唔係取代你，而係幫你 handle 所有可以做 automation 嘅部分。

Harvey（AI 法律工具）嘅應用研究主管 Niko Grupen 提供咗量化數據：「Opus 5 maintained quality at lower reasoning levels, generating 26% fewer tokens on average compared to Opus 4.8 at max reasoning.」Token 節省直接轉化為成本節省同 session 長度——呢個對企業嚟講可能比 benchmark 分數更實際。

五、價格革命：Fable 級能力，一半價錢

Opus 5 保持 Opus 4.8 嘅價格：$5/百萬 input token、$25/百萬 output token。相比 Fable 5 嘅大約雙倍價格，呢個定價策略好明顯——Anthropic 想 Opus 5 成為「everyday driver」。

仲有幾個值得留意嘅產品更新：

  • Fast Mode：research preview，以雙倍價格換取 150% 更快嘅 token 生成速度
  • Automatic Fallbacks：當 safety classifier 拒絕請求時，API 自動 fallback 到另一個模型——確保用戶收到有用回應而非錯誤
  • Mid-conversation Tool Changes：開發者可以喺對話中間切換工具，唔使重置 prompt cache——呢個對長時間 agentic sessions 好關鍵

其中 Mid-conversation tool changes 尤其值得關注。佢解決嘅係一個實戰痛點：長時間 agentic session 入面，你一開始畀咗好多 tools 畀模型，但任務到咗後期某啲 tools 已經唔需要。傳統做法要麼繼續保留（浪費 token + prompt cache），要麼開新 session（丟失 context）。Anthropic 呢個設計容許動態 tool management——呢個先係真正為 agent 時代而設計嘅 infra 改進。

六、擁擠的前沿：Opus 5 喺邊個位？

Opus 5 發布嘅時機好有趣。佢進入嘅唔係一個平靜嘅市場，而係一個 frontiers 大亂鬥嘅局面：Fable 5、GPT 5.6 Sol、Grok 4.5、Kimi K3、Mythos——再加上洶湧嘅開源權重浪潮。

呢次發布同舊日模型發布有一個明顯分別：討論嘅 tone 唔同咗。

以前發布 flagship 模型，大家攞住 spec sheet 逐行對比：MMLU 幾多分？HumanEval 幾多分？而家嘅討論係：

  • 「佢可唔可以自主操控 browser？」
  • 「佢嘅 cost per task 有幾低？」
  • 「佢喺 agentic workflow 入面會唔會 loop？」
  • 「佢嘅 evals 有冇被 game？」

呢個轉變本身就係行業信號：AI 競爭已經從「邊個模型最 smart」轉向「邊個模型最有用」。

「The launch pattern: fewer 'spec sheet' posts than older model launches, and more argument over evaluation methodology, agent demos, and real-world coding performance. This combination explains the launch pattern in these tweets.」

— Latent Space AINews 分析

Artificial Analysis 嘅 AA-Briefcase benchmark 特別值得留意。佢哋測嘅唔係 static QA，而係 agentic knowledge work——模型要喺多步 workflow 中完成複雜任務。Opus 5 喺呢度超越 Fable 5 近 150 Elo，同時 cost per task 低 20%。呢個先係企業用戶真正 care 嘅指標。

🔑 核心洞察：Benchmark 危機嘅根源

Opus 5 引發嘅 benchmark 信任危機，根源在於一個結構性問題：aggregate capability scores compress diverse behaviors into a single number。ECI 將 coding、reasoning、knowledge work 等維度壓縮為一個數字，但 Opus 5 嘅強項係編碼同 tool use——呢啲恰恰係 aggregate score 最難捕捉嘅維度。

社區嘅 frustration 其實係一個健康信號：用戶唔再滿足於「呢個模型 MMLU 幾多分」，而係要「呢個 model 幫我解決真實問題有幾掂」。Agent era 需要 agent-native benchmarks，唔係 chatbot era 留下嚟嘅靜態測試。

七、Agent 時代嘅新規則

Opus 5 嘅發布——同圍繞佢嘅爭議——揭示咗 AI 行業嘅幾個新規則：

第一，Benchmark 已死，Benchmark 萬歲。 現有嘅公開 benchmark 明顯跟唔上模型能力嘅進化——特別係 agentic 方向。FrontierCode 嘅 effort scaling anomaly、ECI 被社區質疑「underrated」——呢啲都係靜態 eval 喺動態 agent 時代嘅失效信號。社區開始呼籲 harder public benchmarks。

第二，Cost per Task 取代 Cost per Token。 Opus 5 嘅定價敘事唔再係「每 token 幾錢」，而係「每完成一個任務幾錢」。呢個 shift 同我哋之前喺 Codex 7M 深潛中睇到嘅一致——「cost per task」正成為行業新定價單位。

第三，Agent demos > Benchmarks。 Opus 5 取消 ChatGPT Pro 訂閱嘅 browser demo，比任何 benchmark 數字都更有說服力。呢個趨勢今年一直喺度加速——我哋見過 Claude Code 嘅 live demos、Codex 嘅 workflow automation、GPT-5.6 Sol 嘅 agentic coding——每次 demo 嘅 impact 都大過 official benchmark。

第四，Distillation 定價嘅威力。 Opus 5 以 Opus 級價格提供接近 Fable 嘅效能，暗示 Anthropic 嘅 distillation 能力可能被低估。用更小嘅模型逼近 frontier performance——呢個策略如果成功，會改變 frontier labs 之間嘅競爭邏輯。

「The practical implication is that Opus 5's reception is being filtered through two simultaneous lenses: as a coding/agentic product that users can immediately operationalize, and as a frontier model subject to increasingly adversarial benchmark and safety scrutiny.」

— Latent Space AINews
