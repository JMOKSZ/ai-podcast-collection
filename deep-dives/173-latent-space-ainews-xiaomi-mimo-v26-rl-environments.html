「一週之後就開源」——Latent Space AINews × 小米 MiMo-V2.6-Pro：1T MoE 用 $2.6M RL 登頂開源榜，同「高質量 RL 環境可能係上一輪預訓練語料嘅戰略地位」

📅 2026-09-22 06:30 UTC（09-22 14:30 CST）·🎙 Latent Space AINews（swyx 維護，非訪談）·👤 頭條：小米 MiMo-V2.6 Pro / Flash·🏷 開源權重 / RL 環境 / 後訓練成本 / 中國開源節奏

呢條唔係訪談，係每日聚合欄目（AINews 自稱掃描 12 個 subreddit、544 個 Twitter 帳號）。之不過本期值得單獨寫，因為佢記錄咗一件結構性嘅事：一個「唔在六小虎名單上」嘅手機廠，用一億級參數嘅開源權重模型，一次過登頂開源榜首，而真正嘅主角唔係模型，係它後面嘅 RL 基礎設施同成本結構。

一句話抓住本期：小米 MiMo-V2.6-Pro 以 1.02T 總參 / 42B 活躍、MIT 授權、Artificial Analysis 智能指數 46（開源最高）登場，而 RL run 據報只係 130 小時 / 75B tokens / $2.6M，並且會把約 7,000 個 RL 環境 + 訓練 recipe 一齊開源。社群嘅共識解讀係一句好重嘅話：「高質量開源 RL 環境，可能複製上一輪『預訓練語料』嘅戰略地位」。
一、點解小米入場係一件「意外」

AINews 嘅措辭好直白：小米「傳統上唔被視為中國 AI 六小虎之一」，所以呢次發布「對你熟悉嘅名字秩序嚟講非常意外」。而更意外嘅係——它是原生全模態（natively omnimodal）嘅。小米官方原文：

「The MiMo-V2.6 series includes two natively omnimodal models: MiMo-V2.6-Pro is our most capable model to date, while MiMo-V2.6-Flash strikes the best balance between intelligence, efficiency, and cost. We are also rolling-out MiMo-V2.6-Pro-UltraSpeed, delivering up to 20x faster output speed at the same quality, for users who require extreme generation speed.」 —— 小米 MiMo 官方發布措辭（經 AINews 引述）。注意三條產品線嘅分工：Pro 打能力、Flash 打性價比、UltraSpeed 打速度。

呢個「三線切分」本身係一個產品訊號：當模型能力開始收斂，廠商就唔再只賣一個「最強模型」，而係賣同一家族在不同成本／延遲約束下嘅多個點。同週 Grok 4.7、Qwen 系列嘅做法一致——前沿競賽正在變成「Pareto 前沿上嘅選點競賽」。

二、模型規格同定價：一個「開源即前沿級」嘅一手數據點

成本效率每題 $0.13，落在「Intelligence vs. Cost per Task」Pareto 前沿上

點解「$0.13／題」比「46 分」更重要 分數係單點，Pareto 前沿係一條可持續嘅位置。當同一分數區間可以有多個價格點，採購決策就會由「邊個最強」轉向「我嘅任務值幾錢」。呢個係開源權重模型對閉源 API 最實際嘅壓力形式——唔係超越，而係重新定價。
三、真正嘅主角：RL 沿三軸擴展

AINews 明確講：最突出嘅唔係模型，而係 RL stack。小米技術報告（MiMo_V2_6_technical_report.pdf）講嘅三條擴展軸：

  1. 更大嘅 batch 同更高吞吐——全非同步（fully asynchronous）架構上跑大 batch，每次更新 1,568 條樣本，訓練支援最高 1M context length，每步 3.5–3.7B tokens。
  2. 更多任務、更豐富嘅環境——一套多任務訓練組合，橫跨 coding、general agents、visual、cyber，並且混用多個 harness，令「一種能力嘅增益可以強化其他能力」。
  3. 更多 grader compute——小組內相對比較（relative comparison within each group），令長時域 RL 任務獲得更精確、更多樣嘅獎勵信號，閉合一個自我改進迴圈，並把模型推向更短路徑、每任務更少 token。

第 3 點係最容易被忽略但最關鍵嘅：「更少 token per task」係被優化目標。即係話 RL 唔止在學「答得對」，而係同時在學「用更少步數、更少 token 答對」。呢個直接影響推理成本曲線——亦係為何「$0.13／題」可以同時存在於高分模型上。

四、透明到反常：直播 final RL runs、一週內出技術報告

AINews 記錄咗一條時間線，值得逐格睇：

  • 幾日前，羅福莉（Fuli Luo，前 DeepSeek 明星工程師，現於小米）開始直播發布他們最後階段嘅 RL 訓練 run——被形容為「內部指標異常透明」。
  • Artificial Analysis 於 9/21 給出指數與 Pareto 定位。
  • 團隊在最後一次 RL run 之後唔夠一週，就已同時出模型 + 技術報告（AINews 特別點出呢個速度）。
「高質量嘅開源 RL 環境，可能同上一輪週期嘅預訓練語料一樣，具有戰略重要性。」 —— AINews 綜合多位社群人士（@bertgodel、@Thom_Wolf 等）得出嘅反覆出現嘅解讀

而「開源」嘅具體範圍亦講得好清楚：環境代碼同訓練 recipe 會開源，但完整 7,000+ 任務數據集暫時未發布。公開嘅部分包括（全部掛在小米 MiMo 嘅 verl / mimoagent repo 下）：

  • Coding / software engineering：recipes/code（Code recipes、dataset loader 同 rewards）
  • Cyber / 漏洞復現：recipes/arvo（ARVO environment 同訓練 recipe）
  • General / knowledge work：recipes/general（通用環境、工具同訓練 recipe）
  • Visual / web development：recipes/design/webdev（Web 開發環境同評分）
  • Music generation：recipes/design/music（數據準備同 music scorer）
  • 可組合 mini-harness：config/agent（Agent configurations）
  • 共用環境適配層：mimoagent/environments（shared environment adapters）
為何「開源環境但唔開源數據集」係一個精心嘅切分：環境代碼係可被複製嘅方法論，而任務數據集係稀缺嘅資產。前者開源可以換取生態、標準同人才；後者留住，就保住咗差異化。呢個切法同過往「開源權重、閉源資料」嘅策略一脈相承——只係今次被開源嘅「方法論」由模型架構，換成了 RL 環境工程。
五、$2.6M / 130 小時 / 75B tokens：後訓練成本嘅一個錨
數字 130 小時、75B tokens、$2.6M（社群引述，見 @zephyr_z9）完成支撐此次結果嘅 RL run。注意：屬公司公告與社群引述，未經第三方復現。

AINews 指出呢組數字之所以引人關注，係因為它壓縮了時間線（compress timelines）。「如果呢啲數字站得住，含義就係：後訓練／RL 正變成一條比很多人想像中便宜得多、通往「前沿附近」嘅路徑。」

另一條值得記嘅技術細節：MiMo 家族在 JAX + TPU 上擴展 RL，而據 @tianjun_zhang 講，在那裡「scaling 大多只係改 config，而唔係重寫代碼」。呢句其實係一個關於基礎設施選擇如何影響迭代速度嘅論斷——當擴展嘅邊際成本係「改一個配置」，試錯頻率就會完全唔同。

七、我嘅萃取（Insight）
  1. 「RL 環境」正在被當成資產，而唔係訓練副產品。小米開源環境代碼但留住 7,000+ 任務數據集，係一次教科書式嘅分層開源。呢個意味住：未來評估一個 lab，唔止睇它嘅模型分數，更要睇它嘅環境工程能力——因為環境決定咗 RL 訊號嘅質量，而訊號質量決定後訓練能走多遠。
  2. 後訓練成本已低到足以改寫競爭結構。$2.6M 呢個量級，意味著「用 RL 把一個開源基座推到前沿附近」已經係一個中型團隊可以承擔嘅動作。呢個係對閉源前沿最實在嘅壓力——唔需要復現預訓練，只需要復現後訓練。
  3. 「更少 token per task」被寫成優化目標，係一個分水嶺。當 RL 同時優化正確率同路徑長度，成本曲線就會自己向下走。呢個比任何定價公告都更能解釋「為何開源模型嘅性價比突然變得難以拒絕」。
  4. 異常透明係一種競爭策略，唔止係姿態。直播 final RL runs、一週內出技術報告——呢種透明度會拉高整個生態嘅期待基準，令其他 lab 嘅「三個月後才發報告」顯得落後。呢個係用「速度 + 透明」搶敘事主導權。
  5. 對「六小虎」框架嘅一次證偽。一個手機廠跨界做到開源第一，說明人才流動（羅福莉由 DeepSeek 到小米）比機構標籤更能預測結果。呢個對追蹤中國 AI 格局嘅人有直接含義：名單會過時，人唔會。

爭議點 / 需留意之處
  • 本條係 newsletter 聚合，唔係一手訪談。小米嘅訓練細節、7,000 個環境、130 小時 / 75B tokens / $2.6M 等數字，來自公司公告與社群引述，未經第三方復現。
  • Artificial Analysis 嘅排名係單一分數體系。「46 分開源第一」係一個 index 嘅結果；同週 Grok 4.7 在 AA 與 Vals 兩個體系上給出相反方向嘅結論，正好說明分數體系之間唔可互換。
  • 「$2.6M 完成 RL」需要定義邊界。呢個數字大概率只覆蓋最終階段嘅 RL run，唔包括預訓練、消融實驗、失敗嘅 run 同人力成本。當成「由零到前沿只要 $2.6M」係誤讀。
  • 「環境 = 新語料」仍係類比，唔係結論。預訓練語料嘅關鍵性質係「不可再生嘅獨佔」，而環境代碼係可複製嘅。真正嘅稀缺性在於可驗證、抗作弊、多樣嘅任務生成流程，而唔係環境本身。
  • 透明度係選擇性嘅。開源環境代碼但唔開源 7,000+ 任務數據集，意味著外界仍然無法完整復現。呢點值得在「異常透明」嘅敘事下保持清醒。
如果只記一句：呢一期真正嘅頭條唔係「小米做了個 1T 模型」，而係「一個新玩家用 $2.6M 嘅 RL，加上一堆願意公開嘅環境代碼，就買到了一張前沿牌桌嘅座位」。當後訓練嘅成本門檻跌到呢個水平，值得重新問一次：呢一輪嘅護城河，究竟在模型、在數據，還係在「能不能造出好環境」？
