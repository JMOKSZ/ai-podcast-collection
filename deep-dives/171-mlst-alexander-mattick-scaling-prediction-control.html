「我可以給你一個完美嘅西洋棋世界模型，你都唔會變成 Magnus Carlsen」——MLST × Alexander Mattick：預測 ≠ 控制，同「world model 只係 branding」

📅 2026-09-21 15:02 UTC（09-21 23:02 CST）·🎙 ML Street Talk（Tim Scarfe 等）·👤 Alexander Mattick（Fraunhofer IIS 研究員、UTN 博士生）·🏷 推論 / world model 批判 / constrained RL / 可靠性

呢集係本日最反共識嘅一集。當全世界都在講 world model 係通用智能嘅路線（Cosmos 3、JEPA 系、Dreamer 系），Mattick 用一條控制理論 + 複雜度嘅線，把它歸為重新命名嘅動態模型 + 品牌工程。而佢真正嘅題眼唔係「無用」，係——預測未來同推論出正確行動，係兩件唔同嘅事。呢個命題直接擊中 2026 年最熱嘅敘事地基。

一句話抓住全集：把「推論（inference）」當成貫穿現代 ML 嘅主線——有了模型之後，要拿出一個答案要付多少代價？——再一路推到深度學習理論、constrained RL 與 world model 嘅批判。標題即主張：規模化預測能力，不能產生智能。但佢實際論證嘅係一個更窄、更硬嘅命題：預測能力 ≠ 控制能力。
一、嘉賓係邊個：Yannic Kilcher Discord 上嘅「Zigzag」

主持人稱佢係 Yannic Kilcher Discord 上「最聰明嘅人」（handle：Zigzag）。Alexander Mattick 係 Fraunhofer IIS 研究員、紐倫堡理工大學（UTN）博士生（該校仍在建校階段，佢係最早嘅博士生之一），FAU Erlangen 計算機本科 + AI 碩士。

佢 2022 年曾上過 MLST，協助製作咗 Yann LeCun 與 Randall Balestriero 那集關於「插值（interpolation）/ spline 理論」嘅訪談研究。研究主軸：constrained RL（安全 RL）、branch-and-bound 嘅節點選擇 RL、GFlowNets、energy-based models、diffusion / flow matching。本集係佢四年後嘅獨立專訪——從「協助研究」到「提出反共識主張」嘅角色轉變值得注意。

二、推論史：一部「把採樣成本搬來搬去」嘅歷史

佢開場給咗一條完整嘅技術脈絡，把現代 ML 各家方法串成一條線——呢條線係全集最有教學價值嘅部分：

時代方法付出嘅代價 / 換到嘅嘢
古典正規化參數密度（如高斯）受限於分佈形狀
—拒絕採樣（rejection sampling）高維立刻敗給維度詛咒
—MCMC可以只採樣、唔需知道密度；但極慢、多模態逃逸困難
—Energy-Based Models（EBM）用能量函數學任意密度、訓練唔需計積分；但把最貴嘅採樣搬到推論期反覆執行
—Diffusion引入無限多層 latent，把問題重述成隨機微分方程，換來一個「時間」額外變數；但擺脫 accept/reject 與局部極小
—Flow Matching / CNF化為從初始分佈到目標分佈嘅梯度流／最優傳輸；代價只剩可逆性
「你為無限維付費，換來唔需要採樣。」 —— Alexander Mattick，一句總結整條推論史

呢個框架嘅威力在於：它把 diffusion、flow matching、EBM 睇成同一條權衡曲線上嘅唔同取捨，而唔係三個互不相干嘅發明。佢令「為何 diffusion 贏」有一個機制性答案，而唔係「因為表現好」。

三、EBM 現在唔值得，world model 係 branding

佢最直率嘅兩個結論：

「我認為 energy-based models 唔係真嘅有用，或者至少而家唔再有用。」 —— Alexander Mattick

理由：即使原理上可採樣，算力上幾乎永遠唔划算；而且 EBM 唔提供任何樣本嘅機率（而呢個機率在異常檢測、動態模型展開時修正累積誤差時好有用）。佢亦指出 GFlowNets 冇解決同一個問題：它假設了一種結構，回到接近變分推論嘅假設世界。

然後係全集最出圈嘅一句——

「我認為 world model，還有 JEPA，最終都只係 branding。」 —— Alexander Mattick，被問 Cosmos 3 等「世界模型」係唔係真有新意時

佢嘅論證唔係情緒化嘅：JEPA 之前就有類 JEPA 嘅模型，world model 之前也有 world model；Schmidhuber 那篇 world model 論文，其實就係 model-based RL。佢給出自己唯一覺得可用嘅切分：

  • 資料收集在迴路內 → 叫 model-based RL（要探索）；
  • 資料收集在迴路外 → 叫 world model（唔用探索）。

而「world model」嘅三種常見定義（他都認為模糊）：①感測器／馬達預測模型；②純影像或影片生成模型；③JEPA 式含內部狀態嘅模型（問題係「內部狀態是否真有用」難以驗證，很多只是看起來漂亮、一致、但不可 benchmark）。Dreamer 系列以大規模影片擴散去玩 Minecraft——佢認為這些都被叫 world model，「已經冇合理嘅區分了」。

四、標題論證：預測 ≠ 控制

針對「有了完美世界模型就唔需要 RL，只要在模型裡規劃」嘅論調，佢嘅反駁係全集核心：

「我可以給你一個完美嘅西洋棋世界模型，你都仍然解決唔到佢——你都唔會變成 Magnus Carlsen。因為『預測未來』同『推論出正確行動』之間是有差別嘅。」 —— Alexander Mattick，全集標題論證

佢用大學控制課嘅經驗補刀：NMPC 講到最後大家都想做 NMPC，然後發現模型稍大就即時算唔動、局部極小、加上約束後多數候選軌跡根本不可行，「於是熱情逐漸消退」——佢預測 world model 會走同一條路。

佢嘅診斷係：目前用 world model 做嘅任務，從控制嘅角度睇根本唔難。所以 demo 睇落好，唔證明呢條路線可以處理真正困難嘅控制問題。

五、Constraints（先驗知識）唔係包袱，係現金

反駁「reward is enough」與 The Bitter Lesson，佢嘅一句話好硬：

「資訊可以非常昂貴，事實上我會講大部分資訊都非常昂貴。」 —— Alexander Mattick

完全唔做先驗、乜都從頭學，等於把已經用血汗換嚟嘅資訊丟掉。佢舉 OpenAI Five（Dota 2）嘅獎勵函數附錄為例——一張巨大嘅權重表（一堆隨機數字），其中：

  • 「待在錯誤車道超過一定時間 = 負獎勵」——本就係一條被改寫成 penalty 嘅約束（等同直接寫「唔好待超過 5 秒」）；
  • 「擊殺敵方英雄給負獎勵」——因為殺敵本身已給金錢獎勵；兩者相關會導致模型在中央互殺刷分。

改成約束就同時解決了相關性與重新調參兩個問題。呢個係全集最工程化、最可直接套用嘅一段——可組合性（composability）才係約束建模嘅真正賣點：把約束顯式化之後，新增一項目標唔再需要重新調整整組權重。

六、Constrained RL 嘅硬骨頭

約束式 MDP 嘅目標係「最大化累積回報，同時讓期望累積成本低於閾值」。佢列咗整條方法演化，每一代嘅失敗模式都好具體：

方法問題
CPO（從 TRPO 嘅改進界推導）唔在約束集內時退化為貪婪下降、邊界震盪
投影法（密度空間中問題變成凸）「幻覺約束」問題；求解器愈好反而愈糟
拉格朗日／零對偶間隙震盪
局部近似（CBVPO、FOCOPS）精確但可能把自己弄進不可解嘅子問題；實質係帶約束嘅 MPC
理論事實 Constrained RL 一般唔存在「平穩確定性策略」——呢意味著 Q-learning 呢條路直接失效。而佢亦坦承「要公平比較 constrained vs unconstrained 非常難」，因為設計一個「隱含某約束」嘅獎勵函數本身就極難。

另一個複雜度層面嘅死結：動作約束相對簡單（投影到集合即可），難嘅係狀態約束——因為它需要模型與環境狀態互動；而且有些約束嘅強制本身係 NP-hard（CSP 類）。所以佢認為最終仍需把部分約束外置到生成過程（如擴散式或蒙地卡羅式）。

七、RL 給唔出最壞情況保證——機械人嘅死穴
「你可以有一個在期望上真嘅好嘅控制器，但它有一個極大嘅失敗案例。平均嚟講追蹤得好完美、只出咗一次大錯，同一路小幅漂移，係完全一樣嘅。」 —— Alexander Mattick，為何需要 L∞ 式保證

佢引〈Learning ReLU networks to high uniform accuracy is intractable〉說明：連放置／縮放這些「帽子」以求一致精度，都係 NP-hard、需要指數級數據。因此真實世界需要 robust RL 或 constrained RL + 模仿／先驗資料——「我唔想讓開心手術機械人從零開始探索」。

呢度佢接上咗階層式 RL（HRL）嘅根本問題：下層給唔出上層可依賴嘅保證。控制理論之所以能做，係因為 H∞ 控制器能給出最壞情況（對抗性）保證；抽象好壞嘅唯一標準係「有冇用」——佢舉 fuzzy logic 為失敗嘅抽象（無法對 fuzzy logic 做 inference，而 Bayesian 可以對 Bayesian model 做 inference）。

佢亦點名 Universal Approximation Theorem 常被濫用：人們把它當成「模型夠大就會做對嘅事」嘅不變量，但嗰個唔係定理實際上講嘅嘢。

八、機械人 demo 嘅可靠性陷阱
「如果你去 BMW，講『我這機器人 90% 嘅時間做對嘅事，另外 10% 會做別嘅事』——佢哋會講：唔，我唔會付你這筆錢。」 —— Alexander Mattick，生產環境所需嘅可靠性水平

佢用嘅比喻係全集最易記嘅畫面：

「你會看到這些中國、美國、德國嘅人形機械人總係在做後空翻同衝刺，卻從嚟唔做呢個任務：站起身、走入隔籬房、打開雪櫃、望入去、拿出一盒牛奶、拿畀我。」 —— Alexander Mattick，解釋為何 demo 揀嘅係好表演嘅任務

原因唔係技術落後，係嗰個任務難得多：接觸密集（contact-rich）、難建模、難採數據。佢亦點名 tactile sensing（觸覺感測）仍然未解，長期係瓶頸。最後一句總結咗軟硬體世界嘅差異：「軟件世界可以回滾，實體世界裡『刪掉你部電腦』等於『壓死人』。」 佢要嘅唔係峰值精度，而係每個狀態都存在最低正確機率，咁先可以用粒子濾波之類做多次量測收斂。

九、ML 理論現狀：盲人摸象，同沒有「物理學標準模型」嘅困境

佢把理論分成兩種流派：參數派（spline 區域、ReLU 嘅局部結構，能解釋特定架構）vs 函數空間派（neural tangent kernel、mean field、diffusion 式非參數解釋，能解釋「為何超參數化唔係壞事」——因為十億參數嘅函數比 50 參數更接近真實函數空間）。佢認為長遠睇函數派更有用（唔綁架構：MLP-mixer、gated activation 換掉都仍成立），但預測力仍不足。

佢形容 ML 理論係「盲人摸象」——幾何派（Randall Balestriero）、可計算性派（Keith Duggar 嘅圖靈機問題）、複雜度派、統計物理派（自旋玻璃、重尾）、有效理論派。佢主張判準只有一個：能唔能做預測、能唔能被證偽。佢自曝曾因一個實作 bug 浪費 2–3 個月——「如果連延續既有工作嘅實作 bug 都分唔出，那就說明理論還不到位」。

佢亦批評可解釋性（mechanistic interpretability）唔穩健：transformer circuits 假設路由在權重置換下不變（唔成立）、有些人把它當成大型 MLP-mixer 建模；並舉例「模型算術嘅 cos/sin 曲線」抽出嚟好靚，但「如果這就是它們做算術的方式，那我們絕無可能解釋它怎麼建模一隻鴨子」。

十、行業 insight（我嘅萃取）
  1. 對「世界模型競賽」嘅一盆冷水。Mattick 直接把它歸為重新命名嘅動態模型 + 品牌工程，並指出其成敗取決於「接觸密集任務嘅可靠性」而唔係 demo 表演力。呢個係本週最重要嘅反面觀點——尤其對照同日 Platt 講嘅「Gemini 2.0→2.5 階躍」：能力曲線在上升，但可靠性鴻溝冇同步收窄。
  2. 「可組合性」係約束建模嘅真正賣點。OpenAI Five 嘅分析給咗好工程化嘅理由：把約束顯式化之後，新增一項目標唔再需要重新調整整組權重——呢個對 agent 系統嘅 reward 設計與評測設計直接可用。
  3. 與 Platt 同日互相印證嘅「可靠性鴻溝」。Platt：科學上要防「騙自己」（多假設檢定、隱藏 hold-out）；Mattick：工程上要防「期望上很好但偶爾大錯」（L∞ 保證）。兩者都指出平均值指標正在系統性高估能力。
  4. 預測 ≠ 控制 係一條可遷移嘅判斷。不止機械人：任何「模型夠好就可以少做探索／少做 RL」嘅主張，都要先回答「你點保證最壞情況」。呢個可直接用嚟審視 agent 產品嘅可靠性宣稱。
  5. 理論現狀最誠實嘅表述。「問題唔係冇理論，而係冇一個能像物理標準模型那樣讓大家從同一起點出發、並能做出可被證偽嘅預測。」——呢句同學界「benchmark 爆炸、論文增量」嘅體感一致。
十一、前後脈絡同爭議點

延續 MLST 近期主線。9/11〈How Replication Could Teach Machines What Good Science Looks Like〉（Edward Hughes）與 9/15〈How Physical AI Learns Across Language, Video and Action〉（Ming-Yu Liu）都在談「世界模型／物理 AI」，本集則從控制理論與複雜度嘅角度給出系統性反駁。與 9/8〈AI 2040: Plan A〉（Kokotajlo & Larsen）形成尺度對照：一邊係宏觀治理路線圖，一邊係「你嘅控制器能唔能給出最壞情況保證」。

爭議點 / 需留意之處

  • 「World model 只係 branding」會直接冒犯一大批人。他同時承認「可以做得很遠」（world model 內做 RL、無限 rollout、GRPO 式嘅模擬採樣確實係範式轉移），立場其實係「有用但被高估」，而標題式嘅話容易被讀成「無用」。
  • 「預測不能創造智能」標題過強。他實際論證嘅係「預測唔等於控制」——呢個係關於決策嘅命題，而非關於「智能」嘅完整命題。標題嘅強度大於內文主張。
  • 佢坦承 constrained vs unconstrained RL 無法公平比較（連設計實驗都會偏袒一方），因此「約束更好」在佢那裡仍屬工程直覺＋局部證據，而非定論。
  • 對可解釋性（mechanistic interpretability）嘅整體否定係當前最受歡迎研究方向之一嘅當面挑戰。
  • GBM/LLM 類比有爭議。佢把 GRPO「唔學價值函數、即時做優勢估計」類比為「便宜模擬器裡嘅蒙地卡羅 rollout」——呢個類比在部分 RL 研究者睇來過度簡化。
如果只記一句：一個完美嘅世界模型畀你嘅係「未來會點」；但要落場贏棋，你需要嘅係「而家應該點做」——呢兩件事之間，隔住嘅唔係更多數據，而係控制理論嘅保證。
