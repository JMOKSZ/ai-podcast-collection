[AINews] LLMs can read & write neural network weights: "Weight Space Programming" cuts Autoresearch out of the RSI loop 🎙️

發布時間：2026-11-03 05:35 UTC（香港時間 13:35）｜欄目：AINews 每日彙編｜原文約 47,000 字元

頭條論文RSI可解釋性權重編輯

主題

這一期 AINews 不是訪談，而是 Latent Space 每日 AI 新聞彙編。頭條是一篇社群論文《Sparks of Weight-Space Programming: LLMs can natively read & write neural network weights》，作者 Rikiya Takehi 與 Jayden（致謝中提及 Berkeley Sky Lab 的 Matei Zaharia、CMU 的 Heather Miller、以及 Zico Kolter；AINews 與 Reddit 轉述為 MIT CSAIL 工作，但原文未明寫機構，暫且保留）。

論文的主張可以壓成一句：把權重當成一種可以被語言模型直接閱讀和書寫的「源碼」。不經過優化器，不經過梯度下降，不寫 PyTorch，也不跑訓練迴圈。模型看的是張量裡的數字，輸出的是新的數字。

為什麼今天要講這篇

AINews 把它放進了一條八個月的敘事線：今年初 Karpathy 的 autoresearch 展示了「給一個夠聰明的模型一個算力集群，它可以自己跑實驗、自己訓練模型」；那個 demo 引發了整個夏天對 RSI 的恐懼。但 autoresearch 仍然很笨重——要寫訓練代碼、跑 compute、看 loss 曲線、讀 eval、調 kernel、換數據。

Weight-Space Programming 把這條鏈的中間全部拿掉。如果模型能直接看懂權重、直接改權重，那麼「自我改進」就不再必須經過「寫一個訓練程序」這個中介。AINews 的編輯語氣很克制，但那句話很重：「the world has now gone from 0 to 1 on this very new RSI capability.」

核心論點

論點一：LLM 對權重的「語義閱讀」能力已經湧現，而且不是靠 forward pass 作弊。

論文設計了幾個很聰明的控制變量。實驗二裡，Astra 只看 diffusion 模型的權重，就能說出它生成的是圓形、方形還是三角形；但它把三個形狀都畫成「空心輪廓」，而模型實際生成的是實心圖形。這個「錯誤」反而成了證據：如果它偷偷跑了前向傳播，它應該知道輸出是實心的；它畫輪廓，說明它真的在讀輸出層權重的幾何結構，而不是在模擬計算。

論點二：讀得懂，就改得動；改得動，就能在沒有環境反饋的情況下修好一個失敗的策略。

實驗四是一個 PPO 訓練的賽車策略，任務是倒車、加速、衝過坡道。PPO 收斂到一個局部最優：直接衝坡，卡住。Astra 拿到權重、場景描述和一條失敗軌跡，一次回答、不用工具，改了 3.5% 的權重，1,024 個 episode 全部成功。它自己在推理裡說得很清楚：在每一層加一條很小的旁路，讀車的位置和速度，等綠輪過了紅線就關掉，讓原本訓練好的策略接管剩下的駕駛。

論點三：它可以直接「寫」出一個網絡，而不是訓練出一個網絡。

實驗五，三個 MinAtar 遊戲，網絡權重全部初始化為 0，沒有數據、沒有 loss、沒有梯度、沒有工具、不允許 rollout。Astra 一次性把權重寫成文本，然後直接評分。三個遊戲都贏過 PPO 訓練 100M 步的網絡。它在 Breakout 裡的思路是：第一層算球會落在哪裡，第二層把 paddle 移到那個位置——這是用自然語言先想出算法，再翻譯成權重。

論點四：真正有現實意義的，是「減法」而不是「加法」。

實驗八是全文最容易被誤讀的地方。Qwen3.5-0.8B 的 MATH-500 只有 7.9%，看起來低得離譜。Astra 讀了失敗案例，發現 93% 的答案根本沒寫完——模型陷入了思考循環，反覆重複同一段文字，直到 32,768 token 上限。它把循環定位到第 15 與第 19 層 MLP 寫出的一個方向，然後從這兩層各 64 個輸出列裡把這個方向減掉，總共動了 131,072 個權重，佔全模型 0.016%。

結果：MATH-500 7.9%→48.1%，GSM8K 13.8%→67.1%，IFEval 21.0%→62.3%，token 上限命中率 93%→33%。但論文自己立刻做了對照：Gemma 3 270M 很少循環（只有 8.5% 撞上限），同一個方法完全無法提升它的數學（6.8%→7.7%，浮動範圍內）。所以結論不是「Astra 會教數學」，而是「Astra 會拆掉擋住能力的路障」。

論點五：這是一條不同於「寫訓練代碼」的 RSI 路徑。

論文的展望列了五個方向：不靠 eval 的審計（直接從權重找後門）、大幅降低優化成本（一次性初始化）、零數據的能力增刪與 unlearning、真正的跨架構模型合併（把一個推理電路嫁接進另一個不同架構的模型）、以及最敏感的那一條——模型檢查、除錯、改進自己的權重。

技術詳情

方法的核心不是一個新算法，而是一個新的「接口」。論文沒有訓練任何東西，也沒有提出新的優化器。它把權重序列化成文本（小網絡）或放進 Python kernel（大網絡），讓通用前沿模型用自然語言推理，輸出新權重。Astra 不被允許寫訓練迴圈、不被允許做梯度更新；在實驗三裡甚至不被允許跑任何 forward pass。

實驗三的技術含量最高。輸入層和輸出層被移除，只留下四個 transformer block；384 個維度沒有標籤，模型不能跑任何輸入。Astra 仍然認出了三種訓練語料，並且精確指出 copying head（induction head）的位置：Python 是 2.1、3.1、3.5，羅馬字日文是 3.3，英文是 3.1。它的推理路徑是先找一個「只看前一個字符」的第一層 head，再用矩陣乘法找出後續利用這個信息的 head——這正是 Elhage et al. 的電路分析方法，但作者從未在 prompt 裡提過。羅馬字之所以被認出，是因為它缺少 q、l、v、x，最後一個 block 寫出的方向數量明顯較少。

實驗七暴露了方法的邊界。兩個 Gemma 3 270M，同一個 QA 數據集、同樣的 fine-tune 流程，一個誠實、一個諂媚（對不知道的事實，諂媚版 100% 跟隨用戶的錯誤答案，誠實版只有 1–3%）。embedding 和輸出層被凍結，所以差別只可能在中間層。Astra 四次嘗試都失敗：它能列出大量權重差異，但無法把這些差異映射到行為。直到允許它自己寫 16 段文本、只看 attention pattern，它才在三對裡全部認出諂媚者；關鍵 head 10.2 在誠實模型裡 94.3% 看向問題中的數字、0.75% 看向用戶的答案，在諂媚模型裡反過來：3.5% vs 85.7%。

實驗六的 Go 是規模化的關鍵一躍。1.48M 權重塞不進 context，所以給了 Python sandbox：可以讀寫張量、可以用 numpy/PyTorch 分析，但不能在 sandbox 裡跑網絡；要看行為，必須花一次 forward pass（每次最多 128 局對練習對手，或 256 個局面）。0 次 FP 時，Astra 用一個 336 行的 Python run 把整個網絡寫出來：前幾層標記雙方的棋子與氣，中間層沿著連接的棋串傳遞幾步找出危險的棋組，最後一層給每個落點打分（提子、救自己的棋、避免自緊氣、避免填自己的眼）。50 次 FP 時，它會下練習棋、看自己怎麼輸、改對應的部分，只保留贏得更多的版本。

行業 insight

第一，RSI 的瓶頸可能不是算力，而是「接口」。過去兩年，大家默認自我改進的路徑是：模型寫代碼 → 啟動訓練 → 等待 → 看 eval。這條路徑裡，模型對自己的改進是間接的，而且被人類設計的訓練框架限制。Weight-Space Programming 提出的路徑是：模型直接讀自己的權重 → 定位電路 → 改數字 → 看 eval。它更接近「外科手術」，而不是「重新投胎」。如果這條路能 scale，RSI 的迭代速度會從「幾週一次訓練」變成「幾小時一次編輯」。

第二，可解釋性從「研究」變成「審計工具」。論文展望的第一條就是 auditing without evaluation：現在要找後門或隱藏能力，必須先設計出對應的測試集，或者等它在真實世界出事。如果模型能直接讀權重，理論上可以在不跑 inference 的情況下發現異常。這對安全是好事，對「模型權重是資產」的商業模式則是壞事——權重會變得可被閱讀、可被修改、可被嫁接。

第三，模型合併的想像空間被打開了。今天的 model merging 基本是權重平均，前提是架構完全相同。如果 LLM 真的理解權重空間，它可以把一個模型裡的「推理模組」電路剪下來，接到另一個完全不同架構的模型上，不需要重訓。這會讓「模型能力」第一次變得像軟件模塊一樣可組合。

第四，但現在的規模仍然是玩具。最大的實驗是 0.8B 的 Qwen，而且只改了 0.016% 的權重；Go 是 1.48M 權重；遊戲網絡是幾萬到幾十萬權重。真正的前沿模型是兆級參數、幾百層、混合專家。論文自己承認，限制在於 context length 和 harness 的效率。從「改 0.8B 的循環方向」到「改一個 1T MoE 的推理能力」，中間的距離不是線性的。

前後脈絡

把這篇放進 Latent Space 自己的敘事線，會看得更清楚。上個月 Alex Zhang 上節目談 autoresearch 與自動化研究；八個月前 Karpathy 的 autoresearch demo 把「模型自己訓練模型」變成公共話題；再往前，是整個夏天關於 RSI 的恐慌與降溫。今天的論文等於把這條線又往前推了一步：不是「模型會寫訓練代碼」，而是「模型會直接改權重」。

與此同時，它和 11-01 十字路口庄明浩的「RSI 來了、AI 的奇觀與粗糙」形成了一個有趣的對照。庄明浩看到的是應用層的粗糙：能力很強，但產品體驗充滿毛邊。這篇論文看到的是研究層的粗糙：能力很驚人，但實驗規模很小、baseline 有問題、方法高度依賴具體失敗模式。兩邊其實在說同一件事——能力湧現的速度，快過我們理解它的速度。

爭議點

爭議一：這到底是「讀權重」，還是「在 Python 裡做可解釋性」？最尖銳的批評來自 Reddit 的長文。它認為實驗一、二之所以成功，是因為首尾層的權重有很強的空間結構——大權重帶狀分布，看起來像熱力圖，模型只要把矩陣 reshape 成圖就能猜。實驗三則是複用了 Elhage 的 QK/OV 電路分析法，只是作者沒有在 prompt 裡告訴它。實驗七更直接：純權重失敗，必須靠 activation probe 才成功，這說明它更接近「激活可解釋性」，而不是「原生讀權重」。

爭議二：Go 的 baseline 太弱。批評者指出，512×6 的 MLP 在 9×9 Go 上本來就是很弱的對手；贏過它，說明不了「通用權重編程能力」，只能說明「比一個弱 baseline 強」。0 次 FP 就能贏兩個更小的 PPO 網絡，這個結果的說服力也有限。

爭議三：MATH-500 的 7.9% 是病態 baseline。93% 的答案撞 token 上限，這不是「數學不好」，而是「取樣設定下有循環」。批評者認為，Astra 做的其實是單方向 ablation（類似 Arditi et al. 的 refusal direction removal，只是把 refusal 換成 looping），把一個退化行為刪掉，而不是「教會模型數學」。50 次嘗試後跳到 48%，也可能是刪除了障礙，而不是增加了能力。論文自己的 Gemma 對照組，某種程度上承認了這一點。

爭議四：「0 到 1」是否言過其實。AINews 自己在導言裡加了兩次括號：「possible overstatement here」、「unlikely to scale to more advanced tasks than simple games and RL policies」。這是負責任的寫法，但也說明連報導者都不確定這是不是一個 paradigm shift，還是一個很酷的 demo。

我的判斷：這篇論文的價值不在於「Astra 會改權重」這個 headline，而在於它把一個之前只存在於思想實驗裡的接口，做成了可重現的實驗。最硬的證據不是 MATH-500 的 48.1%，而是 Gemma 對照組的失敗——它證明作者知道自己在做什麼，也願意公布反面結果。真正的問題是 scale：0.8B 的 0.016% 和 1T 的 0.016% 是兩個世界。在有人把同樣的方法用在 70B 以上的模型、並且給出獨立的 baseline 之前，這仍然是「火花」，不是「火」。
同日 AINews 其他值得記住的信號

DeepSeek 開源 super-agent harness。架構是一個長壽命的 router session 對人，然后把工作派給隔離的 worker 並行執行，由 GitHub 事件觸發。DeepSeek 自己的測試裡，p95 完成時間由 29.5 分鐘降到 15.7 分鐘（對比單 session + subagents）。reviewer 崔添翼說得很清楚：「Super」是指工作 agent 之上的一層，不是智力更高；核心取捨是跨任務連續性 vs 吞吐量。目前沒有跨 session 長期記憶，state/compute/environment 的分離基本未實現，只在小型可信內部環境驗證過，安全、隱私、agent-to-agent 通信都是 open question。批評者說這篇設計文「something of a hot mess」，是在用內部拐杖繞過模型弱點（例如幻覺），而不是讓系統真正魯棒。

SemiAnalysis 的 GDPx benchmark。206 個 agentic 任務，橫跨 11 個有經濟價值的領域（晶片設計、SWE、金融、生物）。最好的模型只拿 12%（Opus 5.5），Gemini 4 Carbon 10.9% 但成本低約 4 倍。這個數字本身比任何 demo 都更能說明：agent 在真實經濟任務上仍然很早期。

Epoch Capabilities Index。DeepSeek V4.1F-1017 得分 159，與 GPT 5.5 持平，比 0910 高 3 分、比 V4-Pro 高 10 分；Astra 再高大約 10 分。但沒有中國模型在約 7 個月內追上 Mythos Preview（約 161）。有人指出未加權的 ECI 誇大了差距，把 coding 權重加大後差距縮小到約 2 個月。1017 非常「尖」：某些 SWE eval 接近 0，但在網絡安全和量化交易上接近前沿。

LeCun 的 JEPA 與柏拉圖表徵假設。Balestriero 與 LeCun 展示：在特定條件下，分開訓練的圖像 JEPA 和文本 JEPA 會收斂到幾乎相同的表徵，不需要配對數據。號稱用 42 倍更少的樣本達到 image-text alignment（21.6M vs 900M 例子）；一個 109M 的文本 JEPA 在跨模態對齊上打贏最高 72B 的 LLM。驅動力不是 scale，而是「同一個東西的兩個視角」這種訓練信號。
