From Restoring Sight to Reimagining the Brain, with Max Hodak 🎙️（2026-08-20 10:00 UTC · 完整访谈）

🔗 https://www.youtube.com/watch?v=7HXqMepjvy8 ｜ 章节完整版，Sarah Guo 单采

主题：Science Corporation 联合创始人兼 CEO Max Hodak 谈「治愈失明」的 PRIMA 视网膜植入物、脑机接口（BCI）的未来，以及把大脑当作计算系统来重新思考医学与人类体验。

嘉宾背景：Max Hodak 是 Neuralink 联合创始人（后离开），2021 年创办 Science Corporation（下称 Science Corp）。公司主打「修复 → 替换 → 升级」人体部件三部曲路线，PRIMA 是其旗舰产品——一种植入视网膜下方的微型光伏芯片，把光线转化为电信号刺激神经，为失明患者恢复功能性视力。Hodak 是硅谷「生物硬件工程化」路线的代表人物，与马斯克的 Neuralink 路线同源但更聚焦眼科落地。

核心论点：

  • PRIMA 是「眼睛的耳蜗植入物」：Hodak 反复用这个类比解释 PRIMA——像人工耳蜗绕过受损毛细胞直接刺激听神经一样，PRIMA 绕过受损光感受器直接刺激视网膜神经节，本质是把视觉信号「数字化注入」神经系统。
  • 把大脑当作计算系统：Hodak 主张，神经科学最大的认知跃迁是接受「大脑是可计算、可接口、可替换部件的系统」，而不是黑箱。治疗失明只是第一步，同一个框架可扩展到其他感觉与认知功能。
  • 医学的终极目标是降低「人类状态的脆弱性」：Science Corp 的长期愿景是 repair（修复）、replace（替换）、ultimately upgrade（最终升级）人体部件——从治疗性恢复走向增强。
  • AI 是理解智力的新透镜：Hodak 指出 AI 模型与生物大脑之间存在惊人的结构平行（章节 22:10「Fertile Ways to Study Neuroscience」），研究 AI 反而能反过来帮我们理解意识与智能的本质。

关键数据/事实：

  • PRIMA 芯片尺寸极小，植入视网膜下方（subretinal），患者多为因视网膜疾病（如干性黄斑变性 AMD、视网膜色素变性 RP）而失明的人群——全球此类患者规模以千万计。
  • 访谈明确讨论「Scope of Timeline and Engineer Cost」（06:32 章节）：这类设备的开发周期与工程成本结构是硬件+临床双轨制。
  • 临床试验流程章节（09:10）讨论了诊所试验的具体路径与监管节奏；09:45 章节谈临床医生对 PRIMA 的反馈——「The Response from Clinicians」。
  • BCI 投资版图（19:50 章节）：Hodak 点评当前脑机接口投资方向，认为真正肥沃的科研切入点（22:10）是理解大脑-感官关系（14:59 章节）而非盲目堆接口。
  • 「Human Preservation vs. Adaptation」（29:06）：Science Corp 的目标定位在「保有人类体验」还是「推动人类适应新硬件」——Hodak 的答案是前者优先：先修复，再谈升级。

重点引用：

「You can think of it like a cochlear implant for the eye.」——Max Hodak 描述 PRIMA 的工作原理（该句同时被官方做成独立 Short 传播）
「Why treating the brain as a computational system could unlock new approaches to medicine.」——节目导语对 Hodak 核心主张的概括

技术详情：PRIMA 属于「光伏视网膜假体」路线：患者佩戴一副特制眼镜，眼镜把视频流编码成近红外光脉冲，植入的芯片接收光能并就地转化为电刺激信号驱动视网膜双极细胞/神经节细胞，患者「看到」的是由眼镜摄像头捕捉、芯片转译的视觉世界。相比传统电极阵列假体（如 Argus II），PRIMA 无需穿颅线缆、完全无线、分辨率更高，是第二代视网膜假体的代表。Hodak 在访谈中把这一「外设眼镜 + 体内芯片」的架构与 BCI 通用架构类比——输入输出分离、体内最小化、体外算力最大化。

行业 insight：

  • 「脑机接口」叙事正从马斯克式的高调侵入式（Neuralink 全植入）转向 Hodak 式「低创伤 + 明确临床终点 + 先眼科后大脑」的务实路线。PRIMA 若走通，将是 BCI 领域第一个大规模商业化的「感觉恢复」产品，给整个赛道提供估值锚点。
  • Hodak 把 AI 与神经科学绑定的视角（AI 模型 ≈ 大脑的计算类比）正在硅谷成为主流研究范式——用模型训练/可解释性工具反推神经机制，BioHub/ESMFold 类「AI for Science」与神经接口是同一波「计算生物学」浪潮的两条支流。
  • 「修复人体部件」从科幻变为工程路线图：Science Corp 的叙事（修复→替换→升级）与长寿科技、细胞疗法形成「人体 2.0」赛道共识，是除纯 AI 之外硅谷资本第二热点的候选。

前後脈絡：No Priors 上一期（8/13）是 Chess.com CEO Erik Allebest 谈社区与 AGI 文化问题，本期从「数字世界」切换到「生物硬件」，延续该节目「AI 之外的技术纵深」选题风格。Hodak 的观点与 8/19 张小珺#151 中 17 岁 ICML 少年「希望 AI 慢一点」形成有趣对照：技术乐观派（Hodak：升级人体）vs 缓冲派（Jonathan：给人类缓冲时间）。另外，Sarah Guo 在 7 月 Valar Atomics 核能集（8/15 上线）中已铺垫「硬科技执行主义」主题，本期是同一框架在生物医疗的延续。

爭議點：

  • 「升级人体」的伦理边界：恢复视力几乎没有反对者，但 Hodak 明确把「upgrade（升级）」纳入长期愿景，直接踩中增强（enhancement）vs 治疗（therapy）的伦理红线——谁有资格升级？公平性如何？
  • 「大脑是计算系统」是强还原论立场，意识研究者（如 Integrated Information Theory 阵营）会质疑：刺激视网膜 ≠ 理解主观体验，功能恢复 ≠ 意识可计算。
  • BCI 投资（19:50 章节）泡沫质疑：Hodak 自己在访谈中都在挑选「肥沃」方向，暗示该领域多数项目并不肥沃。

The /wayfinder Skill: Navigating the "Fog of War" of Planning 🎙️（2026-08-20 20:59 UTC · 新系列首发访谈）

🔗 https://www.latent.space/p/wayfinder-skill ｜ Latent Space 新「Skills」系列第一期，Richard MacManus 采 Matt Pocock

主题：Matt Pocock 发布新 Skill「/wayfinder」，解决 Agent 编程中「项目终点不明确」的规划难题——官方定义：帮你在「战争迷雾」（fog of war）里找路。

嘉宾背景：Matt Pocock，TypeScript 教育顶流。「AI Skills for Real Engineers」项目在 GitHub 上有 220,000+ stars（github.com/mattpocock/skills），YouTube 频道 34.7 万订阅者。他是「Skills 化 AI 工程」运动的核心人物之一，主张把可复用的 Agent 工作流沉淀成标准化的 SKILL.md 文件。

核心论点：

  • Skill 的本质是上下文管理：「whenever you're thinking about context management — because that's really what a skill is, you're managing the context of the agent you're working in — you need to think about the information flow.」Pocock 把 Skill 从「提示词模板」重新定义为「信息流设计」。
  • 核心抽象：map（地图）+ ticket（工单）+ session（会话）：被管理的子会话（child session）只需要两样东西——全局的「map」（已做决策的汇总）和专属的「ticket」（具体任务）。这两个词的精确命名是 Skill 生效的关键。
  • 「Leading words」理论：术语要统一、精确、有引导性——「如果你把所有东西都叫 ticket，或者在别处用不同说法，Agent 就会困惑、行为就会怪异」。Pocock 正在做一本「AI 编程词典」（AI coding dictionary，尚未发布），用一张可探索的知识图谱定义 agent/harness/model 等全部术语，并已把全部课程和 Skill 统一到这本词典上。
  • 「雾」与「地图」的隐喻：借鉴魔兽争霸 3 的战争迷雾——你只能做眼前能确定的决策，每做一个决策，迷雾就往外推一点，地图就亮一块。wayfinder 用这个隐喻引导 Agent 逐步探索未知。
  • 四种 ticket 类型：grilling ticket（拷问式对齐会话）、prototype ticket（原型验证）、research ticket（研究）、task ticket（人类自己做的、Agent 做不了的事）。
  • 「grill me」vs「wayfinder」的分工：能在单次会话内规划完、只是需要先对齐 → 用 grill me；看不到前路、前方有迷雾 → 用 wayfinder。

关键数据/事实：

  • mattpocock/skills GitHub 仓库 220,000+ stars；YouTube 347,000 订阅者。
  • Pocock 的日常工作流：AFK（Away From Keyboard）agents——晚上排好计划，让 Agent 整夜无人值守跑任务；wayfinder 的目标是让「规划阶段」本身也能被编排，产出更细的 spec 再甩给 AFK agent。
  • 实测案例：用 /wayfinder 重构个人网站（20+ 年内容需要重新组织），在 Claude Code 中运行。
  • Pocock 过去几个月「痴迷于术语」：所有课程重写、所有 Skill 共用同一套术语体系。

重点引用：

「/wayfinder helps you navigate 'the fog of war,' where you have a project but you can't quite decide everything right at the start.」
「Because that's really what a skill is, you're managing the context of the agent you're working in.」
「Between me and the agent, there is a communication barrier. And that's what I'm trying to do with my skills all the time, is try to find the right words.」
「Agents are really good at showing you the opportunities for different wording — really good at domain modeling, actually.」

技术详情：wayfinder 的架构是「编排器层」——一个顶层会话（orchestrator）把规划拆成多个子线程（multi-thread），并行做原型、做研究，再汇总结论，人类不再受单会话上下文窗口限制。每个被管理的子会话只拿到 map + ticket 两份文档，避免上下文污染。Pocock 强调「words 先于实现」：先想清楚实体命名（map/ticket/session），Agent 才能清晰映射领域模型——术语体系本身就是 Skill 的接口设计。

行业 insight：

  • Skills 正在成为 Agent 时代的「包管理器」：Latent Space 专门开新系列定期发 Skill，说明生态开始把「可复用 Skill」当作一等公民——与 James 的「CLASS-LEVEL skills、泛化而非新建」策略完全同频。
  • 编排器模式是 Agent 复杂度的答案：Pocock 的「会话管理会话」（grilling session managing other grilling sessions）与 OpenClaw/sessions_spawn 的子代理模型、与 James 四舰队的「指挥官-执行者」分层是同一设计语言。
  • 术语统一 = 人机协作的通用语言：「ubiquitous language between me and the agent」——这是 DDD（领域驱动设计）思想在 Agent 工程的重现，预示「Agent 提示工程」正在向「Agent 领域建模」升级。

前後脈絡：这是 Latent Space 新「Skills 系列」第一期，此前该播客刚在 8/18-19 连续报道 Stripe 收购 OpenRouter、Glean 的模型路由，本周是「Agent 工具链」主题周。Pocock 的「Skill 即上下文管理」与昨日硅谷101 E249 黄东旭「把经验沉淀为 Skill」的观点直接呼应——中美两边在同一时间点得出同一结论：经验沉淀为 Skill 是 Agent 时代个人/组织效率的核心动作。

爭議點：

  • Skill 的「宗教化」风险：220K stars 的 skills 仓库 + 34.7 万订阅者 + Latent Space 新系列，是否在把「写 SKILL.md」变成新的最佳实践泡沫？Pocock 本人承认术语体系「尚未发布」，生态仍缺标准。
  • 「术语先行」vs「实用主义」：反对者会认为过度纠结命名（map vs ticket vs spec）是玄学，真正决定 Agent 表现的是模型能力和任务复杂度，而非措辞。
  • AFK agents 整夜跑任务的可靠性：无人值守 Agent 出错时的止损机制在访谈中未被讨论。
