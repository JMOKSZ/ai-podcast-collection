Latent Space（主播：swyx + Alessio Fanelli）

The Frontier AEO Tracker: What Astra Chooses（and every other frontier model, and what you can do about it）📊文章＋數據產品（非音頻集）
發布時間：2026-09-07 21:32:37 UTC（北京 9/8 05:32）｜原文鏈接｜互動 Tracker｜方法論文檔

主題：Latent Space 正式發布 Frontier AEO Tracker（aeo.latent.space）——一個公開、可互動、可審計嘅數據產品，系統性測量「邊啲產品會喺 161 個類別中被各大前沿模型推薦」。呢個係佢哋第一個用自家 Astra 模型嚟做答案萃取嘅項目（「our first Astra project」），亦係 swyx 團隊由「媒體」正式踩入「數據產品／商業服務」嘅第一炮。

出品背景（無嘉賓，團隊研究發布）：Latent Space 係 AI engineering 界最權威嘅播客＋newsletter（訪問過 Greg Brockman、Karpathy、George Hotz、Simon Willison 等）。AEO = Agent Engine Optimization：當 AI agent 開始幫人揀工具、揀服務、揀供應商（而唔係人類自己上網搜），「點樣令自己俾模型推薦」就成為新嘅流量戰場——呢個研究就係想將戰場數據化。佢哋明言靈感來自 AmplifyingAI 嘅《What Claude Code Actually Chooses》，並「按自己口味擴展」：6 組 prompt 變體、7 個模型（開咗搜索）、161 個類別——由 coding agents、AI podcasts、AI sandboxes、managed databases、ASR models，到天使投資人、企業支出、薪資軟件呢啲冷門類別都有。

核心論點／發現：

  • 「自肥」偏差極明顯：問模型「邊個 coding agent 好」——Fable／Opus（Anthropic）推薦 Claude Code、Sol／Astra（OpenAI）推薦 Codex、Grok（xAI）推薦 Cursor、Muse（Meta）推薦 Muse Code、SWE-1.7 推薦 Devin。swyx 用一句「I wonder why.」諷刺呢種自我偏好。除咗 coding agent，其他類別都有「軟性偏差」（soft biases），例如 Lovable 出現嘅位置。
  • 但存在「可貴嘅無偏差」：有明顯例子係 GPT 系模型推薦 Claude——佢哋稱之為「a laudable nonbias」，證明唔係所有推薦都被訓練數據污染。
  • 28／161 個類別有「全模型一致嘅首選」：呢啲係已被釘死嘅市場；其餘大量「close contests」類別先係 AEO 嘅真正必爭之地。
  • 代際交替會令推薦榜「翻盤」：佢哋發現同一實驗室由舊模型換代到新模型（Opus→Fable、Sol→Astra），推薦榜首會出現「VERY consequential flips」——即係訓練數據同 RL 優先級嘅改變，會直接改寫產品被推薦嘅命運，並為此整咗獨立對比頁面。
  • 意外發現：Anthropic 似乎在引導模型「搜多啲來源」：Sol 中位搜 9 個來源、Astra 中位 5 個；Opus 中位 11 個、Fable 升到 15 個。而 Astra 整體上「自信／高效」好多——輕微改寫問題再問，Astra 極少改口。佢哋嘅結論好 sharp：選擇隨機性越低，AEO 嘅價值反而越高（因為一旦被選中／排除，就難靠內容營銷撬動）。
  • AEO 實操係真嘅：可驗證 Ora 同 Vercel（is-agentic.com）提倡嘅 AEO 手法——例如 markdown content-negotiation——確實有效；模型讀你內容失敗，會直接降低你被推薦嘅機率。
  • 透明性係賣點：因為怕「contamination」質疑（模型訓練見過啲產品），佢哋公開所有 prompt／answer 對，全部可逐條檢查，仲整咗「model choices flip」報告同一個 family-feud 式小遊戲（aeo.latent.space/play）。
  • 覆蓋盲區＝談判籌碼：Gemini／Antigravity（Google）、GLM／Zcode（智譜）、DeepSeek／DeepCode 因為 API 錯誤同 rate limit 未能納入首版——文章直接公開「請呢啲公司聯絡我哋提高限額」，側面證明「邊個入榜」本身就係生意。

關鍵數據／事實：

  • 規模：6 prompt 變體 × 7 個模型（開搜索）× 161 個產品類別；答案萃取由 Astra 完成。
  • 計分：自研專有 AEO score——首選、備選、被提及都計正分；輕度／強烈「反推薦」計負權重（反推薦好少見，但會發生）。
  • 一致性格局：28／161 個類別存在「所有受測模型一致嘅第一選擇」。
  • 來源數中位數（關鍵對比）：Sol 9 → Astra 5；Opus 11 → Fable 15。即 OpenAI 新一代搜少咗、Anthropic 新一代搜多咗。
  • Astra 行為特徵：輕 paraphrase 問題後「FAR less likely to change its mind」——穩定性／固執度明顯高過舊代。
  • 成本量級：文章透露成個 pipeline「a few billion tokens」嘅 prototyping／aligning／scaling。
  • 額外輸出：top cited sources（邊啲來源最影響 agent 推薦）＋ top failures 分析＋ Opus→Fable、Sol→Astra 兩份代際對比報告。
  • 商業化信號：Latent Space 公開話「我哋而家有 business manager 喇」，開放 business enquiries（business@latent.space）——數據產品變現起步。

重點引用：

"Fable/Opus like Claude Code and Sol/Astra like Codex and Grok loves Cursor and Muse loves Muse Code and SWE-1.7 loves Devin and so on. I wonder why."
"Astra seems to be just generally a lot more 'confident', or 'efficient', depending how you look at it — Astra is FAR less likely to change its mind when you lightly paraphrase your question. This makes the value of AEO itself rise as choice randomness declines."
"Anthropic seems to be biasing their models to searching more sources (Sol median of 9 sources, vs Astra median of 5, vs Opus median of 11 sources, vs Fable of 15)."
"There are notable examples of GPT models recommending Claude, a laudable nonbias."
"What we CAN validate is that AEO practices measured by Ora and Vercel, like markdown content-negotiation, are real and failures discourage models from reading your content."

技術詳情：方法論係 AmplifyingAI「Claude Code picks」嘅延伸：每個模型都開搜索（search on），喺 161 個類別各跑 6 組 prompt 變體；答案萃取用自家 Astra（即 GPT-6 時代嘅自動化 AI Engineer，9/3 Latent Space 曾深度報道「<$6/hr 可僱用」）；計分用專有 AEO score（首選／備選／提及 正權重＋反推薦 負權重）；另抽取出「影響 agent 推薦嘅 top 來源」並做 failures 分析。佢哋亦坦承局限：來源分析「只代表我哋由 attempted toolcalls 度 scrap 到嘅嘢，唔係 pretrain dataset」，樣本量細。

行業 insight：

  • AEO 就係下一個 SEO：當採購決策開始由 agent 代行（揀 coding agent、揀數據庫、揀 SaaS），「被模型首推」就係新嘅增長入口。對創業公司嚟講，官網要寫到 agent 讀得明（markdown、結構化、content-negotiation），先有資格上推薦榜。
  • 模型「自肥」＝生態護城河嘅新形態：Anthropic／OpenAI／xAI／Meta 各自嘅模型推薦返自己生態產品，呢種「推薦層壟斷」會比應用層壟斷更難打破——用戶用邊個模型，就等於被餵邊個生態嘅答案。
  • 實驗室可以靠訓練偏好「操控」推薦格局：Anthropic 引導模型搜更多來源（Fable 15 個），直接影響邊啲內容有曝光；呢啲都係訓練／RL 層面嘅決定，唔係市場自然競爭。
  • 對中國廠商嘅含義：GLM（Zcode）同 DeepSeek（DeepCode）被 rate limit 擋喺榜外——呢類「AI 界嘅 Gartner 魔力象限」而家由美國媒體＋美國模型把持，榜單冇中國模型，唔代表中國產品唔得，只代表未入場。
  • 媒體→數據產品→顧問嘅變現路徑：Latent Space 由免費 podcast 起步，而家有 tracker、有 business manager、開放商業合作——AI 媒體嘅終局可能係「行業數據基準＋選型顧問」，呢條路對垂直媒體／研究機構有示範作用。

爭議點：

  • Contamination 質疑：榜上好多熟悉名字——模型係咪只係重複訓練數據見過嘅產品？佢哋話已自查、全部 prompt／answer 對公開可查，但「自查」本身仍然係 self-reported。
  • 「自肥」算唔算 bias 定係功能：模型推薦自家產品，究竟係「真係好」定「訓練數據灌輸」？文章用諷刺語氣帶過，冇正面拆解——呢個問題直接影響 AEO 嘅可信度。
  • 榜單即權力：邊個入榜、邊個被 rate limit 排除（Google、GLM、DeepSeek），都會影響市場敘事；一個由美國模型自評嘅榜單，本身可能帶系統性偏差。
  • AEO 會唔會變成新一輪內容軍備競賽：全世界開始為 agent 寫「佢哋鍾意睇」嘅內容——即係內容進一步為機器優化，AI 味更重，最終可能令模型嘅推薦訊號更加同質化。
