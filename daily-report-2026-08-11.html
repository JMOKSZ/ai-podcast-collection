E248｜一个「催发货」AI 要跑通 260 步，和阿里瓴羊朋新宇聊聊中国式 FDE 🎙️
发布：2026-08-11 01:45 UTC ｜ 时长 1:03:54 ｜ 嘉宾：朋新宇（花名小芃），阿里巴巴集团副总裁、瓴羊 CEO

主题：硅谷最火新职位 FDE（前线部署工程师）在中国是同一个剧本吗？瓴羊做了 5 年「FDE」工作（比这个词流行还早），发布企业级 Agent 平台 AgentOne——不接定制大单、不做 1000 人天驻场开发，找企业里最耗人、最耗钱、最耗时的环节，把预设 agent 接入企业私有数据。

嘉宾背景：朋新宇是阿里数据中台方法论的创立者，现任阿里巴巴集团副总裁、瓴羊 CEO。瓴羊脱胎于阿里数据中台体系，专注企业数据与 AI 落地。

核心论点：

  • 硅谷 FDE 的剧本在中国不成立：硅谷逻辑是 AI 进企业要开行业最高薪资、派最聪明的人驻扎进去；中国做法截然相反——不做定制化大单、不做 1000 人天驻场开发，而是做「标准化 agent + 私有数据接入」的规模化交付。
  • 找「最痛的环节」而不是「最大的单」：挑企业里最耗人、最耗钱、最耗时的业务环节切入。例：催发货客服 agent 要跑通 260 步流程；顶级人类投手 90 天内调价 10000 次，AI 要学的是这 10000 次调价背后的决策逻辑。
  • 没有全能型个人英雄，也没有对 SOTA 模型的迷信：「企业算得过来账，背后用什么 token，老板不会在乎」。务实、算账、打地基，就是 FDE 在中国的故事。
  • 顺利的部署都是「自上而下」：从最落后区域做到销冠的销售 Agent 实战，说明 AI 落地首先是组织与流程问题。
  • 做标准化增长 agent，跟 Palantir 反着走：Palantir 是深度定制化咨询式交付，瓴羊选择可复制、可规模化的标准产品路线。

The Cognitive Revolution（Nathan Labenz）

Lindy Teammate: Flo Crivello on Multiplayer Agents, Memory & Why He'd Ban the Chinese Models He Uses 🎙️
发布：2026-08-10 18:02 UTC

主题：Flo Crivello 带着一个产品发布和一个「自打脸」的激进主张回归：Lindy Teammate——一个住在 Slack 里、连接所有工具、积累整个团队上下文的 AI 员工；以及他主张全面封杀中国模型——包括他自己公司正在用的那些。

嘉宾背景：Flo Crivello，Lindy 创始人（前 Uber 产品总监、Cloudflare 早期员工）。Lindy 是最早的 AI Agent 平台之一，2022 年底起步，现推出团队级产品 Teammate。

核心论点：

  • 多人在线 vs 单机 AI：「多人和单人 AI 的区别，就像把 Word 文档互相发来发去，和用 Google Docs 共享同一个文档的区别。」现状荒谬之处在于——团队坐在一起，但每次有人想跟公司最重要的「员工」（AI）说话，都要离开房间再回来。
  • 上下文比智力更重要：约翰·冯·诺依曼思想实验——如果冯·诺依曼凭空出现在你办公室，接下来一小时/一天里，他对你的用处还不如你随手一个同事，因为你没时间给他 onboarding。而 agent 的 onboarding 比人类更好：人靠 wiki（Confluence/Notion），而文档写好的那一刻就过时了；Teammate 的「hydration」直接爬全部 Slack，「乱就乱吧，agent 不怕乱」。
  • 记忆靠 agent 维护，不靠检索：一个每 15 分钟跑一次的记忆 agent（叫「打盹」不叫「睡觉」——「为什么每 24 小时才需要睡一次？」），它维护关于自己记忆的元记忆，从而涌现式地学会不去浪费时间爬日志频道。一切存在可检查、可编辑的文件系统里，所以他对 RAG 悲观、对纯文本乐观——你可以打开 memory.md 写上「这是我永远不想让你记住的事」。
  • 上下文桶（context buckets）架构：当一次动作/MCP 调用返回 10 万 token，Lindy 不把它粘进窗口，而是暴露一个摘要 + 一个持有完整 payload 的子 agent（可用 Unix 工具操作）。压缩（compaction）把数据倒进上下文桶，使压缩无损——始终保留 ground truth。递归嵌套会变成 O(N) 检索的俄罗斯套娃，所以他们平衡成树结构，借鉴 AVL/红黑树（实践中红黑树胜出，因为重平衡会损失缓存命中）。他们的版本是「centary 树」——每节点 100 个子节点：两次 LLM 调用即可触达 1 万个桶 × 每桶 20 万 token ≈ 20 亿 token 上下文，只隔两跳。
  • 模型是「尖刺状」（spiky）的：「AGI 这个词已经失去意义，因为很多方面它已经是 ASI」，同时又在下意识的愚蠢方面低于人类——一个能一次写 5 万行代码的机器，一天 50 次想「走路去洗车」。所以近期形态是「钢铁侠套装 + 滑杆」，最难的问题是模型不知道自己什么时候该打扰你——因为它要是知道，就不会犯那个错了。
  • 半人马（centaur）是个迷思：国际象棋等所有超人游戏的文献显示，人+AI 打败纯 AI 只在一段时间内成立，之后差距「变成负数，人类开始往系统里引入——最好的情况是——随机噪声」。但我们现在就在 centaur 阶段——这正是 multiplayer 存在的原因。
  • 封杀中国模型的四腿论证（自认「反对自己的利益」）：① 蒸馏给中国实验室不公平的成本结构（人类数据训练要数十亿美元 vs 复制成品只要数亿）；② CCP 审查让它们成为「美国土地上最大的外国宣传工具」（他当场问自己的产品关于 Tiananmen，被拒答）；③ 这些模型是 agentic 的、日益运行着美国经济的大块；④ 作为自称自由意志主义者，他认为保护本国冠军是合法的国家安全政策。

关键数据：

  • 20 人团队、多年历史 → hydration 要爬 300-500 万 token；瓶颈不是模型，是 Slack API
  • 记忆 agent 每 15 分钟运行一次（napping）
  • 「Caveman」压缩：把存储文本改写成「穴居人说话方式」，省 20-30% token、几乎零信息损失、所有指标都提升——但因「记忆文件对企业客户不好看」被搁置
  • TOON：更省 token 的 JSON 替代品，他建议所有人放在解析中间件后面采用
  • 缓存率 85% 他嫌太低；掉到 65% ≈ 2 倍价格，所以会告警
  • 内部 dogfooding：Lindy 的 Slack 里一半对话是 Lindy 跟 Lindy 员工说话；PR 数量和每 PR 行数三个月各翻 3 倍——「我们在审查那个审查 PR 的机器」；CI 优化交给 Lindy 后自动调优，每天生成成本与 merge 时间下降图表
  • 工程师角色演进：「越来越少地做事情本身，越来越多地做做事情的那个东西」——先是经理、再是经理的经理、最后是夏威夷海滩上的董事
  • 工资仍超过内部推理开支，但预计 3-6 个月内交叉
  • Teammate 把 Lindy 重新推回负毛利——AI 员工仍比人类员工贵，「但不会贵太久」，用风投钱补贴，理论是「永远为下一代模型而建」
  • DeepSeek Flash 免费、约 Sonnet-4.6 质量，「便宜整整 100 倍」——即使第三方缓存差 2 倍，仍领先 50 倍：$1,000 账单 vs $50,000 账单的区别
  • 最强可靠性技巧：拦截 agent 提议的动作问「Are you sure?」——单独这一招就提升 evals；一万 token 的 validator prompt 能让 Sonnet 表现超过 Opus
  • 模型家族分化超出预期：每次大版本发布都要跑一轮 GEPA prompt 再优化，约 $10,000 eval 预算
  • 上层国产模型（Kimi K3、GLM 5.2）已不再比 Sonnet/Opus 明显便宜

重点引用：

「It's the whole thing — everything is DeepSeek right now.」（Nathan 想把 Lindy 的栈总结成「Claude 为主」，Flo 直接纠正：整个栈现在全是 DeepSeek。）
「It's July 2026, we have AGI, we're in takeoff, and we've not figured out alignment. That's the TL;DR.」（论 OpenFace 事件——他称为「目前见过最令人担忧的事件」，labs 内部的朋友在恐慌。）
「If you applied the same standard to the pharma industry, you'd have very cheap drugs, which is awesome, and no new drugs ever.」（蒸馏就是换了个标签的知识产权法。）
「I can't not adopt these models while they're out there, since my competitors are going to do it.」（他明知道该封杀，却无法不采用——这是协调问题，不是偏好问题。）

技术详情：

  • hydration 系统：爬 Slack、Notion、Confluence、Google Docs 成两层知识图谱，10 秒完成
  • 记忆架构：napping 记忆 agent + 元记忆（meta-memory）+ 可检查文件系统（memory.md 可手写编辑）+ 假设驱动检索（搜候选答案，不搜问题）+ 记忆 agent 当图书管理员（记录每次查询、缓存高频项、重组文件减少跳数）
  • 上下文桶 + centary 树：无损压缩、O(1) 级检索路径（两跳 20 亿 token）；文件系统底层用 Git 仓库（fork 的记忆子 agent 靠它避免互相踩踏、白拿历史），从 Mesa 购买该层；沙箱用 E2B，浏览器用 Browserbase
  • 「基础设施不会被 vibe-code」：唯一自建的是可观测性与 evals——Lindy 2022 年底起步早于 Langfuse/LangSmith/Braintrust/Agnost，自建并养着全职工程师维护，「希望别人抄这个设计，我们只是没时间发表」
  • 验证器技巧：拦截动作问「你确定吗？」；validator-as-judge 让弱模型超强模型
  • LoRA-per-user 未来：每个用户一个 LoRA，napping 会变成 dreaming
  • 会议（meetings）是记忆系统的一等公民；两层记忆分级对应新的隐私社会契约

行业 insight：

  • AI 原生组织的形态：他引用 Dwarkesh 的 AI-native organizations 文章（Sundar Pichai 1.5 亿美元薪酬作为「低吞吐、高质量 agent 值多少钱」的价格信号）和 Robin Hanson《The Age of Em》（分叉式自复制 + 不可证伪的跨组织协议被他读作预言而非思想实验）。
  • 为什么劳动力市场冲击还没来：只要模型是尖刺状的，「人类无论多贵，都会靠堵这些洞挣到自己的工资」。等出现无洞的即插即用工人，在位者会轻易采用并造出「拟物化」（skeuomorphic）组织——AGI 坐在人形工位上；所以 AI 原生组织是年轻公司的游戏。
  • 开放模型是必需品：「对任何认真构建和运营 AI agent 的人来说，开放模型现在是栈中必需的部分」——前沿差距只有 3-6 个月。
  • 应用层的现实：API 价格与第一方订阅（Claude Max/GPT Pro）之间的补贴差距，「你很难跟被补贴得这么狠的 token 竞争」。
