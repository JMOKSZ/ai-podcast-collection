The War Against Slop and an Emerging Weapon to Fight it: Formal Verification 🎙️

發布 2026-11-20 21:18 UTC ｜ 深度文章（非訪談）｜ 約 9,200 字

主題：2026 年 AI 圈的年度關鍵詞是「slop」——模型產出的低質代碼與內容。當大量代碼由 AI 生成，「如何避免 slop」成了工程師每天的焦慮。形式驗證（formal verification）用數學證明與邏輯來確認軟件／硬件的正確性，隨着 AI 解數學題的能力暴漲，它正從學術 niche 變成可用的工程工具。文章逐一拆解 Harmonic、Theorem、Axiom Math、&Truth 四家公司的路線。

嘉賓背景：核心受訪者是 Clark Barrett，&Truth 共同創辦人兼共同 CEO，史丹佛計算機科學 Corbel Professor（Research），亦是 cvc5 的共同創造者——當今最流行的 SMT（satisfiability modulo theories）求解器之一。他的工具從實驗室走進 Amazon 生產管線，「cvc5 現在每天在 Amazon 的 production pipeline 被呼叫數十億次」，用於 Kiro（Amazon 的 agentic 開發環境）的規格分析與測試生成。

核心論點
  • 測試 ≠ 驗證，差別在「你怎麼知道做完了」。Barrett 的原話切中要害：測試、打補丁、掃描這些工具「相當好，它們找到大量問題」，但你永遠不確定「是否已找到全部，還是有一個我的工具看不見的問題正潛伏着」。形式驗證給出的是封閉答案，而非抽樣信心。
  • Lean 的角色是「檢查你有沒有犯錯」，不是「證明你聰明」。Barrett：「Lean 做的事，就是檢查你有沒有弄錯。你可以把它想成一個非常精密、專門檢查數學的檢查器。」AI 寫證明、Lean 逐步驗證，因此結論不依賴「AI 是對的」這個前提——Harmonic 官網把這點寫成產品承諾：「Aristotle 內部由 AI 寫證明，Lean 檢查每一步，所以結果永遠不建立在 AI 正確之上。」
  • 形式驗證不只是防守，也是訓練信號。Axiom Math 用形式驗證為數學推理系統提供正確性回饋，證明嘗試反過來改進下一代模型。CEO Carina Hong 今年 6 月對 Latent Space 說得更直接：「形式驗證、verified AI，對我們而言不只是處理或踢掉那些爛東西、幻覺、錯誤。它是要放大才華。它是要通往超智慧。」
  • 「veri-coding」將取代 vibe-coding 的工作流。&Truth 的設想：開發者把驗證機器接上 agent，講清楚規格，agent 在底層與形式工具協作。Barrett 描述使用體驗：「你會看到的幾乎沒什麼不同——除了你的 code 第一次就能跑。」人的時間將從寫 code／審 code，轉移到寫規格與審規格。
  • 安全是最大商業場景。&Truth 的目標之一是掃過全世界所有 C code（開源與閉源），確認記憶體安全；不安全就指出「這段 code 這裏有問題，你必須修」。競爭對手 Theorem 的口號更直白：「Verification is the only defense that holds while adversaries scale.」
關鍵數據
  • cvc5 在 Amazon 生產管線每日被呼叫數十億次（Barrett 自述）。
  • Anthropic 在 36 個小型驗證任務上測得：Opus 5.5 以 50% 解題率達成，較 Opus 5 少用約 40% token；趨勢預期延續，因更多模型「在長時程驗證任務上受訓」。
  • Anthropic 用 Lean 形式化費馬最後定理，專案規模 1,300 萬行。
  • Vals 認為 GPT-6.2 Astra 產出了首個 Smoktunowicz Gap Theorem 的 Lean 證明。
  • &Truth 首個產品 &Atlas：世界開源 code 的地圖，從 C 語言起步。
  • Anthropic 的「code → machine-checked guarantee」示意圖用的是 Rocq（前 Coq），而非 Lean——生態並非只有 Lean 一家。
「如果你在做測試、打補丁、掃描——用盡所有現有工具——它們相當好。它們找到一大堆問題。但你永遠不太確定：我是把它們全找到了，還是有一個正潛伏在那裏、我的工具抓不到？」
Clark Barrett，&Truth 共同 CEO、cvc5 共同創造者
技術詳情

SMT 求解器的定位值得記住：它不負責「想出」證明，而負責在給定邏輯理論下判定公式可滿足性。cvc5 之所以能工業化，是因為它把「規格層」形式化之後，讓工具自動搜索反例或證明。這也是為何 Barrett 說形式驗證與 agent 的關係是「協作」而非「取代」——LLM 負責生成候選證明與規格草稿，求解器負責判定，Lean 負責逐步核對。

成本結構是本輪的關鍵變化：形式驗證過去「token 昂貴」，現在開始變得 token 高效。Anthropic 的 36 任務實驗顯示，同一解題率下 token 消耗下降 40%，意味着單位驗證成本在一年內可能再降一個數量級。若此趨勢成立，形式驗證的經濟門檻將從「關鍵系統專用」下降到「CI 可默認開啟」。

行業 insight
  • 「outcome engineering」正在成形。文章引用 Cognition 開發者關係負責人 Nader Dabit 的推文：當你只告訴 agent 團隊「我要這個」、它們自己蓋完，人類唯一剩下的工作就是檢查交付物是否正確。誰能提供可信、便宜、可規模化的正確性檢查，誰就卡住了 agent 時代的收費站。
  • 四家公司的分化很清楚：&Truth 賣「全世界 code 的驗證地圖」與安全掃描；Harmonic 賣自動定理證明器（Aristotle）；Axiom Math 賣數學推理 + 訓練閉環（AxiomProver + AXLE）；Theorem 賣企業級安全驗證。共同點是都把 Lean 當結算層。
  • 對模型公司的戰略含義：如果驗證層成熟，模型能力差距會被「可驗證性」重新定價——能产出可被機器檢查的輸出的模型，比「看起來很強」的模型更有商業價值。這與本週 IPO 定價邏輯（見下）形成互補：市場買的是可信度，不只是 benchmark 分數。
前後脈絡

Latent Space 6 月專訪 Axiom 時已埋下這條線（Carina Hong 的「scaling brilliance」）。本輪文章是把當時的口號落地成產品地圖。與 Dwarkesh 11-13〈The avalanche that hit math〉互相印證：數學能力外溢到 code 驗證，是 RSI 敘事中最可測量的一條支線——不同於模糊的「AGI 將至」，這裏有 50% 解題率、40% token 降幅、1,300 萬行形式化等硬指標。

行業 insight

這一天把「AI 估值」的問題從抽象變成算術。多頭買的是 RSI 期權——「只有少數公司能走到 RSI，所以持有 ANT 合理」；空頭則指出 6,020 億年營收的要求超過任何一家公司歷史上的收入規模。兩者其實不矛盾：市場定價的是「如果 RSI 成立」的條件期望值，而非當前現金流。真正的觀察點是鎖定期解禁後，當「未來光錐的 10% 折扣」被要求兌現時，誰還在買。

更值得注意的是競爭時序：Google 選擇在 Anthropic 定價前夕發布一款「接近 Opus、三分一成本」的模型，Microsoft 則用「96% 能力、5% 成本」直接對標。前沿智能的價格正在以季度為單位崩塌，而能力差距仍在 1–2 個月內。這意味着 IPO 募到的錢必須轉化為算力與人才護城河，而非價格戰彈藥。

What It Would Actually Take for a Machine to Have Agency — Michael Tomasello 🎙️

發布 2026-11-19 14:19 UTC ｜ 片長 1:06:33 ｜ 官方章節 + 完整自動字幕（3,994 秒，2211 段）

主題：代理性（agency）不是玄學，而是一種組織形式。Tomasello 用控制系統（thermostat、交通燈、掃地機器人）作為最具體的最小模型，逐層推到人類的共享代理性，最後回答一個當下最尖銳的問題：機器要有真正的 agency，還缺什麼？

嘉賓背景：Michael Tomasello，發展心理學家。在德國 Max Planck 演化人類學研究所主持類人猿設施二十年，開創「把兒童與類人猿放進同一個實驗」的比較研究範式；十年前回到母校 Duke。著作《The Evolution of Agency: Behavioral Organization from Lizards to Humans》（MIT Press, 2022）。他自述寫書對象是動物行為學界，「結果 AI 圈把它撿走了」。

核心論點
  • 代理性源於「環境不可預測」。若某行為在演化上至關重要且環境可預測，大自然就把它硬編碼進去——呼吸、吞嚥、性行為。需要「決策者」的唯一理由，是環境不可預測，而最不可預測的東西就是其他代理者：獵物、掠食者，以及同種的競爭者與合作者。
  • 控制系統是代理性的最小完整單元。他的課堂練習：如何讓一個按計時器運作的笨交通燈變聰明？答案只有一個——它必須能感知車輛、必須有目標（例如兩邊車流大致相等）、必須有「根據感知與目標決定如何讓世界符合目標」的決策機制。三件套齊備，才脫離刺激—反應。
  • 反 homunculus：關鍵是組織，不是物質。他借用 20 世紀初生物學的活力論（vitalism）之爭作類比：生命不是因為有某種特殊物質，而是因為同樣的元素以不同方式組織。代理性亦然——「不是奇蹟般的小人、不是神奇的心靈實體，而是行動、感知、認知、目標與欲望之間的組織」。這也是他刻意選用 thermostat 的原因：「你可以觸摸它，它是物理機制。」
  • 四層代理性（只談通往人類的那條線）：
    • 基本控制（爬蟲類）：以現代爬蟲為始祖陸生脊椎動物的模型物種，簡單控制迴路，主要不可預測性來自獵物。
    • 目標導向／執行層（哺乳類）：出現 executive function，能想像尚未發生的狀態。他舉松鼠為例——看似要跳，又爬下去改走另一根樹枝，因為「牠能想像自己失敗」。學習因此變成貝氏式的假設生成與機率更新。
    • 意向性／元認知（大型猿類）：能形成意圖與計劃，並在執行前中止；決策後果延遲時，會主動去尋找更多資訊；面對過難的問題會選擇退出、改做高機率成功的事。他引用 Dennett 的意思：「死去的是我的假設，而不是我自己。」
    • 共享代理性（人類）：不是再上一層，而是另一種版本——共同目標、角色分工、彼此知道對方的角色標準，並有社會性的自我調節（「嘿，你在幹什麼？你這樣會讓我們失敗」）。
  • 「學習」被過度中心化。他對 ML 的核心批評：「所有 AI 模型幾乎只關注學習。學習、學習、學習。但學習之所以存在，只是為了幫助代理者做出適應性決策。學習是一個子過程。」理論上，一個完全不學習的 thermostat 式組織也能運作；現實中生物會保存經驗，但那不改變「決策才是主幹、學習是支線」的層級關係。
  • LLM 是「從終點開始蓋」。語言站在一大堆更基礎的認知能力之上：共同注意、視角切換、指物（pointing）、約定俗成的創造。LLM 直接從人類成就的頂點切入，跳過了這層基礎設施。「理論上可能，我不排除；但語言建立在這些更基礎的能力上，你能跳過它們直接到最後嗎？我不太確定。」
  • LLM 不會創造語言約定。人類不只使用語言，還創造語言——世界上有 6,000 種語言，全部是人造的約定。他實驗室做過「Skype 靜音」實驗：讓孩子透過視訊合作但關掉聲音，孩子會即時發明手勢，並在幾輪內約定化（開始使用同一個手勢、互相修正）。「據我所知，大型語言模型不會創造語言約定。它們沒有圍繞主題的論述。」
  • 視角（perspective）是人類認知最強大的部件之一。同一隻動物可以是「狗」、「動物」、「寵物」——取決於你從哪個角度、對誰說話。這種切換看似理所當然，但其他物種做不到。他進一步指出語法本身是視角性的：英語 cleft construction「It was Fred that broke the window」之所以存在，是因為你以為是別人打破的，我在糾正你；主動／被動則是從狗或從貓的視角敘事。
  • 合作有黑暗面，而說謊只在合作者之間可行。黑猩猩之間不互相說謊，因為「你說真話若不是對你有利，那根本不會發生」在牠們的世界裏不可想像。謊言之所以有效，正因為我們預設他人是合作的、我們是容易上當的。政治人物的操作——「他們說」、「我聽到很多人這樣說」、不斷重複——都是在劫持這套自然系統。
  • 資本不是代理者。被問到市場是否可視為 super-organism，他劃線：「你可以說資本傾向流向某處，但做出流向決定的是資本家。」通脹、股市崩盤、塞車屬於「第三類現象」——沒有人意圖造成，但由眾多意圖行動湧現。政策的作用是看穿個體決策與集體結果之間的連結。

技術／方法細節
  • 方法論：比較生物學的「模型物種」法——我們不知道最早的陸生脊椎動物長什麼樣，但現代爬蟲被生物學界認為與最早爬蟲高度相似，因此可用牠們做實驗。他提醒要小心：模型物種不等於原始物種。
  • 實證差異（兒童 vs 黑猩猩）：合作取得食物後，黑猩猩拿到自己那份就走；人類兒童會等到同伴也拿到才結束。黑猩猩不會糾正沒做好自己角色的同伴；兒童會。這是共享代理性最直接的行為證據。
  • Stag hunt 與約定：合作捕鹿是協調問題——「我只在你去的條件下才去，你也只在我去的條件下才去」。David Lewis《Convention》的論點：約定是協調裝置，語言約定正是人類為了協調活動而創造的。
  • Status functions（Searle）：我們把一個人變成總統、把一張紙變成錢、把一個虛構體變成法人。Harari 所說的「虛構」正是文化最強大的產出——公司是虛構的個體，卻是世界上最有力量的事物之一。
  • 「肉是否要緊？」：他引用 Ned Block 的演講標題（does meat matter?）——沒有激素、沒有神經元、沒有肉身，是否影響代理性？「房間裏沒有共識，我也沒有什麼高見。」
  • 對 AI 集體智能的觀察：現有的「agent 社會」多半只是互相反應，缺少共同承諾（joint commitment）與角色規範。他提到系上的博士後 Shaozhe Cheng 正在用 joint commitment 建模共享代理性（CogSci 2026 論文《The Agency Gap》）。
行業 insight

這場訪談真正的殺傷力不在「AI 威脅論 vs 樂觀論」，而在它給出了一個可操作的替代路線圖：若要做真正 agentic 的系統，就從「協調、視角、指物、約定」這些基礎設施由下往上蓋，而不是在巨量文本上微調出一個會說話的終點。這對當前 agent 架構是直接的批評——多 agent 框架（LangGraph、AutoGen 式）多半在編排「互相反應的專家」，而不是在建立共同承諾與角色規範。

同時要看清他的立場邊界：他不認為 LLM 無用（「我每天都用，是不可思議的工具」），也不否認機器可能有代理性（「如果牠走起來像鴨、叫起來像鴨，那就是鴨」）。他反對的是把語言能力誤認為代理性，以及把圖靈測試當作充分條件。

前後脈絡（與本週其他集對照）
  • vs Paul Christiano（Dwarkesh 11-16，已覆蓋）：Christiano 給出「一年內 10% 接管級風險」的量化判斷，主張暫停預訓練；Tomasello 則說「我從七十年代聽到現在」。兩人分歧的根源是本體論：Christiano 擔心的是能力爬升後的控制失效；Tomasello 認為當前系統根本還沒有代理性所需的組織層級，威脅敘事跳過了中間的所有步驟。有趣的是，兩人對「缺什麼」的診斷有交集——都指向 executive / metacognitive 層與「知道自己在做什麼」。
  • vs Dwarkesh 的 RSI 論文（11-13）：Dwarkesh 論證 ML 研究像「拼貼 + 摘低垂果實」，因此 AI 能接手；Tomasello 的框架正好解釋為何可能——但也指出瓶頸：沒有共享約定與視角的系統，只能在既有文本分佈內拼貼，難以創造新約定。這為「RSI 能否自我加速」提供了一個心理學層面的懷疑理由。

爭議點
  • 「我不怕 AI 接管」——在 2026 年的語境下這是少數派立場，且他自認「技術上不夠懂」，對 AI 內部的機制問題多次明確表示「我沒有足夠技術知識判斷」。這種坦白反而讓論點更難被簡單反駁：他談的是概念層的充分條件，不是能力預測。
  • 「學習是子過程」——直接挑戰 RL 為中心的範式。對當前以 scaling + RL 為主的路線，這是一個本體論級別的批評，而非工程建議。
  • 資本不是 agent——與「市場作為超級有機體」的流行隱喻相反，但限定在「作為分析透鏡可以，作為本體主張則危險」。
