這一集的價值不在「AI 又強了」，而在它把 Jev 爆火的來龍去脈與 「Context 才是真正基礎設施」兩條線擰在一起：嘉賓鴨哥（grapeot）是那種把 AI 用到「臨界點」的重度用戶——代碼讓 AI 寫、自媒體讓 AI 運營，甚至孩子受傷後的就醫判斷、保險理賠、幾千張幼兒園照片都交給 AI。他的核心斷言是一句反直覺的話：當模型智能跨過一道坎之後，決定產出品質的是 context，而不是模型的智能；並用一個控制變量實驗作證——同款模型、同一 skill、同一搜索引擎、同一 agent 後端、同一 prompt，唯一差別是「有沒有注入一年積累的個人判斷框架」，結果一份是正確的 checklist，另一份是有立場的 insight。

中文播客

十字路口 Crossing（主播 Koji 杨远骋）

「有了AI，我感觉自己强得可怕！」｜对谈鸭哥 🎙️

發布：2026-10-11 16:00 UTC ／ 2026-10-12 00:00 北京時間 ｜ 時長 72 分 32 秒（4352s）｜ 節目頁：小宇宙 ｜ 形式：公路播客（烏鎮 → 上海）

主題：一位「重量級 AI 用戶」的自述——當你把工作與生活的關鍵環節都交給 AI 之後，會發生什麼？節目從「Jev 為何此刻爆發」講起，經「雲端電腦開始持久化」的趨勢，落到「Context 才是真正基礎設施」的方法論，再以「0 人自媒體公司」與「AI 時代最獎勵什麼樣的人」收尾。它不是一期工具評測，而是一份關於「如何把自己外化成 AI 可用資產」的一手操作手冊。

嘉賓背景：鴨哥（Yan Wang，GitHub／X 帳號 grapeot），Superlinear Academy 聯合創始人（一個 AI Builder 教育生態，社區規模 2 萬+ 成員、700+ 真實 AI 項目），哥倫比亞大學 PhD，先後任職於微軟、Pinterest、Samsara。自我定位是「AI builder」，關注 agent 基礎設施、AI-native 開發、模型能力邊界。他是 Koji 口中「我認識的人裡把 AI 用得最狠的一位」。節目頁順帶透出他的個人畫像：機械操縱（擁有飛機／機動船舶／挖掘機駕照，自購一架螺旋槳飛機花了 1900 美元）、攝影器材黨、天文攝影（在四川租遠程天文台、自寫自訓全套控制軟體神經網路，拍攝為期數年的 600 億像素全天照片）——一個典型的「動手型極客」，而這正是他 context 系統的底色。

核心論點：

Part 1｜Jev 為何在「此刻」爆發（00:00:58–00:11）

  • Jev 的本質是「GPT + JSON Mode」的極致化，而非又一個聊天模型。它不是生成文本，而是輸入一個 state（狀態數據）+ 一組類型化問題，直接輸出帶校準概率的結構化決策；軟體拿到就能用。這呼應了 Kahneman 的 System 1／System 2 隱喻：TypeSafe 賣的是快、類型化、可直接行動的「系統一」決策層。（名稱與架構說明見下方「技術詳情」。）
  • 爆火的三個條件：節目把 Jev 的走紅歸因於「agent 成本結構 + 開發者痛點 + 時機」三者疊加——當 agent 需要對海量微小步驟逐一分類／路由／打分時，用前沿 LLM 為每一步寫一段文字，帳單會爆炸；而 Jev 正好卡在「決策便宜、行動很貴」的那一層。（「決策便宜、行動很貴」一句亦見於 42 章經 9-27 那期標題，跨節目共振。）
  • Agent 裡的「分類器」其實無所不在。鴨哥觀察：真正運轉起來的 agent，內部充滿了各種判斷節點——工單分流、工具調用是否越權、輸出該不該放行、檢索結果夠不夠——這些過去被埋在 prompt 裡、靠大模型逐字「想」出來的判斷，本質上是分類問題，正是 Jev 這類模型要接管的。

Part 2｜「有了AI，我感觉自己强得可怕！」（00:12:20–00:29）

  • 雲端電腦開始「持久化」是最大趨勢。節目點名 Manus、Grok Bot、Muse 三個產品，指出它們的共同動作是——給 AI 一台永不關機的雲端電腦。AI 從「每次對話重新開始的無狀態工具」變成「有連續文件系統、有背景任務、有長期狀態的數字員工」。
  • 「基模擊穿一整套工業」。當基礎模型能力跨過門檻，它會像水銀瀉地一樣穿透一整個行業的工作流——不是逐個應用被替代，而是一整條產業鏈的環節同時被重估。
  • 「AI 變強，管理原則沒變。」這是鴨哥反覆回到的一條：模型再強，你要交付什麼、怎麼驗收、如何授權與邊界，仍然是管理問題——AI 改變的是執行成本，不是判斷標準。
  • 「無限複製的專家天團」。一個人可以同時指揮多個具備不同專長、且行為可複製的 AI 角色，這是個體能力被放大的關鍵機制。

Part 3｜Context 才是真正的基础设施（00:29:40–00:48）——全集的理論核心

  • 「給 AI 裝上耳朵和眼睛」的一年期實驗。鴨哥持續一年採集自己的客觀行為數據：錄音轉寫、會議記錄、微信對話導出、與 AI 的每一次對話與糾正——「這些是我們在真實決策場景下展現出來的判斷邏輯」。
  • 為什麼不把 Context 搬上雲端？節目明言：系統刻意本地優先——這些數據是私人判斷的載體，本地保存既是隱私考量，也讓 AI 能在同一資料夾內對任何專案做 cross-reference（這是 context density 的基礎）。
  • 微信聊天記錄如何讓 AI 如虎添翼：聊天記錄提供了模型訓練資料裡不存在、卻最能代表「你是誰」的判斷痕跡——你如何權衡、如何取捨、什麼讓你發脾氣。這部分數據他自己也承認「我們太接近它，很難自己提取模式」，所以需要一個旁觀者（AI）來讀。

Part 4｜鴨哥的「0 人公司」：半年做到 5700 粉絲（00:36:15–00:49）

  • 0 人運營一個 AI 自媒體：整條流水線——選題、寫作、排版、發布——由 AI agent 自動完成，人只保留「設定標準與驗收」。
  • 從自動發布到自我改進：系統不只知道「發」，還會基於回饋調整下一次的行為，形成閉環。
  • 「0 人公司」真的賺到錢了嗎？節目直面商業化的追問（章節 00:47:03 專設此問）。

Part 5｜AI 時代最獎勵什麼樣的人？（00:49:22–01:12）

  • 「領域經驗 × 管理 AI」：真正的槓桿不是「會寫 prompt」，而是「在你已有一線領域經驗的基礎上，把 AI 當團隊來管理」。
  • 鴨哥的「老鴨湯」（00:52:28）：他個人沉澱的判斷原則與思維方式（即系統中蒸餾出的「axiom」）。

技術詳情（Context Infrastructure 的實作拆解）：

  • ①大量積累（採集客觀行為，而非只寫 prompt）。起點是數據採集：錄音轉寫（Intake Skill）、會議記錄、微信對話導出（wechat_db_parser）、以及與 AI 的每次對話／糾正，全部落成本地檔案、放在同一資料夾，讓 AI 開箱即可對任何專案做 cross-reference。
  • ②分層提煉（三層蒸餾，以「穩定性」為篩選標準）。單一事件可能只是情境反應（沒睡好、資訊不全、隨機選擇），不可靠；跨場景、跨時間反覆一致的才是「你」。
      · L1 Observer：每日掃描檔案變動，提取有意義的觀察，寫流水帳。
      · L2 Reflector：每週合併重複、清理過期、識別跨專案模式，分離信號與噪聲。
      · L3 Axiom：從穩定模式蒸餾決策原則，只保留真正代表你的東西（→ 44 條 axiom）。
    與 Mem0 等流行記憶系統的關鍵區別：後者蒸餾到「事實層」就停了（「你偏好 TypeScript」「你住在上海」）；本系統繼續蒸到「判斷原則層」（「評估技術方案時你如何權衡可維護性與性能」）。事實告訴 AI 你是誰，判斷原則告訴 AI 你怎麼想。
  • ③按需加載（用 skill 當記憶層級）。全部塞入 context window 不可行（有限，且無關資訊會稀釋信號）。解法是 skill 系統，類比 CPU 記憶體層級：L1 cache = AGENTS.md（根路由表）；L2 = skill 庫索引（告訴 AI 需要什麼資訊往哪找）；L3 = 具體 skill 檔。按需加載、漸進披露。
  • 為何是「AI 從 CPU Bound 走向 Memory Bound」：作者類比——CPU 快到一定程度後，繼續升級 CPU 收益遞減，提升改由記憶體架構驅動；LLM 現在到了同樣的拐點。模型智能會因每次升級而貶值（別人也買得起），但你的 context 不會——所以持續投入 context 的收益是累積的。
  • 相關開源 reference implementation（皆為其公開 repo，非節目內容）：
    • Intake Skill：把已同步到 Mac 的 Apple 語音備忘錄，轉成帶日期的本地資產——正規化音檔、逐字稿 CSV、每日 Markdown／HTML 報告、會議記錄。管線為 Apple Voice Memos → data/YYYYMMDD/ → MLX Qwen3 ASR 轉寫 → Codex 後處理。刻意做得「窄」：不錄音、不做說話人分離／聲紋辨識。
    • Semantic Search Skill：面向 agent 的本地語義搜索 CLI。快取格式 v2——每個快取目錄一個邏輯全局索引，背後是單一 SQLite 元資料庫 + 追加式 float32 NumPy 段檔；支援任意 OpenAI 相容 embedding 端點（可設 fallback），預設模型 text-embedding-3-small；SQLite WAL 提供讀快照隔離，寫入端獨佔鎖。
    • Health Quantification：三層解耦的個人健康量化——iPhone HealthKit →（Tailscale 網內 POST）→ Mac FastAPI:7996 → SQLite（唯一事實來源）→ CLI（JSON）→ AI agent；設備身份、傳輸加密與存取控制交給 Tailscale／tailnet ACL，而非 FastAPI 自實作。
    • Apple Photos Skill / Bright Horizons 照片增量備份：本地優先 CLI，SQLite 記錄事件、附件 ID、檔案雜湊與同步水位；憑證只存本地 .env（建議 chmod 600），明言「不要貼進 AI 會話、issue、log 或 commit」。
    • 觀點蒸餾 Skill（workflow_cognitive_profile_extraction.md）：即上述 L1→L3 蒸餾流程的具體 SKILL 定義。

行業 insight：

  • 「決策層」正在變成一個獨立的產品品類。Jev 的爆發不是因為它更會寫，而是因為它把 agent 裡大量微小、高頻、可類型化的判斷從「用大模型逐字想」剝離出來，做成了便宜、快、可直接消費的結構化輸出。當 agent 走到「每步都要判斷」的規模，成本結構必然催生這一層——這是 Jev 在「此刻」而非一年前走紅的結構性原因。
  • 雲端電腦持久化是 agent 從「工具」變「員工」的分水嶺。Manus／Grok Bot／Muse 的同一動作，本質是把狀態還給 AI：有檔案系統、有背景任務、有跨會話記憶。沒有持久化，就永遠是「每次重新開機的實習生」。
  • Context 是唯一不貶值的資產。這是全集最可遷移的判斷：模型每一次升級都在把「智能」變成公共品（別人也能用），而你的判斷框架、審美、從失敗提煉的教訓只屬於你。因此投入模型（貶值維度）收益遞減，投入 context（不貶值維度）收益累積。
  • 「AI 變強，管理原則沒變」是給從業者的定心丸。執行成本坍塌，但交付標準、驗收、授權邊界仍是人的工作——這也解釋了為何「領域經驗 × 管理 AI」被列為 AI 時代最被獎勵的組合。
  • 自媒體／內容生產是被 agent 化最徹底的場景之一。「0 人公司」半年的訂閱／粉絲數據，是本輪最直接可驗證的「個體產能放大」樣本。

前後脈絡：

  • 與本報告流水線自身的奇妙閉環。本系列報告的「前置過濾」用的正是 TypeSafe Jev（jev.py triage，見 workstation 的 jev-decision-layer skill）——即這期節目 Part 1 討論的那個產品。節目的「決策便宜、行動很貴」，與報告流程「先讓 Jev 廉價篩噪音、再由大模型深寫」是同一套成本哲學。
  • 與 10-10 報告的英文三集形成互文。上一輪 Cognitive Revolution 的 Eric Bigelow 說「推理模型只是在攪一鍋 token 湯再撈答案」——若推理模型本質近似採樣／分類，那 Jev 把「決策」直接做成類型化概率輸出，正是把 Bigelow 的觀察產品化。Latent Space 的「數據質量遠勝數據量」與本篇「決定產出的是 context 而非智能」幾乎是同一句話的兩種說法。
  • 與 42 章經（9-27）「AI Trading——決策便宜，行動很貴」跨節目共振：兩期都在把「決策」與「行動」在 AI 經濟學裡的成本結構上拆開。
  • Jev 敘事的時間線：9-15 上線 → 9 月中下旬候補 14 萬／API 過載 → 10-06 中文財經媒體報導估值十天約 50 倍 → 10-10 Latent Space AINews 提及 >$100M ARR／$7.5B 估值 → 10-11 本集把這條線編成「為何此刻爆發」的敘事。
