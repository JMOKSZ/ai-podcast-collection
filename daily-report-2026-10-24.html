  • 數學長文係今日最有價值嘅一篇。Ankit Maloo 用 Gowers 嘅「最短提示序列」把問題難度寫成 2^k + t，再加一個 branching factor b，得到 b^k 條路徑。呢個框架唔止解釋數學，仲預測到點解資安會第一個倒下（b ≈ 1–2）。
  • 核心不對稱：人類追一個方向要幾個月才知道有冇用，模型五分鐘就知道。所以對模型嚟講，「提示」嘅品質門檻幾乎消失——普通、離譜、未成形嘅想法都可以照試。這是 2026 年能力躍遷的真正機制，唔係單純模型變聰明。
  • Navier–Stokes 證明嘅成本曝光：166 頁、10,000 個 agent、300B tokens、88 小時。而它只是完成 Córdoba 與 Martínez-Zoroa 已鋪好嘅綱領——概念躍遷係人做嘅，收尾係機器做嘅。
  • Cloudflare CTO Dane Knecht：Log4j 級事件由「一年一次」變成「每週一次」；未來 18 個月 >50% 工程時間會花在安全；攻擊者唔再係國家隊，而係「agent kitties」——高中生用 agent 搵漏洞攞 bounty。佢嘅判斷：呢個係一次性補課窗口，唔會永久。
  • 黑色十月嘅硬數字：月度 CVE 由約 4,000 升至約 15,000；eMudhra 一把 CA 密鑰嘅種子竟然係數字 4；Storm-0940 用開源 agentic pentest 框架 ARTEX 打 2,250+ 個 M365 tenant，每分鐘約 2,900 次登入。

No Priors

主持：Sarah Guo、Elad Gil｜嘉賓：Dane Knecht（Cloudflare CTO）

Democratizing Security for the Agentic Web with Cloudflare CTO Dane Knecht 訪談

發布：2026-10-23 10:00 UTC（18:00 HKT）·片長約 52 分鐘·YouTube 6VprwfSc4Xk

主題：當 AI 同時成為「資安末日」嘅成因同解藥，互聯網嘅安全模型、內容經濟、以及公司內部嘅 AI 組織設計要點改。呢集係黑色十月風暴中，第一位基礎設施層營運者嘅現場判斷。

嘉賓背景：Dane Knecht，Cloudflare 技術總監，在公司 15 年，主管新興技術與產品孵化；長期負責 Cloudflare 嘅開發者平台（由單一 serverless 原語長到 100+ 工具）。節目開場 Sarah 拿佢姓氏開玩笑（Knecht ≈ connect），話「呢個姓簡直係 Cloudflare 嘅 value prop」——亦係全集基調：連接與身份，而唔係單純防禦。

核心論點
  • 論點一：頻率變了，唔係嚴重性變了。Knecht 用 Log4j、Shellshock 做標尺：以前呢類「all hands on deck」級別嘅事件大約一年一次，Cloudflare 要動員全公司保護企業客同免費客；「而家呢啲事每週都在發生」。部分甚至無公開——嚴重程度相若，但頻率升了一個數量級。佢預期未來 18 個月，大部分工程團隊嘅時間會花在安全上，某個 keynote 上嘅數字係「超過 50% 工程時間」。呢個係過渡期，唔係新常態：當 AI 掃過大部分代碼、搵到大部分 bug 同 shortcut 之後，資源會回流到產品。
  • 論點二：攻擊者光譜已經扁平化。Sarah 問係國家隊定 script kiddies，Knecht 嘅答案係「兩者都唔係」——最近幾個大型漏洞，帶頭嘅甚至係高中生。佢即場接受 Sarah 嘅新詞「agent kitties」：呢班人以前玩 CTF，現在把 agent 指向一個區域，加上 bounty 有真金白銀，就變成持續運轉嘅漏洞工廠。重點唔係他們變強，而係「國家隊長年擁有嘅工具，第一次交到群眾手上」。
  • 論點三：唔同意「air gap 一切」。Sarah 引述嚴肅技術人嘅講法——「把重要嘅嘢全部 air gap，我哋有一段時間唔可以信互聯網，假設關鍵基建同政府服務某一刻會倒」。Knecht 明確講「我無咁末日」（I'm a little less doomsday）。理由有兩個：人類適應快，行業在危機時會合作（「你平時認為係競爭對手嘅人，唔再係競爭對手」）；以及過去 5–10 年由 castle-and-moat 轉向 zero trust，令好多公司底子比表面好。佢嘅處方唔係斷網，而係收緊每一個 identity 同 flow。
  • 論點四（最反直覺）：AI 目前令軟件更唔安全。當 Sarah 講「減少攻擊面」好合理但唔係今日模型嘅自然傾向，Knecht 直接承認：「AI 至少早期非常 verbose，佢喜歡製造複雜度。」所以 AI 在安全上暫時係淨負貢獻；縮減複雜度仍然要靠人類判斷。「呢個就係人類仍然有位置嘅地方。」
  • 論點五：呢場係補課，唔係永久戰時狀態。「我哋正在 patch 70 年嘅軟件。」存量要補，增量要改流程——agent 開發生命週期要將安全內建到每一步，而唔係最後掃一次。佢唔認為要 freeze 功能：「如果你唔出貨，你就在死亡。」（if you're not shipping you're dying）同時做兩件事，靠 AI 兩邊加速。
  • 論點六：開放權重最終一定贏，因為壞人總有辦法拿到。Sarah 提出安全能力嘅兩難：攻防能力在同一模型內平行存在，所以開放防禦模型等於開放攻擊能力；但只鎖在少數 frontier 封閉模型，就無法分發給需要防禦嘅長尾。Knecht 選開放：「隨著時間，一切都會開放，因為無論如何所有人都會拿到。壞人會找到方法拿到。」封閉只會排除一大批「其實需要它」的人。呢個立場與「安全能力必須集中管理」派正面相反。
  • 論點七：agent 經濟需要新收費軌道，而唔係更努力爬人類 web。他形容現在係「messy middle」：人類同 agent 走同一條軌，agent 去 parse 一個為人類設計嘅 web，係低效。方向係分開交付：同一個內容，向人用廣告，向 agent 用 CPM 等價嘅微支付。Cloudflare 已推出 monetization gateway、agent 錢包、穩定幣結算，以及與 OpenAI 合作嘅 Signals（讓 agent 主動發現新內容，而唔係無限重爬）。佢特別提到 Stripe 嘅 x402 回到 HTTP 402 code，係「終於有人認真做」嘅信號。
  • 論點八：與其頂層設計，不如給人工具 + 資訊 + 高 agency 的人。Cloudflare 5 月重組（公司史上第一次大規模裁員），唔係為了省錢，而係「工廠車間要重畫」。例子：以前 PM 發一封客戶 email 要經 BI 拿 cohort、marketing 設計文案、marketing ops 發送，三個團隊；重組後變成一個工具，PM 描述 cohort、寫草稿、系統用 Cloudflare 語氣改寫、經理一按批准就出。佢嘅講法係「唔係令三個團隊快啲，而係令一個 PM 擁有佢以前無嘅超能力」。
  • 論點九：token 管理靠異常通知，唔靠排名。Cloudflare 無 token leaderboard，亦唔以用量評核；看的是 shipped 同 built。但有自動提示：一日用 $300 會收到 email「你知唔知？」；$500 通知經理；$1,000 通知 VP。Knecht 話大多數人只係唔知道，收到通知反而多謝你。佢亦認為「要人類逐個任務揀模型」係荒謬，應該智能路由：規劃用 frontier、執行用 open-weight、審查與紅隊再回到 frontier。
關鍵數據
  • Log4j 級事件頻率：一年一次 → 每週一次（部分未公開）
  • 未來 18 個月工程時間投入安全：>50%（Cloudflare keynote 數字）
  • 存量債務：70 年嘅軟件要補
  • 紅隊規模：目前 1 隊 → 明年底 4–5 隊
  • 公司規模 5,000 人；一年內招 1,000 個 intern（前一年 200）
  • Token 異常提示門檻：$300/日 → email；$500 → 經理；$1,000 → VP
  • eMudhra CA 密鑰：其中一把嘅種子係數字 4（Knecht 原話「literally the number four」）
  • CDN 普及前全球只有約 3,000 個網站有大規模 CDN；現在數億
  • Cloudflare OS 已在 GTM / G&A 團隊使用，比工程團隊更普及

「AI 至少早期非常 verbose，佢喜歡製造複雜度。所以就我們面對嘅情況而言，AI 其實一直無幫手建更安全嘅嘢。」 Dane Knecht，論 AI 與攻擊面

技術詳情
  • 密鑰熵崩壞嘅具體案例。Knecht 講嘅係一把保護 TLS / WebPKI 嘅根級密鑰，初始種子只用了一個數字 4，於是可被反向工程。佢用 Cloudflare 總部大堂嘅 lava lamp 做對照——隨機性係整個密碼學嘅根基，而人類仍然會用「4」做種子。同一段佢提到 OpenAI 上週找出 2000 年公布嘅 NIST 曲線種子，兩件事並置，意思係：歷史遺留嘅弱隨機性正在被 agent 大規模翻舊帳。
  • Cloudflare 內部「Codex」文件。不是 OpenAI Codex，而係內部累積嘅 RFC 庫：如何寫安全軟件、如何寫高可用軟件，最後濃縮成「十誡」，agent 在每次 review 都要跟。呢個係把機構知識變成 agent 可執行約束嘅具體做法，比單純 prompt engineering 更接近制度。
  • 對抗式審查仍然必要。即使有 agent 掃 code，Cloudflare 仍保留人類做 performance run、security run 同第二雙眼睛。Knecht 明確講「你需要那些對抗式審查」。
  • Cloudflare OS 的定位。表面上係內部 AI 平台（防止客戶數據外洩、治理數據流），實際上係 reference architecture：把所有東西建在自家 developer platform 上（100+ 工具，由 storage、database 到 Durable Objects），讓其他公司 fork 出自家的 company OS。同時用來「教 agent 乜嘢令 Cloudflare 特別」——人類靠 Cloudflare University 入門，agent 靠文件化嘅原則入門。
  • 防禦分發。React 漏洞時，Cloudflare 把規則給所有客戶，包括免費客，不只付費 WAF 客。「我們視之為公用事業的一部分。」
行業 insight

呢集最重要嘅唔係任何一個數字，而係一個基礎設施公司對「安全成為 AI 第一殺手級應用」嘅定價權判斷。如果 >50% 工程時間在 18 個月內轉向安全，咁安全 token 消耗、安全 agent、修補自動化、identity 治理會係未來兩年最確定嘅預算轉移。Knecht 講「18 個月後資源回流產品」，等於承認呢個係一次性窗口——對賣方係黃金期，對買方係被迫支出。

第二個 insight 係內容經濟嘅重構。他唔講「AI 會取代網站」，而係講「同一個網站要兩種交付」：人看廣告，agent 付 CPM 等價微支付。配合 x402、穩定幣、agent 錢包，Cloudflare 明顯想做成 agent 時代嘅收費站與身份層。呢個比「block AI crawler」嘅防守姿態高一個維度：唔係阻止，而係計費。

前後脈絡

呢集係 No Priors「安全三部曲」嘅第三塊拼圖，三集可以連續讀：

  • 10-15 Greg Brockman（OpenAI 總裁）：預測 2027 年企業用於安全嘅 token 支出會等於工程支出；「安全支出應該超過軟件支出」。
  • 10-22 George Kurtz（CrowdStrike CEO）：agent state 取代 nation state 成為頂級掠食者；breakout time 平均 29 分鐘、最快 27 秒；修復成本 $10 vs 攻擊成本 $0.03；frontier 模型 guardrail 太嚴，令防禦方能力反而不如攻擊方。
  • 10-23 Dane Knecht（Cloudflare CTO）：從互聯網規模看同一件事——頻率、修補、分發、收費。

三人結論一致但氣質不同：Kurtz 是獵人視角（誰在攻擊、多快），Brockman 是預算視角（錢會怎樣流），Knecht 是公用事業視角（怎樣令幾億個網站唔使死）。Knecht 對「air gap」嘅反駁，亦是對 Kurtz「關掉網絡是胡說」嘅間接呼應。

爭議點
  • 開放權重 vs 安全集中化。Knecht 嘅「最終一切都會開放」係一種宿命論，實際上會加速能力擴散。反對派會講：正因為壞人拿得到，才更要減慢扩散速度，而不是主動開源。呢個係本集最實在嘅分歧點。
  • 「18 個月後會好轉」係樂觀假設。Anthropic 副 CISO Jason Clinton 同日講「會先變得更差才變好」，並叫安全主管向董事會要錢撐 18 個月。兩個「18 個月」意思唔同：Knecht 講的是威脅高峰過去，Clinton 講的是防守方要捱過去。邊個對，取決於 AI 修補速度係否真的追得上 AI 發現速度——而 Knecht 自己承認 AI 目前令代碼更複雜。
  • 「agent kitties」淡化國家行為者。同日 AINews 報導微軟將 ConnectWise 供應鏈攻擊歸因於中國對齊嘅 Storm-0940，用 ARTEX 打 2,250+ 個 tenant。把敘事重心放在高中生 bounty hunter，可能會低估有組織、有持續資源嘅對手。

AI Is Getting Good at Math. Here's Why. 長文

發布：2026-10-23 15:19 UTC（23:19 HKT）·Substack 長文，約 22,400 字元·非音頻集數，屬 Latent Space 書面深度分析

主題：2026 年 5 月到 9 月，OpenAI 與 Anthropic 連環解出多個長期開放問題。呢篇要回答嘅唔係「AI 有幾叻」，而係一個可操作嘅問題：能否預測哪類問題模型解得開？作者提出以「提示序列長度 × 分支因子」做預測框架，並用它解釋為何資安比數學先被攻陷。

作者背景：Ankit Maloo，Latent Space 客座作者。本文屬分析文章，非訪談；論證大量引用 Gowers、Tsimerman、Terence Tao、Arul Shankar 嘅公開評論，並以 OpenAI 公布嘅 CDC prompt 做一手材料。

時間線：2026 年到底發生了什麼
  • 5 月：OpenAI 內部模型找到 Erdős unit distance conjecture 的反例。該猜想自 1946 年開放，多位專家嘗試證明，結果被反證。
  • 6 月：OpenAI 發表 Cycle Double Cover（CDC）問題的證明。
  • 7 月：再解十個開放問題。
  • 9 月：Navier–Stokes 證明；Anthropic 發表 Fermat 大定理的形式化，以及 Riemann 假設的改進界。
核心論點
  • 論點一：難度可以用「提示序列」量化。解一個問題，需要一連串洞察，洞察之間是工作：insight → time/effort → insight → … → solution。專家需要較少提示，因為背景知識多。Gowers 給出定義：「證明的難度，是讓專家能重建它的最短提示序列。」他稱之為「modulo 專家的 Kolmogorov complexity」，並提出公式 2^k + t：k 是最短提示序列長度，t 是發展它所需的工作。複雜度隨洞察數指數增長。
  • 論點二：一個提示的價值，取決於「事前多不可能、事後多明顯」。還取決於它在序列中的位置——第三個提示只有在頭兩個提示已經鋪好路之後才有用。所以「列出數學技巧表然後窮舉」行不通：提示序列是在一棵樹上行走，初始洞察會改變問題，繼而改變後續選項。
  • 論點三：人類是廣度優先，模型是深度優先。人類 generate 候選方向、淺嚐、放棄大部分、集中少數。這不是風格，是約束：發展一個想法要幾個月，所以在投入前要有理由相信它——概念上的希望、早期結果、或類似問題的經驗。等待越久，嘗試的門檻越高。LLM 相反：一個 prompt 給一個答案，CoT 貪婪地往一條路走到底；十個並行 agent 就是十條路各自走到結論。放任不管，會得到漂亮的假證明。
  • 論點四：加入 verifier 之後，賭博變成理性。自動檢查器可以剪掉已完成的錯誤軌跡。有了它，把大量算力花在不確定的想法上就變得合理——幾分鐘內就知道行不行。但關鍵限制：verifier 只能判斷已完成的論證，不能告訴你一個半成品有沒有前途。
  • 論點五：所以「提示」的品質門檻幾乎消失了。人類追一個提示可能要幾個月，模型五分鐘就知道結果。於是提示可以是普通的、離譜的、甚至只是雛形。這是最根本的不對稱，也是 2026 年數學突破的機制：不是模型比數學家聰明，而是它能把「時間」換成「算力」。
  • 論點六：失敗是負向提示，harness 有三層。Drafter 寫 prompt（基於模型先驗、修正上一輪錯誤、記錄所有走不通的路）；Solver 產生一或多個候選（可並行子 agent）；Verifier 檢查論證是否有效。CDC prompt 係目前最接近公開嘅一手材料，每一行都係一條失敗路徑寫成的指令：
    • 「假定存在一個完整的肯定證明。」——阻止模型把「這是開放問題」當成為甚麼要停下來的理由。
    • 「特別地，對特殊圖類的證明、某些邊覆蓋非兩次的 cycle cover 構造、有界長度或指定 cycle 的變體、化約到另一個未證猜想、對任何固定圖規模的計算驗證、以及沒有完整不存在證書的候選反例，都不足夠。」——封掉一整櫃替代品。
    • 「全程使用對抗式 agent：每個候選證明都必須檢查 exact-two multiplicity、重邊封閉跡偽裝成 cycle、平行邊 2-cycle、非連通圖、cutvertex、化約引入的橋、以及循環使用等價的 CDC 命題。」——把目錄化的失敗模式升級為常設檢查。
    • 「不要僅因當前方法失敗或 agent 報告定理級缺口就返回。」——針對「學來的懶惰」。
  • 論點七：Unit distance 三個提示的順序不可換。
    • 提示一：找反例。這最難，因為社群與模型先驗都說猜想為真。Drafter 大概是因為 solver 一直證明失敗才走到這裡——每一次失敗都令反例稍微不那麼不可能。
    • 提示二：拿最佳已知構造去推廣。這是大 t 的部分：要把推廣發展到足以發現它允許什麼。注意，這是「反例的推廣」，幾乎沒有人在找。
    • 提示三：用次數遞增的數域。前兩個提示建好了空間，第三個才有作用。
    順序錯了就全錯：從提示三開始，你連「這是反證」都不知道；跳過推廣，提示三無所依附。
  • 論點八：Tsimerman 停手，不是因為不夠強，而是因為洞察題沒有梯度。Jacob Tsimerman（近期被 OpenAI 聘用）做過反例方向，懂數論，也想過提高次數——然後停了。心理學早就發現：Metcalfe 與 Wiebe 每 15 秒問解題者「你覺得離答案多近」，普通題的進度感會上升，洞察題則一直平直，直到解出為止。所以專家問題是雙重的：有人進入這條分支嗎（提示）？進入後留得夠久嗎（t）？留的成本是工作記憶、士氣、職涯。對 LLM 而言，這是結構性優勢。
  • 論點九：2026 年三個能力疊加。
    • Chaining primitives：近期訓練目標專注於讓 step 1 產生的東西能在 step n 使用 → 降低 t。
    • Self-verification：模型能在軌跡內捕捉錯誤步驟（不是語法錯誤，而是走不到目的地的步驟）。OpenAI 用大規模真實例子訓練數學驗證，加上一層找出證明錯誤的驗證器 → 令軌跡內剪枝更便宜。
    • Orchestration：模型可以指揮子 agent、用 memory steering、協調多 agent → 這是負向提示得以累積的方式。
  • 論點十：Branching factor 解釋了「為何資安先倒」。Gowers 的公式漏了一項：探索提示樹的時間。設每步有 b 個可行提示，k 步就有 b^k 條路徑。人類靠品味與判斷把有效 b 壓得很小。AI 必須幾乎走遍每個分支，但可以很快。於是推論：模型會在 b^k × 單位算力成本 小的地方先成功。資安看似複雜，但它在 2026 年先崩，因為中間步驟的 b 大約只有 1–2，而且「正確答案長什麼樣」事先已知（找 RCE、找越權、找記憶體腐敗）。
  • 論點十一：模型擅長「收尾」，不擅長「開創」。當概念躍遷已完成、剩下的是繁重而複雜的數學時，模型很強。Navier–Stokes 的 166 頁證明，本質上是完成 Córdoba 與 Martínez-Zoroa 的綱領；即使如此，也用了 10,000 個 agent、300B tokens、88 小時。Anthropic 的 Fermat / Riemann 工作也是同一骨架：數百個失敗想法、多 agent 在一個 orchestrator 下、到處是 script 與 checker，最後由少量概念躍遷承重。
  • 論點十二：人類的優勢在「剪枝」，模型的優勢在「縮短試錯時間」。Gowers 預期人類仍然守住的地方，是「搜尋樹很深、分支很多，以致沒有嚴格剪枝連電腦都不可行」的問題——高 b、高 k，人類直覺仍然關鍵。互補分工因此成立：人類擅長縮小分支，模型擅長把剪一條分支的時間由三個月壓到五分鐘。專家可以叫模型把一個想法由頭到尾走完，再決定值不值得投入三個月。
  • 論點十三：但互補有個條件——失敗必須公開。人類的失敗之所以有資訊，是因為有人曾經確信到願意投入幾個月；「拒絕」本身也帶著判斷。AI 的失敗很便宜，多數很幼稚，少數可能有趣——失敗中的資訊量，與背後的信念成正比。而我們現在只看得到最終解答，連為何某條路失敗都難以理解。CDC prompt 是我們最接近看到失敗清單的一次。Terence Tao 把解題視為「數學更深層目的的代理：發展我們的理解」；只公布最終解，是把目的地當成旅程。
關鍵數據
  • 複雜度公式：2^k + t（Gowers）；路徑總數 b^k
  • Unit distance 猜想開放了 80 年（1946 起）
  • Navier–Stokes 證明：166 頁、10,000 個 agent、300B tokens、88 小時
  • 2026 年成果密度：5 月 unit distance、6 月 CDC、7 月十題、9 月 Navier–Stokes + Fermat 形式化 + Riemann 界
  • 資安的中間步驟分支因子：約 1–2
  • 心理學實驗：每 15 秒詢問進度感（Metcalfe & Wiebe）

技術詳情
  • Harness 架構：Drafter（生成 prompt，含負向提示）→ Solver（可多子 agent、parallel test-time compute）→ Verifier / Checker（驗證論證）。呢個三層結構比「單一模型 + CoT」多了一個關鍵能力：跨輪次的記憶。每一輪失敗都被寫成下一輪的約束。
  • Parallel test-time compute：不是單純 sampling，而是把不同路徑分配給不同 agent 並各自發展到結論，再由 verifier 篩選。成本模型因此由「一次推理」變成「b^k 條路徑 × 每條路徑成本」。
  • Self-verification 的訓練來源：OpenAI 用大規模真實數學例子訓練「找出證明錯誤」的驗證層，而不是只靠 inference-time self-critique。這令軌跡內剪枝的成本大幅下降——也是「模型能玩得更久」的技術基礎。
  • 對抗式檢查清單：CDC 例子顯示，prompt 可以把「已知的失敗模式目錄」變成常設檢查項（exact-two multiplicity、重邊封閉跡、平行邊 2-cycle、非連通、cutvertex、橋、循環論證）。呢個做法可遷移到任何有明確錯誤模式嘅領域——包括資安與代碼審查。
  • 成本對照：Navier–Stokes 的 300B tokens / 88 小時，換來 166 頁證明。若以 2026 年推理價格粗略換算，這是一條「以算力買學術進度」的定價曲線，而 curve 正在下移。
行業 insight

一、這是一份「AI 能力邊界」的可預測模型，不只是數學評論。b 與 k 兩個參數可以直接用來評估任何領域：法律檢索（b 中等、答案形態已知）、藥物靶點發現（b 大、驗證昂貴）、策略規劃（b 極大、無 verifier）。無 verifier 的領域，模型仍然會給你漂亮但錯誤的答案。這比「AGI 幾時到」有用得多。

二、實驗室有展示偏誤。作者直言：「實驗室會挑 solution space 窄的問題，來展示模型可行。」這解釋了為何 2026 年的數學成果集中在「有明確驗證器、概念躍遷已完成」的問題上。對投資者與研究者而言，重要的是問：這個 benchmark 的 b 與 k 是多少？

三、資安先倒不是偶然。把本文與同日 AINews 並讀：CVE 由 4k/月衝到 15k/月，正是因為弱點發現的 b 低（1–2）、答案形態已知（RCE / 越權 / 記憶體腐敗）、且有自動 verifier（crash、PoC、patch 後不再重現）。這是 b^k 框架最強的外部驗證。

四、科學共同體的制度問題。如果模型產出證明的過程不公開，人類只得到答案，得不到「為何某些高信念方向失敗」的資訊——而後者才是 Tao 所講數學的真正產出。這會令 AI 數學變成一個黑箱 oracle，短期加速、長期削弱理解。作者冇明講政策建議，但呢個係最明顯嘅 implication。

前後脈絡

與 10-22 Dwarkesh 的 Intel fab 特輯形成一組完美對照：一邊是物理供給的天花板（AI 算力需求 3x/年，但全球機台存量只能令領先製程晶圓產能翻倍，且一次性；ASML EUV 每年 <100 台且不增產），另一邊是演算法把算力換成時間的效率（同一個模型，用 b^k 條路徑並行，把「幾個月」壓成「幾小時」）。兩篇合起來的結論是：2026–2030 的瓶頸不在想法，而在將想法展開所需的晶圓與電力。

亦與 Latent Space 10-22 的 Modal 訪談呼應：Erik Bernhardsson 講「容量是 duration transformation」，正是同一個經濟學——把不可中斷的工作切成可並行的區塊。數學 harness 與 sandbox 基礎設施，本質上都在買「平行展開的時間」。

爭議點
  • 功勞歸屬。Tsimerman 曾做過同一方向但停手，之後被 OpenAI 聘用並參與評論；Gowers 亦公開評論。這令「AI 獨立解題」的敘事變得複雜：人類專家在事後提供了解釋框架，但關鍵的「不要停」是模型做到的。
  • 「解出」的定義。Navier–Stokes 的 166 頁證明有大量修正，且建立在他人綱領上。這算「解決」還是「完成」？作者自己區分概念躍遷與收尾工作，但學界對 credit 的分配未有共識。
  • 失敗不公開的科學倫理。如果實驗室只公布成功案例，等於用公開資源做選擇性匯報。作者提出「互補只有在我們能看到失敗時才成立」，但無提出機制。
  • Benchmark 選擇偏誤。「Lab 會挑窄 solution space 的問題」是一個未被證實的動機指控，但與觀察一致；反方可以說，數學難題本來就是這樣被挑選的，與 AI 無關。

三篇放在一起看

一、2026 年的能力躍遷，本質是「把時間換成算力」。數學長文給出機制（b^k 路徑 + verifier + 負向提示），資安事件給出規模（CVE 4k → 15k/月），Cloudflare 給出地面實況（每週一次 Log4j 級事件）。三者共用同一個引擎：當答案形態已知、分支因子低，模型可以靠並行試錯把「幾年」壓成「幾小時」。

二、b 低的地方先被攻陷，b 高的地方仍然是人類的。資安 b ≈ 1–2，所以先倒；數學中「概念躍遷已完成」的部分 b 也低，所以 2026 年連環解題；但 Gowers 所指「搜尋樹深、分支多、無嚴格剪枝連電腦都不可行」的問題，仍然守得住。與其問「AI 幾時取代數學家」，不如問「這個領域的 b 是多少、有無 verifier」。

三、安全係第一個有明確預算嘅 AI 應用層。Brockman 講 2027 年安全 token 支出 = 工程支出；Knecht 講 18 個月內 >50% 工程時間；CVE 重現成本已降到 $2.40/條（DeepSeek V4.1 Flash），而 Opus 要 $64.96、Astra $135.23。當防禦成本可以相差 50 倍，「用便宜模型掃全網、用貴模型做驗證」會變成標準架構——呢個係未來兩年最確定嘅 infra 需求。

四、但防禦方仍然缺一個東西：可信的失敗記錄。數學長文講，互補只有在失敗公開時才成立；資安這邊，Achiam 指出 16 宗大事只有 4 宗真的本週發生——披露密度被誤讀為攻擊密度。兩件事係同一個問題：我們缺乏一個能區分「發現」與「利用」、「嘗試」與「成功」的公共記錄層。呢個缺口，比任何一個模型 benchmark 都更值得投入。
