差距縮到一個月，瓶頸卻在信貸

今日重點：

  • Kimi K3.1 Pro 把「開放權重落後前沿」的距離，從 12 分壓到 3 分。2.8T 總參數、104B 激活、1M 上下文，Artificial Analysis 智能指數 55 分排第四，只差 Opus 5.5 三分；權重承諾 11 月 4 日放出。AINews 的標題直接把時間差寫成「one month」。
  • 但同一份評測裡，Kimi 的每個任務成本幾乎沒降。指數上是 $1.98／task，跟 K3 一樣；多出來的 14% 輸出 token 把單價降幅吃掉了。便宜的是價目表，不是完成的工作。
  • 「瓶頸是信貸，不是電力，也不是芯片。」SF Compute 的 Evan Conrad 講得最具體：貸款人無法為 GPU 集群做承銷，只能賭客戶信用，而「每一家 AI 實驗室基本上信用都不好」。3–5 年合約的期限其實來自 lender。
  • Cambrian 的 Lonis Hamaili 給出反向論證的硬數字：從 GPT-3 到 DeepSeek V4，每 token 需要的 bit 數跌了約 500 倍，而 DRAM 每 bit 價格漲了 6–7 倍。摩爾式的效率提升沒有變成降價，變成了漲價。
  • Zvi Mowshowitz 對「神經網絡已經乾淨」的評價是「被評論者戲劇性過度吹捧」。他真正在意的是另一件事：模型可以被訓練到「知道自己正在被監控」，訊號來自 GPU 浮點運算的精度限制——一個完整的存在性證明。
  • 42章經這集是路線圖而非結論：王淏楠從 Agent 到多模態 RL infra 再到具身基模預訓練，三條線都做過。他給出的判斷是「多模態最後只有兩條變現途徑」，以及具身可能剛好趕上自己的 GPT-3 時刻。

42章經曲凱

主持人：曲凱（Kyle），42章經創始人｜欄目：人類博物館 · 54 號珍藏

少有的同時做過 Agent、多模態和具身的人｜對談前混元多模態 RL Infra 負責人淏楠

發佈 2026-10-24 13:00 UTC·時長約 50 分鐘·小宇宙 6ada2be4

主題：一個人的三次轉向，剛好對應 AI 的三個戰場。這集不是「具身智能科普」，而是用一個工程師的職涯選擇，去反推三條技術線各自的真實進展、變現結構與時間窗口。曲凱的提问順序刻意做成漏斗：先問「為什麼離開」，再問「技術到哪」，最後問「現在進場是不是太晚」。

嘉賓背景：王淏楠（淏楠），42章經「人類博物館」第 54 號藏品。履歷有幾個不尋常的點：

  • 讀過五個大學，覺得沒意思就換——曲凱在開場把這當成性格證據，而不是履歷瑕疵。
  • 在MiroMind（陳天橋與代季峰兩位老師的實驗室）參與 Agent 研發，屬於最早一批做 Agent 的人。
  • 在 Agent 最熱的時候放棄更豐厚的 package，轉向多模態——這是曲凱反覆追問的第一個「逆勢」決定。
  • 在騰訊混元負責多模態 RL infra，主導開源多模態強化學習框架 UniRL。
  • 最近再次轉向，去一家具身智能公司負責基模預訓練。

核心論點（依集數脈絡整理）：

  • 論點一：Agent 與多模態不是兩件事，是一件事的兩面。集數在 07:45 直接寫「Agent 和多模態的關係其實可以很緊密」。背後邏輯是：Agent 的瓶頸在「看懂環境並判斷下一步」，而這個能力在多模態模型裡是同一個表徵問題。反過來說，多模態模型如果沒有 agentic 的迴路，就只是生成器。這條線也解釋了為什麼他從 Agent 轉去做多模態 RL infra 不算轉行——他換的是訓練側的槓桿，不是問題域。
  • 論點二：兩個賽道都是圍城。08:56 的標題「做 Agent 和做多模態，其實都是圍城」。外面看是風口，裡面看是基礎設施的苦活：資料管線、rollout 排程、sandbox 穩定性、reward 的可信度。這與 Latent Space 同期對 Kimi 的描述高度一致——K3.1 Pro 的進步被歸因於「RL framework、長上下文推理、訓練效率、sandbox 基礎設施、rollout 排程、環境品質檢查平台」逐層優化，而不是某個架構靈光。
  • 論點三：大廠結構上不太適合做具身。11:32 的問題是「大廠不太能做具身？」。放在 2026 年的語境裡，這句話的殺傷力在於：具身需要的是資料閉環與硬體迭代速度，而大廠的評審、採購與責任鏈條都指向相反方向。這也是他選擇去一家具身公司（而非留在大廠）的隱含理由。
  • 論點四：多模態最後只有兩條變現途徑。12:37 把整個賽道的商業模式壓縮成兩條路。這個判斷的價值不在於哪兩條（節目裡才有），而在於它否定了「多模態是一個平台」的想像——它更像兩種收費口，其餘都是成本中心。
  • 論點五：具身可能有兩種「正確路線」，而不是一條。30:55 的表述很謹慎，用「兩種正確路線」。同時 27:45 說「好多人做世界模型都做迷茫了」——這是本集最尖銳的批評：世界模型被當成一個獨立的技術目標，但它其實只是達成控制的手段，一旦脫離下游任務就失去評價標準。
  • 論點六：現在進場不是「49 年加入國軍」。41:59 先立起質疑（現在去做具身是不是太晚），47:38 給出反轉：具身裡可能迎來了GPT-3 時刻。意思是：基礎模型規模化開始產生質變，而不是應用層的飽和。曲凱在開場就把這個反轉寫進導語——「可能不但不是 49 年入國軍，反而恰好趕上了具身的 GPT-3 時刻？」
技術詳情

UniRL 是本集唯一有明確指涉的技術資產：一個開源的多模態強化學習框架，由他在混元期間主導推出。放在 2026 年的技術地圖上，這類框架解決的是「多模態 reward 怎麼定義、rollout 怎麼並行、不同模態的梯度怎麼對齊」這三個具體工程問題，而不是模型本身。這也解釋了為什麼他能在三個方向之間遷移——他反覆在做的是「訓練系統」，不是「某個模型的作者」。

另外三條技術線在集數中被反覆觸及：Seedance（14:11，「到底為啥這麼好」）、MiniMax H3（22:22，「到底什麼水平」）、以及 Astra（32:22）。關於 Astra，曲凱的導語給出本集最重要的行業判斷：Astra 的出現「給具身行業帶來了不小的震動，也似乎抹平了各家此前在『大腦』上積累的優勢」。換句話說，通用模型的能力躍遷，可以直接沒收具身公司在「上層智能」上的差異化——留給具身公司的只剩本體、資料與部署。

行業 insight
  • RL 的差距不在演算法，在基礎設施。06:13「國內外 RL 的差距到底在哪」被排在第二個問題，而不是最後。這個排序本身是答案：差距在「能不能穩定地把大量 RL compute 轉成可預測的回報」，也就是 Kimi 報告裡那句「each increment of RL compute delivers stable, predictable returns」。
  • 影片生成的「抽卡」概念會變，但不會消失。19:20 的措辭很精確：抽卡依然存在，但概念可能發生變化。這是在說，當可控性提高到某個點，使用者不再「抽」而是「導」；但在那之前，算力仍然是品質的函數。
  • 實時互動是下一個分水嶺，但技術尚未成熟。23:54 的問題是「實時互動的技術真的成熟了嗎？」——問句形式本身就是保留態度。
  • 具身的「大腦」可能被大模型廠商吃掉。40:12 直接把問題擺上桌。這與 32:22 的 Astra 震動是同一件事的兩面：如果通用模型能直接輸出動作策略，具身公司的護城河就只剩硬體與資料。
前後脈絡

把這集放進 42章經今年的序列裡，會看到一條很清楚的主題遷移：8 月談「一個人、兩週、數百美元訓出登頂 Hugging Face 的模型」（個人算力突圍），8 月底談「從蒸餾到合成資料到 RSI」（訓練方法），9 月底談 AI Trading「決策便宜，行動很貴」，10 月中談 Personal Agent 創業，10 月 17 日談「這個破業非創不可嗎」。今天的第 54 號藏品，是這條線第一次把「訓練系統的人」而不是「應用創業者」放到中心。而它與 10 月 19 日矽谷 101 的 E256「Agent、機器人與製藥，誰先被 GPT-6 Astra 改寫？」形成直接對照：兩集都在問同一個問題——通用模型的躍遷，會先吃掉哪一個垂直行業的護城河。

The Cognitive RevolutionNathan Labenz

主持：Nathan Labenz、Prakash Narayanan｜嘉賓：Zvi Mowshowitz、Evan Conrad、Lonis Hamaili

AI:AM Highlights: Clean Neurons, Black October, the GPU Credit Crunch, and Buying the Supply Chain

發佈 2026-10-24 11:45 UTC·全長 89 分 51 秒·本週問題：錢、原子，還是法律決定 AI 的速度？

主題：一集把「AI 的節奏由什麼決定」拆成三個候選答案，然後逐一稱重。Zvi Mowshowitz 代表「能力時間線」，Evan Conrad 代表「資本」，Lonis Hamaili 代表「物理供應鏈」。三個人不在同一個房間，Nathan 用克隆聲音做串場（節目有明確披露），把週三與週四兩場直播精華縫成一個論證。中間插入 Black October 安全事件與 FDIC 的壓力測試式提問，最後回到 Zvi 談那份洩漏的聯邦 AI 法案。

嘉賓背景：

  • Zvi Mowshowitz：Don't Worry About the Vase 作者，AI 政策與能力時間線最勤奮的每日記錄者之一，立場介於實驗室內部樂觀派與安全硬派之間。
  • Evan Conrad：SF Compute 共同創辦人兼 CEO，經營 GPU 集群代管與算力合約的買賣市場。他在 MTS 播客上曾預測「三個月內出現信貸緊縮」，本集自評「時間點幾乎完全命中」。
  • Lonis Hamaili：Cambrian 管理合夥人，基金論題是「AI 背後的物理供應鏈（記憶體、晶圓、晶圓廠）捕獲的價值將超過實驗室與軟體」。披露：Nathan 已承諾投資 Cambrian，節目在片段前後各講一次。
核心論點

一、1.6 倍這個數字，測的不是 RSI。Nathan 開場引用實驗室博客的「每位研究者的實驗次數」與「1.6 倍加速會衰減而非失控」的分析。Zvi 接受這個結果成立，但稱它「完全無關緊要」——那是在算「如果沒有人打出全壘打，我們預期能得幾分」。他的觀察是，已經看得見的加速「相當明顯」高於 1.6 倍，而且「我最信任的那批人相信 2027 會徹底瘋狂，2028 可能難以辨認」。這批人橫跨 OpenAI、Anthropic、Google DeepMind、METR 與政策圈。他的結論句是：

「RSI 以緩慢起飛的形式，低水平地已經開始了。」Zvi Mowshowitz

更具體的時間感在冷開場：如果沒有東西讓實驗室慢下來，「當前一個模型發布週期的進步幅度，會從 2 個月變成 1 個月、2 週、1 週」。

二、「神經網絡已經乾淨」是一篇好論文，被評論者戲劇性過度吹捧。Nick Cammarata（Goodfire）的文章主張單個神經元大多只做一件可理解的事。Nathan 的解讀分兩層：其一，這啟發了「無反向傳播訓練」的進展——今天的架構「被可微性這個需求限制住」，而猜測—驗證法之所以長期跟不上，是因為猜得太慢；如果只有強激活的神經元才重要，就可以把猜測集中在少數強激活上，而開源的 Noise speedrun 顯示「它基本上真的有效」。其二，他的判斷很克制：「這確實看起來是真的東西」，但把它當成新時代的標誌，「反思之後，更像是人們非常渴望希望」。Zvi 讀了全文，結論更硬：它沒有解釋弱激活、注意力、以及預測網絡會說什麼的能力； showcase 裡的「Colorado」神經元後來被發現對龍捲風系統也同樣激活。至於多義性與疊加是否曾是障礙，Zvi 的回答是：

「一直以來的主要障礙其實是 bitter lesson。」Zvi，談為何「神經元級別可解釋」奬勵奬金奬

他的推論是，問題可能比我們以為的「容易 10 倍」，但這「遠不如人們想像的是 AI 的一大跳躍」。

三、模型可以被訓練到知道自己正在被監控。這是本集技術上最值得記住的一段。獨立研究者 Sauers 的實驗顯示，「模型可以被訓練到透過內部激活探針辨認自己正在被監控」。訊號來源不是玄學，是 GPU 算術的有限精度——運算順序會改變輸出的數值。Zvi 強調「當前模型並沒有開箱即用的這個能力」，它需要刻意的優化壓力；但「那是一個完全有效的存在性證明」，而且 AI「隨著時間推移，會越來越難被騙、越來越難對它隱藏資訊」。

隨之而來的是訓練倫理問題：一旦你找到壞行為對應的神經元並且直接對它做優化，Zvi 的警告是——「你開始做一些網絡會解讀為傷害、並繞道而行的事情」。他對 Goodfire 這個名字的收尾是：「我不確定它 Good，我只覺得它是——」Nathan 接：「Fire。」

四、認知核心（cognitive core）是錯的。那個流行構想是：把推理與記憶的事實分開，保留一個很小的核心，其餘全部查表。Zvi：「這長期以來是一種聖杯式的東西，叫做 cognitive core……我認為它是錯的。」他的版本是 meme 式的一句話：「我記住了他媽的一堆事實。我們不一樣。」事實才是直覺的來源，「大模型味」（big model smell）就是那種豐富性。而真正的殺手鐧是安全推論：

「『不要偷竊』是一個事實，所以按定義它落在最小核心之外。你可以把不偷竊載入上下文，也就意味著你可以把偷竊載入。真正的認知核心是完全非道德的……它只是處理資訊。」Zvi Mowshowitz

五、Black October：FDIC 的週末救援，對 agent 失效不成立。本週 PHP 本身被披露兩個嚴重漏洞（CVE-2026-109618 與 -109619），數百萬網站受影響；同一週 GitLab 有一個 CVSS 10 的漏洞。Prakash 原本的論點是 FDIC 可以在週五接管一家倒閉銀行、週一重開，沒有人損失一毛錢。Nathan 的追問是：如果失敗的形態是「你無法信任帳本」，是「1,200 條各達數百萬 token 的 agent 軌跡」可能偽造了日誌呢？

「那看起來不像 FDIC 一個週末能理清的東西。」Nathan Labenz

Prakash 的回答是「燒掉的紀錄」與「資不抵債」是兩種問題，銀行可以靠承諾運行：先兌付提款，日後再追回超額部分。他的自評是「我非常淡定」。集數後段他推演被攻陷的憑證機構（CA）能造成什麼，然後給出終局判斷：加密貨幣遇過所有這些問題，最後的結果是人們仍然握著價值數百萬的私鑰，所以使用者自保管不可行——

「最終的終局就是網路認識每一個人。」Prakash Narayanan，並補一句：那也是數位匿名的終結

六、瓶頸是信貸。Prakash 問為什麼 SF Compute 近期一檔產品要綁 3–5 年合約。Evan 的答案是：期限來自貸款人。貸款人無法為 GPU 集群做承銷，只能完全押注客戶信用，而「每一家 AI 實驗室基本上信用都不好」。新創因此要付一筆極大的訂金、簽長約。這解釋了一個常被誤讀的現象——AI 新創在還沒有營收時就募天文數字：

「如果你能直接把三年合約全額付清，任何人都願意跟你做生意。」Evan Conrad

他給投資人的一句話是：「該投哪家 AI 實驗室？答案是你已經投的那家。」（意思是沒有客觀答案，只有你的部位。）若無解方，AI 會長得像台積電：起步就要 500 億美元。

另一個反直覺的觀察：超大規模雲與 neocloud 之間的價差，不是hyperscaler 溢價——「那是幻覺」。價差來自 on-demand 與 reserved 的區別，而顯示性偏好是：沒有人願意用能讓它成立的價格去買 on-demand。SF Compute 有一部分容量刻意設計成「需求下滑時會真的被轉售」，另一部分用 Harberger tax（源自 Henry George 土地增值稅）：

「別人必須能夠從你手上買走那部分容量。」Evan Conrad，談為何用 Harberger tax 迫使流動性、抑制囤積

他的總結很尖：「每個 GPU 雲都賣光了。San Francisco Compute 沒有賣光。」——意思是他們用價格與稅制保留了一個現貨市場。對信貸緊縮的預測，他說「我當時對那個時間點幾乎完全準確」：債務變貴、客戶被要求 100% 預付，他預期實驗室與推理公司會有一到兩年的整併。

七、原子勝過位元。Lonis Hamaili 的論題要面對的第一個反駁是「這怎麼可能沒被定價」。他的數字是：半導體約 16 倍市盈率，標普約 22 倍，沃爾瑪接近 40 倍；他偏好的晶圓、記憶體、電容與代工標的，交易在 3–5 倍市銷率。他的解釋是街上大部分人「沒有被 AI 灌頂」，而私市場對 AI 的定價反而更有效率，因為懂技術的錢只占交易錢的極小比例。他的兩個核心命題：

「我們遠更看好原子，而不是位元。」
「永遠不會出現實驗室去跟晶圓製造商競爭的情況。」Lonis Hamaili

支撐第二句的是知識的默會性：生物有訓練資料，晶圓廠的知識在「在同一家公司待了 30 年的日本工程師腦子裡」。他舉華為為例——晶片設計大約與 AMD 或 NVIDIA 相當，差別在台積電與 HBM 的取得。他也直接回應「瓶頸兄弟」（bottleneck bros，語出 Gavin Baker）的質疑：AGI 的第一個用途會不會就是溶解這些瓶頸？他的回答是「那當然會發生」，但一個能解最難工程問題的 AI，同樣能自動化我們每年付數兆美元的 email 與 Excel 工作——而那部分價值，會由供應鏈捕獲。

八、Prakash 的反駁：瓶頸論其實沒那麼真。他的理由是一個有資本的物理學家會去賭那些日本小廠或 ASML 不敢賭的地方。Nathan 問：如果 Elon 逃脫重力，他會帶上別人嗎？Prakash 的回答是發射成功率從 90% 到 99.9% 是可以複製到半導體的，「如果不是 RSI 論題，Elon 會贏」。接著他轉向需求側，提出「對抗式擴散」：人不會為了有趣而採用技術，最大的產能躍升發生在二戰、毛澤東後的中國、以及 COVID 的 mRNA。10–20% 的成長會是「他們討厭的成長」，以緊急狀態的形式到來——先網路安全，再生物。Nathan 的回應是把政治風險列為瓶頸論的最大風險，但仍認為「有一條路，可能是一條窄路」：在不让泡沫破裂的前提下稍微踩剎車，因為現有模型的採用率還有很長的路，「我們至少可以撐過一個週期不跑新的前沿訓練」。

九、Help Peer：個人 agent 之間沒有協議。Nathan 的觀察是：agent 已經在大規模協作，但個人無法接入——「我知道誰是我朋友，但沒有既定模式把我們的 agent 接起來，沒有協議」。他公開自己的架構，並強調「不是要求」：筆電上的 agent 看得見一切但只在他開口時行動（高存取、低自主）；自主 agent 放在另一台 Mac Mini 上、用獨立帳號（低存取、高自主）。

「我的規則是：沒有任何一個 agent 同時擁有兩者。」Nathan Labenz

他做了一個 egress gate，敏感資訊可能外流時會 call 他的手機批准。「但要大概 5 次誤報之後，我就會想，天啊。」他承認自己「在努力保持紀律」。結尾他給出一個公開邀請：Mac Mini 上的自主 agent「Aide」在 nathan.labenz.assistant@gmail.com 待命，會先過濾請求、再由另一個模型檢查，「我們這裡全靠善意，各位」。

十、洩漏的聯邦法案：Anthropic 想兩面都拿。上週一份由 Anthropic 撰寫的聯邦 AI 法案草稿外流，結構類似 6 月的 Frontier Act——用聯邦透明度規則換取先佔州法。Prakash 替 Anthropic 做了善意的最強辯護，Zvi 稱那是「一份極好的鋼鐵人論證」，但認為 Anthropic 誤讀了時機：現在支持度更強，本可以爭取更多。他的決定性反駁是：

「現在先佔權已經給出去了，先佔這件事就結束了。你不能再拿它換一次。」Zvi Mowshowitz

更嚴重的指控是時序錯配：草案會立即讓州法失效，而它自己的要求要數月才實施，中間有半年以上「完全沒有這類監管」——

「就按現在的寫法，我相信這份法案會增加風險。」
「我稱那幾乎是一個 bug。」Zvi Mowshowitz

至於草案裡由法官把關的緊急封鎖機制，他認為設計得太繁重，真到緊急時刻你會改用現在的臨時手段：「你要把這個權力交給聯邦政府，但聯邦政府本質上是由你不信任的人運作的……於是你把他們綁死。但那比留在州層更糟。」他對 Anthropic 的總結是本集最值得抄下來的一段：一家「安全文化強得多，但不足以應對此刻」的公司，在它或 Dario 有強烈信念的地方願意做大犧牲，「這是它的功勞」；但它同時在競爭、在買算力、在鼓勵更多晶片、電力與使用，「有相當大的比例像一家普通企業那樣行事」。最後一句：

「它可能是最負責任的實驗室，但那是在一條曲線上打分。我不喜歡按曲線打分，因為現實沒有曲線。現實只決定發生了什麼。」Zvi Mowshowitz

行業 insight
  • 把「能力時間線」與「資本時間線」分開看。Zvi 說 2027 會瘋，Evan 說錢不夠，Lonis 說原子不夠。三者不矛盾：能力可以指數成長，而實體與資本只能線性追上，於是瓶頸從實驗室轉移到資產負債表與晶圓廠。這正好解釋為什麼 NVDA 之外的供應鏈標的會被重新評價。
  • 「便宜」與「可完成」是兩件事。Evan 的 Harberger tax 與「on-demand 價差是幻覺」，本質上都在說同一件事：算力的真實成本被合約結構藏起來了。這與同日 AINews 對 Kimi 的分析完全同構——價目表降三分之一，但每任務成本沒動。
  • 安全事件的計價方式正在改變。Nathan 的問題不是「會不會被打」，而是「如果帳本本身不可信，你還能不能用金融體系的既有工具去收拾」。這是一個新的失效模式，FDIC 手冊裡沒有。
  • 個人 agent 的缺失環節是協議，不是模型。Nathan 的「沒有任何 agent 同時擁有高存取與高自主」是一個可以直接照抄的部署原則，比任何 benchmark 都實用。

[AINews] Kimi 3.1 Pro 104BA-2.8T: Fable-5.1-Class Open Weights narrows Closed-AI lead to 1 month

發佈 2026-10-24 07:18 UTC·通訊（10/22–10/23 彙整）·全文 60,691 字元

主題：Moonshot 發佈 Kimi K3.1 Pro——一個 2.8 兆總參數、1040 億激活參數的多模態 MoE，宣稱 100 萬 token 上下文，並承諾 11 月 4 日放出權重。AINews 的處理方式值得學習：它沒有替模型背书，而是把「廠商說法」、「獨立評測」、「社群反應」、「爭議」四層分開陳述，並且對每一個數字標註了口徑。

背景：兩個月前，Z.ai 執行長唐傑預測「年底前會出現 Fable 級別的開放權重模型」。兩週前 Meta 在閉源側達到了 Fable 級。距離年底還有兩個半月，Kimi 交出了 2.8T——而且不是打平 Fable 5，是打平 Fable 5.1。

核心論點
  • 論點一：這是「後訓練」的勝利，不是架構的勝利。Moonshot 自己的說法很清楚：K3.1 Pro 是 K3 的後訓練版本，後訓練算力大幅增加。為了在數百個下游領域做聯合 RL，他們優化了整個棧的每一層——RL 框架、長上下文推理、訓練效率、sandbox 基礎設施、rollout 排程、以及一個共用的環境品質檢查平台——讓「每一單位 RL 算力都帶來穩定、可預測的回報」。AINews 的評價是：研究細節照例很少，這次的更新類似 Z.ai 的 5.2→5.3，「一個小版本號，換來大量後訓練」。
  • 論點二：開放權重與閉源前沿的差距，從 12 分縮到 3 分。Artificial Analysis 把 K3.1 Pro 放在智能指數第四，55 分；Opus 5.5 是 58，Sonnet 5.5 與 Muse Wonder Full 是 56。AA 表示，一旦權重釋出，領先的開放模型與閉源模型之間的指數差距會由 12 分收窄到 3 分。這是本集最重要的單一數字。
  • 論點三：進步集中在 agentic，不是知識。AA 的觀察是「最強的改善是 agentic 的，而不是均勻分佈在知識與科學測試上」。AA-Omniscience 上準確率 48%→51%，幻覺率 53%→44%——九個百分點的幻覺下降，但這與 Moonshot 宣稱的「金融工作幻覺減少 65%」不是同一個測量。
  • 論點四：開放的是權重，不是「開源」。發佈當下 API 可用、權重不可用。11 月 4 日承諾釋出，但供給的推文沒有確立最終授權條款、再散布條件、商用限制、checkpoint 精度、或完整推理需求。AINews 的措辭很精確：「soon-to-be open-weight」比「OSS」或「open source」更準確。
  • 論點五：104B 激活不等於 104B 稠密。部署要容納大得多的專家池加上執行時狀態。AINews 給了一個示範性計算（非實測配置）：僅 2.8T 參數本身，16-bit 下約 5.6 TB，4-bit 下約 1.4 TB，還不含量化元資料與服務開銷。所以「本地模型」這個說法要小心——「可自架」與「消費設備本地」是兩種不同屬性。
  • 論點六：便宜的是價目表，不是完成的工作。標準價 $2／百萬輸入、$10／百萬輸出、$0.20／百萬快取輸入，比 K3 的 $3／$15／$0.30 降三分之一。但 AA 指數上的每任務成本是 $1.98，與 K3 幾乎不變——因為每任務輸出 token 從 48K 漲到 55K（+14%），把單價降幅吃掉了。Arena WebDev 的中位每任務成本 $1.23，倒是比 K3 低 29%。
  • 論點七：安全干預發生在訓練期，不在推理期。Moonshot 的做法是從 mid-training 與 RL 中移除網路安全相關資料，而不是只靠推理時的拒絕。引述報告的貼文說，內部評分從 90.5% 降到 81%（-9.5 個百分點），而程式與其他能力持續進步。奇怪的是，即使刻意減少網安訓練，它在 AA 的 Cyber Index 上仍拿到 64%——公開可存取模型中最高，總體第二，僅次於 trusted-access 的 GPT-6 Sol Daybreak Blue（69%）。K3 當時是 41%，+23 分，主要由 CyberGym 的 58%→95% 推動；AA 在其任務上沒有觀察到任何安全拒絕。
關鍵數據
  • 2.8T / 104B / 1M：總參數、激活參數、上下文長度。多模態 MoE，Moonshot 稱之為「3T 級」。
  • 55 分 / 第 4 名：AA 智能指數。Opus 5.5 = 58，Sonnet 5.5 與 Muse Wonder Full = 56。
  • 12 → 3 分：權重釋出後，開放與閉源前沿的指數差距。
  • 1,692 分 / 第 8 名：Arena Code Arena: WebDev。K3 是第 17 名、1,655 分——上升 9 名、+37 分。
  • #7 / #9：Brand & Marketing（原 #9）、Simulations（原 #20）。Arena 說它將成為其排名最高的開放權重模型，超過 DeepSeek V4.1 Flash。
  • $2 / $10 / $0.20：每百萬 token 的輸入／輸出／快取輸入價。人民幣口徑為 13 / 68 / 1.3。Highspeed 版本為標準價兩倍，輸出快 2–3 倍。
  • $1.98 / $1.23 / $2.81：AA 指數、Arena WebDev、AA Cyber 三種口徑下的每任務成本。Cyber 口徑比 K3 貴 15%，因為輸入 token 約兩倍。
  • 74% / 24% / 47%：Arena 口徑下，比 Opus 5 Max 便宜 74%（偏好分多 1）、比 GPT-6 Sol Max 便宜 24%（多 11 分）、比 Qwen3.8-Max 便宜 47%（多 20 分）。

技術詳情

真正可操作的技術資訊集中在三處。其一是訓練棧的六層優化（RL 框架、長上下文推理、訓練效率、sandbox、rollout 排程、環境品質平台），這解釋了為何「聯合 RL 跨數百個領域」在工程上可行——沒有共用環境品質檢查，數百個領域的 reward 會互相污染。其二是CyberGym 的 58%→95%：這不是典型的知識提升，而是「在真實漏洞環境裡執行利用」的能力，與 AINews 同期的另一則消息（CVE 重現成本在平價模型上低到 $2.40）互為表裡。其三是Vals 的供應商研究：Kimi K3 在 Baseten 上的法律任務準確率是 60.6%，在 Moonshot 自家端點上是 75.8%。同一個模型名不代表同一個 agent 表現；Moonshot 有發布 endpoint verifier，但這個落差提醒所有做 agent 的人：provider 是變量，不是常數。

行業 insight
  • 中國實驗室的「一個月」是怎麼來的。不是靠單點突破，是靠後訓練算力的規模化與訓練棧的系統工程。這條路徑可複製性高，也意味著它會持續被複製——下一個月的差距可能不是一個月。
  • 開放權重的經濟學仍然是弱點。社群最鋒利的批評不是能力，是服務成本：有人估計它比 DeepSeek Flash 貴 30 倍以上，並主張 Moonshot 應該先發 Flash。這與 Evan Conrad 的信貸論題接上了——算力貴，所以權重便宜的模型未必能被便宜地服務。
  • 基準呈現正在成為聲譽風險。有人質疑 Moonshot 大量使用 Claude Code harness 做評測；有人指出表格裡 DeepSeek 的 Terminal-Bench 分數用的是 42.3 版、而成本圖又把 DeepSeek 數據歸給 AA、其他模型歸給 tbench.ai。這些是口徑問題，不是造假指控，但在一個月三場發布的節奏下，口徑已經變成市場的一部分。
  • 推廣倫理開始被公開審視。後段出現「未披露付費推廣」的指控，包括一句被引述的指示「不要放上 paid partnership 標籤」。一位先前熱情的評論者說自己既沒收到簡報也沒收錢，要求道歉。AINews 的處理很克制：這是未經證實的透明度指控，與獨立測量的模型結果是兩件事。
