Latent Space （swyx + Alessio Fanelli）

[AINews] Reflection Beam - 501B-A23B American Open Model 快訊 · 非訪談 發布：2026-10-06 06:28:43 UTC（HKT 14:28）｜ 類型：AINews 新聞彙編（覆蓋 2026-10-03 → 10-05）｜ 內含 Reflection 官方公告與獨立第三方分析

性質說明

本篇並非訪談劇集，而是 Latent Space 旗下 AINews 欄目的每日新聞彙編（smol.ai 出品、現為 Latent Space 子欄目）。它把過去約 48 小時內 12 個 subreddit、544 條 Twitter 的訊號壓成一份可搜索的日誌。之所以收進本報告：本輪 10 檔播客無新訪談，而此篇包含了一宗結構性事件——美國 neo lab「Reflection」發布首個開放權重前沿模型，是同週 AI 圈最值得記錄的新聞。本報告對其中「模型發布」部分做深度萃取，其餘條目作快訊式整理。

主角背景 · Reflection AI
  • Reflection AI：2022 年後成立的美國 neo lab，創辦團隊出自 DeepMind（共同創辦人 Misha Laskin、Ioannis Antonoglou，後者為 AlphaGo／AlphaZero 核心成員）。公司定位為「美國的開源前沿實驗室」，亦是本欄目 Latent Space 一年前首個深度合作發布的對象（當時已暗示其 RL 路線）。
  • 為何今次發布有份量：Reflection 的 stealth 期比 Thinking Machines 更長，外界一度懷疑它會否有模型面世；同期美國開源生態（NVIDIA Nemotron、Thinking Machines 等）持續出貨但普遍被中國開源壓住。今次 Beam 面世，等於宣告 Reflection「正式以 neo lab 身份登場」。
  • 算力側（第三方報導）：Axios 事前報導指 Reflection 每月付約 1.5 億美元租用 xAI 的 Colossus 算力，另與 Nebius 簽下約 10 億美元的算力協議；並稱本月仍有其他未具名美國 lab 會出開源模型。
核心論點
  • 論點一：美國開源前沿需要「補位」。AINews 的定調——Beam 並非 SOTA，但因為「US-trained from scratch（由零在美國訓練）」，市場上有一批買家一直等這個選項。更關鍵是象徵意義：「Reflection 現在宣告自己作為一個能夠運作（functional）的 neo lab 登場。」競爭座標不是 Kimi K3，而是 GLM 5.2。
  • 論點二：Beam 的差異化在「能效」而非「絕對能力」。官方原文：「Beam 與 GLM 5.2 等更大開源模型有競爭力，並在 coding / agentic 任務上接近 Qwen 3.8-Max。當 Kimi K3 這類前沿開源模型在原始能力上仍領先時，Beam 的優勢係推理時的效率。」它自稱在進階推理 benchmark 上以 3–4 倍更少推理算力達到 GLM-5.2 相若分數；對上 2T+ 參數家族（如 Qwen 3.8-Max）能效優勢更明顯。
  • 論點三：RL 是一個獨立的、仍無天花板的規模軸。Beam 官方把「高算力 RL」列為核心 scaling axis——「加大 RL 算力可促成對解題策略更廣泛的探索；更長的 rollout 支撐多步推理、工具使用與對環境回饋的適應。」且「在我們的評測套件上，能力隨 RL 算力增加持續改善，未見平台期」。
  • 論點四：資料品質係能力天花板的直接來源。原文：「在 Beam 開發過程中，我們發現資料品質上的妥協會導致能力平台化及其他訓練問題；對任務品質的系統性改進，是維持整段訓練中能力增益的關鍵。」
  • 論點五：異步 RL 在規模下的真正敵人係「策略陳舊度（policy staleness）」。「長時間運行的 rollout 中，token 由多個模型檢查點生成，較早的 token 相對當前策略越來越陳舊；訓練與推理引擎之間的數值不匹配進一步加劇此問題。」Beam 的解法是同時改算法與降低 train-inference mismatch，做到「即使學習來自一天前生成的交互，仍保持穩定」——即 落後 107 個權重版本仍數值穩定。
  • 論點六（第三方）：這是一次「等 FLOP 複製」。觀察者 Teortaxes 把 Beam 稱為 DeepSeek V3 的 iso-FLOP replication（等算力複製）；Elie Bakouch 估算預訓練 BF16 MFU 只有約 12%，並把架構讀成「3:1 交錯的全局／滑窗注意力」，且 held-out code perplexity 優於 DeepSeek V4。
關鍵數據 · Beam
  • 規模：501B 總參數 / 23B 激活（稀疏 MoE），文字輸入輸出（text-only）。
  • 預訓練：23.8 兆（23.8T）token；資料含網頁、公開來源、專有授權資料集；其中一部分來自「對數以億計 PDF 做 OCR 的管線」。約 95% 原始互聯網 token 在解析／去重／策展中被剔除，但作者稱常規手法會漏掉約 1.8 兆他們保留下來的高質 token（含 87% 的自建 web-code token）。
  • 預訓練基建：6,144 張 NVIDIA GB300 NVL72，端到端 四星期內完成；goodput（保留進最終模型的有效訓練時間佔比）尾段達 92.3%；全程僅執行 9 次半自動 rewind（非確定性梯度範數尖峰或疑似 silent data corruption）。
  • 中間訓練（midtraining）：把有效 context 擴展到 1M token；用多階段策展管線把真實範例轉成「推理密集」的長文，為 RL 建立更強起點。
  • RL 規模（本報告最核心數字）：10.5K 張 NVIDIA GB300、四星期，產生 逾 1 億條（>100M）rollout，最大 context 256K；訓練與評分使用約 13 億（1.3B）sandbox；環境池約 100 萬個 coding / agentic / STEM 任務。平均 11 萬條並發 rollout，峰值17 萬個並發 sandbox；跨 20+ 集群、兩個雲、四個區域，處理超過十億次 sandbox 建立請求，90% 新 sandbox 在 10 秒內就緒。官方稱「我們相信這是任何開放實驗室至今進行的最大規模 RL 訓練之一」。
  • RL 參考對照：Beam 的 reasoning expert 用上其中 8,000 萬條 rollout；欄目對比 Inkling 為 3,000 萬條、小米 MiMo 為 75.3 萬條。
  • 推理能效：FLOPS ≈ 2 × 激活參數量 × 平均生成 token 數（每次乘加算兩次運算）；官方稱達 GLM-5.2 相若分數但用 3–4× 更少推理算力。
  • 工程指標：新權重送到推理艦隊中位數約 12 秒；層級式分發令跨機架流量 減 75%、全艦隊採用新權重新快 2.2×；訓練期間 71 次推理事故全部處理而不終止訓練，推理容量中位 8 分鐘恢復，損失算力僅佔 0.02% GPU-分鐘；trainer 動態 packing 令批次平均 99.99% 填滿，而平均 rollout 長度增長近 70% 時每 GPU 吞吐僅波動 1.5%。

重點引用

「我們介紹 Beam——Reflection 首個開放權重模型。Beam 是一個稀疏 MoE，共 501 億總參數、23 億激活，為 coding、reasoning 與 agentic 工作負載而建。」 “We are introducing Beam, Reflection’s first open-weight model. Beam is a sparse Mixture-of-Experts model with 501 billion total parameters, 23 billion active…”

「當 Kimi K3 這類前沿開源模型在原始能力上仍領先時，Beam 的優勢在於推理時的效率。」 “Where frontier open models like Kimi K3 remain ahead on raw capability, Beam’s advantage is efficiency at inference time.”

「我們相信這是任何開放實驗室至今所進行的最大規模 RL 訓練之一。在整個評測套件上，能力隨著 RL 算力增加持續改善，未見平台期。」 “We believe this is one of the largest scale RL runs conducted by any open lab to date. … capabilities continued to improve as we increased RL compute, with no sign of a plateau.”

「在 Beam 開發過程中，我們發現在資料品質上的妥協會導致能力平台化及其他訓練問題。」 “Throughout Beam’s development, we found that compromises in data quality led to capability plateaus and other training issues.”

「即使以一天陳舊度（落後當前策略 107 個權重版本）訓練 Beam，數值仍保持穩定。」 “Even when training Beam with one-day staleness—107 weight versions behind the current policy—the numerics remain stable.”

「在沒有把瀏覽任務放進 RL 混合時，我們仍在瀏覽能力上見到一致增益。當給予網絡存取，它自發學會了搜尋並查詢其他大語言模型，以及用 OCR API 讀文件。」 “we saw consistent gains in browsing despite the absence of browsing tasks from the RL mixture. When given web access, it organically learned to search for and query other large language models, and to use OCR APIs to read documents.”

「因為這是由零在美國訓練，市場上有一部分人一直在迫切等待這裡有更多選項；更重要的是，Reflection 現在宣告自己作為一個能運作的 neo lab 登場。」——AINews 編輯部 “Still, since this is US-trained from scratch, there’s a segment of the market that has been eagerly waiting for more options here, and more importantly, Reflection has now announced its arrival as a functional neolab!”

技術詳情
  • 架構骨架：MoE，交錯的局部＋全局注意力（第三方讀作 3:1 全局/滑窗交錯）、細粒度 routed experts、受控殘差流、多種負載均衡。預訓練完成時最忙專家的負載僅 1.04×（近完美均勻利用）。
  • 均衡機制：在 DeepSeek 的 auxiliary-loss-free 負載均衡基礎上，加入 expert-bias 更新的餘弦衰減，以減少訓練後期的路由擾動；另加 序列級均衡，令預訓練分布以外的資料也能均衡利用專家，為下游 RL 的分布漂移做準備。
  • 殘差流穩定：基於深度的縮放（depth-based scaling）抵銷子層輸出累加造成的激活增長；配合 SandwichNorm、逐元素注意力門控、FP32 殘差累加（減低把細小更新加入殘差流的捨入誤差）。結果：52 層全部在預訓練期間殘差 RMS 有界。
  • RL 算法：異步策略梯度。針對 staleness 開發新算法並系統性降低 train-inference 數值不匹配，容許「一天前生成的交互」仍穩定學習。基礎設施層面：每 token 帶上「產出它的權重版本」標籤；推論/訓練 GPU 比例可在 3.9:1 至 5.4:1 之間調整，且在同一條訓練血脈內五次更換 GPU mesh 配置而不丟失訓練狀態。
  • 可控推理長度：以可控長度罰則訓練——早期完成長度下降而性能上升（學會更省 token 解題），後期 agentic 能力增強完成長度再升，但多出的 token 帶來真實增益。使用者可經 reasoning effort 參數在「簡短 ↔ 長推理」之間調節。Pareto 前沿呈兩階段位移：先收縮（更省 token），再向外擴（高 effort 追高效能）。
  • RL 環境供應：近 100 萬個環境，主要靠合成資料管線，輔以專有供應商資料與開源；三步迭代策展——先廣譜合成／採集（SWE、terminal、競賽編程、STEM、web search、tool use、知識工作），再按難度（既不能恒常可解、也不能不可能）與品質（不得欠定義、誤導、可猜、可 hack、破損、含噪）重度過濾，最後用 RL 試跑找問題並回饋下一輪。
  • 安全與對齊：從預訓練檢查點另訓一個模型（獨立 SFT + RL 管線），再用 multi-teacher on-policy distillation（MOPD）把「大規模 RL 教師」與「安全對齊教師」的能力合併。三層原則：(1) 不可打破的規則（遵守安全政策、維持 AI agent 身份）；(2) 應持續滿足的品質（用足上下文、準確陳述、承認不確定、透明跟隨用戶請求）；(3) 預設互動風格（直接、徹底、高效、主動預判）。安全訓練採 deliberative alignment，資料對抗式迭代構建（每輪訓練→生成引出有害或過度拒答的 prompt→把成功攻擊併入下一輪 SFT）。在非可驗證域，官方稱能預測 RL 收益（r = 0.79，對比 Best-of-N 上限的 r = 0.46），成功壓抑幻覺與過度格式化。
  • 發布形態：現階段為早期版本，開放 waitlist（platform.reflection.ai）；本月放 Apache 2.0 權重、技術報告、model card、開發者工件；將與發行夥伴與開源函式庫／harness 整合。
行業 insight
  • 「美國開源」的市場缺口開始被填補。Beam 的戰略位置不是爭 SOTA，而是坐實「可信來源的美國開源前沿」這一細分——價格／能效導向、需要 Apache 2.0 授權與可審計來源的企業，正是這批等待者。這對買方是選項增加，對中國開源是「能效維度」的新壓力點。
  • 競爭焦點由「能力」擴大到「每 token 智能」。Beam 明言賣能效；同期 AINews 亦記錄 Cline 的 Pareto 路由聲稱「同等 DeepSWE 分數下每任務 $0.24 vs $13.41」、OpenRouter 的價格路由扭曲（GLM 5.3 在 inference.net 上 $0.08/M 入、$5.00/M 出）。產業的價值函數正從 benchmark 榜單轉向 $ / 每單位智能。
  • RL 環境供應鏈成形。Beam（約 100 萬環境）、Hugging Face（環境在 Hub 上像資料集般被托管與版本化、10 個未改動 harness 即成 RL 環境）同時出現，意味「RL 環境」正從手作資產變成可流通、可版本化的基建——與上輪屠龍之術／MiMo 記錄的「高質開源 RL 環境＝上一輪預訓練語料的戰略地位」互相印證。
