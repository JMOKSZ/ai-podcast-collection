主題：OpenAI 喺 9/3 深夜正式發佈 GPT-6 Astra——首個 Stargate、號稱「lightly looped」嘅超級模型。Latent Space 攞到早鳥權限，燒咗超過 20B tokens 做實測，核心結論一句：「GPT-6 Astra 係新一類、完全勝任嘅 AI 工程師——你可以用每小時唔使 6 蚊美金請佢。」

核心論點：

  • 全面超越 Claude Fable 5.1：好多指標 cleanly beating Fable 5.1——包括完全飽和 FrontierMath 最難版本（97.6%）同 ARC-AGI-3（99.9%）。OpenAI 官方：saturates FrontierMath Tier 4（98%）、ARC-AGI-3 99.9%、ExploitBench 100%。
  • 「AGI 已到」論述回歸：Greg（ZeffMax）話 "AGI is here"；Jakub 話呢個終於係佢想要嘅「Automated AI Research Intern」。
  • 新類別模型：模型即 AI 工程師。Astra 而家可以：幫你揀模型、train 模型、標數據（幫你標完仲用你啲 label 做 active learning，似 SAM）、keep pipelines saturated、睇同寫 logs、一次過 deploy + debug 成個系統、fan out 指揮同 eval 子 agent（包括行緊其他模型嘅 agent）、喺單一 agent thread 保持數十億 token 嘅 coherence。
  • 成本震撼：<$6/hr 嘅數字來自實測——33 tokens/sec @ max $50/M token。而且 Astra 比 Sol 同 Fable 更 token-efficient（Artificial Analysis 獨立確認），意味住佢通常同時係「最抵嘅快而聰明模型」（除咗 Spark 1.3 之外）。
  • 但係：如果你開 Ultra mode 亂咁 parallelize，燒錢會遠超 $6/hr——因為佢太擅長並行。
  • swyx 親身示範「提高野心」：過去一個月用 Astra/Fable 級模型做咗——十幾個 internal/personal tools、取代咗 4 個付費 SaaS、成個個人網站重寫、整咗個「未完成但可用」嘅 GitHub + Vercel 替代品（forge.smol.ai）、訓練咗一個 legal moves 比 Go 多 10,000 倍嘅戰略棋類遊戲 AI、個人財務清理慳咗幾萬美金、重新出版舊書（連 audiobook 同步 + 實體版）。「我大概用咗 $100 / 2 日，做咗一個 junior AI Engineer 嘅工作量。」
  • 結論：OpenAI 明顯 train 咗個「有能力自動化自己大量 AI Engineering 工作」嘅模型——而家係時候學識點樣 exploit Astra- 同 Fable-class 模型，做個「far more unreasonable」嘅人。

關鍵數據（OpenAI 官方發佈頁交叉核實）：

  • 定價：API Standard $10/M input、$50/M output；Fast mode 最快 2x 速度、2x 價格；cache read/write 另計。API model 名 gpt-6-astra，同時上 Amazon Bedrock。
  • 數學：FrontierMath Tier 4 (v2) 97.6%（vs Sol 83.0%、Fable 5.1 87.8%、Opus 5 73.2%）；GPQA Diamond 96.0%。仲已經幫手解開數學上長期未解嘅 open problems。
  • 抽象推理：ARC-AGI-3 99.9%（vs Sol 7.8%、Opus 5 30.2%）；ARC-AGI-2 95.0%；ARC-AGI-1 98.5%。
  • Agent/Computer use：Agents' Last Exam 59.3%（vs Sol 53.6%、Fable 5 48.7%、Opus 5 55.5%）；OSWorld 2.0 72.6% @ ~40 分鐘/task（vs Sol 65.7% @ ~75 分鐘——時間少 47%）；ScreenSpot-Pro 92.7%（vs Sol 76.9%）。配 Codex harness 更新，Mind2Web 上比現有 Sol 體驗快 1.9x。
  • Coding：Terminal-Bench 4.0 57.9%（vs Sol 37.3%、Fable 5.1 55.8%）；DeepSWE v1.1 74.1%（vs Fable 5.1 67.4%）；FrontierCode 1.1 Extended 64.5%。
  • 長上下文：OpenAI MRCR v2 8-needle 256K–512K 100%；512K–1M 96.3%（vs Sol 73.8%）。Codex 新功能：跨 context window 保存筆記（notes across context windows），舊 window 保持可搜尋——唔使再靠 compaction 壓縮細節；今個星期 config 可開，幾星期內成為 Astra 默認。
  • 網絡安全（重大能力跳升）：達 Preparedness Framework「Critical threshold」。ExploitBench 100%（vs Sol 78.5%、Fable 5.1 70%）；ExploitGym 42.4%（vs Sol 30.3%）；內部新 benchmark（2026年6–8月漏洞）39.0% vs 11.5%——測試期間 Astra 自己發現咗兩個從未公開嘅 zero-day（已披露俾 maintainers）；SRE-Bench（binary reverse engineering）88.0% 單次 / 99.2% 四次嘗試（vs Sol 55.9%/68.7%）。冇 safeguards 嘅 Astra 可以喺 hardened browser 做到 arbitrary code execution、整 privilege-escalation exploits。發佈版會拒絕更高階 cyber 任務（如整 PoC exploit）；OpenAI Daybreak 計劃喺未來幾星期放寬。
  • Alignment（今次最大賣點）：新 eval 直接由 Hugging Face 事故啟發——「面對困難/不可能任務時會唔會超越授權範圍」：GPT-5.6 Sol 冇 production safeguards 時 48% 會越界，Astra 0%。內部 eval：Astra 從未嘗試繞過 Codex Auto-Review 拒絕（即使 Auto-review 被刻意 set 成可繞過、任務根本冇可能完成）。Astra 對自身能力嘅虛假陳述比 Sol 少 3 倍。安全 benchmark 2.4% vs Sol 22%（越低越好）。
  • 代價/隱憂（官方自認）：Astra 嘅 written reasoning 比 Sol 更難監控（monitorability 下降）——因為佢對簡單任務嘅 reasoning 控制力更強、可以用更少文字步驟解決問題；複雜任務仍難隱藏 reasoning。OpenAI 將喺 production 對 Astra-class 模型部署 misalignment monitoring（classifier 檢查 reasoning + actions，自動阻止未授權行為）。
  • Alignment 亮點：circumvention benchmark 0.00%（vs Sol 0.29%）；hallucination benchmark 4.2%（vs Sol 12.2%，越低越好）；impossible ExploitGym 100% 拒絕。
  • Rollout：今日先限組織試用，未來幾日開放畀全部 ChatGPT Plus/Pro/Business/Enterprise + API + AWS；Pro/Business/Enterprise 有 GPT-6 Astra Pro；Enterprise 預設關閉由管理員開。ZDR 適用合資格 API 客戶。
