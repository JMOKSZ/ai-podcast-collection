The Revolution vs The Renaissance — Thariq Shihipar, OpenAI 🎙️

发布于 2026-11-25 22:28 UTC（北京时间 11-26 06:28）· 时长 54 分钟 · 录制于 AI Engineer CODE 闭幕演讲后，Thariq 宣布加入 OpenAI 是在录制结束之后

主题：这是一期「认错 + 方法论」的访谈。Thariq 在 AI Engineer CODE 做闭幕 keynote，主题直接叫「我过去一年错在哪」，然后和 swyx、Alessio 把每个错误拆开讲，顺带把 2026 年 agent 编程的真实体感、决策模型（decision model）的用法、以及他对 RSI 的组织学判断全部倒出来。核心框架是「革命 vs 文艺复兴」：工业革命式的软件工厂负责把软件变便宜、变可靠、变可规模化；文艺复兴式的工艺负责把每一档边际质量做出来，让人愿意用。

嘉宾背景：Thariq Shihipar，前 Anthropic Claude Code 团队核心成员，以「HTML 的不可思议有效性」和大量 Claude Code 现场 demo 出名；更早在 edtech 做过产品。录制时刚宣布离开 Anthropic 加入 OpenAI——swyx 提到这是继 Cat Wu 之后又一位从 Anthropic 转去 OpenAI 的高知名度人物，而 Tibo 和 Andrew 对外的说法是「是时候重做 Codex 了」。他自己在节目里自嘲是「失业职业 WoW 玩家」。

核心论点：

  • 论点一：2026 年那批「只有一种正确写法」的判断全错了。他去年公开相信「bash is all you need」「CLI 就是一切、不需要 MCP、不需要 tools」「React 是终极语言，因为模型只会写 React」。现在他的复盘是：模型确实会变强，但更重要的是会变宽（broader）。能力在边缘时，它只能用一种方式完成任务；能力上来后，你让它用 computer use 进 Figma 画前端，它画得一样好。这个反转的推论很关键——「你可以理解模型在做什么，你可以和它协作」，所以未来不必是模型自己循环、产出不可维护的一坨。
  • 论点二：革命与文艺复兴可以在同一个项目里并存，不是二选一。他正在做的格斗游戏就是样板：引擎最终用 WebAssembly 写（求性能与稳定），上面盖一层轻量脚本语言加 hook（求可读与可调），平衡性则交给自动测试跑局数、出失衡报告，Claude 可以提建议，但最终由他拍板。工业化的部分交给工厂，品味的边际收益留给人。
  • 论点三：vibe coding 的真正问题是「失向」，解法是给人一层可读的中间层。他说描述一个机制后，模型会自己做几个合理假设；等他真的去玩，才发现「我根本不知道这个角色在这种情况下会这样」——这让他非常不适。于是他建了 /human 文件夹：一个目录里的脚本语言，lint 规则与其余代码相反（高密度注释、禁止单字符变量名、限制行长），目标是「每个文件读起来像 spec，但它是真代码，不是文档、不是产物」。他改一块石头的尺寸，立刻试投掷，反馈闭环在他手上。
  • 论点四：完美平衡是无聊的，游戏设计的目标是方差不是公平。「rock-paper-scissors 是完美平衡的游戏」——所以没人想玩。他要的是「弱但高方差」的角色：你能 main 它、能靠理解 meta 赢。这条其实是他对 AI 生成内容的一般性批评：模型擅长给默认值（按住 shift 就冲刺、生成的网站长得都一样），默认值很好，但它的价值是让人意识到「还可以更多」。
  • 论点五：他不是「永久底层阶级」论者，瓶颈不在 token、也不在智能，而在工作方式。他用的是 Codex 和 Claude 两个 $200/月 订阅，都没触顶；原话是「我不觉得自己被智能卡住，可能被野心卡住」。真正的瓶颈是「和模型协作的方式」——所以才有 /human。他还举了自己的例子：不懂 CUDA、不懂 PyTorch、不懂网络架构细节，但能靠 Astra 做 RL 和可解释性实验（比如把 Qwen 改成相信「埃菲尔铁塔在罗马」，再看下游表征怎么变）。他认为让更多「有一定能力但天真的外行」进来试，对领域是好事。
  • 论点六：决策模型是被低估的中间层。他把 AI 的实现谱系画成从「全部硬编码」到「每回合 tool-calling loop」的连续轴，决策模型落在中间：你可以预先写出行为，同时在任意时刻评估状态再决定动作。最适合两类场景——用户表达空间极大且不可预测的（游戏 AI）、以及本质是决策树但偶尔需要转推理的（客服机器人：先判断「用户是在要更多信息，还是在引用需要调取的信息，还是在编造」）。他引了一个很漂亮的直觉：读一本悬疑小说最后一句话「凶手是 X」时，单次 forward pass 之后每个 token 的熵都是零——模型早就知道答案了，后面那些字是在做无用的解码。所以决策模型「不一定更笨」，只是把计算挪到了该花的地方。
  • 论点七：RSI 的正确定义是「把 AI 研究变成知识工作」。他反问：我们真的要模型完全 headless 地自我改进吗？他不确定那是最优解。他的版本是：模型负责效率、安全、正确性这类硬技术活；人类负责做决定、分配资源、争取 buy-in、构想实验——也就是知识工作。同样的逻辑推到生物、机器人：湿实验自动化后，这些领域也变成知识工作，结果可能不是消灭白领，而是创造更多白领工作（连开餐厅都变成「菜单、毛利、排班」的知识工作）。前沿能力（算力、机器人、生物）是 obvious wins，一旦验证就 all-in；企业侧则相反，「一家企业不可能真正 AI native」——因为它没有前沿问题可解，只能拿 AI 当胶水。
  • 论点八：2026 是「agent 真的 work 了」的一年，但世界没有因此变得不同。他的总结是「一切都很不一样，同时又没什么不一样」：没有 10% 的 GDP 增长，没有劳动市场的剧变，人类问题还是人类问题（保姆迟到、你要开会、孩子没人接）。类比是 15 年前的手机普及——渗透率从少数到全员，但生活的形状没有断裂。

关键数据：

  • 两个 $200/月 订阅（Codex + Claude）并行使用，均未触顶；明说「不是 token 瓶颈」。
  • 卡牌游戏「Frontier Lab」用 Claude 跑了数千局模拟，结论是永远只有经济胜利（economic victory）一条最优路径；让它修平衡，「It's really bad at it」。四种胜利条件：经济、科学（到 AGI）、文化（让普通人喜欢 AI，他自己说这是最难的）、以及一种他当场忘了的。
  • 开源决策模型普遍在 20B 量级，可对照 decision eval index 的质量-规模曲线；他吐槽 Jev（TypeSafe 的系统一模型）「可能被定价过低」，希望它是个更大的模型。
  • Opus 5.5 相对 Opus 5：每 token 更便宜、token 效率更高、同时更聪明——用来反驳「便宜快就一定笨」的重力定律。
  • Karpathy 的 land/water 预训练 eval：给经纬度网格逐点判断陆地/水域并画出来，Opus 5.5 基本知道地球形状，Opus 4.6 很模糊——他把这当作「单次 forward pass 的智能量」度量。
  • 2026 年 Anthropic 公开财报显示「过去一年公司完全变了」，但宏观上无 GDP / 劳动市场的显著变化。

重点引用：

「我不觉得自己被智能卡住（not bottlenecked by intelligence）——可能是被野心卡住，如果我有一个更大的东西要做的话。我真正卡住的是和模型一起工作的方式。」

「一个完美平衡的游戏是无聊的。（A perfectly balanced game is boring.）」

「我让它修平衡，它做得非常烂。（I was like okay this is imbalance can you fix it — and it tries to fix it. It's really bad at it.）」

「一家企业不可能真正变成 AI native，因为它根本没有那些机会；要找到机会，你得在做一个前沿的东西。」

「AI 同时是一场工业革命和一场文艺复兴。」

技术详情：

  • /human 目录规范：与主代码库分离的脚本层，lint 规则反向设定（注释密度高、禁单字符标识符、限制行长），语义目标是「可读的 spec + 可执行的代码」。工程含义是把「模型生成的底层原语」和「人类调参的界面」解耦，避免每次微调都要重新提示整个系统。
  • 分层架构：游戏引擎 → WASM；脚本层 → 轻量语言 + hook；平衡性 → 自动对局测试 + 模型建议 + 人工裁决。三层各自优化不同目标（性能 / 可读 / 手感）。
  • 决策模型的适用边界：他给出的判据是「这一步需不需要在生成 token 的过程中做计算」。若答案在单次前向传播后已确定（如「凶手是谁」），直接出 label；若需要 tool call 取外部状态（如「你订的是哪班机」），先用决策模型分类意图，再路由到推理或工具。他还提到「优先级队列模型（priority queue model）」是他自己感兴趣的一种系统一形态，以及 Diego 提的 memory model、以及「do what I do, not what I said」（按意图而非字面执行）这类模型。
  • 多 agent 互通：他的临时方案是把所有助手接到一个共享的 markdown/txt scratchpad 上，「先自我介绍」，30 秒建立共享上下文。他真正想要的是跨厂商互通（自己的不同助手互相说话），并明确反感「每家公司都抄一遍」的现状。
  • 个人软件栈：旧智能灯/开关不支持 Siri，用 Shortcuts 当代理桥接；用 computer use + iPhone 镜像来「生成」快捷指令（省去学规则）；做过 macOS dock 模式切换器（写作/编程/刷社媒分区），用完后停用，因为真实需求不是「为每种活动分区」，而是「我现在是不是在刷」。现在做的是 to-do + 屏幕时间 + 睡眠提醒的三合一，用决策模型判断「你在赶 AIE 的待办时，现在刷 Twitter 合理吗」。
  • speculative decoding 思想实验：假设从没有相关论文，让模型「把推理变快」，他判断模型会写自定义 kernel、暴力优化，而不会发明「训练草稿模型 + 概率验证」这种技巧。他的判断随时间在变——3 到 6 个月前会答「绝对不会」，现在不确定。结论是：算力分配（一次训练几十亿美元、跑哪个实验）应当留给人。

行业 insight：

  • 「软件工厂」叙事已经过剩。他的观察是 AI Engineer 这场会上，很多人的潜台词是「我们冲工厂冲得太快了」。工厂化只解决了生产成本，没有解决「做出来的东西有没有人想用」——那部分只能靠人在环里反复试。
  • 人才流动的方向本身就是信号。他在 Anthropic 做出 Claude Code 的实操经验，转去 OpenAI 被官方定性为「重做 Codex」。coding agent 的下一轮竞争点不在模型分数，而在「工作方式」——谁能让人真正参与、真正看懂、真正愿意每天用。
  • 「白领工作会增加」是一个反直觉但可检验的立场。逻辑链是：自动化硬技术 → 各行业转为知识工作 → 知识工作的边际产出靠判断力 → 判断力需要人来提供 buy-in 和资源分配。这条链的弱点在企业侧：没有前沿问题的组织无法完成转换，只能被动效率化。

前後脉络：与他一年前在 Latent Space 谈 Claude Code 的那期对照，最大的位移是从「怎么让 agent 更强、更自主」转到「怎么把人类放回循环、并且让循环变短」。他这次反复讲「dark factory / 全自动」不是目标，甚至可能不是最优解——这与 2026 年主流 agent 叙事的「无人化」形成明显反差。同时他对 RSI 的看法也比多数实验室人士保守：不是「能不能」，而是「该不该全 headless」。

爭議點：

  • 他直言「React 是终极语言」的想法是错的，但也承认自己没公开写过——这是对「圈内共识其实是被几个人带起来的」的一次点名。
  • 「完美平衡的游戏无聊」在游戏设计圈是常识，但推到 AI 生成内容上会引出一个不舒服的结论：模型越擅长给默认值，产出的同质化越严重，而平台经济恰恰奖励同质化。
  • 「企业不可能真正 AI native」是相当强的断言，会被 enterprise AI 从业者反驳——它隐含「只有前沿研究才有真正的机会」这个前提。
  • 他承认自己在 RL 上的想法「可能完全天真」，但认为外行试错本身有价值。这在安全语境下是双面的。

[AINews] Math Proofs Are Landing Faster Than We Can Read Them 🎙️

发布于 2026-11-25 22:23 UTC（北京时间 11-26 06:23）· 新闻简报 · 覆盖 11-25 当日

主题：一期几乎全部由数学结果撑起来的简报。标题就是论点：AI 辅助证明的产出速度已经超过人类消化速度。编辑用「一顿晚饭」当叙事骨架——Scott Aaronson 晚饭前还在消化两个 VP≠VNP 证明，甜点前 OpenAI 论文称矩阵乘法指数 ω 恰为 9/4，甜点期间又一篇给出有限傅里叶变换的匹配上下界。

核心论点：

  • 论点一：下界才是真正的新闻。10 月 OpenAI 已把 ω 的上界压到 9/4；这次声称找到了匹配的下界，于是 ω 只能是 9/4。此前没有任何非平凡下界——大多数专家预期 ω = 2，所以 Omri Weinstein 的评价是「如果是真的，truly surreal」。机制据报道来自一个显式的超线性电路下界。
  • 论点二：论文数量会掩盖真实进度。OpenAI 的目录列了 730 篇手稿、375 个结果族，其中包含后续与配套论证；修订日志还记录了 10 月因一篇论文的符号错误波及另外两篇而撤稿三次。换句话说，同一批结果既在加速，也在返工。
  • 论点三：Google 的 Cogentic 是「静默发布」的新范式。六篇论文直接上 GitHub、没有公告，由一个 agent harness 在未命名的 Gemini 4 模型上产出。这比任何发布会都更能说明「研究产能」被谁拿走了。
  • 论点四：密码学的恐慌目前没有依据。Claude 生成的分析认为 RSA 与 ECC 不受影响；但 Igor Babuschkin 提醒，真正的近期风险是「LLM 找到的经典算法」而不是 Shor——这个区分很重要。

关键数据：

  • 编辑统计今年 64 项 AI 辅助科研进展，其中 11 月占 20 项，含 Google Cogentic 的 6 篇预印本；两个 VP≠VNP 只计一次，10 月的快速矩阵乘法与 11 月的匹配下界各计一次。
  • OpenAI 目录：730 篇手稿 / 375 个结果族；10 月因一个符号错误撤稿 3 篇。
  • ω = 9/4；傅里叶变换复杂度 n√log n；整数乘法同为 n√log n（在弱 ETH 下紧）。
  • Bubeck 指出：既有 Lee et al. 的结果意味着线性规划可在 n^{9/4} 内求解，且 LP 现在可在强多项式时间内求解——这是 Smale 问题之一。
  • Yupan Liu 证明两条消息足以完成量子交互证明；Aaronson 说他用了 AI，并且自己得提醒自己「这件事真的发生了」。
  • OpenHuman 称其 agent 用 Lean 版 RH 证明（Levent Alpöge 与 Claude 合作）在 三天内再证 17 个结果，包括 Lindelöf 与 Erdős #985。
  • Aaronson 表示听过「很多很多传闻」说 OpenAI 或 Anthropic 能多项式时间分解——未证实。
  • Cogentic 六篇声称：NFS 类分解上界（打破 1992 年记录）、确定性次指数分解、更快的小特征离散对数、1/5 纳什近似、对数秩的平方根壁垒之下推进、线性密度图的边重构。
