同一場發布會，三個行業的三種時差

GPT-6 Astra 發布之後，矽谷 101 把三位一線研究者放到同一張桌子上：一位 Agent 創業者、一位機器人創始人兼教授、一位 AI 製藥學者。同一套能力，在三個人嘴裡是三種完全不同的東西——對 Agent 是「更長、更穩，但沒有換代」，對機器人是「定性飛躍，可是慢到不能直接控制」，對製藥是「coding 能力溢出，但實驗設計只做到三成」。這一集真正的主題不是模型有多強，而是：智能曲線已經跑出去了，落地週期還在原地，中間隔著的東西，每個行業都不一樣。

硅谷 101（泓君 Jane）

嘉賓：許華哲（破殼機器人創始人、清華大學交叉信息研究院助理教授）、朱哲清 Bill（Pokee.ai 創始人兼 CEO、前 Meta AI 應用強化學習團隊負責人）、王晟（華盛頓大學計算機學院助理教授、Apodex Lead Scientist）｜時長約 72 分鐘

E256｜Agent、機器人與製藥，誰先被 GPT-6 Astra 改寫？🎙️

發布時間：2026-10-20 07:00（香港時間）｜2026-10-19 23:00 UTC｜錄製於 2026-09-29

主題

這不是一集評測，而是一次「同一模型、三個落地場景」的橫向壓力測試。九月 OpenAI 發布 GPT-6 Astra，總裁 Greg Brockman 在台上直接說「AGI 已經到來」。對機器人圈衝擊尤其意外：一場隻字未提機器人的發布會，模型轉身空降機器人評測榜首，讓多個公認的機器人 benchmark 失效。泓君於是把三個人湊到一塊，問三個問題：個人 Agent 商業化卡在哪？機器人怎麼被底層模型衝擊？AI 製藥真正的瓶頸是什麼？

三條線索最後收束到同一個結論：模型能力與行業改變之間，隔著的不是智能，而是驗證週期。Agent 的迴路是秒到分鐘，機器人是分鐘到小時，製藥是週到月——反饋越慢的行業，模型再強也只能等。這也正好接上硅谷 101 上一集（E255，阿里國際站總裁張闊）留下的問題：模型越來越強，為什麼用戶沒感覺？

嘉賓背景

許華哲是破殼機器人創始人，同時在清華大學交叉信息研究院任教，做具身智能與機器人學習，是「機器人大腦」路線的一線研究者，也直接在一線部署本體。他對 Astra 的評價是三人中最兩極的：定性飛躍，但物理上不能直接用。

朱哲清 Bill 是 Pokee.ai 創始人兼 CEO，前 Meta AI 應用強化學習團隊負責人，史丹佛強化學習博士。Pokee 主打 30B 級別、可在端側與私有算力上運行的小模型，因此他看 Astra 的角度是「成本、延遲、可部署性」，而不是榜單分數。

王晟是華盛頓大學計算機學院助理教授、Apodex 首席科學家，做 AI for Science 裡的生物醫學應用，日常任務是 8 到 24 小時的長程科研 pipeline，團隊已經把內部任務從 Claude 系列整體切換到 Astra。

三個人剛好對應三種距離：Bill 離商業化最近，許華哲離硬件與物理世界最近，王晟離科學驗證最遠。這種組合讓同一件事在三種時間尺度上被拆開，比單一嘉賓的觀點更有信息量。

核心論點 · Agent：Computer Use 回潮，本質是「身份」問題
  • Astra 對 coding 不是換代，對長程任務才是。Bill 的判斷很克制：純 coding 角度，Opus 4.5 到 4.6 才是範式轉變——工具調用幾乎不再出錯，長程 coding 可以自主跑；Astra 只是在「更長的任務上做到更長」，幻覺更低、審美更好、上下文更穩，但沒有解決以前完全解決不了的問題。他甚至說，發布會強調的後訓練與模型開發迭代能力，「試下來並沒有那麼驚豔」。
  • 但它在長程與迭代上確實更穩。跑一個晚上的 24 小時任務仍然會出現幻覺，只是頻率下降；對前文與已完成任務的記憶更穩，不會頻繁「忘記自己做過什麼」。這是 Bill 認為 Astra 對 Agent 產品真正的價值：不是更聰明，而是更少掉鏈子。
  • Computer Use 的回歸，是 API 經濟的倒退。過去兩年業界默認「所有工具都會開 API、都會有 agent access」，App 與系統都在做 agent native。現實是 Amazon、旅遊、購物類 App 不願意開放接口——不是技術問題，是流量與定價權問題。於是 browser use 又回來了。Bill 的結論是混合制：「最後有可能還是一個 mixture 的狀態。」
  • 雲端瀏覽器 Agent 的死穴是 IP 與身份。Meta Muse 給每個用戶一台雲端虛擬機，本質和當年的 Manus 一樣：商用 IP、雲端瀏覽器，商家一封就死。Amazon 已經屏蔽了 Meta Muse。Bill 的破局思路是把 browser sandbox 放回本地——跑在自己的 AI PC、AI Box 上，用用戶自己的家庭 IP，商家就沒有理由封。「如果這個硬件本身屬於這個用戶，他就可以直接確認這個 agent 就是這個用戶的代表行為，我就會願意把 access 開給你。」
  • 所以 toC Agent 的護城河不是模型，是軟硬結合 + 身份驗證。這是整集最尖銳的商業判斷。商家真正怕的不是 AI，而是「一個用戶變成 20 個 agent，20 個 agent 不停比價、刷流量，消費能力卻還是原來那一個」。一對一的代理沒問題，一對二十的代理會把商家的流量入口和定價體系一起打爛。誰能證明「這個 agent 代表這個人」，誰就拿到 access。這也解釋了為什麼 Meta 要把 wearable 做大——硬件是身份的自然載體。
  • 免費 token 是一場燒錢換習慣的賭局。Meta Muse 每人每週 1 億 token 免費，按 input 成本粗算約 100 美元；加上雲端 VM 的 CPU 與記憶體成本（Bill 說他們做 RL rollout 時，CPU 價格一度跟 GPU 一樣貴，最後乾脆自己租大 CPU box 架 sandbox），單用戶成本遠超 100 美元。他的判斷是：這一波 toC 不可能在短期長出 Google Search 那種體量，「我們可能未來需要看到一個完全免費、token 根本不是一個限制的產品才行」。
  • Grok Bot 是「走在後面的人」。Bill 身邊用 Grok Bot 的多是嘗鮮，真正接進工作流的很少；而大量傳統企業的員工還困在 Microsoft Copilot 裡，連自由使用 Codex 與 Claude Code 都做不到。「整個行業現在分差非常大，走在前面的人什麼都可以隨便用，走在後面的人現在還在泥潭裡掙扎。」
核心論點 · 機器人：Astra 把分層那條線往下壓了一格
  • 最震撼的不是動作，是「反思变成動作」。許華哲說，過去的機器人模型能把 CoT 寫出來，但寫完就結束了；Astra 是把反思直接接到下一步動作上——撞到桌子會說「這個桌子還蠻高，我是不是應該把手抬得更高一點」，然後真的抬手。畫金門大橋的 demo 之所以出圈，是因為它第一次畫得很差，第二、三次明顯變好，這是自我更新，不是預設軌跡。
  • 第二個能力是 Real-to-Sim。給幾張圖，Astra 就能把整個實驗室或辦公室的三維場景復現出來，過去需要大量拍攝、人工標定與建模。許華哲承認這對仿真訓練是實質幫助，也讓很多做 Sim-to-Real 的公司鬆了一口氣。
  • 但它把分層架構那條線壓下去了，這才是真正的範式變化。過去業界的分工很清楚：VLM 做任務規劃（「拿雞蛋、開冰箱」），小模型或具身模型做低層控制（「怎麼開門、怎麼打蛋」）。Astra 現在能直接給出「把手往右伸兩公分」「沒抓住就再往前靠一靠」這種低層指令——它把規劃層的邊界往下推了一格。整個機器人圈的架構討論，因此從「誰負責哪一層」變成「這一刀到底切在哪」。
  • 可是它慢到不能做閉環控制。網上所有 Astra 操作機器人的 demo，都要 16 倍或 24 倍速播放，否則就是純等待。原因是模型大，加上內部 CoT 極長；而且最關鍵的一點：簡單任務與複雜任務的思考時長幾乎一樣。複雜任務顯得聰明，簡單任務就變成純開銷。泓君當場的總結很準：「內耗型人格。」
  • 它缺的是「直覺物理」。人隨手碰一個杯子，知道裡面有水會灑、是玻璃會碎；Astra 要靠語言推理才能得出這個結論，而在任務執行的瞬間，它來不及。許華哲認為這一層仍然需要世界模型或高速模型做反射式反應，端到端讓 Astra 控制一切「還不是很合理」。
  • 筷子夾小球：兩種智能的正面對照。自家模型快、連續嘗試、失敗了就換角度，中間沒有邏輯思考；Astra 每做一步都要分析「為什麼失敗」，再給自己下指令，更像人類思考，但慢，而且一旦分析錯就卡在死局裡，無法繼續推進。旋轉類任務（抓起物體再塞進牆上的小孔）Astra 也明顯偏弱。
  • 它有一個學習天花板。許華哲團隊的反覆測試發現：第一次做一小時，第二次 45 分鐘，第三次之後「永遠都是 45 分鐘」，變成常數。人或充分訓練的小模型會越做越快，Astra 不會——它每次都在重新推理，沒有把經驗壓縮成技能。
  • 對產業的衝擊是分化的。利好本體與硬件：Astra 出來兩三週，史丹佛就有課題組把它接進宇樹機器人做家庭任務，論文兩週就寫出來。對「大腦」公司則是分水嶺：一派繼續做更快的專用具身模型，從 Astra 身上學數據標註與 CoT 範式；另一派乾脆放棄自研，轉型成部署公司，把自己的能力包成 Astra 可調用的工具。許華哲自己對 Real-to-Sim 的評價反而冷淡：「它只是把 3D 的外觀做得非常好，但是它並沒有因為 Astra 出現，然後物理引擎變得更準確了。」
  • 數據標註的門檻變了：要標因果，不只標動作。過去的標註是「我做了什麼」，現在要標「我為什麼成功、為什麼失敗」——是抓的位置偏上，還是東西沾了水太滑。只做正向標註，訓練不出通用機器人大腦。他提到一個傳言：OpenAI 現在只買不標註的生數據，認為外面的標註都是錯的，全部內部重標；某種程度上也是為了保密標註方法。這讓數據市場分成兩層：賣「生肉」的靠規模與覆蓋，賣「熟肉」的靠理解前沿模型的訓練品味，單價可以差十倍以上。
  • 時間表：2028 年初。許華哲給的預測是，從錄製時間（2026 年 9 月底）起約 18 個月，通用機器人開始真正實用；到那時，一般人在家裡可以用自然語言讓機器人做 90% 的家務。他也承認這相当激進，但認為「物理世界的東西總是要慢一點」，機器人比大模型慢了一倍速度是正常的。
核心論點 · AI 製藥：不是智能不夠，是反饋太慢
  • 他們已經整體切換到 Astra，理由不是知識，是 Computer Use 與長程。生物醫學裡大量「古董級軟件」是領域默認工具，界面難用、術語多，跨領域的人上手成本極高。Astra 能直接看屏幕、點滑鼠、照著網路上的 tutorial 與 user log 學會操作，還能順便教會使用者。王晟團隊的任務常常跑 8 到 24 小時，Astra 慢，但慢得讓人放心——「做得慢說明它可能會更深思熟慮」。他們的日常是切換式：白天用反饋快的模型，晚上讓 Astra 跑整晚的長程 pipeline。
  • 但 Astra 在生物醫學「知識」上沒有進步。王晟說得很直接：提升主要來自 general coding、查文獻、長程任務，不是 biomedical knowledge。專門測生物醫學知識的 benchmark，Astra 並沒有提升。真正被解決的是 dry lab 裡那些 coding 型任務——他估計 Astra 在 Terminal-Bench Science 上六十幾分，但「它其實已經做得比我好了」。
  • 最嚴重的問題是拒答。模型能力越強，對生物醫學任務的防範越嚴，動不動就 refuse。團隊內部因此用 Kimi K3 或 Muse Spark 1.3 做日常，需要用 Astra 時得用特殊方式說明「這不是危險任務，我只是在設計一個 benchmark」。這是一個很少被公開討論的反直覺現象：前沿模型在敏感科學領域，越強越不能用。
  • 實驗設計的完成度只有 30%。這是整集最具體的數字。模型可以預測蛋白活性、可以生成分子式，但真正重要的場景是「給出一個可執行的實驗方案」——什麼溫度、什麼濕度、用什麼分子、怎麼合成、怎麼給老鼠用藥、什麼週期。這些它做得很差。王晟的比喻很狠：就像你跟 Astra 說「用這個廚房裡的番茄、雞蛋、土豆做一道菜」，它會給你設計一道海鮮大餐——它不知道這個廚房裡有什麼。
  • 所以濕實驗室是必需品，而且要為 AI 重新設計。不是「AI 設計、人工驗證」這種分割流程，而是把細胞、培養皿、小分子全部前置準備好，AI 一預測完就立刻進實驗，讓乾濕閉環盡量短。他提出一個概念反轉：過去叫 Computer Use（AI 操作電腦），現在真正需要的是 Human Use AI——AI 學會怎麼指揮真實世界裡的實驗員與機械人。
  • 時間線是硬約束。細胞與老鼠實驗幾週；靈長類一批四個月，有時做兩批就是八個月；AI 製藥公司通常做完猴子實驗就授權給大藥廠做人體實驗，授權費一千萬美元以上；從設計分子到授權，整體 6 到 12 個月。而藥物從研發到上市是 5 到 10 年——「現在還沒有一款真正由 AI 發現並被驗證的藥」，不是因為 AI 不行，是因為時間還沒到。
  • AlphaFold 3 開源之後，護城河搬到濕實驗數據。模型與工具開源，等於底層基礎設施 ready，垂直科學公司反而更有利——因為它們手上有真實老鼠與人體實驗積累的數據，一條完整動物實驗數據價值幾萬到幾十萬美元，而且完全不在網路預訓練語料裡。這是一條用時間與金錢堆出來、無法爬取的護城河。
  • 新商業模式已經出現：幫 AI 做實驗。Adaptyv Bio 與 Anthropic 合作，把濕實驗包成 MCP，模型一給預測就立刻排隊做實驗，剛融了 4000 萬美元。王晟預測未來每一個濕實驗公司都會用 MCP／API 直接接進大模型，中間的人類溝通成本被整段刪掉。Anthropic 已經明確配備濕實驗能力，最近辦的蛋白質設計比賽也以濕實驗驗證為最終標準；OpenAI 應該也在布局。DeepMind 的路線則更像把驗證放在 Isomorphic Labs。
  • Claude 的 ART 酶：21 小時，但生物圈很冷靜。九月底 Claude 只花 21 小時自己找到一個叫 ART 的新酶系統，結構非常像 CRISPR，被懷疑是新的基因編輯機制，基因編輯公司股價應聲跌約 10%。但泓君在 Alignment 2026 大會上問王晟，得到的觀察是：AI 圈非常興奮，生物圈相對平淡——「大家想在實驗室裡驗證了再說。」這個反差，就是整集的主題句。
核心論點 · 蒸餾與人的位置
  • 「普通人連蒸餾價值都沒有」這句話，在機器人領域不成立。許華哲的反駁很直接：機器人每個人都是生活的專家，你擅長做飯、我擅長疊衣服、他擅長走路跳舞，「在今天就是家常菜的每個人做的都值得被蒸餾」。但他也承認，一兩年後當機器人能做大模型今天對普通人做的事，門檻就會升到「必須是舞蹈專家或 Gordon Ramsay 才值得被蒸餾」。
  • 王晟提出雙向蒸餾。知識層面 AI 確實比單個科學家全面，但科學發現需要長期投入與背書；反過來，他也天天在蒸餾 AI——跨學科的新東西不懂就快速向 AI 學，獲取知識的速度變快，反而能做出更好的研究。更關鍵的是，人負責「定義問題」：新的疾病、想活到 200 歲、每個人不同的身體狀況，這些問題源源不斷，AI 不會自己長出來。
  • Bill 的版本更技術：現在只是「過擬合得不夠」。模型記住了大量知識與 know-how，在固定 benchmark 與落地場景上做大量 overfitting，但很多領域其實還值得被 overfit。真正的 general intelligence 要跳出「每個場景蒸餾一次」，變成「從零開始學」——不是蒸餾人做得多好，而是蒸餾人怎麼學，並且學得比人快。

技術詳情

1. Astra 的 CoT 與延遲結構。許華哲判斷，對外公開的那段 CoT 是「假的」，內部真正的 CoT 非常長；而且長度不隨任務難度調節。這造成兩個後果：一是每一步決策都附帶固定開銷，簡單任務被拖慢；二是無法做連續反饋控制——機器人需要的是毫秒級反射，而 Astra 的單位是「思考一次、動一下、再思考」。這也解釋了為什麼它的 demo 必須加速播放。

2. 分層架構的邊界正在移動。傳統分層：VLM 負責任務規劃（高層語義），具身小模型負責運動控制（低層動作）。Astra 能給出「往右兩公分」這種低層指令，等於把規劃層往下壓。但許華哲認為端到端仍不現實，原因不只是速度，還有缺乏直覺物理——需要世界模型或高速反射模型補上這一層。未來的架構更可能是「Astra 做慢規劃 + 小模型做快控制」的雙系統，界面設計（Astra 給什麼粒度的指令）才是關鍵工程問題。

3. 本地 vs 雲端。本地部署的理想模型尺寸小於 10B；十幾 B 到數十 B 技術上可行，但芯片與散熱成本會上一級。雲端 API 的瓶頸不是模型大小，是網路延遲與卡代：準靜態任務（抓取、放置、插花）可以接受 200ms 甚至數百毫秒；高動態任務（倒水、抖毛巾）必須本地，因為「卡一下水就冒出來了」。

4. Real-to-Sim 的實際價值。給幾張圖片生成可訓練的仿真場景，大幅降低場景建模成本；但物理引擎的精度沒有改變，所以它解決的是「場景多樣性」，不是「物理真實性」。這是許華哲認為它被過度炒作的原因。

5. 數據標註的因果結構。新標準要求標註：動作、結果、失敗原因（抓取位置偏上／表面濕滑／遮擋）、以及補救策略。這種標註才能訓練出「反思—調整」的閉環，而不只是模仿。OpenAI 只買生數據、內部重標的做法，意味著標註方法本身成為核心 IP。

6. Computer Use 的技術定義。透過視覺理解判斷下一步點哪裡、輸入什麼，串起幾十個動作完成目標。與 API 的差別是：不需要接口、不需要密碼，像人一樣看屏幕、用滑鼠鍵盤。代價是慢、脆弱、容易被反爬與 IP 封鎖。

7. Jev 在機器人上的實測。Jev 沒有圖像輸入，必須先用 VLM 把視覺轉成狀態向量再餵給它；測試疊積木經常疊不起來或疊了就倒，因為它缺乏「第一塊有點歪、第二塊要往另一邊靠」的平衡修正。它快，但快得沒有物理常識。

8. AI 製藥的乾濕閉環。dry lab 做預測與模擬，wet lab 做真實驗證。王晟主張的不是「AI 設計 → 人驗證」的線性流程，而是把濕實驗前置條件全部準備好、AI 一預測就立刻實驗，並且用 MCP／API 讓模型直接調度實驗資源。實驗室要為 AI 重新設計，而不是讓 AI 適應人類的實驗室。

行業 insight
  • 落地速度由反饋迴路長度決定，而不是模型能力。Agent 的迴路是秒到分鐘，所以 browser use 一週就能迭代；機器人是分鐘到小時，所以 18 個月才看到通用性；製藥是週到月，所以 5 到 10 年才有一款藥。三個行業用同一個模型，落地時差卻以數量級計。這是本集最值得帶走的一個框架。
  • 前沿 lab 的 token 大戶不是 toC，是 AI for Science。泓君提到，前沿模型研究者認為 toC 與消費級 agent 的 token 消耗其實花不了多少錢，推理成本還在下降；真正燒錢的是那些未解決、未定義的科學問題——OpenAI 解一個 Navier–Stokes 就燒掉約 2200 萬美元。這改變了對「模型公司商業模式」的想像：最賺錢的應用未必是最燒 token 的應用。
  • toC Agent 的競爭會從模型層轉向 access 層。誰能拿到商家的 API 或不被封的瀏覽器，誰就有產品；而 access 的前提是身份驗證，身份的載體是硬件。這條推理鏈把「AI 軟件公司」重新拉回「軟硬結合」，也解釋了 Meta 為什麼要做 wearable。
  • 機器人產業會分成三層。本體與硬件（受益於跨本體泛化）、專用具身模型（做快、做小、做反射）、部署與集成（把 Astra 當大腦，自己賣場景）。中間那層最危險——既不夠快，又不夠通用。
  • 科學數據的價值被重新定價。一條完整的動物實驗數據幾萬到幾十萬美元，且不在預訓練語料裡。當模型能力商品化，稀缺性從「模型」轉移到「不可爬取的實驗數據」與「能調度實驗的接口」。Adaptyv 這類公司本質上是在賣「AI 與現實之間的轉接頭」。
  • 監管與安全會成為科研的生產力瓶頸。王晟團隊要繞過拒答才能做正常研究，這是很少被討論的摩擦成本。當模型越來越強，安全對齊的半徑也越大，前沿科研的可用性反而下降——這會催生一批「合規科研模型」或「私有科研模型」的需求。
  • 對創業者的含義。如果你做應用，別跟模型比智能，去解決 access、身份、驗證、部署這些「模型不屑做也做不了」的臟活；如果你做模型，別只在公開 benchmark 上追分，因為那些 benchmark 可能本身定義錯了（王晟與許華哲從兩個領域得出同一個結論）。
前後脈絡

與 E255（張闊）的呼應。上一集問「模型越來越強，為什麼用戶沒感覺」，張闊從電商與產品角度回答；這一集給出了機制層的答案：能力提升集中在長程、專業、可驗證的任務上，而普通人日常接觸的任務早就飽和。王晟甚至說，對前沿科學家提升巨大，對普通人「感知已經不大了」。同一家公司、兩集節目，從需求側與供給側各答了一半。

與 42章經 Ambi（10/17）的對照。子皓談 personal agent 的互動成本與環境智能，落點在「agent 要一直存在」；Bill 談 toC agent 的經濟模型，落點在「agent 要證明自己是誰」。一個講體驗，一個講權限，其實是同一件事的兩面：agent 要成為用戶的代理，先要取得身份的合法性。

與 Crossing Treg（10/18）的對照。Treg 認為應用公司應該退到 Claude Code 與 Codex 生態邊上做單點；Bill 的觀察更悲觀——連 browser use 都會被商家封，應用層的 access 本身不穩定。兩者合起來看：平台化與封閉化會同時發生，創業者的位置在「平台之間的縫隙」，而縫隙會移動。

與 Latent Space 金融 Agent 專題（10/14）的呼應。那集談可追溯性、human-in-the-loop、kill switch；王晟的「飛機要有駕駛員」是同一原則在科學領域的版本。人類在迴路不是因為 AI 不行，而是因為決策的不可逆性與責任歸屬。

與 Dwarkesh × Noam Brown（9/17）的呼應。Agent swarms 與遞歸自我改進是那集的主線；這一集給出了真實的成本樣本：OpenAI 解一道數學題調用約一萬個子 agent、270 萬條訊息、1300 億 output token。 swarm 不是免費的，它把推理成本放大到千萬美元級別。

許華哲觀點的演變。他過去在公開訪談中對具身智能的落地相對保守，這次給出 2028 年初的時間表，屬於明顯轉向樂觀；但他同時對 Real-to-Sim 與端到端路線保持懷疑。這種「對能力樂觀、對路徑悲觀」的組合，比單純看多或看空更有參考價值。

爭議點
  • 「機器人 benchmark 失效」是否等於能力飛躍？許華哲說 RoboDojo 等公認仿真 benchmark 上 Astra 都拿第一，是定性變化；但王晟對生物醫學 benchmark 的批評（Kaggle 化、定義不良）同樣適用於機器人。如果 benchmark 本身測的是錯的東西，拿第一說明的是「匹配了測試」，不完全是「通用能力」。
  • Real-to-Sim 是突破還是炒作？許華哲直指物理引擎精度沒變，只是外觀更真，屬於 hype；但產業界普遍把它當成 sim 訓練的文藝復興。分歧在於「視覺真實」對策略遷移到底有多大貢獻。
  • 小模型追平大模型，可能追錯了方向。Bill 從工程角度看到差距縮小；王晟從科學角度提醒，大家追的 benchmark 本身定義得不好，追平了也不代表有用。這是「指標最佳化」與「真實能力」的經典衝突。
  • 能力越強、拒答越嚴。這是本集最反直覺、也最少被公開討論的觀點。安全對齊讓模型在生物醫學場景越來越不可用，科研人員只能繞路或改用較弱的模型。這是一個真實的生產力損失，但在安全話語裡幾乎沒有位置。
  • OpenAI 只買生數據、認為外部標註都是錯的。這是許華哲聽到的傳言，未經證實。如果為真，意味著數據標註產業的價值會被壓縮到「原材料」層，方法論溢價消失。
  • Jev 的「系統 1」敘事與機器人實測不符。Jev 在疊積木任務上明顯不如 Astra，因為它沒有視覺輸入、缺乏物理常識。這對「快思考模型可以取代具身模型」的說法是一個直接反例。
  • 2028 年初的時間表。18 個月做到 90% 家務，與目前雙臂任務、疊衣服完全做不了、旋轉插入偏弱的實測差距很大。許華哲自己也說這個預測「相當激進」。
一句話總結：這一集不是關於 Astra 有多強，而是關於「強」在不同行業裡要經過多長的管道才能變成「有用」。Agent 卡在身份與 access，機器人卡在速度與直覺物理，製藥卡在濕實驗的日曆。模型能力是必要條件，但從來不是充分條件。
