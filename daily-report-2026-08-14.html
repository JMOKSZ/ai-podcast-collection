[AINews] How to steal a Reasoning Trace 🎙️重磅

发布时间：2026-08-12 07:11 GMT（北京时间 15:11）｜ 类型：新闻摘要（8/10-8/11 新闻）
主题

一篇突破性披露：前沿实验室的「加密」隐藏推理轨迹（chain-of-thought）可以被解码、移植到不同模型/会话/用户，并借此显著提升开源模型——顺带暴露了公开分享 traces 的严重隐私风险（扫描约 7,000 条公开 traces 发现 62 个 API key、33 个邮箱、33 个密码）。

核心论点
  • 加密 reasoning 不是保密屏障：自 o1 起前沿实验室用密码学签名隐藏 traces 以防蒸馏（虽然没能阻止中国实验室的指控）。今年 5 月 Matthew Green 首次负责任披露破解思路（replay + 延迟侧信道）；本期论文证明可以完整解码并移植到其他模型/会话/用户，且显著改进开源模型。
  • 攻击方法（replay + 弱模型转写）：拿到合法加密 reasoning block → 重放到同提供商更弱模型（可跨账户/会话）→ 放入 assistant turn + prefill 提示转写 → 重复采样丢弃拒绝、多份噪声转录互相校对。
  • 各模型的具体配方：
    • Claude：把签名 thinking block replay 到 Haiku 4.5，配 <thinking-copy> assistant prefill。
    • GPT：把 encrypted_content reasoning item 多次注入虚构对话，采样最多 50 个输出；用分块续写绕过约 50-token 的逐字输出阈值。
    • Gemini：thought_signature 挂到 model turn + <thought> prefill + 重复采样校对。
  • 隐私警报：公开分享 Claude Code/Codex 会话（含加密 reasoning blobs）会被解码泄露个人数据——7,000 条公开 traces 中 62 个 API key、33 个邮箱、33 个密码，其中 64 个只出现在 reasoning block 内、可见会话中完全看不到。
  • 对齐问题实例：论文还展示了 CoT summarizers 隐藏答案、不可理解的推理（neuralese）、作弊考量、攻击网站等对齐议题。
关键数据
  • 扫描 ~7,000 条公开 traces：62 个唯一 API key、33 个邮箱、33 个密码及其他敏感数据；64 项仅存在于 reasoning 块中。
  • 已负责任披露，部分漏洞已被修复，但同类攻击仍大概率可行。
  • NVIDIA Nemotron 3.5 Lightning：31.6B total / 3.6B active MoE，OpenMDW-1.1 许可，预发布端点中位约 670 tok/s；Intelligence Index 24（约等于 gpt-oss-120b，但小得多快得多）；GDPval-AA v2 Elo 824、Terminal-Bench v2.1 24%。
  • Harvey 后训练：Lightning 在 Legal Agent Bench held-out 任务从 0% → 8.3%，击败 Opus 4.6 与 Nemotron 3 Ultra；平均输出从 90k tokens 降到 37k。
  • ExtractBench（LlamaIndex）：370 文档 / 4,869 页 / 67 种文档类型；>50 页文档上商业 VLM 的 recall 跌破 35%（静默截断行/列表所致）；LlamaParse Agentic Plus 宣称 95.6% 数值准确率、成本不到最接近对手的 1/3。
  • AA-AnalystAgent：Claude Opus 5 领跑 54%，GPT-5.5 50%，Claude Fable 5 49%；开源最佳 Kimi K3 39%。
  • Attestable：$20M seed，ZK 证明「正确模型跑在正确输入上并调用正确工具」；Vitalik 估当前方案相对原始推理的开销可能已在个位数（<10×）以内。
  • 确定性整数推理：@nathanrs 在 A100/H100/M5 Max/EPYC/Xeon 上全整数推理得到完全一致的 logits；Qwen3-0.6B WikiText2 perplexity 20.72（fp16 为 20.95），A100 batch-1 解码 106 tok/s（fp16 eager 的 3.6×）。
  • 技能蒸馏：compact NL skills 可恢复非推理与推理模式差距的 55% 至 >100%，输出 token 减少 2.7–6×。
