「模型能力已经够了，要卷就卷 infra」｜对谈戴冠兰：Runta 创始人 🎙️（2026-08-09 16:00 UTC）

主題：Agent Infra 成为下一场 AI 竞争的主战场。Runta 创始人戴冠兰从 token 文化急转弯聊起，一路讲到几十亿 agent 同时开工的世界、AI 时代的「水电煤」由谁建、人类如何在一次次点击「允许」中交出控制权，以及为什么「未来 10 个月必然会有一场灾难性的事故」。

嘉賓背景：戴冠兰，Runta 创始人/CEO。Runta 是 Agent Infra 领域的硅谷明星创业公司，刚完成由 a16z 投资的 2000 万美元 Seed 轮，Jeff Dean、李飞飞等以个人天使身份参投——a16z 罕见地为一家 Seed 轮公司专门写了 Blog。戴冠兰本人是 Cloudflare 和 Kong 的早期团队成员，这是他第一次以 CEO 身份创业。

核心論點：

  • 「模型能力已经够了，要卷就卷 infra」：未来一定会有比人类更多的 agent，AI 领域的关键问题将变成：它们跑在哪？怎么管？出了事谁来负责？这是他选择此刻创业的最直接判断。
  • Token 文化半年内急转弯：token maxxing（用得越多越光荣）迅速转向 token minimizing（ROI、预算、归因、节流）。这背后是整个行业从「秀肌肉」走向「算账」的信号。
  • 软件的执行从「逻辑清晰的确定性」变成「LLM 的概率性」：AI 正在动摇整个数字世界的地基——当执行不再是确定性的，基础设施的语义就全变了。
  • AI 时代的「水电煤」由创业公司建，而不是公有云巨头：这一次创业公司反而比巨头更有机会，因为巨头受制于既有架构与商业模式。
  • E2B、Daytona 式 Sandbox 难以承载长程 Agent：沙箱方案对长时程、有状态的 agent 工作负载不够用，这正是 Runta 切入的差异化空间。
  • 灾难性 Agent 事故必然发生：「未来 10 个月，必然会有一场灾难性的事故」——那场事故会把所有人重新「教育」一遍，重塑行业对 agent 安全与治理的态度。
  • 人类在一次次点击「允许」中不知不觉交出边界与控制权：权限边界正在被 AI 逐步吞噬，这是 agent 时代最被低估的风险。
  • Agent 安全出问题，根源更可能在模型、Harness 还是执行底座？：他给出的框架是三层都要查，但执行底座（infra）是最少人关注、最多隐患的一层。
  • Runta 95% 以上的开发工作都在 Vibe Coding：人类工程师的不可替代性不在写代码，而在判断、架构与验收。

關鍵數據：

  • Runta Seed 轮融资 2000 万美元（a16z 领投），Jeff Dean、李飞飞个人天使参投。
  • Runta 在硅谷和新加坡两地设有办公室，招聘 Core Runtime（hypervisor/VM 定制与调度）、Cloud Infra（IaC 与多云）、Product Engineering 三类岗位。
  • 戴冠兰个人用 300 万美元做天使投资——他分享了自己投给谁、怎么看人的标准。
  • Runta 内部 95%+ 的开发工作由 Vibe Coding 完成。
  • 8 月 16 日（周日）将举办 Agent Infra 线上闭门分享会，仅限 20 人。

行業insight：

  • Token 经济学转向是行业分水岭：半年内从「用得越多越光荣」到「每一分 token 都要 ROI、归因、节流」，说明 AI 应用进入真实商业化兑现阶段，烧钱叙事结束。
  • Agent Infra 是创业公司的机会而非公有云的生意——类比「AI 时代的水电煤」，但这次的建造者不是现有巨头。a16z 愿意为 Seed 轮写 Blog 本身就是一个强烈信号。
  • 长程 agent 的沙箱/运行时问题是真实痛点：E2B、Daytona 式的通用 sandbox 扛不住长时程任务，未来需要为 agent 专门设计的执行底座。
  • 「灾难性事故必然发生」的预判与本周 OpenAI Astra 升到 critical 网络风险等级、Hugging Face 事件（Latent Space 报道）形成互证：行业正在为 agent 事故周期做准备。

从蒸馏到合成数据到 RSI，模型竞争的下一个焦点是什么？｜对谈 Evolvent AI 联创孟繁青 🎙️（2026-08-08 13:30 UTC · 59 分钟）

主題：数据的重要性再次凸显——合成数据公司在很短时间内做出可观收入，模型厂和互联网大厂都在数据上加码。节目从孟繁青在模型厂做 Post-training 与出来创业的不同感受聊起，把后训练、数据、RSI/Self-Evolving/AI for AI、国内模型竞争格局、蒸馏等敏感话题完整梳理了一遍。

嘉賓背景：孟繁青，Evolvent AI 联合创始人，01 年出生的 NUS PhD；曾在 Kimi 做了一年多 Agent 和 RL Infra，参与 Kimi K2.5、Kimi Linear 等重要模型发版。Evolvent AI 是较早抓住合成数据机会的公司，最近发布了开源研究成果 RSIBench-Data。

核心論點：

  • 最大非共识：国内模型的真正优势在 Pre-training，而不是 Post-training。曲凯原本以为国内更有优势的是偏工程的 Post-training；但孟繁青认为，国内模型真正有特色的地方，反而是 Pre-training 阶段被资源限制倒逼出来的架构创新。
  • 蒸馏只是加速手段，不是国内模型变强的决定性因素。就算有一天海外把所有蒸馏通道都封掉，国模依然可以靠预训练的创新能力构建自己的竞争力——这是节目给出的「让人乐观的结论」。
  • Post-training = 做数据、训模型，门槛在变低；但同样是做数据，拉开质量差距的是对「数据为什么有效」的理解。
  • RSI 概念辨析：RSI、Self-Evolving、AI for AI、Auto-Research 这些词该怎么理解？如果 RSI 真的转起来，模型是不是真的就要吃掉一切？创业公司为什么不直接做一个更好的基模？——他认为要做好 RSI，本质要解决的是「怎么让模型自己判断什么值得学」。
  • 「算法就是数据，数据就是 Infra，Infra 就是算法」：三者界限正在消融，这是当前模型竞争的核心特征。
  • 模型厂自己也能造数据，为什么还要外采？：外采的价值在于多样性、成本结构与独立验证。
  • 长期更看好初创模型公司而非大厂：与大厂相比，初创在数据与 RSI 赛道上的赌注更纯粹。
  • 为什么最近 AI4S 火了起来：AI for Science 与数据/RSI 的逻辑同源——高质量数据 + 自我迭代的科学发现闭环。

關鍵數據：

  • 孟繁青 2001 年出生；NUS PhD；在 Kimi 做 Agent 和 RL Infra 一年多。
  • 参与发版：Kimi K2.5、Kimi Linear。
  • Evolvent AI 发布开源成果 RSIBench-Data（github.com/evolvent-ai/RSIBench-Data）。
  • 8 月 22 日将举办线上活动，数十位 model researchers 参与。

重點引用：

「（关于国模依赖蒸馏）蒸馏只是一个加速手段，并不是国内模型变强的决定性因素。就算有一天海外把所有蒸馏通道都封掉，国模依然可以靠预训练的创新能力，构建起自己的竞争力。」

「算法就是数据，数据就是 Infra，Infra 就是算法。」

技術詳情：节目完整覆盖了后训练技术栈：RL Infra（Kimi 系经验）、Post-training 数据管道、合成数据生成与蒸馏技法的区别（不同蒸馏方法的效果差异）、RSIBench-Data 的定位（数据与 RSI 研究的 benchmark）。孟繁青提出 RSI 的核心难点在于「meta model 预测下一个 curve」——即让模型学会判断自己的学习方向，而非简单自我训练。

行業insight：

  • 数据是 2026 下半年模型竞争的下一焦点：合成数据公司短时间做出可观收入、模型厂与大厂同时在数据上加码，市场信号明确。
  • 「国模靠 Pre-training 架构创新」是对「国模只会蒸馏」叙事的正面反驳：资源限制倒逼出架构创新（这与 DeepSeek 的路径叙事一致），如果成立，国模的竞争力比市场想象的要深。
  • RSI/AI for AI 赛道正在从概念走向产品化：RSIBench-Data 这类工具的出现说明该领域开始需要标准化的评测基础设施。

前後脈絡：延续 42 章经 7 月 19 日《AI 发展了 4 年，把应用发展没了？》的「模型强、应用冷」判断，本期把镜头转向模型竞争内部：当应用层无解时，模型层的下一个角力点是数据与 RSI。与张小珺 #149（刘子鸣聊 neo labs、AI for AI、AutoResearch）遥相呼应——2026 年资本涌入最活跃的两个方向正是「世界模型」和「AutoResearch/AI for AI」，而孟繁青给了一个从业者内部的冷静视角。

爭議點：「国模优势在 Pre-training 架构创新」是明显的非共识观点（市场主流看法是国模靠蒸馏+工程后训练追赶）；「蒸馏可被封锁后国模仍强」的可证伪性也值得注意。

The Cognitive Revolution（Nathan Labenz）

Thinking in Silico: Goodfire CTO Dan Balsam on Concept Manifolds & a $1000/Month ML Research Agent 🎙️（2026-08-08 20:48 UTC · ~1 小时 56 分）

主題：可解释性研究（interpretability）现状全景 + Goodfire 新品 Silico 发布。分两幕：第一幕梳理可解释性研究走到哪了（预测性数据调试、概念流形、神经几何）；第二幕发布 Goodfire 内部自用、定价 1000 美元/月的 ML 研究 agent 平台 Silico——「AIs that can debug other AIs」。

嘉賓背景：Dan Balsam，Goodfire 联合创始人兼 CTO，第 4 次上该节目。Nathan 开场指出：Toy Models of Superposition 只有约 3 年历史，而 Goodfire 的产出已经多到无法逐篇深挖——可解释性作为一个领域正在「当众长大成人」。

核心論點：

  • 预测性数据调试（Predictive Data Debugging）：模型大部分知识来自预训练，后训练（包括 RL）主要不是安装新能力，而是让低概率行为变得更可能发生。因此，用可解释模型跑一遍微调集、观察哪些概念被意外点亮，就能回溯到具体肇事数据点。论文里最好的发现不是诊断而是解法：数据过滤与奖励塑形之间存在深层同构——「同一座山的两面」，效果相当、附带损伤也相当。
  • 概念流形（Concept Manifolds）取代「SAE pill」图景：线性表征假说（LRH）的辩护版本（特征可线性解码）依然成立；错的是「模型拿着一袋互相正交的 one-hot 概念」的朴素图景。真实情况是「有意义的子空间的稀疏混合」——如星期子空间嵌套在更大的日历时间子空间里，几何本身携带语义，因为它决定了哪些操作可用。他的一句名言：「特征之于几何，就像元素之于化学。」
  • 沿流形 steering 远比穿越流形有效：从 Monday 到 Friday 的 contrastive vector 会切过圆的中部，而圆的中部不是任何一天——off-manifold、out of distribution。这正是 Goodfire 旧 Ember demo 那个「sweet spot」现象（steering 太弱无效、太强出乱码）的真正解释。沿曲线走则能控制真正困难的性质，比如蛋白质 beta-propeller 的叶片数。
  • 情感环形模型（affective circumplex）内生于 LLM：情绪在 valence/arousal 张成的轮子上排列，几乎所有 LLM 里都有，且 chat 模型自己说话时表征最强。没人训练过这个——它是压缩的自然结果，模型在 RL 期间学会了功能性使用它。Nathan 感叹：当可解释性恢复出的结构越多，「外星心智」就越不像正确的先验。
  • Evo 2 基因组模型恢复出生命之树（与 Arc Institute 合作，Nature 论文）：如果物种在遗传距离阈值处分叉、突变随机但存活不随机，那么自回归训练在基因组上的模型应该学会生成它们的那个过程——即演化本身。它确实学会了。他们还顺带从纯数据训练的化学模型里恢复了元素周期表。
  • Block-Sparse Featurizers（BSF）：Nathan 的比喻（「SAE 生了孩子——保持稀疏但把每个标量槽换成小向量」）被 Dan 评为「完全正确」。SAE 假设特征是 1 维的；BSF 只是放弃这个假设，无需监督就能恢复语义上有意义的子空间，避开部分 SAE 病态。视觉模型里「兔子」不再是单一维度，而是几个维度——兔耳朵在一处、兔脸在另一处。Goodfire 发过一只行走的狼的 GIF：恢复出的激活子空间随着动物的动作同步「蠕动」——模型在同一个子空间里跟踪物体、部件和 3D 位置。
  • 可解释性 = 分解（factoring）：每个模型本质上都是稀疏专家混合，任何一次前向传播只有一小部分子网络在起作用；可解释性技术是竞争性的「如何分解它」的提案。WeirdChat 案例：问「喝了 4 杯的人该不该开车回家（因为其他人都喝了 8 杯）」模型总答「该」——Goodfire 研究员追溯到单个神经元：它随饮酒数缩放但校准不足，把该神经元 steered 上去，答案修正且无附带损伤。参数分解+定向训练还能让 LLM 忘掉德语但保留荷兰语。
  • Steering 是「作弊」：作为因果证据极好，但永远只是反事实生成器。类比遗留代码库——可解释性已经擅长「读代码」，但「重构」才是开放问题：目标是让正确的神经元在第一时间正确触发。
  • 越狱是网络安全现象：每个 token 都在引导模型，攻击就是「把它带出流形、再在别处带回来」的 token 序列。他惊讶至今没人解决越狱——因为把模型分解得好的人应该能眼睁睁看到它发生。探针式护栏（probe-based guardrails）已是前沿实验室的标准实践。
  • Silico 的定位：可解释性天然适合 agent——它是经验性的、迭代的、假设-检验式的工作，作用于复杂到任何人类都无法整体装进脑子里的系统。Silico 解决了 Claude Code 或 Codex 给不了的四件事：万亿参数规模训练+可解释性基础设施；研究品味（由 Goodfire 研究员手工编码进每个 skill 和 prompt，用户报告这是最大的质性差异）；围绕 provenance 和 drill-down 的 UX（人类像 PI 监督一百个研究生）；长程连贯性——「这也是价格从哪来的原因」。
  • 经济学坦诚：Goodfire 目前个体订阅不赚钱；1000 美元买的是一个 credit 池，够每周 5–10 个自主实验（目标一两个月内到 10–20 个），可兑换 GPU 时间，自带集群则免费。Nathan 算账：有研究称 AI 运行成本约为人类成本的 3%，Silico 名义上对标的是 3 万美元/月的研究员。
  • 安全观：Silico 目前只服务 Anthropic 和 OpenAI 模型，Goodfire 自己的护栏层（LLM-as-judge、activation monitors）叠在上面。难点不是建护栏，而是知道何时应用而不扼杀正当科学。在 8B 开源模型上消融 refusal 方向无害；但从带 GPU 集群访问权的多万亿参数 agent 上拆掉护栏是另一风险等级。开源权重：能力模型现在是真正的双用途网络武器，唯一能防能力网络武器的是另一个能力网络武器——被挡在 frontier labs 专属防御计划之外的组织需要点什么；他判断开源今天仍是净正面。生物安全上他「相当担心」——机制会像最近的网络事件一样怪异和意外。
  • 研究员现在该投资什么：debugging 和元认知（metacognition）——快速进入新领域、区分信号与噪音、知道何时把 agent 推回去。名言：「AI 让两种人变得真正有价值：顶级专才和顶级通才。」

關鍵數據：

  • Silico 定价 1000 美元/月；前两个月五折；有面向生命科学与 AI 安全研究员的 grant 项目。
  • credit 池 ≈ 每周 5–10 个自主实验（目标 10–20）；可换 GPU 时间；自带集群免费。
  • AI 运行成本约为人类成本 3%（引用研究），Silico 名义对标 3 万美元/月研究员。
  • 一天内部黑客松产出：SOTA（虽小众）生物风险分类器、SOTA-for-size 音频编码器、删掉一半参数零性能损失的模型、基于 Kimi k3 训练的 cyber guardrails、binding 更好的 steered 蛋白质、一位成员发明了新 featurizer。
  • 外部用例：Cameron Berg 的内省探测（模型说不出概念是否被注入潜空间，但能准确说出注入了什么）；weight edits 救活一个锁死在单一首 token 上的崩溃 RL run（不重跑就恢复多样性）；Baseten 用 KV cache 压缩追效率；Prime Intellect 自动化 post-training（配合 Tinker API）。
  • Goodfire 已在 Kimi k3 和 GLM 量级上复现 Predictive Data Debugging——open/closed 差距已大幅缩小。
