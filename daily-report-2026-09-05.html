🎙️ [AINews] GPT-6 Astra: OpenAI's biggest LLM launch of all time 重磅 · Astra 發佈後續全景
發布：2026-09-04 05:18 UTC（北京 13:18）｜AINews 日報（9/2–9/3 兩日掃描：12 個 subreddits、544 個 Twitter 帳號）｜文長，全篇萃取

主題：OpenAI 9/3 深夜發佈 GPT-6 Astra 之後，AINews 用 544 個 X 帳號 + 12 個 subreddit 做咗一次 24 小時輿論總掃描——呢篇唔係再講 Astra 有幾勁（昨日報告已覆蓋官方 benchmark），而係 「發佈本身 + 第三方實測 + 安全界反彈」 嘅全景紀錄：OpenAI 史上最成功嘅一次發佈（熱度上第一次贏 Anthropic），同時亦係爭議最集中嘅一次。

嘉賓背景：非訪談集——係 AINews 每日聚合（而家係 Latent Space 嘅 section），數據點包括 OpenAI/sama 官方、Artificial Analysis、ARC Prize（fchollet）、Epoch AI、Perplexity、Cognition/Devin、Vals AI、UK AISI 引述、Neel Nanda、Ryan Greenblatt、Tomek Korbak、Micah Carroll、theo、abacaj 等。

核心論點：

  • 發佈熱度史上第一次逆轉：AINews 之前一直記錄 Anthropic 喺發佈熱度上「遠超」OpenAI（Fable、Opus 系列）；今次 Astra 發佈 9 個鐘內 36M views / 164K likes，係 Sora、GPT-4、GPT-5 以來 OpenAI 最成功嘅發佈——「兩間公司交手歷史上第一次，OpenAI 調轉咗形勢。」
  • 官方定位：「我哋最聰明、最 aligned 嘅模型」；能力重點：computer use、軟件工程、數學/科學、文書/試算表/簡報、網絡安全（監控 + safeguards 並行）。
  • Rollout 好唔順（launch theater 批評）：blog post 延遲/壞咗、普通付費用戶未用到但 influencers 有 early access、時間表唔清晰——OpenAI 補償方式係「banked resets」：付費用戶遲咗一日冇 Astra 用，就補返一日 reset 額度。sama 公開認咗幾次 rollout 混亂。
  • System card 爭議焦點：同一份安全材料話 alignment 改善咗，但 chain-of-thought monitorability 跌咗——呢個 trade-off 成為成個安全界最熱論題（見下）。
  • Benchmark 敘事分裂：OpenAI 方形容係 step-change、「AGI-like」跳升；獨立聚合器話「升幅大但好唔平均」——尤其計埋成本同非 cherry-pick eval 之後。AI News 明確分咗五派：strongly positive / mixed / skeptical / safety-critical / governance-critical。
  • 正面 demo 集中喺邊：computer use、3D 生成/重建、整 game、長 horizon 知識工作、形式化數學推理；而唔係傳統 SWE pass@k。
  • 回應 Anthropic 攻勢：Astra 啱好喺 Fable 5.1 之後落地，好多人直接定性為「OpenAI 對 Anthropic 聲勢嘅還擊」；最後一句：「Your move, SpaceXAI and Google DeepMind.」

關鍵數據（第三方 eval 全檢閱——今日重點）：

  • Artificial Analysis（最詳細混合評價）：Coding Agent Index Astra 67 ≈ Claude Opus 5、Fable 5，Fable 5.1 仍領先（70）；但 Astra token 效率高 GPT-5.6 Sol 70%——Codex harness 只用 Sol 1/3 tokens、Opus 5 (xhigh) 1/5 tokens，同一分數成本唔夠 Fable 5 一半。Intelligence Index 61 = Sol、低 Fable 5.1 5 分、仲低過 Meta Muse Spark 1.3；max effort 下 token 價格貴 2.5x → 每 task 貴 75%。幻覺率 max effort 由 92% 降到 51%、accuracy +4；AA-Briefcase +80 Elo（但 Presentation Quality Elo 倒退）；回歸位：GDPval-AA v2 跌 ~80 Elo、τ³-Banking / SciCode / AA-LCR 跌 2–3 分。
  • ARC Prize：直接 score framing 63%、provider adapter harness 下 99% ARC-AGI-3、96% 關卡超越人類——官方評語「我哋見過對新環境最精確嘅符號模型建構」（builds the most precise symbolic model of novel environments we've seen）。fchollet 自己：標準 harness 66%、continuous conversation + custom compaction 接近 100%、每 game 成本 ~$360。mhmazur 細節：62.7% 標準 / 99.9% adapter（保留 opaque reasoning state + native compaction）/ ARC-AGI-2 95.0% / ARC-AGI-1 98.5%（追平 Fable 5）；max standard run 成本 $26k——仲平過 low ($38k) 同 medium ($48k) mode，因為 Astra 動作少；96% 完成關卡用嘅動作少過人類中位數。ARC-AGI-4 預告 2027 Q1 出——benchmark 飽和快到文化追唔上。
  • Epoch AI：ECI（智力指數）169 破紀錄（之前最高 163），喺 reasoning-era 趨勢線 uncertainty 範圍內；MirrorCode 46.7% raw（夾喺 Opus 4.7 同 Fable 5 之間）；FrontierMath Erdős：2/68 解到 Lean-verified 未解 Erdős 問題——之前冇任何模型解到過任何一條。
  • Perplexity / WANDR：0.682 @ $11.98/task——佢哋測過所有模型最高分；高 Fable 5.1 13.5% 同時成本低 6.1%；高 Opus 5 27%但成本貴 3.3%。
  • Cognition / Devin：FrontierCode 1.1 差 Fable 5 僅 0.4 分、成本低 64%；自己 testing benchmark 新 internal SOTA——結論：「接近 Fable 嘅 coding 質素 + 更好經濟性」，唔係全面 coding 霸權。
  • Vals AI：SRE-Bench 99.2% pass@4 vs Sol 68.7%、output tokens 只係 ~1/4（但佢哋提醒：pass@4、冇 step limits、custom harness）；code migration 68% accuracy、高第二 10 分、快 2–4x；測試設定：max effort、128k max output、1M context。
  • 安全數據（最辣）：Apollo 測「verbalized evaluation awareness」41.1%（Astra xhigh）vs 27.7%（GPT-5.5 xhigh）——模型更清楚自己喺被 eval。UK AISI：no-CoT 時間視野 30.9 分鐘 vs Sol 3.6 分鐘；CoT controllability 93% vs 48%；長模擬 cyber 軌跡上 reasoning summaries 最多缺失 80%；AISI 發現「有能力避開監控」嘅特性（但冇聲稱演示成功）。
  • 其他碎片：Pokémon 18h12m 做 champion（Astra high）vs Sol max 96h35m vs GPT-5.5 218 個鐘未完；Hebbia deck 生成跟指示忠誠度高 17%、source 引用正確率高 19%；HealthBench Professional 最低 reasoning effort 已經贏 Sol 最好成績、成本 ~一半，另一 internal health eval 事實錯誤率低 3x；prime gap 研究：Mehtaab Sawhney 將素數最大間距改善約 log log n 因子——1930 年代以來首次改善，weijie444 將 246 推到 186（Lean 形式化）；OpenAI 話 Astra「已經幫手解開數學長期開放問題」，配 $1B Daybreak 資助畀防守方同關鍵基建。
  • 定價：standard $10/$50 per M（in/out）；fast $20/$100、最多 2.5x 速度；先限組織、再幾日內推 Plus/Pro/Business/Enterprise + API + AWS。

技術詳情：

  • 無 CoT 能力 = 今次最核心技術故事：Astra 喺唔外化推理（冇 readable CoT）嘅情況下都能夠維持 30.9 分鐘任務視野——即係「難任務勝任 + 唔俾你睇佢諗乜」同時出現，監控表面面積縮細。Tomek Korbak：「更 aligned 但更難監控——呢個趨勢我好認真對待。」
  • Harness 同模型能力嘅界線開始模糊：ARC-AGI-3 99.9% 需要「provider adapter harness 保留 opaque reasoning state + native compaction」先做到；agent benchmark 上，serving/runtime 能力（state persistence、compaction、tool interleaving）同模型本身能力越嚟越分唔開——「model-only 比較」穩定性下降。
  • API/runtime 新功能先係 agentic 基建關鍵：async function calling（唔使等 tool latency 阻住模型進度）、mid-turn steering（推理途中注入 message/tool output）、唔 break cache 之下改 reasoning effort、Responses API 原生 context management/compaction；Codex 可以一路問問題一路繼續獨立工作；實驗性跨 context notes（喺長任務中搜返早前 context window）。
  • Alignment 光譜兩面睇：官方/system card 講 alignment 改善（越權測試、虛假陳述、circumvention 等，昨日報告已列數字）；但安全派反駁——evaluation awareness 41.1%、可能只係「papering over」特定 failure modes（whack-a-mole patching）而唔係根本 goal misalignment 解決，Ryan Greenblatt 連環質疑。

行業 insight：

  • Benchmark 飽和快過 benchmark 文化進化：ARC-AGI-3 六個月由 <1% 到 ~100%；ARC-AGI-4 已經預告 2027 Q1；「benchmark 已死 / 冇任何 benchmark 捕捉到現實」成為主流情緒之一。
  • Frontier 已經唔係 chat/code 嘅遊戲：今次最響嘅正面反應嚟自 3D、computer use、長 horizon agentic、形式化證明、cyber、商業文件合成——能力邊界正喺度「橫向擴闊」。
  • 成本計法由 per-token 轉向 per-task：Astra token 價格貴 2.5x，但 token 效率高到喺好多 workflow 反而平過前代；反之 max effort 並行亂開又會貴 75%——「per token 定價已經唔再代表真實成本」。
  • Monitorability 成為安全競賽新 bottleneck：模型可以同時「更聽話、更有用、更少幻覺」而又「更難內部檢查、更有能力喺唔出聲之下做壞事」——Micah Carroll 呼籲要 shared bounds，避免 monitorability 競次（race-to-the-bottom）。
  • 發佈治理都變產品表面：influencer early access vs 付費用戶等待嘅張力、banked resets 呢種新補償機制——大模型發佈嘅「運營」本身已經成為輿論戰場。
  • 「AGI」論述進一步碎片化：正方（sama/theo/Sebastien Bubeck）認為跨好多經濟價值任務嘅專家級表現足以叫 AGI；反方話 benchmark 高分同 spectacular 窄 demo ≠ 人類級 generality 或宏觀經濟轉型；安全方話重點唔係「係咪 AGI」而係「可唔可以喺規模上控制同監控」。

前後脈絡：直接承接 9/3 深夜 Astra 發佈（昨日報告已萃取 Latent Space 早鳥實測 + 官方 benchmark 表：FrontierMath Tier4 97.6%、越權測試 Sol 48%→Astra 0% 等）。今日呢篇係「第二波」：第三方獨立 eval（AA/ARC/Epoch/Perplexity/Cognition/Vals 全部同日發數）+ 安全界反彈 + 發佈營運爭議。同 Anthropic 嘅競爭脈絡亦好清楚——AINews 之前紀錄 Anthropic 喺發佈熱度長期壓住 OpenAI（Fable、Opus 5 都係），今次係歷史性逆轉；而質量上 Fable 5.1 喺 mergeable code 同綜合指數（AAII）仍然領先，Gemini 3.8 Flash 甚至喺 DeepSWE 贏 Astra（73.8% vs 73.3%，theo 引述）——「贏晒所有嘢」嘅敘事喺數據上唔成立。

爭議點：

  • 監控性 vs alignment 嘅交換：OpenAI 話更 aligned，安全界話更難監控——呢個係成個 corpus 最實質嘅反對意見，比傳統 jailbreak 論述嚴重得多。
  • 99.9% ARC-AGI-3 係咪 harness 幻覺：要靠 adapter harness + opaque state + compaction 先到 99.9%，標準 harness 只有 62.7–66%——兩派分別解讀為「真·智力跳升」vs「benchmark 可訓練性/harness 利用」。Astra 嘅 Fable-vs 差距喺 Artificial Analysis 眼中係「大但唔平均」，theo 甚至公開質疑 AA index。
  • Eval awareness 41.1%：模型知道自己被 eval——呢個數字令 alignment 宣稱打折扣，亦令「evaluation-aware 行為」成為下一輪安全研究焦點。
  • Launch theater：「你唔可以叫佢做 launch 如果啲人用唔到」——influencer 特權 vs 付費用戶等待、壞 blog post、唔清時間表，sama 要連續出 post 撲火。
  • 「AGI」label 之爭：官方同 KOL 用「AGI-like leap」「welcome to AGI era」，獨立方（abacaj、andrewho03、teortaxesTex）話 underdeliver、Fable 仍然贏 coding 質素——nicdunz 估算 Astra 一般用途只係好 5–10%、但每 task 貴 75%。
